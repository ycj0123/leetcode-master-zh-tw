# 本週小結！（動態規劃（dynamic programming, DP）系列四）

## 週一

[動態規劃：目標和！](https://programmercarl.com/0494.目标和.html)要求在數列之間加入 + 或者 -，使其和為 S。

所有數的總和為 sum，假設加法的總和為 x，那麼可以推出 x = (S + sum) / 2。

S 和 sum 都是固定的，那此時問題就轉化為 0/1 背包問題（0/1 knapsack problem）（數列中的數只能使用一次）：給你一些物品（數字），裝滿背包（就是 x）有幾種方法。

1. 確定 dp 陣列（array）以及下標（subscript）的含義

**dp[j] 表示：填滿 j（包括 j）這麼大容積的包，有 dp[j] 種方法**

2. 確定遞迴公式（recurrence formula）

dp[j] += dp[j - nums[i]]

**注意：求裝滿背包有幾種方法類似的題目，遞迴公式基本都是這樣的**。

3. dp 陣列如何初始化（initialization）

dp[0] 初始化為 1，dp[j] 其他下標對應的數值應該初始化為 0。

4. 確定遍歷（traversal）順序

0/1 背包問題一維（one dimensional）dp 的遍歷，nums 放在外迴圈（loop），target 在內迴圈，且內迴圈倒序。


5. 舉例推導 dp 陣列

輸入：nums: [1, 1, 1, 1, 1], S: 3

bagSize = (S + sum) / 2 = (3 + 5) / 2 = 4

## 週二

這道題目[動態規劃：一和零！](https://programmercarl.com/0474.一和零.html)算有點難度。

**不少同學都以為是 bounded knapsack，其實這是一道標準的 0/1 背包問題**。

只不過這個背包有兩個維度，一個是 m 一個是 n，而不同長度的字串（string）就是不同大小的待裝物品。

**所以這是一個二維（two-dimensional）0/1 背包問題！**

1. 確定 dp 陣列（dp table）以及下標的含義

**dp[i][j]：最多有 i 個 0 和 j 個 1 的 strs 的最大子集（subset）的大小為 dp[i][j]。**


2. 確定遞迴公式

dp[i][j] = max(dp[i][j], dp[i - zeroNum][j - oneNum] + 1);

字串集合（set）中的一個字串 0 的數量為 zeroNum，1 的數量為 oneNum。

3. dp 陣列如何初始化

因為物品價值不會是負數（negative number），初始為 0，保證遞迴（recursion）的時候 dp[i][j] 不會被初始值覆蓋。

4. 確定遍歷順序

0/1 背包問題一定是外層 for 迴圈（for-loop）遍歷物品，內層 for 迴圈遍歷背包容量且從後向前遍歷！

5. 舉例推導 dp 陣列

以輸入：["10","0001","111001","1","0"]，m = 3，n = 3 為例

## 週三

此時 0/1 背包問題我們就講完了，正式開始無界背包問題（unbounded knapsack problem）。

在[動態規劃：關於完全背包，你該了解這些！](https://programmercarl.com/背包问题理论基础完全背包.html)中我們講解了無界背包問題的理論基礎。

其實無界背包問題和 0/1 背包問題的區別就是無界背包問題的物品是無限數量。

遞迴公式也是一樣的，但難點在於遍歷順序上！

無界背包問題的物品是可以添加多次的，所以遍歷背包容量要從小到大去遍歷，即：

```CPP
// 先遍歷物品，再遍歷背包
for(int i = 0; i < weight.size(); i++) { // 遍歷物品
    for(int j = weight[i]; j < bagWeight ; j++) { // 遍歷背包容量
        dp[j] = max(dp[j], dp[j - weight[i]] + value[i]);

    }
}
```

基本網上題的題解介紹到這裡就到此為止了。

**那麼為什麼要先遍歷物品，再遍歷背包呢？** （靈魂拷問）

其實對於純無界背包問題，先遍歷物品，再遍歷背包 與 先遍歷背包，再遍歷物品都是可以的。我在文中[動態規劃：關於完全背包，你該了解這些！](https://programmercarl.com/背包问题理论基础完全背包.html)也給出了詳細的解釋。

這個細節是很多同學忽略掉的點，其實也不算細節了，**相信不少同學在寫背包的時候，兩層 for 迴圈的先後順序搞不清楚，靠感覺來的**。

所以理解究竟是先遍歷啥，後遍歷啥非常重要，這也體現出遍歷順序的重要性！

在文中，我也強調了是對純無界背包問題，兩個 for 迴圈先後順序無所謂，那麼題目稍有變化，可就有所謂了。

## 週四

在[動態規劃：給你一些零錢，你要怎麼湊？](https://programmercarl.com/0518.零钱兑换II.html)中就是給你一堆零錢（零錢個數無限），為湊成 amount 的組合（combination）數有幾種。

**注意這裡組合數和排列（permutation）數的區別！**

看到無限零錢個數就知道是無界背包問題，

但本題不是純無界背包問題了（求是否能裝滿背包），而是求裝滿背包有幾種方法。

這裡在遍歷順序上可就有說法了。

* 如果求組合數就是外層 for 迴圈遍歷物品，內層 for 遍歷背包。
* 如果求排列數就是外層 for 遍歷背包，內層 for 迴圈遍歷物品。

這裡同學們需要理解一波，我在文中也給出了詳細的解釋，下週我們將介紹求排列數的無界背包問題題目來加深對這個遍歷順序的理解。

其實這是一種錯覺，或者說對動規理解得不夠深入！
