# 本週小結！（二元樹（binary tree）系列二）

本週趕上了十一國慶，估計大家已經對本週末沒什麼概念了，但是我們該做總結還是要做總結的。

本週的主題其實是**簡單但並不簡單**，本週所選的題目大多是看一下就會的題目，但是大家看完本週的文章估計也發現了，二元樹的簡單題目其實裡面都藏了很多細節。這些細節我都給大家展現了出來。


## 週一

本週剛開始我們講解了判斷二元樹是否對稱的（symmetric）寫法，[二元樹：我對稱嗎？](https://programmercarl.com/0101.对称二叉树.html)。

這道題目的本質是要比較兩個樹（tree）（這兩個樹是根節點（root node）的左右子樹（subtree）），遍歷（traversal）兩棵樹而且要比較內側和外側節點（node），所以準確來說是一個樹的遍歷順序是左右中，一個樹的遍歷順序是右左中。

而本題的疊代（iteration）法中我們使用了佇列（queue），需要注意的是這不是層次序走訪（level order traversal），而僅僅是透過一個容器（container）來成對地存放我們要比較的元素（element），認識到這一點之後就發現：用佇列，用堆疊（stack），甚至用陣列（array），都是可以的。

那麼做完本題之後，再看如下兩個題目。
* [100.相同的樹](https://leetcode.cn/problems/same-tree/description/)
* [572.另一個樹的子樹](https://leetcode.cn/problems/subtree-of-another-tree/)

**[二元樹：我對稱嗎？](https://programmercarl.com/0101.对称二叉树.html)中的遞迴（recursion）法和疊代法只需要稍作修改其中一個樹的遍歷順序，便可刷了 100.相同的樹。**

100.相同的樹的遞迴程式碼如下：

```CPP
class Solution {
public:
    bool compare(TreeNode* left, TreeNode* right) {
        // 首先排除 null node 的情況
        if (left == NULL && right != NULL) return false;
        else if (left != NULL && right == NULL) return false;
        else if (left == NULL && right == NULL) return true;
        // 排除了 null node，再排除數值不相同的情況
        else if (left->val != right->val) return false;

        // 此時就是：左右節點都不為空，且數值相同的情況
        // 此時才做遞迴，做下一層的判斷
        bool outside = compare(left->left, right->left);   // 左子樹：左、 右子樹：左 （相對於求對稱二元樹，只需改一下這裡的順序）
        bool inside = compare(left->right, right->right);    // 左子樹：右、 右子樹：右
        bool isSame = outside && inside;                    // 左子樹：中、 右子樹：中 （邏輯處理）
        return isSame;

    }
    bool isSymmetric(TreeNode* p, TreeNode* q) {
        return compare(p, q);
    }
};
```

100.相同的樹，精簡之後程式碼如下：

```CPP
class Solution {
public:
    bool compare(TreeNode* left, TreeNode* right) {
        if (left == NULL && right != NULL) return false;
        else if (left != NULL && right == NULL) return false;
        else if (left == NULL && right == NULL) return true;
        else if (left->val != right->val) return false;
        else return compare(left->left, right->left) && compare(left->right, right->right);

    }
    bool isSameTree(TreeNode* p, TreeNode* q) {
        return compare(p, q);
    }
};
```

100.相同的樹，疊代法程式碼如下：

```CPP
class Solution {
public:

    bool isSameTree(TreeNode* p, TreeNode* q) {
        if (p == NULL && q == NULL) return true;
        if (p == NULL || q == NULL) return false;
        queue<TreeNode*> que;
        que.push(p);
        que.push(q);
        while (!que.empty()) {
            TreeNode* leftNode = que.front(); que.pop();
            TreeNode* rightNode = que.front(); que.pop();
            if (!leftNode && !rightNode) {
                continue;
            }
            if ((!leftNode || !rightNode || (leftNode->val != rightNode->val))) {
                return false;
            }
            // 相對於求對稱二元樹，這裡兩個樹都要保持一樣的遍歷順序
            que.push(leftNode->left);
            que.push(rightNode->left);
            que.push(leftNode->right);
            que.push(rightNode->right);
        }
        return true;
    }
};

```

而 572.另一個樹的子樹，則和 100.相同的樹幾乎一樣了，大家可以直接 AC 了。

## 週二

在[二元樹：看看這些樹的最大深度](https://programmercarl.com/0104.二叉树的最大深度.html)中，我們講解了如何求二元樹的最大深度（depth）。

本題可以使用前序遍歷（preorder traversal），也可以使用後序遍歷（post-order traversal）（左右中），使用前序求的就是深度，使用後序呢求的是高度（height）。

**而根節點的高度就是二元樹的最大深度**，所以本題中我們透過後序求的根節點高度來求二元樹最大深度，所以[二元樹：看看這些樹的最大深度](https://programmercarl.com/0104.二叉树的最大深度.html)中使用的是後序遍歷。

本題當然也可以使用前序，程式碼如下：（**充分表現出求深度回溯（backtracking）的過程**）
```CPP
class Solution {
public:
    int result;
    void getDepth(TreeNode* node, int depth) {
        result = depth > result ? depth : result; // 中

        if (node->left == NULL && node->right == NULL) return ;

        if (node->left) { // 左
            depth++;    // 深度+1
            getDepth(node->left, depth);
            depth--;    // 回溯，深度-1
        }
        if (node->right) { // 右
            depth++;    // 深度+1
            getDepth(node->right, depth);
            depth--;    // 回溯，深度-1
        }
        return ;
    }
    int maxDepth(TreeNode* root) {
        result = 0;
        if (root == 0) return result;
        getDepth(root, 1);
        return result;
    }
};
```

**可以看出使用了前序（中左右）的遍歷順序，這才是真正求深度的邏輯！**

注意以上程式碼是為了把細節體現出來，簡化一下程式碼如下：

```CPP
class Solution {
public:
    int result;
    void getDepth(TreeNode* node, int depth) {
        result = depth > result ? depth : result; // 中
        if (node->left == NULL && node->right == NULL) return ;
        if (node->left) { // 左
            getDepth(node->left, depth + 1);
        }
        if (node->right) { // 右
            getDepth(node->right, depth + 1);
        }
        return ;
    }
    int maxDepth(TreeNode* root) {
        result = 0;
        if (root == 0) return result;
        getDepth(root, 1);
        return result;
    }
};
```

## 週三

在[二元樹：看看這些樹的最小深度](https://programmercarl.com/0111.二叉树的最小深度.html)中，我們講解如何求二元樹的最小深度，這道題目要是稍不留心很容易犯錯。

**注意這裡最小深度是從根節點到最近葉節點（leaf node）的最短路徑（shortest path）上的節點數量。注意是葉節點。**

什麼是葉節點，左右孩子都為空的節點才是葉節點！

**求二元樹的最小深度和求二元樹的最大深度的差別主要在於處理左右孩子不為空的邏輯。**

注意到這一點之後，遞迴法和疊代法都可以參照[二元樹：看看這些樹的最大深度](https://programmercarl.com/0104.二叉树的最大深度.html)寫出來。

## 週五

在[二元樹：我平衡嗎？](https://programmercarl.com/0110.平衡二叉树.html)中講解了如何判斷二元樹是否是平衡二元樹（balanced binary tree）

今天講解一道判斷平衡二元樹的題目，其實方法上我們之前講解深度的時候都講過了，但是這次我們透過這道題目徹底搞清楚二元樹高度與深度的問題，以及對應的遍歷方式。

二元樹節點的深度：指從根節點到該節點的最長簡單路徑（simple path）邊（edge）的條數。
二元樹節點的高度：指從該節點到葉節點的最長簡單路徑邊的條數。

**但 LeetCode 中強調的深度和高度很明顯是按照節點來計算的**。

關於根節點的深度究竟是 1 還是 0，不同的地方有不一樣的標準，LeetCode 的題目中都是以節點為一度，即根節點深度是 1。但維基百科上定義用邊為一度，即根節點的深度是 0，我們暫時以 LeetCode 為準（畢竟要在這上面刷題）。

當然此題用疊代法，其實效率很低，因為沒有很好地模擬（simulation）回溯的過程，所以疊代法有很多重複的計算。

雖然理論上所有的遞迴都可以用疊代來實作，但是有的場景難度可能比較大。

**例如：都知道回溯法其實就是遞迴，但是很少人用疊代的方式去實作回溯演算法（backtracking algorithm）！**

講了這麼多二元樹題目的疊代法，有的同學會疑惑，疊代法中究竟什麼時候用佇列，什麼時候用堆疊？

**如果是模擬前中後序遍歷就用堆疊，如果是適合層次序走訪就用佇列，當然還有其他情況，那麼就是先用佇列試試行不行，不行就用堆疊。**

## 週六

在[二元樹：找我的所有路徑？](https://programmercarl.com/0257.二叉树的所有路径.html)中正式涉及到了回溯，很多同學過了這道題目，可能都不知道自己使用了回溯，其實回溯和遞迴都是相伴相生的。最後我依然給出了疊代法的版本。

我在題解中第一個版本的程式碼會把回溯的過程充分體現出來，如果大家直接看簡潔的程式碼版本，很可能就會忽略了回溯的存在。

我在文中也強調了這一點。

有的同學還不理解，文中精簡之後的遞迴程式碼，回溯究竟隱藏在哪裡了。

文中我明確地說了：**回溯就隱藏在 traversal(cur->left, path + "->", result); 中的 path + "->"。每次函數（function）呼叫完，path 依然是沒有加上 "->" 的，這就是回溯了。**

如果還不理解的話，可以把
```CPP
traversal(cur->left, path + "->", result);
```

改成
```CPP
string tmp = path + "->";
traversal(cur->left, tmp, result);
```
看看還行不行了，答案是這麼寫就不行了，因為沒有回溯了。

一些同學可能上來就能寫出程式碼，大體上也知道是為啥，可以自圓其說，但往細節一扣，就不知道了。

所以剛接觸二元樹的同學，建議按照文章分析的步驟一步一步來，不要上來就照著精簡的程式碼寫（那樣寫完了也很容易忘的，知其然不知其所以然）。

**簡短的程式碼看不出遍歷的順序，也看不出分析的邏輯，還會把必要的回溯的邏輯隱藏了，所以盡量按照原理分析一步一步來，寫出來之後，再去最佳化程式碼。**
