
# 本週小結！（貪心演算法系列一）

## 週一

本週正式開始了貪心演算法（greedy algorithm），在[關於貪心算法，你該了解這些！](https://programmercarl.com/贪心算法理论基础.html)中，我們介紹了什麼是貪心法（greedy）以及貪心的固定做法。

**貪心的本質是選擇每一階段的區域最佳（local optimum），從而達到總體最佳（global optimum）。**

有沒有啥固定做法呢？

**不好意思，貪心沒固定做法，就刷題而言，如果感覺好像區域最佳可以推出總體最佳，然後想不到反例，那就試一試貪心吧！**

而嚴格的資料證明一般有如下兩種：

* 數學歸納法（mathematical induction）
* 反證法

數學就不在講解範圍內了，感興趣的同學可以自己去查一查資料。

正是因為貪心演算法有時候會感覺這是常識，本就應該這麼做！所以大家經常看到網路上有人說這是一道貪心題目，有人說這不是。

這裡說一下我的依據：**如果找到區域最佳，然後推出整體最佳，那麼就是貪心**，大家可以參考哈。

## 週二


在[貪心算法：分發餅乾](https://programmercarl.com/0455.分发饼干.html)中講解了貪心演算法的第一道題目。

這道題目很明顯能看出來是用貪心，也是入門好題。

我在文中給出**區域最佳：大餅乾餵給胃口大的，充分利用餅乾尺寸餵飽一個；總體最佳：餵飽盡可能多的小孩**。

很多錄友都是用小餅乾優先先餵飽小胃口的。

後來我想一想，雖然結果是一樣的，但是大家的這個思考方式更好一些。

**因為用小餅乾優先餵飽小胃口的，這樣可以盡量保證最後省下來的是大餅乾（雖然題目沒有這個要求）！**

所以還是小餅乾優先先餵飽小胃口更好一些，也比較直觀。

一些錄友不清楚[貪心算法：分發餅乾](https://programmercarl.com/0455.分发饼干.html)中時間複雜性（time complexity）是怎麼來的？

就是快速排序（quick sort）$O(n\log n)$，遍歷（traversal）$O(n)$，加一起還是 $O(n\log n)$。

## 週三

接下來就要上一點難度了，要不然大家會誤以為貪心演算法就是常識判斷一下就行了。

在[貪心算法：擺動序列](https://programmercarl.com/0376.摆动序列.html)中，需要計算最長 wiggle sequence。

其實就是讓序列（sequence）有盡可能多的局部峰值。

區域最佳：刪除（delete）單調（monotonic）坡度上的節點（node）（不包括單調坡度兩端的節點），那麼這個坡度就可以有兩個局部峰值。

整體最佳：整個序列有最多的局部峰值，從而達到最長 wiggle sequence。

在計算峰值的時候，還是有一些程式碼技巧的，例如序列兩端的峰值如何處理。

這些技巧，其實還是要多看多用才會掌握。


## 週四

在[貪心算法：最大子序和](https://programmercarl.com/0053.最大子序和.html)中，詳細講解了用貪心的方式來求最大次序列（subsequence）和，其實這道題目是一道動態規劃（dynamic programming, DP）的題目。

**貪心的解題思路為區域最佳：當前「連續和」為負數（negative number）的時候立刻放棄，從下一個元素（element）重新計算「連續和」，因為負數加上下一個元素，「連續和」只會越來越小。從而推出總體最佳：選取最大「連續和」**

程式碼很簡單，但是思路卻比較難，還需要反覆琢磨。

針對[貪心算法：最大子序和](https://programmercarl.com/0053.最大子序和.html)文章中給出的貪心程式碼如下：
```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int result = INT32_MIN;
        int count = 0;
        for (int i = 0; i < nums.size(); i++) {
            count += nums[i];
            if (count > result) { // 取區間累計的最大值（相當於不斷確定最大子序列終止位置）
                result = count;
            }
            if (count <= 0) count = 0; // 相當於重設最大子序列起始位置，因為遇到負數一定是拉低總和
        }
        return result;
    }
};
```
不少同學都來問，如果陣列（array）全是負數這個程式碼就有問題了，如果陣列裡有 `int` 最小值這個程式碼就有問題了。

大家不要腦洞模擬（simulation）哈，可以親自構造一些測試資料（test data）試一試，就發現其實沒有問題。

陣列都為負數，`result` 記錄的就是最大的負數，如果陣列裡有 `int` 最小值，那麼最終 `result` 就是 `int` 最小值。


## 總結

本週我們講解了[貪心算法的理論基礎](https://programmercarl.com/贪心算法理论基础.html)，了解了貪心本質：區域最佳推出總體最佳。

然後講解了第一道題目[分發餅乾](https://programmercarl.com/0455.分发饼干.html)，還是比較基礎的，可能會給大家一種貪心演算法比較簡單的錯覺，因為貪心有時候接近於常識。

其實我還準備了一些簡單的貪心題目，甚至網路上很多都質疑這些題目是不是貪心演算法。這些題目我沒有立刻發出來，因為真的會讓大家感覺貪心過於簡單，而忽略了貪心的本質：區域最佳和總體最佳兩個關鍵點。

**所以我在貪心系列難度會有所交替，難的題目在於拓展思路，簡單的題目在於分析清楚其貪心的本質，後續我還會發一些簡單的題目來做貪心的分析。**

在[擺動序列](https://programmercarl.com/0376.摆动序列.html)中大家就初步感受到貪心沒那麼簡單了。

本週最後是[最大子序和](https://programmercarl.com/0053.最大子序和.html)，這道題目要用貪心的方式做出來，就比較有難度，都知道負數加上正數之後會變小，但是這道題目依然會讓很多人搞混淆，其關鍵在於：**不能讓「連續和」為負數的時候加上下一個元素，而不是不讓「連續和」加上一個負數**。這塊真的需要仔細體會！
