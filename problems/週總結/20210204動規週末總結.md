# 本週小結！（動態規劃（dynamic programming, DP）系列五）

## 週一

[動態規劃：377. 組合總和 Ⅳ](../0377.組合總和Ⅳ.md)中給定一個由正整數（positive integer）組成且不存在重複（duplicate）數字的陣列（array），找出和為給定目標正整數的組合（combination）的個數（順序不同的序列（sequence）被視作不同的組合）。

題目表面上雖然是組合，但又強調順序不同的序列被視作不同的組合，其實這道題目求的是排列（permutation）數！

遞迴公式（recurrence formula）：dp[i] += dp[i - nums[j]];

這個和上上週講的組合問題又不一樣，關鍵就體現在遍歷（traversal）順序上！

在[動態規劃：518.零錢兌換II](../0518.零錢兌換II.md) 中就已經講過了。

**如果求組合數就是外層 for 迴圈（for-loop）遍歷物品，內層 for 遍歷背包**。

**如果求排列數就是外層 for 遍歷背包，內層 for 迴圈遍歷物品**。

如果把遍歷 nums（物品）放在外迴圈（loop），遍歷 target 的作為內迴圈的話，舉一個例子：計算 dp[4] 的時候，結果集（result set）只有 {1,3} 這樣的集合（set），不會有 {3,1} 這樣的集合，因為 nums 遍歷放在外層，3 只能出現在 1 後面！

所以本題最終遍歷順序：**target（背包）放在外迴圈，將 nums（物品）放在內迴圈，內迴圈從前到後遍歷**。

```CPP
class Solution {
public:
    int combinationSum4(vector<int>& nums, int target) {
        vector<int> dp(target + 1, 0);
        dp[0] = 1;
        for (int i = 0; i <= target; i++) { // 遍歷背包
            for (int j = 0; j < nums.size(); j++) { // 遍歷物品
                if (i - nums[j] >= 0 && dp[i] < INT_MAX - dp[i - nums[j]]) {
                    dp[i] += dp[i - nums[j]];
                }
            }
        }
        return dp[target];
    }
};
```

## 週二

爬樓梯之前我們已經做過了，就是斐波那契序列（Fibonacci sequence），很好解，但[動態規劃：70. 爬樓梯進階版（完全背包）](../0070.爬楼梯完全背包版本.md)中我們進階了一下。

改為：每次可以爬 1 、 2、.....、m 個台階。問有多少種不同的方法可以爬到樓頂呢？

1 階，2 階，.... m 階就是物品，樓頂就是背包（knapsack problem）。

每一階可以重複使用，例如跳了 1 階，還可以繼續跳 1 階。

問跳到樓頂有幾種方法其實就是問裝滿背包有幾種方法。

**此時大家應該發現這就是一個無界背包問題（unbounded knapsack problem）了！**


和昨天的題目[動態規劃：377. 組合總和 Ⅳ](../0377.組合總和Ⅳ.md)基本就是一道題了，遍歷順序也是一模一樣的！

程式碼如下：
```CPP
class Solution {
public:
    int climbStairs(int n) {
        vector<int> dp(n + 1, 0);
        dp[0] = 1;
        for (int i = 1; i <= n; i++) { // 遍歷背包
            for (int j = 1; j <= m; j++) { // 遍歷物品
                if (i - j >= 0) dp[i] += dp[i - j];
            }
        }
        return dp[n];
    }
};

```

程式碼中 m 表示最多可以爬 m 個台階，程式碼中把 m 改成 2 就是本題 70.爬樓梯可以 AC 的程式碼了。

## 週三

[動態規劃：322.零錢兌換](../0322.零錢兌換.md)給定不同面額的硬幣 coins 和一個總金額 amount。編寫一個函數（function）來計算可以湊成總金額所需的最少的硬幣個數（每種硬幣的數量是無限的）。

這裡我們都知道這是無界背包問題。

遞迴公式：dp[j] = min(dp[j - coins[i]] + 1, dp[j]);

關鍵看遍歷順序。

本題求錢幣最小個數，**那麼錢幣有順序和沒有順序都可以，都不影響錢幣的最小個數**。

所以本題並不強調集合是組合還是排列。

**那麼本題的兩個 for 迴圈的關係是：外層 for 迴圈遍歷物品，內層 for 遍歷背包或者外層 for 遍歷背包，內層 for 迴圈遍歷物品都是可以的！**


外層 for 迴圈遍歷物品，內層 for 遍歷背包：
```CPP
// 版本一
class Solution {
public:
    int coinChange(vector<int>& coins, int amount) {
        vector<int> dp(amount + 1, INT_MAX);
        dp[0] = 0;
        for (int i = 0; i < coins.size(); i++) { // 遍歷物品
            for (int j = coins[i]; j <= amount; j++) { // 遍歷背包
                if (dp[j - coins[i]] != INT_MAX) { // 如果 dp[j - coins[i]] 是初始值則跳過
                    dp[j] = min(dp[j - coins[i]] + 1, dp[j]);
                }
            }
        }
        if (dp[amount] == INT_MAX) return -1;
        return dp[amount];
    }
};
```

外層 for 遍歷背包，內層 for 迴圈遍歷物品：

```CPP
// 版本二
class Solution {
public:
    int coinChange(vector<int>& coins, int amount) {
        vector<int> dp(amount + 1, INT_MAX);
        dp[0] = 0;
        for (int i = 1; i <= amount; i++) {  // 遍歷背包
            for (int j = 0; j < coins.size(); j++) { // 遍歷物品
                if (i - coins[j] >= 0 && dp[i - coins[j]] != INT_MAX ) {
                    dp[i] = min(dp[i - coins[j]] + 1, dp[i]);
                }
            }
        }
        if (dp[amount] == INT_MAX) return -1;
        return dp[amount];
    }
};
```

## 週四

[動態規劃：279.完全平方數](../0279.完全平方數.md)給定正整數 n，找到若干個完全平方（perfect square）（比如 1, 4, 9, 16, ...）使得它們的和等於 n。你需要讓組成和的完全平方的個數最少（平方數可以重複使用）。


如果按順序把前面的文章都看了，這道題目就是簡單題了。dp[i] 的定義，遞迴公式，初始化（initialization），遍歷順序，都是和[動態規劃：322. 零錢兌換](../0322.零錢兌換.md) 一模一樣的。

要是沒有前面的基礎上來做這道題，那這道題目就有點難度了。

**這也體現了刷題順序的重要性**。

先遍歷背包，再遍歷物品：

```CPP
// 版本一
class Solution {
public:
    int numSquares(int n) {
        vector<int> dp(n + 1, INT_MAX);
        dp[0] = 0;
        for (int i = 0; i <= n; i++) { // 遍歷背包
            for (int j = 1; j * j <= i; j++) { // 遍歷物品
                dp[i] = min(dp[i - j * j] + 1, dp[i]);
            }
        }
        return dp[n];
    }
};
```

先遍歷物品，再遍歷背包：

```CPP
// 版本二
class Solution {
public:
    int numSquares(int n) {
        vector<int> dp(n + 1, INT_MAX);
        dp[0] = 0;
        for (int i = 1; i * i <= n; i++) { // 遍歷物品
            for (int j = 1; j <= n; j++) { // 遍歷背包
                if (j - i * i >= 0) {
                    dp[j] = min(dp[j - i * i] + 1, dp[j]);
                }
            }
        }
        return dp[n];
    }
};
```
