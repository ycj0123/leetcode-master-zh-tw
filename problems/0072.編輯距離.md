# 72. edit distance

[LeetCode 題目連結](https://leetcode.cn/problems/edit-distance/)

給你兩個單字 word1 和 word2，請你計算出將 word1 轉換成 word2 所使用的最少操作數。

你可以對一個單字進行如下三種操作：

* 插入一個字元（character）
* 刪除一個字元
* 替換一個字元

* 範例 1：
* 輸入：word1 = "horse", word2 = "ros"
* 輸出：3
* 解釋：
horse -> rorse (將 'h' 替換為 'r')
rorse -> rose (刪除 'r')
rose -> ros (刪除 'e')


* 範例 2：
* 輸入：word1 = "intention", word2 = "execution"
* 輸出：5
* 解釋：
intention -> inention (刪除 't')
inention -> enention (將 'i' 替換為 'e')
enention -> exention (將 'n' 替換為 'x')
exention -> exection (將 'n' 替換為 'c')
exection -> execution (插入 'u')

提示：

* 0 <= word1.length, word2.length <= 500
* word1 和 word2 由小寫英文字母組成

## 解題思路

edit distance 終於來了，這道題目如果大家沒有了解動態規劃的話，會感覺超級複雜。

edit distance 是用動態規劃來解決的經典題目，這道題目看上去好像很複雜，但用動態規劃可以很巧妙地算出最少 edit distance。

接下來我依然使用動態規劃五部曲，對本題做一個詳細的分析：


### 1. 確定 dp 陣列（array）（dp table）以及下標（subscript）的含義

**dp[i][j] 表示以下標 i-1 為結尾的字串（string） word1，和以下標 j-1 為結尾的字串 word2，最近 edit distance 為 dp[i][j]**。

有同學問了，為什麼要表示下標 i-1 為結尾的字串呢，為什麼不表示下標 i 為結尾的字串呢？

為什麼這麼定義我在 [718. 最長重複子陣列（subarray）](https://programmercarl.com/0718.最长重复子数组.html) 中做了詳細的講解。

其實用 i 來表示也可以！用 i-1 就是為了方便後面 dp 陣列初始化的。

### 2. 確定遞迴公式（recurrence formula）

在確定遞迴公式的時候，首先要考慮清楚編輯的幾種操作，整理如下：

```
if (word1[i - 1] == word2[j - 1])
    不操作
if (word1[i - 1] != word2[j - 1])
    增
    刪
    換
```

也就是如上 4 種情況。

`if (word1[i - 1] == word2[j - 1])` 那麼說明不用任何編輯，`dp[i][j]` 就應該是 `dp[i - 1][j - 1]`，即 `dp[i][j] = dp[i - 1][j - 1];`

此時可能有同學有點不明白，為什麼要即 `dp[i][j] = dp[i - 1][j - 1]` 呢？

那麼就再回顧上面講過的 `dp[i][j]` 的定義，`word1[i - 1]` 與 `word2[j - 1]` 相等了，那麼就不用編輯了，以下標 i-2 為結尾的字串 word1 和以下標 j-2 為結尾的字串 `word2` 的最近 edit distance `dp[i - 1][j - 1]` 就是 `dp[i][j]` 了。

在下面的講解中，如果哪裡看不懂，就回想一下 `dp[i][j]` 的定義，就明白了。

**在整個動態規劃的過程中，最為關鍵的就是正確理解 `dp[i][j]` 的定義！**


`if (word1[i - 1] != word2[j - 1])`，此時就需要編輯了，如何編輯呢？

* 操作一：word1 刪除一個元素（element），那麼就是以下標 i - 2 為結尾的 word1 與 j-1 為結尾的 word2 的最近 edit distance 再加上一個操作。

即 `dp[i][j] = dp[i - 1][j] + 1;`


* 操作二：word2 刪除一個元素，那麼就是以下標 i - 1 為結尾的 word1 與 j-2 為結尾的 word2 的最近 edit distance 再加上一個操作。

即 `dp[i][j] = dp[i][j - 1] + 1;`

這裡有同學發現了，怎麼都是刪除元素，新增元素去哪了。

**word2 新增一個元素，相當於 word1 刪除一個元素**，例如 `word1 = "ad" ，word2 = "a"`，`word1` 刪除元素 `'d'` 和 `word2` 新增一個元素 `'d'`，變成 `word1="a", word2="ad"`，最終的操作數是一樣！dp 陣列如下圖所示意的：

```
            a                         a     d
   +-----+-----+             +-----+-----+-----+
   |  0  |  1  |             |  0  |  1  |  2  |
   +-----+-----+   ===>      +-----+-----+-----+
 a |  1  |  0  |           a |  1  |  0  |  1  |
   +-----+-----+             +-----+-----+-----+
 d |  2  |  1  |
   +-----+-----+
```

操作三：替換元素，`word1` 替換 `word1[i - 1]`，使其與 `word2[j - 1]` 相同，此時不用增刪元素。

可以回顧一下，`if (word1[i - 1] == word2[j - 1])` 的時候我們的操作是 `dp[i][j] = dp[i - 1][j - 1]` 對吧。 

那麼只需要一次替換的操作，就可以讓 word1[i - 1] 和 word2[j - 1] 相同。

所以 `dp[i][j] = dp[i - 1][j - 1] + 1;`

綜上，當 `if (word1[i - 1] != word2[j - 1])` 時取最小的，即：`dp[i][j] = min({dp[i - 1][j - 1], dp[i - 1][j], dp[i][j - 1]}) + 1;`

遞迴公式程式碼如下：

```CPP
if (word1[i - 1] == word2[j - 1]) {
    dp[i][j] = dp[i - 1][j - 1];
}
else {
    dp[i][j] = min({dp[i - 1][j - 1], dp[i - 1][j], dp[i][j - 1]}) + 1;
}
```

### 3. dp 陣列如何初始化


再回顧一下 dp[i][j] 的定義：

**dp[i][j] 表示以下標 i-1 為結尾的字串 word1，和以下標 j-1 為結尾的字串 word2，最近 edit distance 為 dp[i][j]**。

那麼 dp[i][0] 和 dp[0][j] 表示什麼呢？

dp[i][0] ：以下標 i-1 為結尾的字串 word1，和空字串（empty string） word2，最近 edit distance 為 dp[i][0]。

那麼 dp[i][0] 就應該是 i，對 word1 裡的元素全部做刪除操作，即：dp[i][0] = i;

同理 dp[0][j] = j;

所以 C++ 程式碼如下：

```CPP
for (int i = 0; i <= word1.size(); i++) dp[i][0] = i;
for (int j = 0; j <= word2.size(); j++) dp[0][j] = j;
```


### 4. 確定遍歷（traversal）順序

從如下四個遞迴公式：

* `dp[i][j] = dp[i - 1][j - 1]`
* `dp[i][j] = dp[i - 1][j - 1] + 1`
* `dp[i][j] = dp[i][j - 1] + 1`
* `dp[i][j] = dp[i - 1][j] + 1`

可以看出 dp[i][j] 是依賴左方，上方和左上方元素的，如圖：

![72.编辑距离](https://file1.kamacoder.com/i/algo/20210114162113131.jpg)

所以在 dp 矩陣（matrix）中一定是從左到右從上到下去遍歷。

程式碼如下：

```CPP
for (int i = 1; i <= word1.size(); i++) {
    for (int j = 1; j <= word2.size(); j++) {
        if (word1[i - 1] == word2[j - 1]) {
            dp[i][j] = dp[i - 1][j - 1];
        }
        else {
            dp[i][j] = min({dp[i - 1][j - 1], dp[i - 1][j], dp[i][j - 1]}) + 1;
        }
    }
}
```

### 5. 舉例推導 dp 陣列


以範例 1 為例，輸入：`word1 = "horse", word2 = "ros"` 為例，dp 矩陣狀態（state）圖如下：

![72.编辑距离1](https://file1.kamacoder.com/i/algo/20210114162132300.jpg)

以上動態規劃五部曲分析完畢，C++ 程式碼如下：

```CPP
class Solution {
public:
    int minDistance(string word1, string word2) {
        vector<vector<int>> dp(word1.size() + 1, vector<int>(word2.size() + 1, 0));
        for (int i = 0; i <= word1.size(); i++) dp[i][0] = i;
        for (int j = 0; j <= word2.size(); j++) dp[0][j] = j;
        for (int i = 1; i <= word1.size(); i++) {
            for (int j = 1; j <= word2.size(); j++) {
                if (word1[i - 1] == word2[j - 1]) {
                    dp[i][j] = dp[i - 1][j - 1];
                }
                else {
                    dp[i][j] = min({dp[i - 1][j - 1], dp[i - 1][j], dp[i][j - 1]}) + 1;
                }
            }
        }
        return dp[word1.size()][word2.size()];
    }
};
```
* 時間複雜性（time complexity）：O(n * m)
* 空間複雜度（space complexity）：O(n * m)

```java
public int minDistance(String word1, String word2) {
    int m = word1.length();
    int n = word2.length();
    int[][] dp = new int[m + 1][n + 1];
    // 初始化
    for (int i = 1; i <= m; i++) {
        dp[i][0] =  i;
    }
    for (int j = 1; j <= n; j++) {
        dp[0][j] = j;
    }
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            // 因為 dp 陣列有效位從 1 開始
            // 所以目前遍歷到的字串的位置為 i-1 | j-1
            if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1];
            } else {
                dp[i][j] = Math.min(Math.min(dp[i - 1][j - 1], dp[i][j - 1]), dp[i - 1][j]) + 1;
            }
        }
    }
    return dp[m][n];
}
```

### TypeScript：

```typescript
function minDistance(word1: string, word2: string): number {
    /**
        dp[i][j]: word1 前 i 個字元，word2 前 j 個字元，最少操作數
        dp[0][0]=0：表示 word1 前 0 個字元為 '', word2 前 0 個字元為 ''
     */
    const length1: number = word1.length,
        length2: number = word2.length;
    const dp: number[][] = new Array(length1 + 1).fill(0)
        .map(_ => new Array(length2 + 1).fill(0));
    for (let i = 0; i <= length1; i++) {
        dp[i][0] = i;
    }
    for (let i = 0; i <= length2; i++) {
        dp[0][i] = i;
    }
    for (let i = 1; i <= length1; i++) {
        for (let j = 1; j <= length2; j++) {
            if (word1[i - 1] === word2[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1];
            } else {
                dp[i][j] = Math.min(
                    dp[i - 1][j],
                    dp[i][j - 1],
                    dp[i - 1][j - 1]
                ) + 1;
            }
        }
    }
    return dp[length1][length2];
};
```

```rust
impl Solution {
    pub fn min_distance(word1: String, word2: String) -> i32 {
        let mut dp = vec![vec![0; word2.len() + 1]; word1.len() + 1];
        for i in 1..=word2.len() {
            dp[0][i] = i;
        }

        for (j, v) in dp.iter_mut().enumerate().skip(1) {
            v[0] = j;
        }
        for (i, char1) in word1.chars().enumerate() {
            for (j, char2) in word2.chars().enumerate() {
                if char1 == char2 {
                    dp[i + 1][j + 1] = dp[i][j];
                    continue;
                }
                dp[i + 1][j + 1] = dp[i][j + 1].min(dp[i + 1][j]).min(dp[i][j]) + 1;
            }
        }

        dp[word1.len()][word2.len()] as i32
    }
}
```

```rust
impl Solution {
    pub fn min_distance(word1: String, word2: String) -> i32 {
        let mut dp = vec![0; word1.len() + 1];
        for (i, v) in dp.iter_mut().enumerate().skip(1) {
            *v = i;
        }

        for char2 in word2.chars() {
            // 相當於 dp[i][0] 的初始化
            let mut pre = dp[0];
            dp[0] += 1; // j = 0, 將前 i 個字元變成空字串的個數
            for (j, char1) in word1.chars().enumerate() {
                let temp = dp[j + 1];
                if char1 == char2 {
                    dp[j + 1] = pre;
                } else {
                    dp[j + 1] = dp[j + 1].min(dp[j]).min(pre) + 1;
                }
                pre = temp;
            }
        }

        dp[word1.len()] as i32
    }
}
```
