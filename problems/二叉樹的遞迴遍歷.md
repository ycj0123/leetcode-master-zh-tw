# 二元樹（binary tree）的遞迴（recursion）遍歷（traversal）

## 演算法公開課

**[《程式碼隨想錄》演算法影片公開課](https://programmercarl.com/other/gongkaike.html)：[每次寫遞迴都要靠直覺？ 這次帶你學透二元樹的遞迴遍歷！](https://www.bilibili.com/video/BV1Wh411S7xt)，相信結合影片再看本篇題解，更有助於大家對本題的理解**。

## 想法

這次我們要好好談一談遞迴，為什麼很多同學看遞迴演算法都是「一看就會，一寫就廢」。

主要是對遞迴不成體系，沒有方法論，**每次寫遞迴演算法，都是靠玄學來寫程式碼**，程式碼能不能編譯通過都靠運氣。

**本篇將介紹前後中序的遞迴寫法，一些同學可能會感覺很簡單，其實不然，我們要透過簡單題目把方法論確定下來，有了方法論，後面才能應付複雜的遞迴。**

這裡幫助大家確定下來遞迴演算法的三個要素。**每次寫遞迴，都按照這三要素來寫，可以保證大家寫出正確的遞迴演算法！**

1. **確定遞迴函數（recursive function）的參數（parameter）和轉回值（return value）：**
確定哪些參數是遞迴的過程中需要處理的，那麼就在遞迴函數裡加上這個參數，並且還要明確每次遞迴的轉回值是什麼，進而確定遞迴函數的傳回類型（return type）。

2. **確定終止條件（termination condition）：**
寫完了遞迴演算法，執行的時候，經常會遇到堆疊溢出（stack overflow）的錯誤，就是沒寫終止條件或者終止條件寫得不對，作業系統也是用一個堆疊（stack）的結構來保存每一層遞迴的資訊，如果遞迴沒有終止，作業系統的記憶體（memory）堆疊必然就會溢位（overflow）。

3. **確定單層遞迴的邏輯：**
確定每一層遞迴需要處理的資訊。在這裡也就會重複呼叫（recursive call）自己來實作遞迴的過程。

好了，我們確認了遞迴的三要素，接下來就來練練手：


**以下以前序遍歷（preorder traversal）為例：**

1. **確定遞迴函數的參數和轉回值**：因為要印出前序遍歷節點（node）的數值，所以參數裡需要傳入 vector 來放節點的數值，除了這一點就不需要再處理什麼資料了，也不需要有轉回值，所以遞迴函數傳回類型就是 void，程式碼如下：

```cpp
void traversal(TreeNode* cur, vector<int>& vec)
```

2. **確定終止條件**：在遞迴的過程中，如何算是遞迴結束了呢，當然是當前遍歷的節點是空了，那麼本層遞迴就要結束了，所以如果當前遍歷的這個節點是空，就直接 return，程式碼如下：

```cpp
if (cur == NULL) return;
```

3. **確定單層遞迴的邏輯**：前序遍歷是中左右的順序，所以在單層遞迴的邏輯，是要先取中節點的數值，程式碼如下：

```cpp
vec.push_back(cur->val);    // 中
traversal(cur->left, vec);  // 左
traversal(cur->right, vec); // 右
```

單層遞迴的邏輯就是按照中左右的順序來處理的，這樣二元樹的前序遍歷，基本就寫完了，再看一下完整程式碼：

前序遍歷：

```CPP
class Solution {
public:
    void traversal(TreeNode* cur, vector<int>& vec) {
        if (cur == NULL) return;
        vec.push_back(cur->val);    // 中
        traversal(cur->left, vec);  // 左
        traversal(cur->right, vec); // 右
    }
    vector<int> preorderTraversal(TreeNode* root) {
        vector<int> result;
        traversal(root, result);
        return result;
    }
};
```

那麼前序遍歷寫出來之後，中序橫過（inorder traversal）和後序遍歷（post-order traversal）就不難理解了，程式碼如下：

中序橫過：

```CPP
void traversal(TreeNode* cur, vector<int>& vec) {
    if (cur == NULL) return;
    traversal(cur->left, vec);  // 左
    vec.push_back(cur->val);    // 中
    traversal(cur->right, vec); // 右
}
```

後序遍歷：

```CPP
void traversal(TreeNode* cur, vector<int>& vec) {
    if (cur == NULL) return;
    traversal(cur->left, vec);  // 左
    traversal(cur->right, vec); // 右
    vec.push_back(cur->val);    // 中
}
```
