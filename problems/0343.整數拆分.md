# 343. 整數拆分

[LeetCode 題目連結](https://leetcode.cn/problems/integer-break/)

給定一個正整數（positive integer） n，將其拆分為至少兩個正整數的和，並使這些整數（integer）的乘積最大化。回傳你可以獲得的最大乘積。

範例 1:
* 輸入: 2
* 輸出: 1
* 解釋: 2 = 1 + 1, 1 × 1 = 1。

範例 2:
* 輸入: 10
* 輸出: 36
* 解釋: 10 = 3 + 3 + 4, 3 × 3 × 4 = 36。
* 說明: 你可以假設 n 不小於 2 且不大於 58。

## 解題思路

看到這道題目，都會想拆成兩個呢，還是三個呢，還是四個....

我們來看一下如何使用動態規劃來解決。

### 動態規劃

動態規劃五部曲，分析如下：

1. 確定 dp 陣列（array）（dp table）以及下標（subscript）的含義

dp[i]：分拆數字 i，可以得到的最大乘積為 dp[i]。

dp[i] 的定義將貫徹整個解題過程，下面哪一步想不懂了，就想想 dp[i] 究竟表示的是什麼！

2. 確定遞迴公式

可以想 dp[i] 最大乘積是怎麼得到的呢？

其實可以從 1 遍歷（traversal） j，然後有兩種管道得到 dp[i]。

一個是 j * (i - j) 直接相乘。

一個是 j * dp[i - j]，相當於是拆分 (i - j)，對這個拆分不理解的話，可以回想 dp 陣列的定義。

**那有同學問了，j 怎麼就不拆分呢？**

j 是從 1 開始遍歷，拆分 j 的情況，在遍歷 j 的過程中其實都計算過了。那麼從 1 遍歷 j，比較 (i - j) * j 和 dp[i - j] * j 取最大的。遞迴公式：dp[i] = max(dp[i], max((i - j) * j, dp[i - j] * j));

也可以這麼理解，j * (i - j) 是單純地把整數拆分為兩個數相乘，而 j * dp[i - j] 是拆分成兩個以及兩個以上的個數相乘。

如果定義 dp[i - j] * dp[j] 也是預設將一個數強制拆成 4 份以及 4 份以上了。

所以遞迴公式：dp[i] = max({dp[i], (i - j) * j, dp[i - j] * j});

那麼在取最大值的時候，為什麼還要比較 dp[i] 呢？

因為在遞迴公式推導的過程中，每次計算 dp[i]，取最大的而已。


3. dp 的初始化（initialization）

不少同學應該疑惑，dp[0] dp[1] 應該初始化多少呢？

有的題解裡會給出 dp[0] = 1，dp[1] = 1 的初始化，但解釋比較牽強，主要還是因為這麼初始化可以讓題目通過。

嚴格從 dp[i] 的定義來說，dp[0] dp[1] 就不應該初始化，也就是沒有意義的數值。

拆分 0 和拆分 1 的最大乘積是多少？

這是無解的。

這裡我只初始化 dp[2] = 1，從 dp[i] 的定義來說，拆分數字 2，得到的最大乘積是 1，這個沒有任何異議！


4. 確定遍歷順序

確定遍歷順序，先來看看遞迴公式：dp[i] = max(dp[i], max((i - j) * j, dp[i - j] * j));


dp[i] 是依靠 dp[i - j] 的狀態（state），所以遍歷 i 一定是從前向後遍歷，先有 dp[i - j] 再有 dp[i]。


所以遍歷順序為：
```CPP
for (int i = 3; i <= n ; i++) {
    for (int j = 1; j < i - 1; j++) {
        dp[i] = max(dp[i], max((i - j) * j, dp[i - j] * j));
    }
}
```
注意列舉（enumeration） j 的時候，是從 1 開始的。從 0 開始的話，那麼讓拆分一個數拆個 0，求最大乘積就沒有意義了。

j 的結束條件是 j < i - 1，其實 j < i 也是可以的，不過可以節省一步，例如讓 j = i - 1 的話，其實在 j = 1 的時候，這一步就已經拆出來了，重複計算，所以 j < i - 1 

至於 i 是從 3 開始，這樣 dp[i - j] 就是 dp[2]，正好可以透過我們初始化的數值求出來。

更最佳化一步，可以這樣：

```CPP
for (int i = 3; i <= n ; i++) {
    for (int j = 1; j <= i / 2; j++) {
        dp[i] = max(dp[i], max((i - j) * j, dp[i - j] * j));
    }
}
```

因為拆分一個數 n 使之乘積最大，那麼一定是拆分成 m 個近似相同的子數相乘才是最大的。 

例如 6 拆成 3 * 3，10 拆成 3 * 3 * 4。100 的話也是拆成 m 個近似數值的子數相乘才是最大的。 

只不過我們不知道 m 究竟是多少而已，但可以明確的是 m 一定大於等於 2，既然 m 大於等於 2，也就是最差也應該是拆成兩個相同的可能是最大值。

那麼 j 遍歷，只需要遍歷到 n/2 就可以，後面就沒有必要遍歷了，一定不是最大值。

至於「拆分一個數 n 使之乘積最大，那麼一定是拆分成 m 個近似相同的子數相乘才是最大的」這個我就不去做數學證明了，感興趣的同學，可以自己證明。 

5. 舉例推導 dp 陣列

舉例當 n 為 10 的時候，dp 陣列裡的數值，如下：

![343.整數拆分](https://file1.kamacoder.com/i/algo/20210104173021581.png)

以上動態規劃五部曲分析完畢，C++ 程式碼如下：

```CPP
class Solution {
public:
    int integerBreak(int n) {
        vector<int> dp(n + 1);
        dp[2] = 1;
        for (int i = 3; i <= n ; i++) {
            for (int j = 1; j <= i / 2; j++) {
                dp[i] = max(dp[i], max((i - j) * j, dp[i - j] * j));
            }
        }
        return dp[n];
    }
};
```

* 時間複雜性（time complexity）：O(n^2)
* 空間複雜度（space complexity）：O(n)

### 貪心法（greedy）

本題也可以用貪心法，每次拆成 n 個 3，如果剩下是 4，則保留 4，然後相乘，**但是這個結論需要數學證明其合理性！**

我沒有證明，而是直接用了結論。感興趣的同學可以自己再去研究研究數學證明。

給出我的 C++ 程式碼如下：

```CPP
class Solution {
public:
    int integerBreak(int n) {
        if (n == 2) return 1;
        if (n == 3) return 2;
        if (n == 4) return 4;
        int result = 1;
        while (n > 4) {
            result *= 3;
            n -= 3;
        }
        result *= n;
        return result;
    }
};
```

* 時間複雜性：O(n)
* 空間複雜度：O(1)

## 總結

本題掌握其動態規劃的方法，就可以了，貪心法的解法確實簡單，但需要有數學證明，如果能自圓其說也是可以的。

其實這道題目的遞迴公式並不好想，而且初始化的地方也很有講究，我在寫本題的時候一開始寫的程式碼是這樣的：

```CPP
class Solution {
public:
    int integerBreak(int n) {
        if (n <= 3) return 1 * (n - 1);
        vector<int> dp(n + 1, 0);
        dp[1] = 1;
        dp[2] = 2;
        dp[3] = 3;
        for (int i = 4; i <= n ; i++) {
            for (int j = 1; j <= i / 2; j++) {
                dp[i] = max(dp[i], dp[i - j] * dp[j]);
            }
        }
        return dp[n];
    }
};
```
**這個程式碼也是可以通過的！**

在解釋遞迴公式的時候，也可以解釋通，dp[i] 就等於 拆解 i - j 的最大乘積 * 拆解 j 的最大乘積。看起來沒毛病！

但是在解釋初始化的時候，就發現自相矛盾了，dp[1] 為什麼一定是 1 呢？根據 dp[i] 的定義，dp[2] 也不應該是 2 啊。

但如果遞迴公式是 dp[i] = max(dp[i], dp[i - j] * dp[j]);，就一定要這麼初始化。遞迴公式沒毛病，但初始化解釋不通！

雖然程式碼在初始位置有一個判斷 if (n <= 3) return 1 * (n - 1);，保證 n <= 3 結果是正確的，但程式碼後面又要給 dp[1] 賦值（assignment） 1 和 dp[2] 賦值 2，**這其實就是自相矛盾的程式碼，違背了 dp[i] 的定義！**

我舉這個例子，其實就是說做題的嚴謹性，上面這個程式碼也可以 AC，大體上一看好像也沒有毛病，遞迴公式也說得過去，但是僅僅是恰巧通過了而已。

class Solution {
    public int integerBreak(int n) {
        //dp[i] 為正整數 i 拆分後的結果的最大乘積
        int[] dp = new int[n+1];
        dp[2] = 1;
        for(int i = 3; i <= n; i++) {
            for(int j = 1; j <= i-j; j++) {
                // 這裡的 j 其實最大值為 i-j，再大只不過是重複而已，
                //並且，在本題中，我們分析 dp[0], dp[1] 都是無意義的，
                //j 最大到 i-j，就不會用到 dp[0] 與 dp[1]
                dp[i] = Math.max(dp[i], Math.max(j*(i-j), j*dp[i-j]));
                // j * (i - j) 是單純地把整數 i 拆分為兩個數，也就是 j, i-j，再相乘
                //而 j * dp[i - j] 是將 i 拆分成兩個以及兩個以上的個數，再相乘。
            }
        }
        return dp[n];
    }
}

class Solution:
         # 假設對正整數 i 拆分出的第一個正整數是 j（1 <= j < i），則有以下兩種方案：
        # 1) 將 i 拆分成 j 和 i−j 的和，且 i−j 不再拆分成多個正整數，此時的乘積是 j * (i-j)
        # 2) 將 i 拆分成 j 和 i−j 的和，且 i−j 繼續拆分成多個正整數，此時的乘積是 j * dp[i-j]
    def integerBreak(self, n):
        dp = [0] * (n + 1)   # 建立一個大小為 n+1 的陣列來儲存計算結果
        dp[2] = 1  # 初始化 dp[2] 為 1，因為當 n=2 時，只有一種切割方式 1+1=2，乘積為 1
       
        # 從 3 開始計算，直到 n
        for i in range(3, n + 1):
            # 遍歷所有可能的切割點
            for j in range(1, i // 2 + 1):

        return dp[n]  # 回傳最終的計算結果

class Solution:

        if n <= 3:
            return 1 * (n - 1)  # 對於 n 小於等於 3 的情況，回傳 1 * (n - 1)

    def integerBreak(self, n):
        if n == 2:  # 當 n 等於 2 時，只有一種拆分方式：1+1=2，乘積為 1
            return 1
        if n == 3:  # 當 n 等於 3 時，只有一種拆分方式：2+1=3，乘積為 2
            return 2

            n -= 3  # 每次減去 3
        result *= n  # 將剩餘的 n 乘以最後的結果
        return result
