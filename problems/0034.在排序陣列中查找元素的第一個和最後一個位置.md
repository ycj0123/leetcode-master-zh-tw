# 34. 在已排序陣列（sorted array）中尋找元素（element）的第一個和最後一個位置

[LeetCode 連結](https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/)


給定一個按照升序（ascending order）排列的整數（integer）陣列（array） nums，和一個目標值 target。找出給定目標值在陣列中的開始位置和結束位置。

如果陣列中不存在目標值 target，回傳 [-1, -1]。

進階：你可以設計並實作時間複雜性（time complexity）為 $O(\log n)$ 的演算法解決此問題嗎？


範例 1：
* 輸入：nums = [5,7,7,8,8,10], target = 8
* 輸出：[3,4]

範例 2：
* 輸入：nums = [5,7,7,8,8,10], target = 6
* 輸出：[-1,-1]

範例 3：
* 輸入：nums = [], target = 0
* 輸出：[-1,-1]


## 解題思路

這道題目如果基礎不是很好，不建議大家看簡短的程式碼，簡短的程式碼隱藏了太多邏輯，結果就是稀里糊塗把題目 AC 了，但是沒有想清楚具體細節！

對二元搜尋（binary search）還不了解的同學先做這兩題：

* [704.二元搜尋](https://programmercarl.com/0704.二分查找.html)
* [35.搜尋插入位置](https://programmercarl.com/0035.搜索插入位置.html)

下面我來把所有情況都討論一下。

尋找 target 在陣列裡的左右邊界（boundary），有如下三種情況：

* 情況一：target 在陣列範圍的右邊或者左邊，例如陣列 {3, 4, 5}，target 為 2 或者陣列 {3, 4, 5}，target 為 6，此時應該回傳 {-1, -1}
* 情況二：target 在陣列範圍中，且陣列中不存在 target，例如陣列 {3,6,7}，target 為 5，此時應該回傳 {-1, -1}
* 情況三：target 在陣列範圍中，且陣列中存在 target，例如陣列 {3,6,7}，target 為 6，此時應該回傳 {1, 1}

這三種情況都考慮到，說明就想得很清楚了。

接下來，再去尋找左邊界和右邊界。

採用二元搜尋來尋找左右邊界，為了讓程式碼清晰，我分別寫兩個二元搜尋來尋找左邊界和右邊界。

**剛剛接觸二元搜尋的同學不建議一上來就想用一個二元搜尋來尋找左右邊界，很容易把自己繞進去，建議紮紮實實地寫兩個二元搜尋分別找左邊界和右邊界**

### 尋找右邊界

先來尋找右邊界，至於二元搜尋，如果看過 [704.二元搜尋](https://programmercarl.com/0704.二分查找.html) 就會知道，二元搜尋中什麼時候用 while (left <= right)，什麼時候用 while (left < right)，其實只要清楚 **loop invariant**，很容易區分兩種寫法。

那麼這裡我採用 while (left <= right) 的寫法，區間（interval）定義為 [left, right]，即左閉右閉的區間（如果這裡有點看不懂了，強烈建議把 [704.二元搜尋](https://programmercarl.com/0704.二分查找.html) 這篇文章先看了，704 題目做了之後再做這道題目就好很多了）

確定好：計算出來的右邊界是不包含 target 的右邊界，左邊界同理。

可以寫出如下程式碼

```CPP
// 二元搜尋，尋找 target 的右邊界（不包括 target）
// 如果 rightBorder 沒有被賦值（即 target 在陣列範圍的左邊，例如陣列 [3,3]，target 為 2），為了處理情況一
int getRightBorder(vector<int>& nums, int target) {
    int left = 0;
    int right = nums.size() - 1; // 定義 target 在左閉右閉的區間裡，[left, right]
    int rightBorder = -2; // 記錄一下 rightBorder 沒有被賦值的情況
    while (left <= right) { // 當 left==right，區間 [left, right] 依然有效
        int middle = left + ((right - left) / 2);// 防止溢位，等同於 (left + right)/2
        if (nums[middle] > target) {
            right = middle - 1; // target 在左區間，所以 [left, middle - 1]
        } else { // 當 nums[middle] == target 的時候，更新 left，這樣才能得到 target 的右邊界
            left = middle + 1;
            rightBorder = left;
        }
    }
    return rightBorder;
}
```

## 總結

初學者建議大家一塊一塊地去拆解這道題目，正如本題解描述，想清楚三種情況之後，先專注於尋找右區間，然後專注於尋找左區間，最後再根據左右區間做最終判斷。

不要一上來就想如何一起尋找左右區間，寫著寫著就會顧此失彼，繞進去出不來了。

// 解法 2
// 1、首先，在 nums 陣列中二元搜尋 target；
// 2、如果二元搜尋失敗，則 binarySearch 回傳 -1，表明 nums 中沒有 target。此時，searchRange 直接回傳 {-1, -1}；
// 3、如果二元搜尋成功，則 binarySearch 回傳 nums 中值為 target 的一個下標。然後，透過左右滑動指標，來找到符合題意的區間

class Solution {
	public int[] searchRange(int[] nums, int target) {
		int index = binarySearch(nums, target); // 二元搜尋
		
		if (index == -1) { // nums 中不存在 target，直接回傳 {-1, -1}
			return new int[] {-1, -1}; // 匿名陣列 
		}
		// nums 中存在 target，則左右滑動指標，來找到符合題意的區間
		int left = index;
		int right = index;
        // 向左滑動，找左邊界
		while (left - 1 >= 0 && nums[left - 1] == nums[index]) { // 防止陣列越界。邏輯短路，兩個條件順序不能換
			left--;
		}
        // 向右滑動，找右邊界
		while (right + 1 < nums.length && nums[right + 1] == nums[index]) { // 防止陣列越界。
			right++;
		}
		return new int[] {left, right};
    }
	
	/**
	 * 二元搜尋
	 * @param nums
	 * @param target
	 */
	public int binarySearch(int[] nums, int target) {
		int left = 0;
		int right = nums.length - 1; // loop invariant：左閉右閉區間
		
		while (left <= right) { // loop invariant：左閉右閉區間
			int mid = left + (right - left) / 2;
			if (nums[mid] == target) {
				return mid;
			} else if (nums[mid] < target) {
				left = mid + 1;
			} else {
				right = mid - 1; // loop invariant：左閉右閉區間
			}
		}
		return -1; // 不存在
	}
}

class Solution {
    public int[] searchRange(int[] nums, int target) {
        int left = searchLeft(nums,target);
        int right = searchRight(nums,target);
        return new int[]{left,right};
    }
    public int searchLeft(int[] nums,int target){
        // 尋找元素第一次出現的地方
        int left = 0;
        int right = nums.length-1;
        while(left<=right){
            int mid = left+(right-left)/2;
            // >= 的都要縮小 因為要找第一個元素
            if(nums[mid]>=target){
                right = mid - 1;
            }else{
                left = mid + 1;
            }
        }
        // right = left - 1
        // 如果存在答案 right 是首選
        if(right>=0&&right<nums.length&&nums[right]==target){
            return right;
        }
        if(left>=0&&left<nums.length&&nums[left]==target){
            return left;
        }
        return -1;
    }

    public int searchRight(int[] nums,int target){
        // 找最後一次出現
        int left = 0;
        int right = nums.length-1;
        while(left<=right){
            int mid = left + (right-left)/2;
            // <= 的都要更新 因為我們要找最後一個元素

                right = mid - 1;

            return left;
        }
        if(right>=0&&right<=nums.length&&nums[right]==target){

class Solution:
    def searchRange(self, nums: List[int], target: int) -> List[int]:
        def binarySearch(nums:List[int], target:int) -> int:
            left, right = 0, len(nums)-1
            while left<=right: # loop invariant：左閉右閉區間
                middle = left + (right-left) // 2
                if nums[middle] > target:
                    right = middle - 1
                elif nums[middle] < target: 
                    left = middle + 1
                else:
                    return middle
            return -1
        index = binarySearch(nums, target)
        if index == -1:return [-1, -1] # nums 中不存在 target，直接回傳 {-1, -1}
        # nums 中存在 target，則左右滑動指標，來找到符合題意的區間

        # 向左滑動，找左邊界

        # 向右滑動，找右邊界
        while right+1 < len(nums) and nums[right + 1] == target: right +=1
        return [left, right]

# 解法 3
# 1、首先，在 nums 陣列中二元搜尋得到第一個大於等於 target 的下標（左邊界）與第一個大於 target 的下標（右邊界）；
# 2、如果左邊界 <= 右邊界，則回傳 [左邊界, 右邊界]。否則回傳 [-1, -1]
class Solution:
    def searchRange(self, nums: List[int], target: int) -> List[int]:
        def binarySearch(nums:List[int], target:int, lower:bool) -> int:
            left, right = 0, len(nums)-1
            ans = len(nums)
            while left<=right: # loop invariant：左閉右閉區間
                middle = left + (right-left) //2 
                # lower 為 True，執行前半部分，找到第一個大於等於 target 的下標，否則找到第一個大於 target 的下標
                if nums[middle] > target or (lower and nums[middle] >= target): 
                    right = middle - 1
                    ans = middle
                else: 
                    left = middle + 1
            return ans

        leftBorder = binarySearch(nums, target, True) # 搜尋左邊界
        rightBorder = binarySearch(nums, target, False) -1  # 搜尋右邊界
        if leftBorder<= rightBorder and rightBorder< len(nums) and nums[leftBorder] == target and  nums[rightBorder] == target:
            return [leftBorder, rightBorder]
        return [-1, -1]

# 解法 4
# 1、首先，在 nums 陣列中二元搜尋得到第一個大於等於 target 的下標 leftBorder；
# 2、在 nums 陣列中二元搜尋得到第一個大於等於 target+1 的下標，減 1 則得到 rightBorder；
# 3、如果開始位置在陣列的右邊或者不存在 target，則回傳 [-1, -1]。否則回傳 [leftBorder, rightBorder]
class Solution:
    def searchRange(self, nums: List[int], target: int) -> List[int]:
        def binarySearch(nums:List[int], target:int) -> int:
            left, right = 0, len(nums)-1
            while left<=right: # loop invariant：左閉右閉區間
                middle = left + (right-left) //2 
                if nums[middle] >= target: 
                    right = middle - 1
                else: 
                    left = middle + 1
            return left  # 若存在 target，則回傳第一個等於 target 的值 

        leftBorder = binarySearch(nums, target) # 搜尋左邊界
        rightBorder = binarySearch(nums, target+1) -1  # 搜尋右邊界
        if leftBorder == len(nums) or nums[leftBorder]!= target: # 情況一和情況二
            return [-1, -1]
        return [leftBorder, rightBorder]

class Solution {
    fun searchRange(nums: IntArray, target: Int): IntArray {
        var index = binarySearch(nums, target)
        // 沒找到，回傳 [-1, -1]
        if (index == -1) return intArrayOf(-1, -1)
        var left = index
        var right = index
        // 尋找左邊界
        while (left - 1 >=0 && nums[left - 1] == target){
            left--
        }
        // 尋找右邊界
        while (right + 1 <nums.size && nums[right + 1] == target){
            right++
        }
        return intArrayOf(left, right)
    }
    // 二元搜尋常規寫法
    fun binarySearch(nums: IntArray, target: Int): Int {
        var left = 0;
        var right = nums.size - 1
        while (left <= right) {
            var middle = left + (right - left)/2
            if (nums[middle] > target) {
                right = middle - 1
            }
            else {
                if (nums[middle] < target) {
                    left = middle + 1
                }
                else {
                    return middle
                }
            }
        }
        // 沒找到，回傳 -1
        return -1
    }
