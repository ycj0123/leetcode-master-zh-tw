# 844.比較含退格（backspace）的字串（string）

[LeetCode 題目連結](https://leetcode.cn/problems/backspace-string-compare/)

給定 S 和 T 兩個字串，當它們分別被輸入到空白的文字編輯器（text editor）後，判斷二者是否相等，並回傳結果。`#` 代表退格字元（character）。

注意：如果對空文字輸入退格字元，文字繼續為空。

範例 1：
* 輸入：S = "ab#c", T = "ad#c"
* 輸出：true
* 解釋：S 和 T 都會變成 “ac”。

範例 2：
* 輸入：S = "ab##", T = "c#d#"
* 輸出：true
* 解釋：S 和 T 都會變成 “”。

範例 3：
* 輸入：S = "a##c", T = "#a#c"
* 輸出：true
* 解釋：S 和 T 都會變成 “c”。

範例 4：
* 輸入：S = "a#c", T = "b"
* 輸出：false
* 解釋：S 會變成 “c”，但 T 仍然是 “b”。


## 解題思路

本文將給出空間複雜度（space complexity）O(n) 的堆疊（stack）模擬（simulation）方法以及空間複雜度是 O(1) 的 two pointers 方法。

### 普通方法（使用堆疊的思路）

這道題目一看就是要使用堆疊的節奏，這種匹配（消除）問題也是堆疊的擅長所在，跟著一起刷題的同學應該知道，在[堆疊與佇列（queue）：匹配問題都是堆疊的強項](https://programmercarl.com/1047.删除字符串中的所有相邻重复项.html)，我就已經提過了一次使用堆疊來做類似的事情了。

**那麼本題，確實可以使用堆疊的思路，但是沒有必要使用堆疊，因為最後比較的時候還要比較堆疊裡的元素（element），有點麻煩**。

這裡直接使用字串 string，來作為堆疊，末尾新增和彈出，string 都有相應的介面（interface），最後比較的時候，只要比較兩個字串就可以了，比比較堆疊裡的元素方便一些。

程式碼如下：

```CPP
class Solution {
public:
    bool backspaceCompare(string S, string T) {
        string s; // 當堆疊來用
        string t; // 當堆疊來用
        for (int i = 0; i < S.size(); i++) {
            if (S[i] != '#') s += S[i];
            else if (!s.empty()) {
                s.pop_back();

        }
        for (int i = 0; i < T.size(); i++) {
            if (T[i] != '#') t += T[i];
            else if (!t.empty()) {
                t.pop_back();
            }
        }
        if (s == t) return true; // 直接比較兩個字串是否相等，比用堆疊來比較方便多了
        return false;
    }
};
```
* 時間複雜性（time complexity）: O(n + m)，n 為 S 的長度，m 為 T 的長度，也可以理解為 O(n) 的時間複雜性
* 空間複雜度: O(n + m)

當然以上程式碼，大家可以發現有重複的邏輯處理 S、處理 T，可以把這塊公共邏輯抽離出來，程式碼精簡如下：


* 時間複雜性：O(n + m)

### 最佳化方法（從後向前 two pointers）

當然還可以有使用 O(1) 的空間複雜度來解決該問題。

同時從後向前遍歷（traversal）S 和 T（i 初始為 S 末尾，j 初始為 T 末尾），記錄 `#` 的數量，模擬消除的操作，如果 `#` 用完了，就開始比較 S[i] 和 T[j]。

動畫如下：

<img src='https://file1.kamacoder.com/i/algo/844.比较含退格的字符串.gif' width=600> </img></div>

如果 S[i] 和 T[j] 不相同回傳 false，如果有一個指標（pointer）（i 或者 j）先走到字串頭部位置，也回傳 false。

程式碼如下：

```CPP
class Solution {
public:
    bool backspaceCompare(string S, string T) {
        int sSkipNum = 0; // 記錄 S 的 # 數量
        int tSkipNum = 0; // 記錄 T 的 # 數量
        int i = S.size() - 1;
        int j = T.size() - 1;
        while (1) {
            while (i >= 0) { // 從後向前，消除 S 的 #
                if (S[i] == '#') sSkipNum++;
                else {
                    if (sSkipNum > 0) sSkipNum--;
                    else break;
                }
                i--;
            }
            while (j >= 0) { // 從後向前，消除 T 的 #
                if (T[j] == '#') tSkipNum++;
                else {
                    if (tSkipNum > 0) tSkipNum--;
                    else break;
                }
                j--;
            }
            // 後半部分 # 消除完了，接下來比較 S[i] != T[j]
            if (i < 0 || j < 0) break; // S 或者 T 遍歷到頭了
            if (S[i] != T[j]) return false;
            i--;j--;
        }
        // 說明 S 和 T 同時遍歷完畢
        if (i == -1 && j == -1) return true;
        return false;
    }
};
```

* 時間複雜性：O(n + m)
* 空間複雜度：O(1)

```typescript
    const stack1: string[] = [],
        stack2: string[] = [];
    for (let c of s) {
        if (c === '#') {
            stack1.pop();
        } else {
            stack1.push(c);
        }
    }
    for (let c of t) {
        if (c === '#') {
            stack2.pop();
        } else {
            stack2.push(c);
        }

        if (stack1[i] !== stack2[i]) return false;
    }
    return true;
};
```

```typescript
function getIndexAfterDel(s: string, startIndex: number): number {
    let backspaceNum: number = 0;
    while (startIndex >= 0) {
        // 不可消除
        if (s[startIndex] !== '#' && backspaceNum === 0) break;
        // 可消除
        if (s[startIndex] === '#') {
            backspaceNum++;
        } else {
            backspaceNum--;
        }
        startIndex--;
    }
    return startIndex;
}
```

```rust
impl Solution {
    pub fn backspace_compare(s: String, t: String) -> bool {
        let (s, t) = (
            s.chars().collect::<Vec<char>>(),
            t.chars().collect::<Vec<char>>(),
        );
        Self::get_string(s) == Self::get_string(t)
    }

    pub fn get_string(mut chars: Vec<char>) -> Vec<char> {
        let mut slow = 0;
        for i in 0..chars.len() {
            if chars[i] == '#' {
                slow = (slow as u32).saturating_sub(1) as usize;
            } else {
                chars[slow] = chars[i];
                slow += 1;
            }
        }
        chars.truncate(slow);
        chars
    }
}
```
