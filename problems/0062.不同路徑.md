# 62.不同路徑

[LeetCode 題目連結](https://leetcode.cn/problems/unique-paths/)

一個機器人位於一個 m x n 格子（grid）的左上角（起始點在下圖中標記為「Start」）。

機器人每次只能向下或者向右移動一步。機器人試圖到達格子的右下角（在下圖中標記為「Finish」）。

問總共有多少條不同的路徑？

範例 1：

![](https://file1.kamacoder.com/i/algo/20210110174033215.png)

* 輸入：m = 3, n = 7
* 輸出：28

範例 2：

* 輸入：m = 2, n = 3
* 輸出：3

解釋：從左上角開始，總共有 3 條路徑可以到達右下角。

1. 向右 -> 向右 -> 向下
2. 向右 -> 向下 -> 向右
3. 向下 -> 向右 -> 向右


範例 3：

* 輸入：m = 7, n = 3
* 輸出：28

範例 4：

* 輸入：m = 3, n = 3
* 輸出：6

提示：

* 1 <= m, n <= 100
* 題目資料保證答案小於等於 2 * 10^9

## 解題思路

### 深度優先搜尋（depth-first search, DFS）

這道題目，剛一看最直覺的想法就是用圖論（graph theory）裡的深度優先搜尋，來列舉（enumeration）出有多少種路徑。

注意題目中說機器人每次只能向下或者向右移動一步，那麼其實**機器人走過的路徑可以抽象為一棵二元樹（binary tree），而葉節點（leaf node）就是終點！**

如圖舉例：

![62.不同路徑](https://file1.kamacoder.com/i/algo/20201209113602700.png)

此時問題就可以轉化為求二元樹葉節點的個數，程式碼如下：

```CPP
class Solution {
private:
    int dfs(int i, int j, int m, int n) {
        if (i > m || j > n) return 0; // 越界了
        if (i == m && j == n) return 1; // 找到一種方法，相當於找到了葉節點
        return dfs(i + 1, j, m, n) + dfs(i, j + 1, m, n);
    }
public:
    int uniquePaths(int m, int n) {
        return dfs(1, 1, m, n);
    }
};
```

**大家如果提交了程式碼就會發現逾時了！**

來分析一下時間複雜性（time complexity），這個深度優先搜尋的演算法，其實就是要遍歷（traversal）整個二元樹。

這棵樹的深度（depth）其實就是 m+n-1（深度按從 1 開始計算）。

那二元樹的節點（node）個數就是 2^(m + n - 1) - 1。可以理解深度優先搜尋的演算法就是遍歷了整個滿二元樹（full binary tree）（其實沒有遍歷整個滿二元樹，只是近似而已）

所以上面深度優先搜尋程式碼的時間複雜性為 O(2^(m + n - 1) - 1)，可以看出，這是指數（exponential）級別的時間複雜性，是非常大的。

### 動態規劃（dynamic programming, DP）

機器人從 (0 , 0) 位置出發，到 (m - 1, n - 1) 終點。

按照動態規劃五部曲來分析：

1. 確定 dp 陣列（array）（dp table）以及下標（subscript）的含義

dp[i][j] ：表示從（0 ，0）出發，到 (i, j) 有 dp[i][j] 條不同的路徑。


2. 確定遞迴公式（recurrence formula）

想要求 dp[i][j]，只能有兩個方向來推導出來，即 dp[i - 1][j] 和 dp[i][j - 1]。

此時再回顧一下 dp[i - 1][j] 表示什麼，是從 (0, 0) 的位置到 (i - 1, j) 有幾條路徑，dp[i][j - 1] 同理。

那麼很自然，dp[i][j] =  dp[i - 1][j] + dp[i][j - 1]，因為 dp[i][j] 只有這兩個方向過來。

3. dp 陣列的初始化

如何初始化呢，首先 dp[i][0] 一定都是 1，因為從 (0, 0) 的位置到 (i, 0) 的路徑只有一條，那麼 dp[0][j] 也同理。

所以初始化程式碼為：

```
for (int i = 0; i < m; i++) dp[i][0] = 1;
for (int j = 0; j < n; j++) dp[0][j] = 1;
```

4. 確定遍歷順序

這裡要看一下遞迴公式 dp[i][j] =  dp[i - 1][j] + dp[i][j - 1]，dp[i][j] 都是從其上方和左方推導而來，那麼從左到右一層一層遍歷就可以了。

這樣就可以保證推導 dp[i][j] 的時候，dp[i - 1][j] 和 dp[i][j - 1] 一定是有數值的。

5. 舉例推導 dp 陣列

如圖所示：

![62.不同路徑1](https://file1.kamacoder.com/i/algo/20201209113631392.png)

以上動態規劃五部曲分析完畢，C++ 程式碼如下：

```CPP
class Solution {
public:
    int uniquePaths(int m, int n) {
        vector<vector<int>> dp(m, vector<int>(n, 0));
        for (int i = 0; i < m; i++) dp[i][0] = 1;
        for (int j = 0; j < n; j++) dp[0][j] = 1;
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
            }
        }
        return dp[m - 1][n - 1];
    }
};
```

* 時間複雜性：O(m × n)
* 空間複雜度（space complexity）：O(m × n)

其實用一個一維陣列（one dimensional array）（也可以理解是 rolling array）就可以了，但是不利於理解，可以最佳化一點空間，建議先理解了二維（two-dimensional），再理解一維，C++ 程式碼如下：

```CPP
class Solution {
public:
    int uniquePaths(int m, int n) {
        vector<int> dp(n);
        for (int i = 0; i < n; i++) dp[i] = 1;
        for (int j = 1; j < m; j++) {
            for (int i = 1; i < n; i++) {
                dp[i] += dp[i - 1];
            }
        }
        return dp[n - 1];
    }
};
```

* 時間複雜性：O(m × n)
* 空間複雜度：O(n)

### 數論（number theory）方法

在這個圖中，可以看出總共 m、n 的話，無論怎麼走，走到終點都需要 m + n - 2 步。

![62.不同路徑](https://file1.kamacoder.com/i/algo/20201209113602700-20230310120944078.png)

在這 m + n - 2 步中，一定有 m - 1 步是要向下走的，不用管什麼時候向下走。

那麼有幾種走法呢？可以轉化為，給你 m + n - 2 個不同的數，隨便取 m - 1 個數，有幾種取法。

那麼這就是一個組合（combination）問題了。

那麼答案，如圖所示：

![62.不同路徑2](https://file1.kamacoder.com/i/algo/20201209113725324.png)

**求組合的時候，要防止兩個 int 相乘溢位（overflow）！** 所以不能把算式的分子（numerator）都算出來，分母（denominator）都算出來再做除法。

例如如下程式碼是不行的。

```CPP
class Solution {
public:
    int uniquePaths(int m, int n) {
        int numerator = 1, denominator = 1;
        int count = m - 1;
        int t = m + n - 2;
        while (count--) numerator *= (t--); // 計算分子，此時分子就會溢位
        for (int i = 1; i <= m - 1; i++) denominator *= i; // 計算分母
        return numerator / denominator;
    }
};

```

需要在計算分子的時候，不斷除以分母，程式碼如下：

```CPP
class Solution {
public:
    int uniquePaths(int m, int n) {
        long long numerator = 1; // 分子
        int denominator = m - 1; // 分母
        int count = m - 1;
        int t = m + n - 2;
        while (count--) {
            numerator *= (t--);
            while (denominator != 0 && numerator % denominator == 0) {
                numerator /= denominator;
                denominator--;
            }
        }
        return numerator;
    }
};
```

* 時間複雜性：O(m)
* 空間複雜度：O(1)

**計算組合問題的程式碼還是有難度的，特別是處理溢位的情況！**

## 總結

本文分別給出了深度優先搜尋，動態規劃，數論三種方法。

深度優先搜尋當然是逾時了，順便分析了一下使用深度優先搜尋的時間複雜性，就可以看出為什麼逾時了。

然後再給出動態規劃的方法，依然是使用動態規劃五部曲，這次我們就要考慮如何正確地初始化了，初始化和遍歷順序其實也很重要！

class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        numerator = 1  # 分子
        denominator = m - 1  # 分母
        count = m - 1  # 計數器，表示剩餘需要計算的乘積項個數
        t = m + n - 2  # 初始乘積項
        while count > 0:
            numerator *= t  # 計算乘積項的分子部分
            t -= 1  # 遞減乘積項
            while denominator != 0 and numerator % denominator == 0:
                numerator //= denominator  # 約分分子
                denominator -= 1  # 遞減分母
            count -= 1  # 計數器減 1，繼續下一項的計算
        return numerator  # 回傳最終的唯一路徑數

// 初始化 dp 陣列
int **initDP(int m, int n) {
    // 動態配置 dp 陣列
    int **dp = (int**)malloc(sizeof(int *) * m);
    int i, j;
    for(i = 0; i < m; ++i) {
        dp[i] = (int *)malloc(sizeof(int) * n);
    }

    // 從 0,0 到 i,0 只有一種走法，所以 dp[i][0] 都是 1，同理 dp[0][j] 也是 1
    for(i = 0; i < m; ++i)
        dp[i][0] = 1;
    for(j = 0; j < n; ++j)
        dp[0][j] = 1;
    return dp;
}

int uniquePaths(int m, int n){
    // dp 陣列，dp[i][j] 代表從 dp[0][0] 到 dp[i][j] 有幾種走法
    int **dp = initDP(m, n);

    int i, j;
    // 到達 dp[i][j] 只能從 dp[i-1][j] 和 dp[i][j-1] 出發
    //dp[i][j] = dp[i-1][j] + dp[i][j-1]

        for(j = 1; j < n; ++j) {
            dp[i][j] = dp[i-1][j] + dp[i][j-1];
        }
    }
    int result = dp[m-1][n-1];
    free(dp);
    return result;
}
