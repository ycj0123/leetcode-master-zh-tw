> 鏈接串列（linked list）操作中，可以使用原鏈接串列來直接進行刪除操作，也可以設定一個 dummy head 再進行刪除操作，接下來看一看哪種方式更方便。

# 203.移除鏈接串列元素（element）

[LeetCode 題目連結](https://leetcode.cn/problems/remove-linked-list-elements/)

題意：刪除鏈接串列中等於給定值（value） val 的所有節點（node）。

範例 1：
輸入：head = [1,2,6,3,4,5,6], val = 6
輸出：[1,2,3,4,5]

範例 2：
輸入：head = [], val = 1
輸出：[]

範例 3：
輸入：head = [7,7,7,7], val = 7
輸出：[]

## 解題思路

這裡以鏈接串列 1 4 2 4  來舉例，移除元素 4。

![203_鏈接串列刪除元素1](https://file1.kamacoder.com/i/algo/20210316095351161.png)

如果使用 C，C++ 程式語言的話，不要忘了還要從記憶體（memory）中刪除這兩個移除的節點， 清理節點記憶體之後如圖：

![203_鏈接串列刪除元素2](https://file1.kamacoder.com/i/algo/20210316095418280.png)

**當然如果使用 Java，Python 的話就不用手動管理記憶體了。**

還要說明一下，就算使用 C++ 來做 LeetCode，如果移除一個節點之後，沒有手動在記憶體中刪除這個節點，LeetCode 依然也是可以通過的，只不過，記憶體使用的空間大一些而已，但建議依然要養成手動清理記憶體的習慣。

這種情況下的移除操作，就是讓節點 next 指標（pointer）直接指向下下一個節點就可以了，

那麼因為單向鏈接串列（singly-linked list）的特殊性，只能指向下一個節點，剛剛刪除的是鏈接串列中的第二個，和第四個節點，那麼如果刪除的是頭節點（head node）又該怎麼辦呢？

這裡就涉及如下鏈接串列操作的兩種方式：

* **直接使用原來的鏈接串列來進行刪除操作。**
* **設定一個 dummy head 再進行刪除操作。**


來看第一種操作：直接使用原來的鏈接串列來進行移除。

![203_鏈接串列刪除元素3](https://file1.kamacoder.com/i/algo/2021031609544922.png)

移除頭節點和移除其他節點的操作是不一樣的，因為鏈接串列的其他節點都是透過前一個節點來移除當前節點，而頭節點沒有前一個節點。

所以頭節點如何移除呢，其實只要將頭節點向後移動一位就可以，這樣就從鏈接串列中移除了一個頭節點。

![203_鏈接串列刪除元素4](https://file1.kamacoder.com/i/algo/20210316095512470.png)

依然別忘將原頭節點從記憶體中刪掉。
![203_鏈接串列刪除元素5](https://file1.kamacoder.com/i/algo/20210316095543775.png)


這樣移除了一個頭節點，是不是發現，在單向鏈接串列中移除頭節點 和 移除其他節點的操作方式是不一樣的，其實在寫程式碼的時候也會發現，需要單獨寫一段邏輯來處理移除頭節點的情況。

那麼可不可以 以一種統一的邏輯來移除 鏈接串列的節點呢。

其實**可以設定一個 dummy head**，這樣原鏈接串列的所有節點就都可以按照統一的方式進行移除了。

來看看如何設定一個 dummy head。依然還是在這個鏈接串列中，移除元素 1。

![203_鏈接串列刪除元素6](https://file1.kamacoder.com/i/algo/20210316095619221.png)

這裡來給鏈接串列新增一個 dummy head 為新的頭節點，此時要移除這個舊頭節點元素 1。

這樣是不是就可以使用和移除鏈接串列其他節點的方式統一了呢？

來看一下，如何移除元素 1 呢，還是熟悉的方式，然後從記憶體中刪除元素 1。

最後呢在題目中，return 頭節點的時候，別忘了 `return  dummyNode->next;`， 這才是新的頭節點

**直接使用原來的鏈接串列來進行移除節點操作：**

```CPP
class Solution {
public:
    ListNode* removeElements(ListNode* head, int val) {
        // 刪除頭節點
        while (head != NULL && head->val == val) { // 注意這裡不是 if
            ListNode* tmp = head;
            head = head->next;
            delete tmp;
        }

        // 刪除非頭節點
        ListNode* cur = head;
        while (cur != NULL && cur->next!= NULL) {
            if (cur->next->val == val) {
                ListNode* tmp = cur->next;
                cur->next = cur->next->next;
                delete tmp;
            } else {
                cur = cur->next;
            }
        }
        return head;
    }
};
```

* 時間複雜性（time complexity）: O(n)
* 空間複雜度（space complexity）: O(1)

**設定一個 dummy head 再進行移除節點操作：**

```CPP
class Solution {
public:
    ListNode* removeElements(ListNode* head, int val) {
        ListNode* dummyHead = new ListNode(0); // 設定一個 dummy head
        dummyHead->next = head; // 將 dummy head 指向 head，這樣方便後面做刪除操作
        ListNode* cur = dummyHead;
        while (cur->next != NULL) {
            if(cur->next->val == val) {
                ListNode* tmp = cur->next;
                cur->next = cur->next->next;
                delete tmp;
            } else {
                cur = cur->next;
            }
        }
        head = dummyHead->next;
        delete dummyHead;
        return head;
    }
};

```

* 時間複雜性: O(n)
* 空間複雜度: O(1)

**也可以透過遞迴（recursion）的思路解決本題:**

基礎情況：對於空鏈接串列，不需要移除元素。

遞迴情況：首先檢查頭節點的值是否為 val，如果是則移除頭節點，答案即為在頭節點的後續節點上遞迴的結果；如果頭節點的值不為 val，則答案為頭節點與在頭節點的後續節點上遞迴得到的新鏈接串列拼接的結果。

```CPP
class Solution {
public:
    ListNode* removeElements(ListNode* head, int val) {
        // 基礎情況：空鏈接串列
        if (head == nullptr) {
            return nullptr;
        }

        // 遞迴處理
        if (head->val == val) {
            ListNode* newHead = removeElements(head->next, val);
            delete head;
            return newHead;
        } else {
            head->next = removeElements(head->next, val);
            return head;
        }
    }
};
```
* 時間複雜性：O(n)
* 空間複雜度：O(n)

```c
struct ListNode* removeElements(struct ListNode* head, int val){
    struct ListNode* temp;
    // 當頭節點存在並且頭節點的值等於 val 時
    while(head && head->val == val) {
        temp = head;
        // 將新的頭節點設定為 head->next 並刪除原來的頭節點
        head = head->next;
        free(temp);
    }

    struct ListNode *cur = head;
    // 當 cur 存在並且 cur->next 存在時
    // 此解法需要判斷 cur 存在因為 cur 指向 head。若 head 本身為 NULL 或者原鏈接串列中元素都為 val 的話，cur 也會為 NULL
    while(cur && (temp = cur->next)) {
        // 若 cur->next 的值等於 val
        if(temp->val == val) {
            // 將 cur->next 設定為 cur->next->next 並刪除 cur->next
            cur->next = temp->next;
            free(temp);
        }
        // 若 cur->next 不等於 val，則將 cur 後移一位
        else
            cur = cur->next;
    }

    // 回傳頭節點
    return head;
}
```

```java
class Solution {
    public ListNode removeElements(ListNode head, int val) {
        if (head == null) {
            return head;
        }

        // 假設 removeElements() 回傳後面完整的已經去掉 val 節點的子鏈接串列
        // 在當前遞迴層用當前節點接住後面的子鏈接串列

        if (head.val == val) {
            return head.next;
        }
        return head;

    }
```

```typescript
 * Definition for singly-linked list.
 * class ListNode {
 *     val: number
 *     next: ListNode | null
 *     constructor(val?: number, next?: ListNode | null) {
```

```rust
    pub fn remove_elements(head: Option<Box<ListNode>>, val: i32) -> Option<Box<ListNode>> {
```

### Scala:

```scala
/**
 * Definition for singly-linked list.
 * class ListNode(_x: Int = 0, _next: ListNode = null) {
 *   var next: ListNode = _next
 *   var x: Int = _x
 * }
 */
object Solution {
  def removeElements(head: ListNode, `val`: Int): ListNode = {
    if (head == null) return head
    var dummy = new ListNode(-1, head) // 定義 dummy head
    var cur = head // cur 表示當前節點
    var pre = dummy // pre 表示 cur 前一個節點
    while (cur != null) {
      if (cur.x == `val`) {
        // 相等，就刪除那麼 cur 的前一個節點 pre 執行 cur 的下一個
        pre.next = cur.next
      } else {
        // 不相等，pre 就等於當前 cur 節點
        pre = cur
      }
      // 向下疊代
      cur = cur.next
    }
    // 最終回傳 dummy 的下一個，就是鏈接串列的頭
    dummy.next
  }
}
```

```kotlin
        // 注意：回傳的不是虛擬節點
        return dummyNode.next
    }
```

```CSharp
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     public int val;
 *     public ListNode next;
 *     public ListNode(int val=0, ListNode next=null) {
 *         this.val = val;
 *         this.next = next;
 *     }
 * }
 */
public class Solution
{
    public ListNode RemoveElements(ListNode head, int val)
    {
        ListNode dummyHead = new ListNode(0,head);
        ListNode temp = dummyHead;
        while(temp.next != null)
        {
            if(temp.next.val == val)
            {
                temp.next = temp.next.next;
            }
            else
            {
                temp = temp.next;
            }
        }
        return dummyHead.next;
    }
}
```

```ruby
# 定義鏈接串列節點
class ListNode
  attr_accessor :val, :next
  def initialize(val = 0, _next = nil)
    @val = val
    @next = _next
  end
end

# 刪除鏈接串列中值為 val 的節點
def remove_elements(head, val)
  # 建立一個 dummy head，這樣可以簡化刪除頭節點的處理
  # dummy head 的值為 0，指向當前鏈接串列的頭節點
  dummy = ListNode.new(0)
  dummy.next = head
  
  # 初始化當前節點為 dummy head
  current = dummy
  
  # 遍歷鏈接串列，直到當前節點的下一個節點為空
  while current.next
    # 如果當前節點的下一個節點的值等於 val
    if current.next.val == val
      # 跳過該節點，即將當前節點的 next 指向下一個節點的 next
      current.next = current.next.next
    else
      # 否則繼續遍歷，當前節點向前移動
      current = current.next
    end
  end
  
  # 回傳刪除 val 後的新鏈接串列的頭節點，dummy head 的 next 就是新的頭節點
  dummy.next
end
```
