### 遞迴（recursion）法

本題可以使用前序（preorder）（中左右），也可以使用後序遍歷（post-order traversal）（左右中），使用前序求的就是深度，使用後序求的是高度。

* 二元樹節點的深度：指從根節點到該節點的最長簡單路徑（simple path）邊（edge）的條數或者節點數（取決於深度從 0 開始還是從 1 開始）
* 二元樹節點的高度：指從該節點到葉節點的最長簡單路徑邊的條數或者節點數（取決於高度從 0 開始還是從 1 開始）

**而根節點的高度就是二元樹的最大深度**，所以本題中我們透過後序求得的根節點高度來求二元樹最大深度。

這一點其實是很多同學沒有想清楚的，很多題解同樣沒有講清楚。

我先用後序遍歷（左右中）來計算樹（tree）的高度。

1. 確定遞迴函式（function）的參數（parameter）和轉回值（return value）：參數就是傳入樹的根節點，回傳就回傳這棵樹的深度，所以轉回值為 int 類型。

程式碼如下：
```CPP
int getdepth(TreeNode* node)
```

2. 確定終止條件：如果為空節點的話，就回傳 0，表示高度為 0。

程式碼如下：
```CPP
if (node == NULL) return 0;
```

3. 確定單層遞迴的邏輯：先求它的左子樹（left subtree）的深度，再求右子樹（right subtree）的深度，最後取左右深度最大的數值，再 +1（加 1 是因為算上當前中間節點），就是目前節點為根節點的樹的深度。

程式碼如下：

```CPP
int leftdepth = getdepth(node->left);       // 左
int rightdepth = getdepth(node->right);     // 右
int depth = 1 + max(leftdepth, rightdepth); // 中
return depth;
```

所以整體 C++ 程式碼如下：

```CPP
class Solution {
public:
    int getdepth(TreeNode* node) {
        if (node == NULL) return 0;
        int leftdepth = getdepth(node->left);       // 左
        int rightdepth = getdepth(node->right);     // 右
        int depth = 1 + max(leftdepth, rightdepth); // 中
        return depth;
    }
    int maxDepth(TreeNode* root) {
        return getdepth(root);
    }
};
```

程式碼精簡之後 C++ 程式碼如下：
```CPP
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (root == null) return 0;
        return 1 + max(maxDepth(root->left), maxDepth(root->right));
    }
};

```

**精簡之後的程式碼根本看不出是哪種遍歷方式，也看不出遞迴三部曲的步驟，所以如果對二元樹的操作還不熟練，盡量不要直接照著精簡程式碼來學。**


本題當然也可以使用前序，程式碼如下：（**充分表現出求深度回溯（backtracking）的過程**）

```CPP
class Solution {
public:
    int result;
    void getdepth(TreeNode* node, int depth) {
        result = depth > result ? depth : result; // 中

        if (node->left == NULL && node->right == NULL) return ;

        if (node->left) { // 左
            depth++;    // 深度+1
            getdepth(node->left, depth);
            depth--;    // 回溯，深度-1
        }
        if (node->right) { // 右
            depth++;    // 深度+1
            getdepth(node->right, depth);
            depth--;    // 回溯，深度-1
        }
        return ;
    }
    int maxDepth(TreeNode* root) {
        result = 0;
        if (root == NULL) return result;
        getdepth(root, 1);
        return result;
    }
};
```

**可以看出使用了前序（中左右）的遍歷順序，這才是真正求深度的邏輯！**

注意以上程式碼是為了把細節體現出來，簡化一下程式碼如下：


### 疊代（iteration）法

使用疊代法的話，使用層次序走訪（level order traversal）是最為合適的，因為最大的深度就是二元樹的層數，和層次序走訪的方式極為吻合。

在二元樹中，一層一層地來遍歷二元樹，記錄一下遍歷的層數就是二元樹的深度，如圖所示：


![層次序走訪](https://file1.kamacoder.com/i/algo/20200810193056585.png)

所以這道題的疊代法就是一道模板（template）題，可以使用二元樹層次序走訪的模板來解決。

如果對層次序走訪還不清楚的話，可以看這篇：[二元樹：層次序走訪登場！](https://programmercarl.com/0102.二叉树的层序遍历.html)

C++ 程式碼如下：

```CPP
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (root == NULL) return 0;
        int depth = 0;
        queue<TreeNode*> que;
        que.push(root);
        while(!que.empty()) {
            int size = que.size();
            depth++; // 記錄深度
            for (int i = 0; i < size; i++) {
                TreeNode* node = que.front();
                que.pop();
                if (node->left) que.push(node->left);
                if (node->right) que.push(node->right);
            }
        }
        return depth;
    }
};
```

二元樹最大深度疊代
```c
int maxDepth(struct TreeNode* root){
    //若傳入根節點為 NULL，回傳 0
    if(!root)
        return 0;
    
    int depth = 0;
    //配置佇列空間
    struct TreeNode** queue = (struct TreeNode**)malloc(sizeof(struct TreeNode*) * 6000);
    int queueFront = 0;
    int queueEnd = 0;

    //將根節點入佇列
    queue[queueEnd++] = root;

    int queueSize;
    //求出當前佇列中元素個數
    while(queueSize = queueEnd - queueFront) {
        int i;
        //若當前佇列中節點有左右子樹，則將它們的左右子樹入佇列
        for(i = 0; i < queueSize; i++) {
            struct TreeNode* tempNode = queue[queueFront + i];
            if(tempNode->left)
                queue[queueEnd++] = tempNode->left;
            if(tempNode->right)
                queue[queueEnd++] = tempNode->right;
        }
        //更新佇列頭下標
        queueFront += queueSize;
        //深度+1
        depth++;
    }
    return depth;
}
```

```c
int maxDepth(struct TreeNode *root)
{
    if(root == NULL)
        return 0;
    struct TreeNode *stack[10000] = {};
    int top = -1;
    struct TreeNode *p = root, *r = NULL; // r 指向上一個被造訪的節點
    int depth = 0, maxDepth = -1;
    while(p != NULL || top >= 0)
    {
        if(p != NULL)
        {
            stack[++top] = p;
            depth++;
            p = p->left;
        }
        else
        {
            p = stack[top];
            if(p->right != NULL && p->right != r) // 右子樹未被造訪
                p = p->right;
            else
            {
                if(depth >= maxDepth) maxDepth = depth;
                p = stack[top--];
                depth--;
                r = p;
                p = NULL;
            }
        }
    }
    return maxDepth;
}
```
