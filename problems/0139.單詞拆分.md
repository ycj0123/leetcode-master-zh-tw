# 139.單字拆分

[LeetCode 題目連結](https://leetcode.cn/problems/word-break/)

給定一個非空字串（string） s 和一個包含非空單字的串列 wordDict，判定 s 是否可以被空白拆分為一個或多個在字典（dictionary）中出現的單字。

說明：

拆分時可以重複使用字典中的單字。

你可以假設字典中沒有重複的單字。

範例 1：
* 輸入: s = "leetcode", wordDict = ["leet", "code"]
* 輸出: true
* 解釋: 回傳 true 因為 "leetcode" 可以被拆分成 "leet code"。

範例 2：
* 輸入: s = "applepenapple", wordDict = ["apple", "pen"]
* 輸出: true
* 解釋: 回傳 true 因為 "applepenapple" 可以被拆分成 "apple pen apple"。
* 注意你可以重複使用字典中的單字。

範例 3：
* 輸入: s = "catsandog", wordDict = ["cats", "dog", "sand", "and", "cat"]
* 輸出: false

## 解題思路

看到這道題目的時候，大家應該回想起我們之前講解回溯（backtracking）專題的時候，講過的一道題目[回溯演算法（backtracking algorithm）：分割回文（palindrome）串](https://programmercarl.com/0131.分割回文串.html)，就是列舉（enumeration）字串的所有分割情況。

[回溯演算法：分割回文串](https://programmercarl.com/0131.分割回文串.html)：是列舉分割後的所有子字串（substring），判斷是否回文。

本道是列舉分割所有字串，判斷是否在字典裡出現過。

那麼這裡我也給出回溯法 C++ 程式碼：

```CPP
class Solution {
private:
    bool backtracking (const string& s, const unordered_set<string>& wordSet, int startIndex) {
        if (startIndex >= s.size()) {
            return true;
        }
        for (int i = startIndex; i < s.size(); i++) {
            string word = s.substr(startIndex, i - startIndex + 1);
            if (wordSet.find(word) != wordSet.end() && backtracking(s, wordSet, i + 1)) {
                return true;
            }
        }
        return false;
    }
public:
    bool wordBreak(string s, vector<string>& wordDict) {
        unordered_set<string> wordSet(wordDict.begin(), wordDict.end());
        return backtracking(s, wordSet, 0);
    }
};
```

* 時間複雜性（time complexity）：O(2^n)，因為每一個單字都有兩個狀態（state），切割和不切割
* 空間複雜度（space complexity）：O(n)，演算法遞迴（recursion）系統呼叫堆疊（call stack）的空間

那麼以上程式碼很明顯要逾時了，逾時的資料如下：

```
"aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaab"
["a","aa","aaa","aaaa","aaaaa","aaaaaa","aaaaaaa","aaaaaaaa","aaaaaaaaa","aaaaaaaaaa"]
```

遞迴的過程中有很多重複計算，可以使用陣列（array）保存一下遞迴過程中計算的結果。

這個叫做備忘（memoization）遞迴，這種方法我們之前已經提過很多次了。

使用 memory 陣列保存每次計算的以 startIndex 起始的計算結果，如果 memory[startIndex] 裡已經被賦值了，直接用 memory[startIndex] 的結果。

C++ 程式碼如下：

```CPP
class Solution {
private:
    bool backtracking (const string& s,
            const unordered_set<string>& wordSet,
            vector<bool>& memory,
            int startIndex) {
        if (startIndex >= s.size()) {
            return true;
        }
        // 如果memory[startIndex]不是初始值了，直接使用memory[startIndex]的結果
        if (!memory[startIndex]) return memory[startIndex];
        for (int i = startIndex; i < s.size(); i++) {
            string word = s.substr(startIndex, i - startIndex + 1);
            if (wordSet.find(word) != wordSet.end() && backtracking(s, wordSet, memory, i + 1)) {
                return true;
            }
        }
        memory[startIndex] = false; // 記錄以startIndex開始的子字串是不可以被拆分的
        return false;
    }
public:
    bool wordBreak(string s, vector<string>& wordDict) {
        unordered_set<string> wordSet(wordDict.begin(), wordDict.end());
        vector<bool> memory(s.size(), 1); // -1 表示初始化狀態
        return backtracking(s, wordSet, memory, 0);
    }
};
```

這個時間複雜性其實也是：O(2^n)。只不過對於上面那個逾時測試案例（test case）最佳化效果特別明顯。

**這個程式碼就可以 AC 了，當然回溯演算法不是本題的主菜，背包才是！**

### 背包問題（knapsack problem）

單字就是物品，字串 s 就是背包，單字能否組成字串 s，就是問物品能不能把背包裝滿。

拆分時可以重複使用字典中的單字，說明就是一個無界背包問題（unbounded knapsack problem）！

動態規劃（dynamic programming, DP）五部曲分析如下：

1. 確定 dp 陣列以及下標（subscript）的含義

**dp[i] : 字串長度為 i 的話，dp[i] 為 true，表示可以拆分為一個或多個在字典中出現的單字**。

2. 確定遞推公式

如果確定 dp[j] 是 true，且 [j, i] 這個區間（interval）的子字串出現在字典裡，那麼 dp[i] 一定是 true。（j < i ）。

所以遞推公式是 if([j, i] 這個區間的子字串出現在字典裡 && dp[j] 是 true) 那麼 dp[i] = true。

3. dp 陣列如何初始化（initialization）

從遞推公式中可以看出，dp[i] 的狀態依靠 dp[j] 是否為 true，那麼 dp[0] 就是遞推的根基，dp[0] 一定要為 true，否則遞推下去後面就都是 false 了。

那麼 dp[0] 有沒有意義呢？

dp[0] 表示如果字串為空的話，說明出現在字典裡。

但題目中說了「給定一個非空字串 s」所以測試資料（test data）中不會出現 i 為 0 的情況，那麼 dp[0] 初始化為 true 完全就是為了推導公式。

下標非 0 的 dp[i] 初始化為 false，只要沒有被覆蓋說明都是不可拆分為一個或多個在字典中出現的單字。

4. 確定遍歷（traversal）順序

題目中說是拆分為一個或多個在字典中出現的單字，所以這是無界背包問題。

還要討論兩層 for 迴圈（for-loop）的前後順序。

**如果求組合（combination）數就是外層 for 迴圈遍歷物品，內層 for 遍歷背包**。

**如果求排列（permutation）數就是外層 for 遍歷背包，內層 for 迴圈遍歷物品**。

我在這裡做一個總結：

求組合數：[動態規劃：518.零錢兌換II](https://programmercarl.com/0518.零钱兑换II.html)
求排列數：[動態規劃：377. 組合總和 Ⅳ](https://programmercarl.com/0377.组合总和.html)、[動態規劃：70. 爬樓梯進階版（無界背包問題）](https://programmercarl.com/0070.爬楼梯完全背包版本.html)
求最小數：[動態規劃：322. 零錢兌換](https://programmercarl.com/0322.零钱兑换.html)、[動態規劃：279.完全平方（perfect square）數](https://programmercarl.com/0279.完全平方数.html)

而本題其實我們求的是排列數，為什麼呢。拿 s = "applepenapple", wordDict = ["apple", "pen"] 舉例。

"apple", "pen" 是物品，那麼我們要求物品的組合一定是 "apple" + "pen" + "apple" 才能組成 "applepenapple"。

"apple" + "apple" + "pen" 或者 "pen" + "apple" + "apple" 是不可以的，那麼我們就是強調物品之間順序。

所以說，本題一定是先遍歷背包，再遍歷物品。

5. 舉例推導 dp[i]

以輸入: s = "leetcode", wordDict = ["leet", "code"] 為例，dp 狀態如圖：


![139.單詞拆分](https://file1.kamacoder.com/i/algo/20210202162652727.jpg)

dp[s.size()] 就是最終結果。

動態規劃五部曲分析完畢，C++ 程式碼如下：

```CPP
class Solution {
public:
    bool wordBreak(string s, vector<string>& wordDict) {
        unordered_set<string> wordSet(wordDict.begin(), wordDict.end());
        vector<bool> dp(s.size() + 1, false);
        dp[0] = true;
        for (int i = 1; i <= s.size(); i++) {   // 遍歷背包
            for (int j = 0; j < i; j++) {       // 遍歷物品
                string word = s.substr(j, i - j); //substr(起始位置，截取的個數)
                if (wordSet.find(word) != wordSet.end() && dp[j]) {
                    dp[i] = true;
                }
            }
        }
        return dp[s.size()];
    }
};
```

* 時間複雜性：O(n^3)，因為 substr 回傳子字串的複本是 O(n) 的複雜性（這裡的 n 是 substring 的長度）
* 空間複雜度：O(n)

## 拓展 

關於遍歷順序，再給大家講一下為什麼先遍歷物品再遍歷背包不行。

這裡可以給出先遍歷物品再遍歷背包的程式碼：

```CPP
class Solution {
public:
    bool wordBreak(string s, vector<string>& wordDict) {
        unordered_set<string> wordSet(wordDict.begin(), wordDict.end());
        vector<bool> dp(s.size() + 1, false);
        dp[0] = true;
        for (int j = 0; j < wordDict.size(); j++) { // 物品
            for (int i = wordDict[j].size(); i <= s.size(); i++) { // 背包
                string word = s.substr(i - wordDict[j].size(), wordDict[j].size());
                // cout << word << endl;
                if ( word == wordDict[j] && dp[i - wordDict[j].size()]) {
                    dp[i] = true;
                }
                // for (int k = 0; k <= s.size(); k++) cout << dp[k] << " "; //這裡印出 dp陣列的情況 
                // cout << endl;
            }
        }
        return dp[s.size()];

    }
};
```

使用案例：s = "applepenapple", wordDict = ["apple", "pen"]，對應的 dp 陣列狀態如下：

![](https://file1.kamacoder.com/i/algo/20240809155103.png)

最後 dp[s.size()] = 0 即 dp[13] = 0，而不是 1，因為先用 "apple" 去遍歷的時候，dp[8] 並沒有被賦值為 1（還沒用 "pen"），所以 dp[13] 也不能變成 1。

除非是先用 "apple" 遍歷一遍，再用 "pen" 遍歷，此時 dp[8] 已經是 1，最後再用 "apple" 去遍歷，dp[13] 才能是 1。

class Solution {
    private Set<String> set;
    private int[] memo;
    public boolean wordBreak(String s, List<String> wordDict) {
        memo = new int[s.length()];
        set = new HashSet<>(wordDict);
        return backtracking(s, 0);
    }

    public boolean backtracking(String s, int startIndex) {
        // System.out.println(startIndex);
        if (startIndex == s.length()) {
            return true;
        }
        if (memo[startIndex] == -1) {
            return false;
        }

        for (int i = startIndex; i < s.length(); i++) {
            String sub = s.substring(startIndex, i + 1);
	    // 拆分出來的單字無法匹配
            if (!set.contains(sub)) {
                continue;                
            }
            boolean res = backtracking(s, i + 1);
            if (res) return true;
        }
        // 這裡是關鍵，找遍了startIndex~s.length()也沒能完全匹配，標記從startIndex開始不能找到
        memo[startIndex] = -1;
        return false;
    }
}

class Solution:
    def backtracking(self, s: str, wordSet: set[str], startIndex: int) -> bool:
        # 邊界情況：已經遍歷到字串末尾，回傳True
        if startIndex >= len(s):
            return True

        # 遍歷所有可能的拆分位置
        for i in range(startIndex, len(s)):
            word = s[startIndex:i + 1]  # 截取子字串
            if word in wordSet and self.backtracking(s, wordSet, i + 1):
                # 如果截取的子字串在字典中，並且後續部分也可以被拆分成單字，回傳True
                return True

        # 無法進行有效拆分，回傳False
        return False

    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        wordSet = set(wordDict)  # 轉換為 hash set，提高查詢效率
        return self.backtracking(s, wordSet, 0)

class Solution(object):
    def wordBreak(self, s, wordDict):

        # 先對單字按長度排序
        wordDict.sort(key=lambda x: len(x))
        n = len(s)
        dp = [False] * (n + 1)
        dp[0] = True
        # 遍歷背包
        for i in range(1, n + 1):
            # 遍歷單字
            for word in wordDict:
                # 簡單的「修剪法」
                if len(word) > i:
                    break
                dp[i] = dp[i] or (dp[i - len(word)] and s[i - len(word): i] == word)
        return dp[-1]

	// 裝滿背包s的前幾位字元的方式有幾種
	dp := make([]int, len(s)+1)
	dp[0] = 1
	for i := 0; i <= len(s); i++ { // 背包
		for j := 0; j < len(wordDict); j++ { // 物品
			if i >= len(wordDict[j]) && wordDict[j] == s[i-len(wordDict[j]):i] {

function wordBreak(s: string, wordDict: string[]): boolean {
    // 只需要記憶結果為false的情況
    const memory: boolean[] = [];
    return backTracking(s, wordDict, 0, memory);
    function backTracking(s: string, wordDict: string[], startIndex: number, memory: boolean[]): boolean {
        if (startIndex >= s.length) return true;
        if (memory[startIndex] === false) return false;
        for (let i = startIndex + 1, length = s.length; i <= length; i++) {
            const str: string = s.slice(startIndex, i);
            if (wordDict.includes(str) && backTracking(s, wordDict, i, memory))
                return true;
        }
        memory[startIndex] = false;
        return false;
    }
};

bool wordBreak(char* s, char** wordDict, int wordDictSize) {
    int len = strlen(s);
    // 初始化
    bool dp[len + 1];
    memset(dp, false, sizeof (dp));
    dp[0] = true;
    for (int i = 1; i < len + 1; ++i) {
        for(int j =  0; j < wordDictSize; j++){
            int wordLen = strlen(wordDict[j]);
            // 分割點是由i和字典單字長度決定
            int k = i - wordLen;

                continue;

            dp[i] = (dp[k] && !strncmp(s + k, wordDict[j], wordLen)) || dp[i];
        }
    }
    return dp[len];
}
