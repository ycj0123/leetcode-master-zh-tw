# 100. 相同的樹

[LeetCode 題目連結](https://leetcode.cn/problems/same-tree/)

給定兩個二元樹（binary tree），編寫一個函式（function）來檢驗它們是否相同。

如果兩個樹在結構上相同，並且節點（node）具有相同的值（value），則認為它們是相同的。

## 解題思路

在[101. 對稱（symmetric）二元樹](https://programmercarl.com/0101.对称二叉树.html)中，我們講到對於二元樹是否對稱，要比較的是根節點（root node）的左子樹（left subtree）與右子樹（right subtree）是不是相互翻轉的，理解這一點就知道了**其實我們要比較的是兩個樹（這兩個樹是根節點的左右子樹）**，所以在遞迴（recursion）遍歷（traversal）的過程中，也是要同時遍歷兩棵樹。

理解這一本質之後，就會發現，求二元樹是否對稱，和求二元樹是否相同幾乎是同一道題目。

**如果沒有讀過[二元樹：我對稱嗎？](https://programmercarl.com/0101.对称二叉树.html)這一篇，請認真讀完再做這道題，就會有感覺了。**

遞迴三部曲中：

1. 確定遞迴函數（recursive function）的參數（parameter）和轉回值（return value）

我們要比較的是兩個樹是否是相互相同的，參數也就是兩個樹的根節點。

轉回值自然是 bool 類型。

程式碼如下：
```
bool compare(TreeNode* tree1, TreeNode* tree2)
```

分析過程同[101. 對稱二元樹](https://programmercarl.com/0101.对称二叉树.html)。

2. 確定終止條件（termination condition）

**要比較兩個節點數值相不相同，首先要把兩個節點為空的情況弄清楚！否則後面比較數值的時候就會操作空指標（null pointer）了。**

節點為空的情況有：

* tree1 為空，tree2 不為空，不對稱，return false
* tree1 不為空，tree2 為空，不對稱 return  false
* tree1、tree2 都為空，對稱，回傳 true

此時已經排除掉了節點為空的情況，那麼剩下的就是 tree1 和 tree2 不為空的時候：

* tree1、tree2 都不為空，比較節點數值，不相同就 return false

此時 tree1、tree2 節點不為空，且數值也不相同的情況我們也處理了。

程式碼如下：
```CPP
if (tree1 == NULL && tree2 != NULL) return false;
else if (tree1 != NULL && tree2 == NULL) return false;
else if (tree1 == NULL && tree2 == NULL) return true;
else if (tree1->val != tree2->val) return false; // 注意這裡我沒有使用 else
```

分析過程同[101. 對稱二元樹](https://programmercarl.com/0101.对称二叉树.html)

3. 確定單層遞迴的邏輯

* 比較二元樹是否相同：傳入的是 tree1 的左子節點（child node），tree2 的左子節點（原文誤寫為右孩子）。
* 如果左右都相同就回傳 true，有一側不相同就回傳 false。

程式碼如下：

```CPP
bool left = compare(tree1->left, tree2->left);   // 左子樹：左、 右子樹：左
bool right = compare(tree1->right, tree2->right);  // 左子樹：右、 右子樹：右
bool isSame = left && right;                    // 左子樹：中、 右子樹：中（邏輯處理）
return isSame;
```
最後遞迴的 C++ 整體程式碼如下：

```CPP
class Solution {
public:
    bool compare(TreeNode* tree1, TreeNode* tree2) {
        if (tree1 == NULL && tree2 != NULL) return false;
        else if (tree1 != NULL && tree2 == NULL) return false;
        else if (tree1 == NULL && tree2 == NULL) return true;
        else if (tree1->val != tree2->val) return false; // 注意這裡我沒有使用 else

        // 此時就是：左右節點都不為空，且數值相同的情況
        // 此時才做遞迴，做下一層的判斷
        bool left = compare(tree1->left, tree2->left);   // 左子樹：左、 右子樹：左
        bool right = compare(tree1->right, tree2->right);  // 左子樹：右、 右子樹：右
        bool isSame = left && right;                    // 左子樹：中、 右子樹：中（邏輯處理）
        return isSame;

    }
    bool isSameTree(TreeNode* p, TreeNode* q) {
        return compare(p, q);
    }
};
```


**我給出的程式碼並不簡潔，但是把每一步判斷的邏輯都清楚地描繪出來了。**

如果上來就看網上各種簡潔的程式碼，看起來真的很簡單，但是很多邏輯都掩蓋掉了，而題解可能也沒有把掩蓋掉的邏輯說清楚。

**盲目地照著抄，結果就是：發現這是一道「簡單題」，稀里糊塗地就過了，但是真正的每一步判斷邏輯未必想得清楚。**

當然我可以把如上程式碼整理如下：

### 遞迴

```CPP
class Solution {
public:
    bool compare(TreeNode* left, TreeNode* right) {
        if (left == NULL && right != NULL) return false;
        else if (left != NULL && right == NULL) return false;
        else if (left == NULL && right == NULL) return true;
        else if (left->val != right->val) return false;
        else return compare(left->left, right->left) && compare(left->right, right->right);

    }
    bool isSameTree(TreeNode* p, TreeNode* q) {
        return compare(p, q);
    }
};
```

### 疊代（iteration）法

```CPP
class Solution {
public:

    bool isSameTree(TreeNode* p, TreeNode* q) {
        if (p == NULL && q == NULL) return true;
        if (p == NULL || q == NULL) return false;
        queue<TreeNode*> que;
        que.push(p);   //  加入根節點 p
        que.push(q);  //  加入根節點 q
        while (!que.empty()) {  //
            TreeNode* leftNode = que.front(); que.pop();
            TreeNode* rightNode = que.front(); que.pop();
            if (!leftNode && !rightNode) {  // 若 p 的節點與 q 的節點都為空
                continue;
            }
            // 若 p 的節點與 q 的節點有一個為空或 p 的節點的值與 q 節點不同
            if ((!leftNode || !rightNode || (leftNode->val != rightNode->val))) {
                return false;
            }
            que.push(leftNode->left);   // 加入 p 節點的左子樹節點
            que.push(rightNode->left); // 加入 q 節點的左子樹節點
            que.push(leftNode->right);  // 加入 p 節點的右子樹節點
            que.push(rightNode->right);  // 加入 q 節點的右子樹節點
        }
        return true;
    }
};
```

var isSameTree = (p, q) => {
    const queue = [{ p, q }];
    // 這是用 { } 解決了 null 的問題！
    while (queue.length) {
        const cur = queue.shift();
        if (cur.p == null && cur.q == null) continue;
        if (cur.p == null || cur.q == null) return false;
        if (cur.p.val != cur.q.val) return false;

            q: cur.q.left

### TypeScript：

> 遞迴法-前序遍歷（preorder traversal）

```typescript
function isSameTree(p: TreeNode | null, q: TreeNode | null): boolean {
    if (p === null && q === null) return true;
    if (p === null || q === null) return false;
    if (p.val !== q.val) return false;
    return isSameTree(p.left, q.left) && isSameTree(p.right, q.right);
};
```

> 疊代法-層次序走訪（level order traversal）

```typescript
function isSameTree(p: TreeNode | null, q: TreeNode | null): boolean {
    const queue1: (TreeNode | null)[] = [],
        queue2: (TreeNode | null)[] = [];
    queue1.push(p);
    queue2.push(q);
    while (queue1.length > 0 && queue2.length > 0) {
        const node1 = queue1.shift(),
            node2 = queue2.shift();
        if (node1 === null && node2 === null) continue;
        if (
            (node1 === null || node2 === null) ||
            node1!.val !== node2!.val
        ) return false;
        queue1.push(node1!.left);
        queue1.push(node1!.right);
        queue2.push(node2!.left);
        queue2.push(node2!.right);
    }
    return true;
};
```
