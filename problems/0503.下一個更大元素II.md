# 503. 下一個更大元素 II

[LeetCode 題目連結](https://leetcode.cn/problems/next-greater-element-ii/)

給定一個循環陣列（array）（最後一個元素（element）的下一個元素是陣列的第一個元素），輸出每個元素的下一個更大元素。數字 x 的下一個更大的元素是按陣列遍歷（traversal）順序，這個數字之後的第一個比它更大的數，這意味著你應該循環地搜尋它的下一個更大的數。如果不存在，則輸出 -1。

範例 1:

* 輸入: [1,2,1]
* 輸出: [2,-1,2]
* 解釋: 第一個 1 的下一個更大的數是 2；數字 2 找不到下一個更大的數；第二個 1 的下一個最大的數需要循環搜尋，結果也是 2。

提示:

* 1 <= nums.length <= 10^4
* -10^9 <= nums[i] <= 10^9

## 解題思路

做本題之前建議先做[739. 每日溫度](https://programmercarl.com/0739.每日温度.html) 和 [496. 下一個更大元素 I](https://programmercarl.com/0496.下一个更大元素I.html)。

這道題和[739. 每日溫度](https://programmercarl.com/0739.每日温度.html)也幾乎如出一轍。

不過，本題要循環陣列了。

關於 monotonic stack 的講解我在題解[739. 每日溫度](https://programmercarl.com/0739.每日温度.html)中已經詳細講解了。

本篇我側重於說一說，如何處理循環陣列。

相信不少同學看到這道題，就想那我直接把兩個陣列拼接在一起，然後使用 monotonic stack 求下一個最大值不就行了！

確實可以！

將兩個 nums 陣列拼接在一起，使用 monotonic stack 計算出每一個元素的下一個最大值，最後再把結果集（result set）即 result 陣列 resize 到原陣列大小就可以了。

程式碼如下：

```CPP
// 版本一
class Solution {
public:
    vector<int> nextGreaterElements(vector<int>& nums) {
        // 拼接一個新的 nums
        vector<int> nums1(nums.begin(), nums.end());
        nums.insert(nums.end(), nums1.begin(), nums1.end());
        // 用新的 nums 大小來初始化 result
        vector<int> result(nums.size(), -1);
        if (nums.size() == 0) return result;

        // 開始 monotonic stack
        stack<int> st;
        st.push(0);
        for (int i = 1; i < nums.size(); i++) { 
            if (nums[i] < nums[st.top()]) st.push(i); 
            else if (nums[i] == nums[st.top()]) st.push(i);
            else { 
                while (!st.empty() && nums[i] > nums[st.top()]) {
                    result[st.top()] = nums[i];
                    st.pop();
                }
                st.push(i);
            }
        }
        // 最後再把結果集即 result 陣列 resize 到原陣列大小
        result.resize(nums.size() / 2);
        return result;
    }
};

```

這種寫法確實比較直觀，但做了很多無用操作，例如修改了 nums 陣列，而且最後還要把 result 陣列 resize 回去。

resize 倒是不費時間，是 O(1) 的操作，但擴充 nums 陣列相當於多了一個 O(n) 的操作。

其實也可以不擴充 nums，而是在遍歷的過程中模擬（simulation）走了兩遍 nums。

程式碼如下：

```CPP
// 版本二
class Solution {
public:
    vector<int> nextGreaterElements(vector<int>& nums) {
        vector<int> result(nums.size(), -1);
        if (nums.size() == 0) return result;
        stack<int> st;
        st.push(0);
        for (int i = 1; i < nums.size() * 2; i++) { 
            // 模擬遍歷兩遍 nums，注意一下都是用 i % nums.size() 來操作
            if (nums[i % nums.size()] < nums[st.top()]) st.push(i % nums.size());
            else if (nums[i % nums.size()] == nums[st.top()]) st.push(i % nums.size()); 
            else {
                while (!st.empty() && nums[i % nums.size()] > nums[st.top()]) {
                    result[st.top()] = nums[i % nums.size()];
                    st.pop();
                }
                st.push(i % nums.size());
            }
        }
        return result;
    }
};
```

可以看到版本二不僅程式碼精簡了，也比版本一少做了無用功！

最後再給出 monotonic stack 的精簡版本，即三種情況都做了合併的操作。


```Java 
class Solution {
    public int[] nextGreaterElements(int[] nums) {
        // 邊界判斷
        if(nums == null || nums.length <= 1) {
            return new int[]{-1};
        }
        int size = nums.length;
        int[] result = new int[size]; // 存放結果
        Arrays.fill(result,-1); // 預設全部初始化為 -1
        Stack<Integer> st= new Stack<>(); // 堆疊中存放的是 nums 中的元素下標
        for(int i = 0; i < 2*size; i++) {
            while(!st.empty() && nums[i % size] > nums[st.peek()]) {
                result[st.peek()] = nums[i % size]; // 更新 result
                st.pop(); // 彈出堆疊頂
            }
            st.push(i % size);
        }
        return result;
    }
```

```python
class Solution:
    def nextGreaterElements(self, nums: List[int]) -> List[int]:
        res = [-1] * len(nums)
        stack = []
        # 第一次遍歷 nums
        for i, num in enumerate(nums):   
            while stack and num > nums[stack[-1]]:
                res[stack[-1]] = num
                stack.pop()
            stack.append(i)
        # 此時 stack 仍有剩餘，有部分數「無下一個更大元素」待修正
        # 第二次遍歷 nums
        for num in nums:
            # 一旦 stack 為空，就表明所有數都有下一個更大元素，可以回傳結果    
            if not stack:   
                return res
            while stack and num > nums[stack[-1]]:
                res[stack[-1]] = num
                stack.pop()
            # 不要將已經有下一個更大元素的數加入堆疊，這樣會重複賦值，只需對第一次遍歷剩餘的數再嘗試尋找下一個更大元素即可
        # 最後仍有部分最大數無法有下一個更大元素，回傳結果
        return res  
```

```go
// 版本一
func nextGreaterElements(nums []int) []int {
    // 拼接一個新的 nums
    numsNew := make([]int, len(nums) * 2)
    copy(numsNew, nums)
    copy(numsNew[len(nums):], nums)
    // 用新的 nums 大小來初始化 result
    result := make([]int, len(numsNew))
    for i := range result {
        result[i] = -1
    }
    
    // 開始 monotonic stack
    st := []int{0}
    for i := 1; i < len(numsNew); i++ {
        if numsNew[i] < numsNew[st[len(st)-1]] {
            st = append(st, i)
        } else if numsNew[i] == numsNew[st[len(st)-1]] {
            st = append(st, i)
        } else {
            for len(st) > 0 && numsNew[i] > numsNew[st[len(st)-1]] {
                result[st[len(st)-1]] = numsNew[i]
                st = st[:len(st)-1]
            }
            st = append(st, i)
        }
    }
    result = result[:len(result)/2]
    return result
}
```

```go
    result := make([]int,length)

        result[i] = -1
```

```typescript
    const length: number = nums.length;
    const stack: number[] = [];
    stack.push(0);
    const resArr: number[] = new Array(length).fill(-1);
    for (let i = 1; i < length * 2; i++) {
```

```rust
impl Solution {
    pub fn next_greater_elements(nums: Vec<i32>) -> Vec<i32> {
        let mut ans = vec![-1; nums.len() * 2];
        let mut stack = vec![];
        let double = nums.repeat(2);
        for (idx, &i) in double.iter().enumerate() {
            while !stack.is_empty() && double[*stack.last().unwrap()] < i {
                let pos = stack.pop().unwrap();
                ans[pos] = i;
            }
            stack.push(idx);
        }
        ans.into_iter().take(nums.len()).collect()
    }
}
```

```rust
impl Solution {
    pub fn next_greater_elements(nums: Vec<i32>) -> Vec<i32> {
        let (mut stack, mut res) = (vec![], vec![-1; nums.len()]);

        for i in 0..nums.len() * 2 {
            while let Some(&top) = stack.last() {
                if nums[i % nums.len()] <= nums[top] {

                }
                let saved_index = stack.pop().unwrap();
```
