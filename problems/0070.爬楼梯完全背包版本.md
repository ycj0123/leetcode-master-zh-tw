# 70. 爬樓梯（進階版）

[KamaCoder：57. 爬樓梯](https://kamacoder.com/problempage.php?pid=1067)

假設你正在爬樓梯。需要 n 階你才能到達樓頂。

每次你可以爬至多 m (1 <= m < n) 個台階。你有多少種不同的方法可以爬到樓頂呢？

注意：給定 n 是一個正整數（positive integer）。 

輸入描述：輸入共一行，包含兩個正整數，分別表示 n, m 

輸出描述：輸出一個整數（integer），表示爬到樓頂的方法數。 

輸入範例：3 2 

輸出範例：3 

提示： 

當 m = 2，n = 3 時，n = 3 這表示一共有三個台階，m = 2 代表你每次可以爬一個台階或者兩個台階。

此時你有三種方法可以爬到樓頂。

* 1 階 + 1 階 + 1 階
* 1 階 + 2 階
* 2 階 + 1 階


## 解題思路

之前講這道題目的時候，因為還沒有講背包問題（knapsack problem），所以就只是講了一下爬樓梯最直接的動態規劃（dynamic programming, DP）方法（斐波那契）。

**這次終於講到了背包問題，我選擇帶錄友們再爬一次樓梯！**

這道題目我們在[動態規劃：爬樓梯](https://programmercarl.com/0070.爬楼梯.html)中已經講過一次了，這次我又給本題加點料，LeetCode 上沒有原題，所以可以在 KamaCoder [57. 爬樓梯](https://kamacoder.com/problempage.php?pid=1067)上來刷這道題目。

我們之前做的爬樓梯是只能至多爬兩個台階。

這次**改為：一步一個台階，兩個台階，三個台階，.......，直到 m 個台階。問有多少種不同的方法可以爬到樓頂呢？**

這又有難度了，這其實是一個無界背包問題（unbounded knapsack problem）。

1 階，2 階，.... m 階就是物品，樓頂就是背包。

每一階可以重複使用，例如跳了 1 階，還可以繼續跳 1 階。

問跳到樓頂有幾種方法其實就是問裝滿背包有幾種方法。

**此時大家應該發現這就是一個無界背包問題了！**

和昨天的題目[動態規劃：377. 組合（combination）總和 Ⅳ](https://programmercarl.com/0377.组合总和Ⅳ.html)基本就是一道題了。

DP五部曲分析如下：

1. 確定 dp 陣列（array）以及下標（subscript）的含義

**dp[i]：爬到有 i 個台階的樓頂，有 dp[i] 種方法**。

2. 確定遞迴公式（recurrence formula）

在[動態規劃：494.目標和](https://programmercarl.com/0494.目标和.html)、[動態規劃：518.零錢兌換II](https://programmercarl.com/0518.零钱兑换II.html)、[動態規劃：377. 組合總和 Ⅳ](https://programmercarl.com/0377.组合总和Ⅳ.html)中我們都講過了，求裝滿背包有幾種方法，遞迴公式一般都是 dp[i] += dp[i - nums[j]];

本題呢，dp[i] 有幾種來源，dp[i - 1]，dp[i - 2]，dp[i - 3] 等等，即：dp[i - j]

那麼遞迴公式為：dp[i] += dp[i - j]

3. dp 陣列如何初始化

既然遞迴公式是 dp[i] += dp[i - j]，那麼 dp[0] 一定為 1，dp[0] 是遞迴（recursion）中一切數值的基礎所在，如果 dp[0] 是 0 的話，其他數值都是 0 了。

下標非 0 的 dp[i] 初始化為 0，因為 dp[i] 是靠 dp[i-j] 累計上來的，dp[i] 本身為 0 這樣才不會影響結果

4. 確定遍歷（traversal）順序

這是背包裡求排列（permutation）問題，即：**1、2 步和 2、1 步都是上三個台階，但是這兩種方法不一樣！**

所以需將 target 放在外迴圈（loop），將 nums 放在內迴圈。

每一步可以走多次，這是無界背包問題，內迴圈需要從前向後遍歷。

5. 舉例來推導 dp 陣列

鑑於本題和[動態規劃：377. 組合總和 Ⅳ](https://programmercarl.com/0377.组合总和Ⅳ.html)幾乎是一樣的，這裡我就不再重複舉例了。


以上分析完畢，C++ 程式碼如下：
```CPP
#include <iostream>
#include <vector>
using namespace std;
int main() {
    int n, m;
    while (cin >> n >> m) {
        vector<int> dp(n + 1, 0);
        dp[0] = 1;
        for (int i = 1; i <= n; i++) { // 遍歷背包
            for (int j = 1; j <= m; j++) { // 遍歷物品
                if (i - j >= 0) dp[i] += dp[i - j];
            }
        }
        cout << dp[n] << endl;
    }
}
```

* 時間複雜度（time complexity）：O(n * m)
* 空間複雜度（space complexity）：O(n)

程式碼中 m 表示最多可以爬 m 個台階，程式碼中把 m 改成 2 就是 LeetCode：70.爬樓梯的解題思路。

**當然注意 LeetCode 是核心程式碼模式，KamaCoder 是 ACM 模式**

```Java
import java.util.Scanner;
class climbStairs{
    public static void main(String [] args){
        Scanner sc = new Scanner(System.in);
        int m, n;
        while (sc.hasNextInt()) {
            // 從鍵盤輸入參數，中間用空白隔開
            n = sc.nextInt();
            m = sc.nextInt();

            // 求排列問題，先遍歷背包再遍歷物品
            int[] dp = new int[n + 1];
            dp[0] = 1;
            for (int j = 1; j <= n; j++) {
                for (int i = 1; i <= m; i++) {
                    if (j - i >= 0) dp[j] += dp[j - i];
                }
            }
            System.out.println(dp[n]);
        }
    }
}
```

### Python3：
```python3
def climbing_stairs(n,m):
    dp = [0]*(n+1) # 背包總容量
    dp[0] = 1 
    # 排列題，注意迴圈順序，背包在外物品在內
    for j in range(1,n+1):
        for i in range(1,m+1):
            if j>=i:
                dp[j] += dp[j-i] # 這裡 i 就是重量而非 index
    return dp[n]

if __name__ == '__main__':
    n,m = list(map(int,input().split(' ')))
    print(climbing_stairs(n,m))
```

```go
import (

func climbStairs(n int, m int) int {
    dp := make([]int, n+1)
    dp[0] = 1
```
