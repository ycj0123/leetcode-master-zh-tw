# 堆疊與佇列理論基礎

我想堆疊（stack）和佇列（queue）的原理大家應該很熟悉了，佇列是先進先出（first in first out, FIFO），堆疊是先進後出（first in last out, FILO）。

如圖所示：

![堆疊與佇列理論1](https://file1.kamacoder.com/i/algo/20210104235346563.png) 

那麼我這裡再列出四個關於堆疊的問題，大家可以思考一下。以下是以 C++ 為例，使用其他程式設計語言（programming language）的同學也對應思考一下，自己使用的程式設計語言裡堆疊和佇列是什麼樣的。

1. C++ 中 stack 是容器（container）嗎？
2. 我們使用的 stack 是屬於哪個版本的 STL？
3. 我們使用的 STL 中 stack 是如何實作的？
4. stack 提供疊代器（iterator）來遍歷（traversal）stack 空間嗎？

相信這四個問題並不那麼好回答，因為一些同學使用資料結構（data structure）會停留在非常表面上的應用，稍稍往深一問，就會有好像懂，好像也不懂的感覺。

有的同學可能僅僅知道有堆疊和佇列這麼個資料結構，卻不知道底層實作，也不清楚所使用堆疊和佇列和 STL 是什麼關係。

所以這裡我再大家掃一遍基礎知識，

首先大家要知道堆疊和佇列是 STL（C++ 標準程式館（standard library））裡面的兩個資料結構。

C++ 標準程式館是有多個版本的，要知道我們使用的 STL 是哪個版本，才能知道對應的堆疊和佇列的實作原理。

那麼來介紹一下，三個最為普遍的 STL 版本：

1. HP STL
其他版本的 C++ STL，一般是以 HP STL 為藍本實作出來的，HP STL 是 C++ STL 的第一個實作版本，而且開放原始碼（open source）。

2. P.J.Plauger STL
由 P.J.Plauger 參照 HP STL 實作出來的，被 Visual C++ 編譯器（compiler）所採用，不是開放原始碼的。

3. SGI STL
由 Silicon Graphics Computer Systems 公司參照 HP STL 實作，被 Linux 的 C++ 編譯器 GCC 所採用，SGI STL 是開放原始碼軟體，原始碼（source code）可讀性（readability）甚高。

接下來介紹的堆疊和佇列也是 SGI STL 裡面的資料結構，知道了使用版本，才知道對應的底層實作。

來說一說堆疊，堆疊先進後出，如圖所示：


![堆疊與佇列理論2](https://file1.kamacoder.com/i/algo/20210104235434905.png) 

堆疊提供 push 和 pop 等等介面（interface），所有元素（element）必須符合先進後出規則，所以堆疊不提供走訪功能，也不提供疊代器（iterator）。不像是 set 或者 map 提供疊代器 iterator 來遍歷所有元素。

**堆疊是以底層容器完成其所有的工作，對外提供統一的介面，底層容器是可插拔的（也就是說我們可以控制使用哪種容器來實作堆疊的功能）。**

所以 STL 中堆疊往往不被歸類為容器，而被歸類為 container adapter。

那麼問題來了，STL 中堆疊是用什麼容器實作的？

從下圖中可以看出，堆疊的內部結構，堆疊的底層實作可以是 vector、deque、list 都是可以的，主要就是陣列（array）和鏈接串列（linked list）的底層實作。


![堆疊與佇列理論3](https://file1.kamacoder.com/i/algo/20210104235459376.png)

**我們常用的 SGI STL，如果沒有指定底層實作的話，預設是以 deque 為預設情況下堆疊的底層結構。**

deque 是一個雙端佇列（double-ended queue, deque），只要封住一端，只開通另一端就可以實作堆疊的邏輯了。

**SGI STL 中佇列底層實作預設情況下一樣使用 deque 實作的。**

我們也可以指定 vector 為堆疊的底層實作，初始化（initialization）語句如下：

```cpp
std::stack<int, std::vector<int> > third;  // 使用 vector 為底層容器的堆疊
```

剛剛講過堆疊的特性，對應的佇列的情況是一樣的。

佇列中先進先出的資料結構，同樣不允許有遍歷行為，不提供疊代器，**SGI STL 中佇列一樣是以 deque 為預設情況下的底部結構。**

也可以指定 list 為其底層實作，初始化 queue 的語句如下：

```cpp
std::queue<int, std::list<int>> third; // 定義以 list 為底層容器的佇列
```

所以 STL 佇列也不被歸類為容器，而被歸類為 container adapter。

我這裡講的都是 C++ 語言中的情況，使用其他語言的同學也要思考堆疊與佇列的底層實作問題，不要對資料結構的使用淺嘗輒止，而要深挖其內部原理，才能夯實基礎。
