
# 大廠技術面試流程和注意事項 

大型網路企業一般透過幾輪技術面試來考察大家的各項能力，一般流程如下：

* 第一關線上測驗：一般會考選擇題和程式設計題
* 第二關基礎演算法面試：就是基礎的演算法都是該專欄要講的
* 第三關綜合技術面試：會考察程式設計語言（programming language），計算機基礎知識，以及了解專案經歷等等
* 第四關技術主管面試：會問一些比較廣泛的內容，考察大家解決問題和快速學習的能力
* 最後 HR 面試：主要了解面試者與企業文化相不相符，面試者的職涯發展，offer 的選擇以及介紹一下企業提供的薪資待遇等等

並不是說一定是這五輪面試，不同的公司情況都不一樣，甚至同一個公司不同事業群面試的流程都是不一樣的

可能第一關和第二關放到一起，可能第三關和第四關放到一起，這裡盡量將各個維度拆開，讓同學們了解技術面試需要做哪方面的準備。

我們來逐一展開分析各個面試環節面試官是從哪些維度來考察大家的


## 第一關 線上測驗

第一關的話通常是選擇題 + 程式設計題，還有些公司線上測驗都是程式設計題。

* 選擇題：計算機基礎知識涉及電腦網路、作業系統、資料庫（database）、程式設計語言等等
* 程式設計題：一般是程式碼量比較大的題目

第一關線上測驗，**通常應屆畢業生的話，BAT 級別的企業都會提前發筆試題，寄到信箱裡然後指定時間內做完，一定要慎重對待，線上測驗沒有過，後面就沒有面試機會了**

線上測驗通常是 **選擇題 + 程式設計題，還有些公司線上測驗都是程式設計題**

選擇題則是計算機基礎知識涉及電腦網路、作業系統、資料庫、程式設計語言等等，這裡如果有些同學對計算機基礎心裡沒有底的話，可以去牛客網上找一找歷年各大公司的線上測驗題目找找感覺。

程式設計題則一般是程式碼量比較大的題目，圖（graph）、複雜資料結構或者一些模擬（simulation）類的題目，程式設計題目都是我們這門課程會講述的重點

所以也給同學們推薦一個程式設計學習的網站，也就是 LeetCode

LeetCode 是專門針對演算法練習的題庫，LeetCode 現在也推出了中文網站，所以更方便中文的演算法愛好者在上面刷題。這門課程也是主要在 LeetCode 上選擇經典題目。

牛客網上涉及到工程師面試的各個環節，有很多網路公司歷年面試的題目還是很不錯的。

**建議學習計算機基礎知識可以在牛客網上，刷演算法題可以選擇 LeetCode。**

## 第二關 基礎演算法面試

### 更注意考察的是思維方式

這一塊和線上測驗對演算法的考察又不一樣，線上測驗僅僅就是要一個結果，對了就是對了不對就是不對，

而第二關的演算法面試**面試官更想看到同學們的思考過程**，而不僅僅是一個答案。

通常第一關線上測驗的題目是程式碼量比較大的題目，而第二關則是一些基礎演算法

面試官會讓面試者在白紙上寫程式碼或者給面試者一台電腦來寫程式碼，

**一般面試官傾向於使用白紙，這樣更好看到同學們的思考方式**

### 應該用什麼語言寫演算法題呢？

應該用什麼語言寫演算法題呢？ **用自己最熟悉的語言，但最好是 Java 或者 C++**

如果不會 Java 或 C++ 的話，那更建議透過做演算法題，順便學習一下。

如果想在程式設計的路上走得更遠，掌握一門重型語言是十分重要的，學好了 C++ 或者 Java 再學腳本（script）語言會非常快，相當於降維打擊

反而如果只會腳本語言，工作之後再學習高階語言會很困難，很多東西會不理解。

所以這裡建議特別是應屆生，大家有時間就要打好語言的基礎，不要太迷信用 10 行程式碼呼叫一個套件（package）解決 100 行程式碼的事，

因為這樣也不會清楚省略掉的 90 行做了哪些工作。

這裡建議大家 **在打基礎的時候最好不要一開始就走捷徑。**

**簡單程式碼一定要可以手寫出來，不要過於依賴 IDE 的自動完成（autocomplete）。**

例如寫一個反轉（reverse）二元樹（binary tree）的函數（function），很多同學在刷了很多 LeetCode 上面的題目

但是 LeetCode 上一般都把二元樹的結構已經定義好了，所以可以上來直接寫函數的實作

但是面試的時候要在白紙上寫程式碼，一些同學一下子不知道二元樹的定義應該如何寫，不是結構體定義得不對，就是忘了如何寫指標（pointer）。

總之，錯漏百出。 **所以基本結構的定義以及程式碼一定要訓練在白紙上寫出來**

後面我在講解各個知識點的時候會再給同學們強調一遍哪些程式碼是一定要手寫出來的

## 第三關 綜合技術面試

綜合技術面試一般從如下三點考察大家。

### 程式設計語言

程式設計語言，這裡是面試官**考察程式設計語言掌握程度**，如果是 C++ 的話，會問 STL、繼承、多型、指標等等，這裡還可以問很多問題。

### 計算機基礎知識

**考察計算機方面的綜合知識**，這裡不同方向考察的側重點不一樣，如果是後端（back end）開發，Linux、TCP、處理程序（process）執行緒（thread）這些是一定要問的。

### 專案經驗

在專案經驗中面試官想考察什麼呢

專案經驗主要從這三方面進行考察 **技術原理、技術深度、應變能力**

考察技術原理，做了一個專案，是不是僅僅呼叫一下介面（interface）就完事，之後介面背後做了些什麼呢？這些還是要了解的

考察技術深度，如果是後端開發的話，可以從系統的擴容、快取（cache）、資料儲存等多方面進行考察

考察應變能力，如果面試官針對專案問同學們一個場景，**最為忌諱的回答是什麼？「我沒考慮過這種情況」。** 這會讓面試官對同學們的印象大打折扣。

這個時候，面試官最欣賞的候選人，就是儘管沒考慮過，但也會思考出一個方案，然後跟面試官進行討論。

最終討論出一個可行的方案，這會讓面試官對同學們的好感倍增。

通常應屆生沒有什麼專案經驗，特別是大學生，其實可以自己做一些小專案。

例如做一個可以連線的五子棋遊戲，這裡就涉及到了網路知識，可以結合著自己網路知識來介紹自己的專案。

已經工作的人，就要找出自己工作專案的亮點，其實一個專案不是每一個人都有機會參與核心的開發。

也不是每個人都有解決難題的機會，這也是我們在工作中遇到難點，要勇往直前的動力，因為這就是自己專案經驗最值錢的一部分。


## 第四關 技術主管面試

技術主管面試主要考察面試者兩個能力， **解決問題的能力和快速學習的能力**

### 考察解決問題的能力

面試官最喜歡問的相關問題:
* **在專案中遇到的最大的技術挑戰是什麼，而你是如何解決的**
* **給出一個專案問題來讓面試者分析**

如果你是學生，就會問在你學習中遇到哪些挑戰，這些都是面試官經常問的問題。

面試官可能還會給出一個具體的專案場景，問同學們如何去解決。

例如社群動態的後端設計，如果是你應該怎麼設計，這種問題大家也不必驚慌

因為面試官也知道你沒有設計過，所以大家只要大膽說出自己的設計方案就好

面試官會再進一步指引你的方案可能哪裡有問題，最終討論出一個看似合理的結果。

**這裡面試官考察的主要是針對專案問題，同學們是如何思考的，如何解決的。**

### 考察快速學習的能力

面試官最喜歡問的相關問題:
* **快速學習的能力 如何快速學習一門新的技術或者語言？**
* **讀研究所之後發現自己和大學畢業有什麼差別？**

再具體一點面試官會問，如果有個專案這兩天就要啟動，而這個專案使用了你沒有用過的語言或者技術，你將怎麼完成這個專案？

換句話說，面試官會問：你如何快速學習一門新的程式設計語言或技術，這裡同學們就要好好總結一下自己學習的技巧

如果你是研究生，面試官還喜歡問：讀研究所之後發現自己和大學畢業有什麼差別？

**這裡要體現出自己思維方式和學習方法上的進步，而不是用了兩三年的時間多學了哪些技術，因為網路產業是不斷變化的。**

面試官更喜歡考察的是同學們快速學習的能力。

## 第五關 HR 面試

終於到了 HR 面試了，大家是不是感覺萬事大吉了，這裡萬萬不可大意，否則到手的 offer 就飛掉了。

要知道 HR 那裡如果有十個名額，技術面試留給 HR 的人數通常是大於十個的，也就是 HR 有選擇權，HR 會選擇符合公司文化與價值觀的候選人。

這裡呢給大家列舉一些關鍵問題

### 為什麼選擇我們公司？

這個大家一定要有所準備，不能被問到了之後一臉茫然，然後說就是想找個工作，那基本就沒戲了

要從技術氛圍、職涯發展、公司潛力等等方面來說自己為什麼選擇這家公司

### 有沒有職涯規劃？

其實如果剛剛畢業並沒有明確的職涯規劃，這裡建議大家不要說自己想工作幾年想做專案經理、工作幾年想做產品經理的

這樣會被 HR 認為職涯規劃不清晰，盡量從技術的角度規劃自己。

### 是否接受加班？

雖然大家都不喜歡加班，但是這個問題我還是建議如果手頭沒有 offer 的話，大家盡量選擇接受

除非是超級高手手頭 N 多高薪 offer，可以直接說不接受，然後起身瀟灑離去

### 堅持最長的一件事情是什麼？

這裡大家最好之前就想好，有一些同學可能印象裡自己沒有堅持很長的事情，也沒有好好想過這個問題，在 HR 面試的時候被問到的時候，一臉茫然

憋了半天說出一個不痛不癢的事情。這就是一個減分項了

### 如果校園徵才，直接會問：期望薪資 XXX 是否接受？

這裡大家如果感覺自己表現得很好給面試官留下了很好的印象，**可以在這裡爭取 special offer，或者 ssp offer**

這都是可以的，但是要真的對自己信心十足。

### 如果社會徵才，則會了解前一家目前公司薪水多少？

**這裡大家切記不要虛報薪資，因為入職前是要查薪資轉帳紀錄的，這是比較嚴肅的問題。**

其實 HR 也不會只聊很嚴肅的話題，也會聊一聊家常之類的，問一問家在哪裡？再介紹一下公司薪酬福利待遇，這些就比較放鬆了

## 總結

這裡面試流程就是這樣了，還是那句話不是所有公司都按照這個流程來面試，但是如果是一線網路公司，一般都會從我說的這幾方面來考察大家
大家加油！
