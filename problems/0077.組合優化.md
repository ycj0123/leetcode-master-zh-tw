## 解題思路

在[回溯演算法（backtracking algorithm）：求組合問題！](https://programmercarl.com/0077.组合.html)中，我們透過回溯搜尋法，解決了 n 個數中求 k 個數的組合問題。

文中的回溯法（backtracking）是可以進行修剪最佳化的，本篇我們繼續來看一下題目 77. 組合。

連結：https://leetcode.cn/problems/combinations/

**看本篇之前，需要先看[回溯演算法：求組合問題！](https://programmercarl.com/0077.组合.html)**。

大家先回憶一下[77. 組合]給出的回溯法程式碼：

```CPP
class Solution {
private:
    vector<vector<int>> result; // 存放符合條件結果的集合
    vector<int> path; // 用來存放符合條件結果
    void backtracking(int n, int k, int startIndex) {
        if (path.size() == k) {
            result.push_back(path);
            return;
        }
        for (int i = startIndex; i <= n; i++) {
            path.push_back(i); // 處理節點
            backtracking(n, k, i + 1); // 遞迴
            path.pop_back(); // 回溯，撤銷處理的節點
        }
    }
public:
    vector<vector<int>> combine(int n, int k) {
        result.clear(); // 可以不寫
        path.clear();   // 可以不寫
        backtracking(n, k, 1);
        return result;
    }
};
```

## 修剪最佳化

我們說過，回溯法雖然是蠻力搜尋（brute force searching），但有時候也可以稍微進行修剪最佳化。

在遍歷（traversal）的過程中有如下程式碼：

```CPP
for (int i = startIndex; i <= n; i++) {
    path.push_back(i);
    backtracking(n, k, i + 1);
    path.pop_back();
}
```

這個遍歷的範圍是可以進行修剪最佳化的，怎麼最佳化呢？

來舉一個例子，n = 4，k = 4 的話，那麼第一層 for 迴圈（for-loop）的時候，從元素（element） 2 開始的遍歷都沒有意義了。在第二層 for 迴圈，從元素 3 開始的遍歷都沒有意義了。

這麼說有點抽象，如圖所示：

![77.組合4](https://file1.kamacoder.com/i/algo/20210130194335207.png)


圖中每一個節點（node）（圖中為矩形（rectangle）），就代表本層的一個 for 迴圈，那麼每一層的 for 迴圈從第二個數開始遍歷的話，都沒有意義，都是無效遍歷。

**所以，可以修剪的地方就在遞迴（recursion）中每一層的 for 迴圈所選擇的起始位置**。

**如果 for 迴圈選擇的起始位置之後的元素個數已經不足我們需要的元素個數了，那麼就沒有必要搜尋了**。

注意程式碼中 i，就是 for 迴圈裡選擇的起始位置。
```CPP
for (int i = startIndex; i <= n; i++) {
```

接下來看一下最佳化過程如下：

1. 已經選擇的元素個數：path.size();

2. 還需要的元素個數為: k - path.size();

3. 列表中剩餘元素（n-i） >= 還需要的元素個數（k - path.size()）

4. 在集合（set） n 中至多要從該起始位置 : i <= n - (k - path.size()) + 1，開始遍歷

為什麼有個 +1 呢，因為包括起始位置，我們需要的是一個左閉的集合。

舉個例子，n = 4，k = 3，目前已經選取的元素為 0（path.size 為 0），n - (k - 0) + 1 即 4 - ( 3 - 0) + 1 = 2。

從 2 開始搜尋都是合理的，可以是組合 [2, 3, 4]。

這裡大家想不懂的話，建議也舉一個例子，就知道是不是要 +1 了。

所以最佳化之後的 for 迴圈是：

```CPP
for (int i = startIndex; i <= n - (k - path.size()) + 1; i++) // i 為本次搜尋的起始位置
```

最佳化後整體程式碼如下：

```CPP
class Solution {
private:
    vector<vector<int>> result;
    vector<int> path;
    void backtracking(int n, int k, int startIndex) {
        if (path.size() == k) {
            result.push_back(path);
            return;
        }
        for (int i = startIndex; i <= n - (k - path.size()) + 1; i++) { // 最佳化的地方
            path.push_back(i); // 處理節點
            backtracking(n, k, i + 1);
            path.pop_back(); // 回溯，撤銷處理的節點
        }
    }
public:

    vector<vector<int>> combine(int n, int k) {
        backtracking(n, k, 1);
        return result;
    }
};
```
* 時間複雜性（time complexity）: O(n * 2^n)
* 空間複雜度（space complexity）: O(n)



## 總結

本篇我們針對求組合問題的回溯法程式碼做了修剪最佳化，這個最佳化如果不畫圖的話，其實不好理解，也不好講清楚。

所以我依然是把整個回溯過程抽象為一棵樹狀結構（tree structure），這樣就可以直觀地看出，修剪究竟是剪在哪裡。

```java
class Solution {
    List<List<Integer>> result = new ArrayList<>();
    LinkedList<Integer> path = new LinkedList<>();
    public List<List<Integer>> combine(int n, int k) {
        combineHelper(n, k, 1);
        return result;
    }

    /**
     * 每次從集合中選取元素，可選擇的範圍隨著選擇的進行而收縮，調整可選擇的範圍，就是要靠 startIndex
     * @param startIndex 用來記錄本層遞迴中，集合從哪裡開始遍歷（集合就是 [1,...,n] ）。
     */
    private void combineHelper(int n, int k, int startIndex){
        //終止條件
        if (path.size() == k){
            result.add(new ArrayList<>(path));
            return;
        }
        for (int i = startIndex; i <= n - (k - path.size()) + 1; i++){
            path.add(i);
            combineHelper(n, k, i + 1);
            path.removeLast();
        }
    }
}
```

### C

```c
int* path;
int pathTop;
int** ans;
int ansTop;

void backtracking(int n, int k,int startIndex) {
    //當 path 中元素個數為 k 個時，我們需要將 path 陣列放入 ans 二維陣列中
    if(pathTop == k) {
        //path 陣列為我們動態配置，若直接將其位址放入二維陣列，path 陣列中的值會隨著我們回溯而逐漸變化
        //因此建立新的陣列儲存 path 中的值
        int* temp = (int*)malloc(sizeof(int) * k);
        int i;
        for(i = 0; i < k; i++) {
            temp[i] = path[i];
        }
        ans[ansTop++] = temp;
        return ;
    }

    int j;
    for(j = startIndex; j <= n- (k - pathTop) + 1;j++) {
        //將目前節點放入 path 陣列
        path[pathTop++] = j;
        //進行遞迴
        backtracking(n, k, j + 1);
        //進行回溯，將陣列最上層節點彈出
        pathTop--;
    }
}

int** combine(int n, int k, int* returnSize, int** returnColumnSizes){
    //path 陣列儲存符合條件的結果
    path = (int*)malloc(sizeof(int) * k);
    //ans 二維陣列儲存符合條件的結果陣列的集合。（陣列足夠大，避免極端情況）
    ans = (int**)malloc(sizeof(int*) * 10000);
    pathTop = ansTop = 0;

    //回溯演算法
    backtracking(n, k, 1);
    //最後的回傳大小為 ans 陣列大小
    *returnSize = ansTop;
    //returnColumnSizes 陣列儲存 ans 二維陣列對應下標中一維陣列的長度（都為 k）
    *returnColumnSizes = (int*)malloc(sizeof(int) *(*returnSize));
    int i;
    for(i = 0; i < *returnSize; i++) {
        (*returnColumnSizes)[i] = k;
    }
    //回傳 ans 二維陣列
    return ans;
}
```

### Swift

```swift
func combine(_ n: Int, _ k: Int) -> [[Int]] {
    var path = [Int]()
    var result = [[Int]]()
    func backtracking(start: Int) {
        // 結束條件，並收集結果
        if path.count == k {
            result.append(path)
            return
        }

        // 單層邏輯
        // let end = n
        // 修剪最佳化
        let end = n - (k - path.count) + 1
        guard start <= end else { return }
        for i in start ... end {
            path.append(i) // 處理節點
            backtracking(start: i + 1) // 遞迴
            path.removeLast() // 回溯
        }
    }

    backtracking(start: 1)
    return result
}
```

### Scala

```scala
object Solution {
  import scala.collection.mutable // 匯入套件
  def combine(n: Int, k: Int): List[List[Int]] = {
    var result = mutable.ListBuffer[List[Int]]() // 存放結果集
    var path = mutable.ListBuffer[Int]() //存放符合條件的結果

    def backtracking(n: Int, k: Int, startIndex: Int): Unit = {
      if (path.size == k) {
        // 如果 path 的 size == k 就達到題目要求，添加到結果集，並回傳
        result.append(path.toList)
        return
      }
      // 修剪最佳化
      for (i <- startIndex to (n - (k - path.size) + 1)) { 
        path.append(i) // 先把數字添加進去
        backtracking(n, k, i + 1) // 進行下一步回溯
        path = path.take(path.size - 1) // 回溯完再刪除掉剛剛添加的數字
      }
    }

    backtracking(n, k, 1) // 執行回溯
    result.toList // 最終回傳 result 的 List 形式，return 關鍵字可以省略
  }
}
```
