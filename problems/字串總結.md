# 字串（string）：總結篇

其實我們已經學習了十天的字串了，從字串的定義到程式館函數（library function）的使用原則，從各種反轉（reverse）到 KMP 演算法（KMP algorithm），相信大家應該對字串有比較深刻的認識了。 

那麼這次我們來做一個總結。

## 什麼是字串

字串是若干字元（character）組成的有限序列（sequence），也可以理解為是一個字元陣列（character array），但是很多語言對字串做了特殊的規定，接下來我來說一說 C/C++ 中的字串。

在 C 語言中，把一個字串存入一個陣列（array）時，也把結束符號 '\0' 存入陣列，並以此作為該字串是否結束的旗標（flag）。

例如這段程式碼：

```
char a[5] = "asd";
for (int i = 0; a[i] != '\0'; i++) {
}
```

在 C++ 中，提供一個 string 類別（class），string 類別會提供 size 介面（interface），可以用來判斷 string 類別字串是否結束，就不用 '\0' 來判斷是否結束。

例如這段程式碼：

```
string a = "asd";
for (int i = 0; i < a.size(); i++) {
}
```

那麼 vector< char > 和 string 又有什麼區別呢？ 

其實在基本操作上沒有區別，但是 string 提供更多的字串處理的相關介面，例如 string 重載（overload）了 +，而 vector 卻沒有。

所以想處理字串，我們還是會定義一個 string 類型。


## 要不要使用程式館函數 

在文章[344.反轉字串](https://programmercarl.com/0344.反转字符串.html)中強調了**打基礎的時候，不要太迷戀於程式館函數。**

甚至一些同學習慣於呼叫 substr、split、reverse 之類的程式館函數，卻不知道其實作原理，也不知道其時間複雜度（time complexity），這樣實作出來的程式碼，如果在面試現場，面試官問：「分析其時間複雜度」的話，一定會一臉懵逼！

所以建議**如果題目關鍵的部分直接用程式館函數就可以解決，建議不要使用程式館函數。**

**如果程式館函數僅僅是 解題過程中的一小部分，並且你已經很清楚這個程式館函數的內部實作原理的話，可以考慮使用程式館函數。**

## 雙指標（two pointers） 法


在[344.反轉字串](https://programmercarl.com/0344.反转字符串.html)，我們使用 雙指標 法實作了反轉字串的操作，**雙指標 法在陣列，鏈接串列（linked list）和字串中很常用。**

接著在[字串：替換空白](https://programmercarl.com/剑指Offer05.替换空格.html)，同樣還是使用 雙指標 法在時間複雜度 O(n) 的情況下完成替換空白。

**其實很多陣列填充類的問題，都可以先預先給陣列擴容到填充後的大小，然後再從後向前進行操作。**

那麼針對陣列刪除（delete）操作的問題，其實在[27. 移除元素](https://programmercarl.com/0027.移除元素.html)中就已經提到了使用 雙指標 法進行移除操作。

同樣的道理在[151.翻轉字串裡的單字](https://programmercarl.com/0151.翻转字符串里的单词.html)中我們使用 O(n) 的時間複雜度，完成了刪除冗餘（redundant）空白。

一些同學會使用 for 迴圈（for-loop）裡呼叫程式館函數 erase 來移除元素（element），這其實是 O(n^2) 的操作，因為 erase 就是 O(n) 的操作，所以這也是典型的不知道程式館函數的時間複雜度，上來就用的案例了。

## 反轉系列

在反轉上還可以加一些玩法，其實考察的是對程式碼的掌控能力。

[541. 反轉字串 II](https://programmercarl.com/0541.反转字符串II.html)中，一些同學可能為了處理邏輯：每隔 2k 個字元的前 k 個字元，寫了一堆邏輯程式碼或者再搞一個計數器（counter），來統計 2k，再統計前 k 個字元。 

其實**當需要固定規律一段一段去處理字串的時候，要想一想在 for 迴圈的表式（expression）上做做文章**。

只要讓 i += (2 * k)，i 每次移動 2 * k 就可以了，然後判斷是否需要有反轉的區間（interval）。

因為要找的也就是每 2 * k 區間的起點，這樣寫程式會高效很多。

在[151.翻轉字串裡的單字](https://programmercarl.com/0151.翻转字符串里的单词.html)中要求翻轉字串裡的單字，這道題目可以說是綜合考察了字串的多種操作。是考察字串的好題。

這道題目透過 **先整體反轉再局部反轉**，實作了反轉字串裡的單字。

後來發現反轉字串還有一個厲害的用處，就是達到左旋的效果。

在[字串：反轉個字串還有這個用處？](https://programmercarl.com/剑指Offer58-II.左旋转字符串.html)中，我們透過**先局部反轉再整體反轉**達到了左旋的效果。

## KMP 

KMP 的主要想法是**當出現字串不匹配時，可以知道一部分之前已經匹配的文字內容，可以利用這些資訊避免從頭再去做匹配了。**

KMP 的精髓所在就是前綴（prefix）表，在[KMP 精講](https://programmercarl.com/0028.实现strStr.html)中提到了，什麼是 KMP，什麼是前綴表，以及為什麼要用前綴表。

前綴表：起始位置到下標（subscript） i 之前（包括 i）的子字串（substring）中，有多大長度的相同前綴尾綴（suffix）。

那麼使用 KMP 可以解決兩類經典問題：

1. 匹配問題：[28. 實作 strStr()](https://programmercarl.com/0028.实现strStr.html)
2. 重複子字串問題：[459.重複的子字串](https://programmercarl.com/0459.重复的子字符串.html)

再一次強調了什麼是前綴，什麼是尾綴，什麼又是最長相等前後綴。

前綴：指不包含最後一個字元的所有以第一個字元開頭的連續子字串。

尾綴：指不包含第一個字元的所有以最後一個字元結尾的連續子字串。

然後**針對前綴表到底要不要減一，這其實是不同 KMP 實作的方式**，我們在[KMP 精講](https://programmercarl.com/0028.实现strStr.html)中針對之前兩個問題，分別給出了兩個不同版本的 KMP 實作。

其中主要**理解 j=next[x] 這一步最為關鍵！**
