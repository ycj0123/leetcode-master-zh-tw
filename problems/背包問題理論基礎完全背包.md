# 無界背包問題（unbounded knapsack problem）理論基礎 - 二維（two-dimensional）DP 陣列（array）

本題 LeetCode 上沒有原題，大家可以去[KamaCoder 第 52 題](https://kamacoder.com/problempage.php?pid=1052)練習，題意是一樣的。

## 無界背包問題

有 N 件物品和一個最多能背重量為 W 的背包。第 i 件物品的重量是 weight[i]，得到的價值是 value[i]。**每件物品都有無限個（也就是可以放入背包多次）**，求解將哪些物品裝入背包裡物品價值總和最大。

**無界背包和 0/1 背包問題（0/1 knapsack problem）唯一不同的地方就是，每種物品有無限件**。

同樣 LeetCode 上沒有純無界背包問題，都是需要無界背包的各種應用，需要轉化成無界背包問題，所以我這裡還是以純無界背包問題進行講解理論和原理。

在下面的講解中，我拿下面資料舉例子：

背包最大重量為 4，物品為：

|       | 重量 | 價值 |
| ----- | ---- | ---- |
| 物品0 | 1    | 15   |
| 物品1 | 3    | 20   |
| 物品2 | 4    | 30   |

**每件商品都有無限個！**

問背包能背的物品最大價值是多少？

**如果沒看到之前的 0/1 背包講解，一定要先仔細看如下兩篇，0/1 背包是基礎，本篇在講解無界背包，之前的背包基礎我將不會重複講解**。

* [0/1 背包理論基礎（二維陣列）](https://programmercarl.com/背包理论基础01背包-1.html)
* [0/1 背包理論基礎（一維陣列（one dimensional array））](https://programmercarl.com/背包理论基础01背包-2.html)

動態規劃（dynamic programming, DP）五部曲分析無界背包，為了從原理上講清楚，我們先從二維 dp 陣列分析：

### 1. 確定 dp 陣列以及下標（subscript）的含義

**dp[i][j] 表示從下標為 [0-i] 的物品，每個物品可以取無限次，放進容量為 j 的背包，價值總和最大是多少**。

很多讀者／錄友也會疑惑，憑什麼上來就定義 dp 陣列，思考過程是什麼樣的，這個思考過程我在 [0/1 背包理論基礎（二維陣列）](https://programmercarl.com/背包理论基础01背包-1.html) 中的「確定 dp 陣列以及下標的含義」有詳細講解。


### 2. 確定遞迴公式（recurrence formula）

這裡再把基本資訊給出來：

|       | 重量 | 價值 |
| ----- | ---- | ---- |
| 物品0 | 1    | 15   |
| 物品1 | 3    | 20   |
| 物品2 | 4    | 30   |

對於遞迴公式，首先我們要明確有哪些方向可以推導出 dp[i][j]。

這裡依然拿 dp[1][4] 的狀態（state）來舉例：（[0/1 背包理論基礎（二維陣列）](https://programmercarl.com/背包理论基础01背包-1.html) 中也是這個例子，要注意下面的不同之處）

求取 dp[1][4] 有兩種情況：

1. 放物品 1
2. 還是不放物品 1

如果不放物品 1，那麼背包的價值應該是 dp[0][4]，即容量為 4 的背包，只放物品 0 的情況。

推導方向如圖：

![](https://file1.kamacoder.com/i/algo/20241126112952.png)

如果放物品 1，**那麼背包要先留出物品 1 的容量**，目前容量是 4，物品 1 的容量（就是物品 1 的重量）為 3，此時背包剩下容量為 1。

容量為 1，只考慮放物品 0 和物品 1 的最大價值是 dp[1][1]，**注意這裡和 [0/1 背包理論基礎（二維陣列）](https://programmercarl.com/背包理论基础01背包-1.html) 有所不同了**！

在 [0/1 背包理論基礎（二維陣列）](https://programmercarl.com/背包理论基础01背包-1.html) 中，背包先空留出物品 1 的容量，此時容量為 1，只考慮放物品 0 的最大價值是 dp[0][1]，**因為 0/1 背包每個物品只有一個，既然空出物品 1，那背包中也不會再有物品 1**！

而在無界背包中，物品是可以放無限個，所以即使空出物品 1 空間重量，那背包中也可能還有物品 1，所以此時我們依然考慮放物品 0 和物品 1 的最大價值即：**dp[1][1]，而不是 dp[0][1]**

所以放物品 1 的情況 = dp[1][1] + 物品 1 的價值，推導方向如圖：

![](https://file1.kamacoder.com/i/algo/20241126113104.png)


（**注意上圖和 [0/1 背包理論基礎（二維陣列）](https://programmercarl.com/背包理论基础01背包-1.html) 中的區別**，對於理解無界背包很重要）

兩種情況，分別是放物品 1 和不放物品 1，我們要取最大值（畢竟求的是最大價值）

`dp[1][4] = max(dp[0][4], dp[1][1] + 物品1 的價值) `

以上過程，抽象化如下：

* **不放物品 i**：背包容量為 j，裡面不放物品 i 的最大價值是 dp[i - 1][j]。

* **放物品 i**：背包空出物品 i 的容量後，背包容量為 j - weight[i]，dp[i][j - weight[i]] 為背包容量為 j - weight[i] 且不放物品 i 的最大價值，那麼 dp[i][j - weight[i]] + value[i]（物品 i 的價值），就是背包放物品 i 得到的最大價值

遞迴公式：`dp[i][j] = max(dp[i - 1][j], dp[i][j - weight[i]] + value[i]);`

（注意，無界背包二維 dp 陣列和 0/1 背包二維 dp 陣列遞迴公式的區別，0/1 背包中是 `dp[i - 1][j - weight[i]] + value[i])`）

### 3. dp 陣列如何初始化（initialization）

**關於初始化，一定要和 dp 陣列的定義吻合，否則到遞迴公式的時候就會越來越亂**。

首先從 dp[i][j] 的定義出發，如果背包容量 j 為 0 的話，即 dp[i][0]，無論是選取哪些物品，背包價值總和一定為 0。如圖：

![動態規劃-背包問題2](https://file1.kamacoder.com/i/algo/2021011010304192.png)

再看其他情況。

狀態變遷方程式（state transition equation）`dp[i][j] = max(dp[i - 1][j], dp[i][j - weight[i]] + value[i]);` 可以看出有一個方向 i 是由 i-1 推導出來，那麼 i 為 0 的時候就一定要初始化。

dp[0][j]，即：存放編號 0 的物品的時候，各個容量的背包所能存放的最大價值。

那麼很明顯當 `j < weight[0]` 的時候，dp[0][j] 應該是 0，因為背包容量比編號 0 的物品重量還小。

當 `j >= weight[0]` 時，**dp[0][j] 如果能放下 weight[0] 的話，就一直裝，每一種物品有無限個**。

程式碼初始化如下：

```CPP
for (int i = 1; i < weight.size(); i++) {  // 當然這一步，如果把 dp 陣列預先初始化為 0 了，這一步就可以省略，但很多同學應該沒有想清楚這一點。
    dp[i][0] = 0;
}

// 正序遍歷，如果能放下就一直裝物品 0
for (int j = weight[0]; j <= bagWeight; j++)
    dp[0][j] = dp[0][j - weight[0]] + value[0];
```

（注意上面初始化和 [0/1 背包理論基礎（二維陣列）](https://programmercarl.com/背包理论基础01背包-1.html) 的區別在於物品有無限個）


此時 dp 陣列初始化情況如圖所示：

![](https://file1.kamacoder.com/i/algo/20241114161608.png)

dp[0][j] 和 dp[i][0] 都已經初始化了，那麼其他下標應該初始化多少呢？

其實從遞迴公式：dp[i][j] = max(dp[i - 1][j], dp[i][j - weight[i]] + value[i]); 可以看出 dp[i][j] 是由上方和左方數值推導出來的，那麼其他下標初始為什麼數值都可以，因為都會被覆蓋。

但只不過一開始就統一把 dp 陣列初始為 0，更方便一些。

最後初始化程式碼如下：

```CPP
// 初始化 dp
vector<vector<int>> dp(weight.size(), vector<int>(bagweight + 1, 0));
for (int j = weight[0]; j <= bagWeight; j++) {
    dp[0][j] = dp[0][j - weight[0]] + value[0]; 
}
```


### 4. 確定遍歷（traversal）順序

[0/1 背包理論基礎（二維陣列）](https://programmercarl.com/背包理论基础01背包-1.html) 中我們講過，0/1 背包二維 DP 陣列，先遍歷物品還是先遍歷背包都是可以的。

因為兩種遍歷順序，對於二維 dp 陣列來說，遞迴公式所需要的值，二維 dp 陣列裡對應的位置都有。

詳細可以看 [0/1 背包理論基礎（二維陣列）](https://programmercarl.com/背包理论基础01背包-1.html) 中的 【遍歷順序】的講解

所以既可以先遍歷物品再遍歷背包：

```CPP 
for (int i = 1; i < n; i++) { // 遍歷物品
    for(int j = 0; j <= bagWeight; j++) { // 遍歷背包容量
        if (j < weight[i]) dp[i][j] = dp[i - 1][j];
        else dp[i][j] = max(dp[i - 1][j], dp[i][j - weight[i]] + value[i]);
    }
}
```

也可以先遍歷背包再遍歷物品：

```CPP  
for(int j = 0; j <= bagWeight; j++) { // 遍歷背包容量
    for (int i = 1; i < n; i++) { // 遍歷物品
        if (j < weight[i]) dp[i][j] = dp[i - 1][j];
        else dp[i][j] = max(dp[i - 1][j], dp[i][j - weight[i]] + value[i]);
    }
}
```

### 5. 舉例推導 dp 陣列

以本篇舉例資料為例，填滿了 dp 二維陣列如圖：

![](https://file1.kamacoder.com/i/algo/20241126113752.png)

因為物品 0 的 CP 值（性價比）是最高的，而且在無界背包中，每一類物品都有無限個，所以有無限個物品 0，既然物品 0 CP 值最高，當然是優先放物品 0。


### 本題程式碼：


```CPP 
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, bagWeight;
    int w, v;
    cin >> n >> bagWeight;
    vector<int> weight(n);
    vector<int> value(n);
    for (int i = 0; i < n; i++) {
        cin >> weight[i] >> value[i];
    }

    vector<vector<int>> dp(n, vector<int>(bagWeight + 1, 0));

    // 初始化
    for (int j = weight[0]; j <= bagWeight; j++)
        dp[0][j] = dp[0][j - weight[0]] + value[0];

    for (int i = 1; i < n; i++) { // 遍歷物品
        for(int j = 0; j <= bagWeight; j++) { // 遍歷背包容量
            if (j < weight[i]) dp[i][j] = dp[i - 1][j];
            else dp[i][j] = max(dp[i - 1][j], dp[i][j - weight[i]] + value[i]);
        }
    }

    cout << dp[n - 1][bagWeight] << endl;

    return 0;
}

```

```Java 
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int bagWeight = scanner.nextInt();

        int[] weight = new int[n];
        int[] value = new int[n];

        for (int i = 0; i < n; i++) {
            weight[i] = scanner.nextInt();
            value[i] = scanner.nextInt();
        }

        int[][] dp = new int[n][bagWeight + 1];

        // 初始化
        for (int j = weight[0]; j <= bagWeight; j++) {
            dp[0][j] = dp[0][j - weight[0]] + value[0];
        }

        // 動態規劃
        for (int i = 1; i < n; i++) {
            for (int j = 0; j <= bagWeight; j++) {
                if (j < weight[i]) {
                    dp[i][j] = dp[i - 1][j];
                } else {
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - weight[i]] + value[i]);
                }
            }
        }

        System.out.println(dp[n - 1][bagWeight]);
        scanner.close();
    }
}
```

### Python 

```python 
def knapsack(n, bag_weight, weight, value):
    dp = [[0] * (bag_weight + 1) for _ in range(n)]

    # 初始化
    for j in range(weight[0], bag_weight + 1):
        dp[0][j] = dp[0][j - weight[0]] + value[0]

    # 動態規劃
    for i in range(1, n):
        for j in range(bag_weight + 1):
            if j < weight[i]:
                dp[i][j] = dp[i - 1][j]
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - weight[i]] + value[i])

    return dp[n - 1][bag_weight]

# 輸入
n, bag_weight = map(int, input().split())
weight = []
value = []
for _ in range(n):
    w, v = map(int, input().split())
    weight.append(w)
    value.append(v)

# 輸出結果
print(knapsack(n, bag_weight, weight, value))

```
