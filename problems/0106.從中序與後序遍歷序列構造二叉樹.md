## 解題思路

首先回憶一下如何根據兩個順序構造一個唯一的二元樹，相信理論知識大家應該都清楚，就是以後序陣列（array）的最後一個元素作為切割點，先切中序陣列，根據中序陣列，反過來再切後序陣列。一層一層切下去，每次後序陣列最後一個元素就是節點（node）元素。

如果讓我們肉眼看兩個序列，畫一棵二元樹的話，應該輕輕鬆鬆就能畫出來。

流程如圖：

![106.從中序與後序遍歷序列構造二元樹](https://file1.kamacoder.com/i/algo/20210203154249860.png)

那麼程式碼應該怎麼寫呢？

說到一層一層切割，就應該想到了遞迴（recursion）。

來看一下一共分幾步：

* 第一步：如果陣列大小為零的話，說明是空節點了。

* 第二步：如果不為空，那麼取後序陣列最後一個元素作為節點元素。

* 第三步：找到後序陣列最後一個元素在中序陣列的位置，作為切割點

* 第四步：切割中序陣列，切成中序左陣列和中序右陣列 （順序別搞反了，一定是先切中序陣列）

* 第五步：切割後序陣列，切成後序左陣列和後序右陣列

* 第六步：遞迴處理左區間（interval）和右區間

不難寫出如下程式碼：（先把框架（framework）寫出來）

```CPP
TreeNode* traversal (vector<int>& inorder, vector<int>& postorder) {

    // 第一步
    if (postorder.size() == 0) return NULL;

    // 第二步：後序遍歷陣列最後一個元素，就是目前的中間節點
    int rootValue = postorder[postorder.size() - 1];
    TreeNode* root = new TreeNode(rootValue);

    // 葉節點
    if (postorder.size() == 1) return root;

    // 第三步：找切割點
    int delimiterIndex;
    for (delimiterIndex = 0; delimiterIndex < inorder.size(); delimiterIndex++) {
        if (inorder[delimiterIndex] == rootValue) break;
    }

    // 第四步：切割中序陣列，得到中序左陣列和中序右陣列
    // 第五步：切割後序陣列，得到後序左陣列和後序右陣列

    // 第六步
    root->left = traversal(中序左陣列, 後序左陣列);
    root->right = traversal(中序右陣列, 後序右陣列);

    return root;
}
```

**難點大家應該發現了，就是如何切割，以及邊界（boundary）值找不好很容易混亂。**

此時應該注意確定切割的標準，是左閉右開，還有左開右閉，還是左閉右閉，這個就是不變量（invariant），要在遞迴中保持這個不變量。

**在切割的過程中會產生四個區間，把握不好不變量的話，一會兒左閉右開，一會兒左閉右閉，必然混亂！**

我在[陣列：每次遇到二分法，都是一看就會，一寫就廢](https://programmercarl.com/0035.搜索插入位置.html)和[陣列：這個迴圈（loop）可以轉暈很多人！](https://programmercarl.com/0059.螺旋矩阵II.html)中都強調過 loop invariant 的重要性，在二元搜尋（binary search）以及螺旋（spiral）矩陣（matrix）的求解中，堅持 loop invariant 非常重要，本題也是。


首先要切割中序陣列，為什麼先切割中序陣列呢？

切割點在後序陣列的最後一個元素，就是用這個元素來切割中序陣列的，所以必須先切割中序陣列。

中序陣列相對比較好切，找到切割點（後序陣列的最後一個元素）在中序陣列的位置，然後切割，如下程式碼中我堅持左閉右開的原則：


```CPP
// 找到中序橫過的切割點
int delimiterIndex;
for (delimiterIndex = 0; delimiterIndex < inorder.size(); delimiterIndex++) {
    if (inorder[delimiterIndex] == rootValue) break;
}

// 左閉右開區間：[0, delimiterIndex)
vector<int> leftInorder(inorder.begin(), inorder.begin() + delimiterIndex);
// [delimiterIndex + 1, end)
vector<int> rightInorder(inorder.begin() + delimiterIndex + 1, inorder.end() );
```

接下來就要切割後序陣列了。

首先後序陣列的最後一個元素肯定不能要了，這是切割點，也是目前二元樹中間節點的元素，已經用過了。

後序陣列的切割點怎麼找？

後序陣列沒有明確的切割元素來進行左右切割，不像中序陣列有明確的切割點，切割點左右分開就可以了。

**此時有一個很重要的點，就是中序陣列大小一定是和後序陣列的大小相同的（這是必然）。**

中序陣列我們都切成了左中序陣列和右中序陣列了，那麼後序陣列就可以按照左中序陣列的大小來切割，切成左後序陣列和右後序陣列。

程式碼如下：

```CPP
// postorder 捨棄末尾元素，因為這個元素就是中間節點，已經用過了
postorder.resize(postorder.size() - 1);

// 左閉右開，注意這裡使用了左中序陣列大小作為切割點：[0, leftInorder.size)
vector<int> leftPostorder(postorder.begin(), postorder.begin() + leftInorder.size());
// [leftInorder.size(), end)
vector<int> rightPostorder(postorder.begin() + leftInorder.size(), postorder.end());
```

此時，中序陣列切成了左中序陣列和右中序陣列，後序陣列切割成左後序陣列和右後序陣列。

接下來可以遞迴了，程式碼如下：

```CPP
root->left = traversal(leftInorder, leftPostorder);
root->right = traversal(rightInorder, rightPostorder);
```

完整程式碼如下：

```CPP
class Solution {
private:
    TreeNode* traversal (vector<int>& inorder, vector<int>& postorder) {
        if (postorder.size() == 0) return NULL;

        // 後序遍歷陣列最後一個元素，就是目前的中間節點
        int rootValue = postorder[postorder.size() - 1];
        TreeNode* root = new TreeNode(rootValue);

        // 葉節點
        if (postorder.size() == 1) return root;

        // 找到中序橫過的切割點
        int delimiterIndex;
        for (delimiterIndex = 0; delimiterIndex < inorder.size(); delimiterIndex++) {
            if (inorder[delimiterIndex] == rootValue) break;
        }

        // 切割中序陣列
        // 左閉右開區間：[0, delimiterIndex)
        vector<int> leftInorder(inorder.begin(), inorder.begin() + delimiterIndex);
        // [delimiterIndex + 1, end)
        vector<int> rightInorder(inorder.begin() + delimiterIndex + 1, inorder.end() );

        // postorder 捨棄末尾元素
        postorder.resize(postorder.size() - 1);

        // 切割後序陣列
        // 依然左閉右開，注意這裡使用了左中序陣列大小作為切割點
        // [0, leftInorder.size)
        vector<int> leftPostorder(postorder.begin(), postorder.begin() + leftInorder.size());
        // [leftInorder.size(), end)
        vector<int> rightPostorder(postorder.begin() + leftInorder.size(), postorder.end());

        root->left = traversal(leftInorder, leftPostorder);
        root->right = traversal(rightInorder, rightPostorder);

        return root;
    }
public:
    TreeNode* buildTree(vector<int>& inorder, vector<int>& postorder) {
        if (inorder.size() == 0 || postorder.size() == 0) return NULL;
        return traversal(inorder, postorder);
    }
};
```

```CPP
class Solution {
private:
    // 中序區間：[inorderBegin, inorderEnd)，後序區間[postorderBegin, postorderEnd)
    TreeNode* traversal (vector<int>& inorder, int inorderBegin, int inorderEnd, vector<int>& postorder, int postorderBegin, int postorderEnd) {
        if (postorderBegin == postorderEnd) return NULL;

        int rootValue = postorder[postorderEnd - 1];
        TreeNode* root = new TreeNode(rootValue);

        if (postorderEnd - postorderBegin == 1) return root;

        int delimiterIndex;
        for (delimiterIndex = inorderBegin; delimiterIndex < inorderEnd; delimiterIndex++) {
            if (inorder[delimiterIndex] == rootValue) break;
        }
        // 切割中序陣列
        // 左中序區間，左閉右開[leftInorderBegin, leftInorderEnd)
        int leftInorderBegin = inorderBegin;
        int leftInorderEnd = delimiterIndex;
        // 右中序區間，左閉右開[rightInorderBegin, rightInorderEnd)
        int rightInorderBegin = delimiterIndex + 1;
        int rightInorderEnd = inorderEnd;

        // 切割後序陣列
        // 左後序區間，左閉右開[leftPostorderBegin, leftPostorderEnd)
        int leftPostorderBegin =  postorderBegin;
        int leftPostorderEnd = postorderBegin + delimiterIndex - inorderBegin; // 終止位置需要加上中序區間的大小 size
        // 右後序區間，左閉右開[rightPostorderBegin, rightPostorderEnd)
        int rightPostorderBegin = postorderBegin + (delimiterIndex - inorderBegin);
        int rightPostorderEnd = postorderEnd - 1; // 排除最後一個元素，已經作為節點了

        root->left = traversal(inorder, leftInorderBegin, leftInorderEnd,  postorder, leftPostorderBegin, leftPostorderEnd);
        root->right = traversal(inorder, rightInorderBegin, rightInorderEnd, postorder, rightPostorderBegin, rightPostorderEnd);

        return root;
    }
public:
    TreeNode* buildTree(vector<int>& inorder, vector<int>& postorder) {
        if (inorder.size() == 0 || postorder.size() == 0) return NULL;
        // 左閉右開的原則
        return traversal(inorder, 0, inorder.size(), postorder, 0, postorder.size());
```

```CPP
        int rightPreorderEnd = preorderEnd;

        root->left = traversal(inorder, leftInorderBegin, leftInorderEnd,  preorder, leftPreorderBegin, leftPreorderEnd);
        root->right = traversal(inorder, rightInorderBegin, rightInorderEnd, preorder, rightPreorderBegin, rightPreorderEnd);

        return root;
    }

public:
    TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
        if (inorder.size() == 0 || preorder.size() == 0) return NULL;

        // 參數堅持左閉右開的原則
        return traversal(inorder, 0, inorder.size(), preorder, 0, preorder.size());
    }
};
```

## 思考題

前序和中序可以唯一確定一棵二元樹。

後序和中序可以唯一確定一棵二元樹。

那麼前序和後序可不可以唯一確定一棵二元樹呢？

**前序和後序不能唯一確定一棵二元樹！**因為沒有中序橫過就無法確定左右部分，也就是無法分割。

舉一個例子：

![106.從中序與後序遍歷序列構造二元樹2](https://file1.kamacoder.com/i/algo/20210203154720326.png)

tree1 的前序遍歷是 [1 2 3]，後序遍歷是 [3 2 1]。

tree2 的前序遍歷是 [1 2 3]，後序遍歷是 [3 2 1]。

那麼 tree1 和 tree2 的前序和後序完全相同，這是一棵樹嗎，很明顯是兩棵樹！

所以前序和後序不能唯一確定一棵二元樹！

```go
func rebuild(inorder []int, postorder []int, rootIdx int, l, r int) *TreeNode {
    if l > r {    // 說明沒有元素，回傳空樹
        return nil
    }
    if l == r {  // 只剩唯一一個元素，直接回傳
        return &TreeNode{Val : inorder[l]}
    }
    rootV := postorder[rootIdx]  // 根據後序陣列找到根節點的值
    rootIn := hash[rootV]        // 找到根節點在對應的中序陣列中的位置
    root := &TreeNode{Val : rootV}   // 構造根節點
    // 重建左節點和右節點
    root.Left = rebuild(inorder, postorder, rootIdx-(r-rootIn)-1, l, rootIn-1)
    root.Right = rebuild(inorder, postorder, rootIdx-1, rootIn+1, r)
    return root
}
```

```go
    }

        return root
    }

            break;
        }

    // 左閉右開區間：[0, delimiterIndex)
    leftInorder := inorder[:delimiterIndex]
    // [delimiterIndex + 1, end)
    rightInorder := inorder[delimiterIndex+1:]

    // [len(leftInorder), end)
    rightPostorder := postorder[len(leftInorder):]
    
    root.Left = buildTree(leftInorder, leftPostorder)
    root.Right = buildTree(rightInorder, rightPostorder)
```

```typescript
        postBegin: number, postEnd: number
```

```c
    int index;
    for(index = 0; index < inorderSize; index++) {
        if(inorder[index] == rootValue)
            break;
    }
    int leftNum = index;
    int rightNum = inorderSize - index - 1;

    int* leftInorder = inorder;
    int* rightInorder = inorder + leftNum + 1;

    // 4.根據中序橫過陣列左右陣列的各自大小切割前序遍歷陣列。也分為左右陣列
    int* leftPreorder = preorder+1;
    int* rightPreorder = preorder + 1 + leftNum;

    // 5.遞迴進入左右陣列，將回傳的結果作為根節點的左右孩子
    root->left = buildTree(leftPreorder, leftNum, leftInorder, leftNum);
    root->right = buildTree(rightPreorder, rightNum, rightInorder, rightNum);

    // 6.回傳根節點
    return root;
}
```

```swift
    func buildTree(_ preorder: [Int], _ inorder: [Int]) -> TreeNode? {

                      preorderBegin: 0,

                      inorder: inorder,

    func helper(preorder: [Int], preorderBegin: Int, preorderEnd: Int, inorder: [Int], inorderBegin: Int, inorderEnd: Int) -> TreeNode? {
        if preorderBegin == preorderEnd {
            return nil
        }

        // 前序遍歷陣列的第一個元素作為分割點
        let rootValue = preorder[preorderBegin]
        let root = TreeNode(rootValue)


        if preorderEnd - preorderBegin == 1 {
            return root
        }

        var index = 0 // 從中序橫過陣列中找到根節點的下標
        if let ind = inorder.firstIndex(of: rootValue) {
            index = ind
        }

        // 遞迴
        root.left = helper(preorder: preorder,
                           preorderBegin: preorderBegin + 1,
                           preorderEnd: preorderBegin + 1 + index - inorderBegin,
                           inorder: inorder,
                           inorderBegin: inorderBegin,
                           inorderEnd: index)
        root.right = helper(preorder: preorder,
                            preorderBegin: preorderBegin + 1 + index - inorderBegin,
                            preorderEnd: preorderEnd,
                            inorder: inorder,
                            inorderBegin: index + 1,
                            inorderEnd: inorderEnd)
        return root
    }
```

```scala
    var len = inorder.size
    if (len == 0) return null
    // 2、後序陣列的最後一個元素是目前根元素
    var rootValue = postorder(len - 1)
    var root: TreeNode = new TreeNode(rootValue, null, null)
    if (len == 1) return root   // 如果陣列只有一個節點，就直接回傳

    root.left = buildTree(inorder.slice(0, delimiterIndex), postorder.slice(0, delimiterIndex))
    root.right = buildTree(inorder.slice(delimiterIndex + 1, len), postorder.slice(delimiterIndex, len - 1))
    root   // 回傳 root，return 關鍵字可以省略
  }
}
```
