# 第18題. 四數之和

[LeetCode 題目連結](https://leetcode.com/problems/4sum/)

題意：給定一個包含 n 個整數（integer）的陣列（array）nums 和一個目標值 target，判斷 nums 中是否存在四個元素（element）a、b、c 和 d，使得 a + b + c + d 的值與 target 相等？找出所有滿足條件且不重複的四元組（quadruple）。

**注意：**

答案中不可以包含重複的四元組。

範例：
給定陣列 nums = [1, 0, -1, 0, -2, 2]，和 target = 0。
滿足要求的四元組集合（set）為：
[
  [-1,  0, 0, 1],
  [-2, -1, 1, 2],
  [-2,  0, 0, 2]
]

## 解題思路

四數之和，和 [15.三數之和](./0015.三數之和.md) 是相同的解題思路，都是使用雙指標（two pointers）法，基本解法就是在 [15.三數之和](./0015.三數之和.md) 的基礎上再套一層 for 迴圈（for-loop）。

但是有一些細節需要注意，例如：不要判斷 `nums[k] > target` 就回傳了，三數之和可以透過 `nums[i] > 0` 就回傳了，因為 0 已經是確定的數了，四數之和這道題目 target 是任意值。比如：陣列是 `[-4, -3, -2, -1]`，`target` 是 `-10`，不能因為 `-4 > -10` 而跳過。但是我們依舊可以去做修剪法，邏輯變成 `nums[k] > target && (nums[k] >=0 || target >= 0)` 就可以了。

[15.三數之和](./0015.三數之和.md) 的雙指標解法是一層 for 迴圈 `num[i]` 為確定值，然後迴圈內有 left 和 right 下標（subscript）作為雙指標，找到 `nums[i] + nums[left] + nums[right] == 0`。

四數之和的雙指標解法是兩層 for 迴圈 `nums[k] + nums[i]` 為確定值，依然是迴圈內有 left 和 right 下標作為雙指標，找出 `nums[k] + nums[i] + nums[left] + nums[right] == target` 的情況，三數之和的時間複雜度（time complexity）是 O(n^2)，四數之和的時間複雜度是 O(n^3)。

那麼一樣的道理，五數之和、六數之和等等都採用這種解法。

對於 [15.三數之和](./0015.三數之和.md) 雙指標法就是將原本蠻力（brute force）O(n^3) 的解法，降為 O(n^2) 的解法，四數之和的雙指標解法就是將原本蠻力 O(n^4) 的解法，降為 O(n^3) 的解法。

之前我們講過雜湊表（hash table）的經典題目：[454.四數相加II](./0454.四數相加II.md)，相對於本題簡單很多，因為本題是要求在一個集合中找出四個數相加等於 target，同時四元組不能重複。

而 [454.四數相加II](./0454.四數相加II.md) 是四個獨立的陣列，只要找到 `A[i] + B[j] + C[k] + D[l] = 0` 就可以，不用考慮有重複的四個元素相加等於 0 的情況，所以相對於本題還是簡單了不少！

C++ 程式碼

```CPP
class Solution {
public:
    vector<vector<int>> fourSum(vector<int>& nums, int target) {
        vector<vector<int>> result;
        sort(nums.begin(), nums.end());
        for (int k = 0; k < nums.size(); k++) {
            // 修剪法處理
            if (nums[k] > target && nums[k] >= 0) {
            	break; // 這裡使用 break，統一透過最後的 return 回傳
            }
            // 對 nums[k] 去重複
            if (k > 0 && nums[k] == nums[k - 1]) {
                continue;
            }
            for (int i = k + 1; i < nums.size(); i++) {
                // 2 級修剪法處理
                if (nums[k] + nums[i] > target && nums[k] + nums[i] >= 0) {
                    break;
                }

                // 對 nums[i] 去重複
                if (i > k + 1 && nums[i] == nums[i - 1]) {
                    continue;
                }
                int left = i + 1;
                int right = nums.size() - 1;
                while (right > left) {
                    // nums[k] + nums[i] + nums[left] + nums[right] > target 會溢位
                    if ((long) nums[k] + nums[i] + nums[left] + nums[right] > target) {
                        right--;
                    // nums[k] + nums[i] + nums[left] + nums[right] < target 會溢位
                    } else if ((long) nums[k] + nums[i] + nums[left] + nums[right]  < target) {
                        left++;
                    } else {
                        result.push_back(vector<int>{nums[k], nums[i], nums[left], nums[right]});
                        // 對 nums[left] 和 nums[right] 去重複
                        while (right > left && nums[right] == nums[right - 1]) right--;
                        while (right > left && nums[left] == nums[left + 1]) left++;

                        // 找到答案時，two pointers 同時收縮
                        right--;
                        left++;
                    }
                }

            }
        }
        return result;
    }
};


```

* 時間複雜度：O(n^3)
* 空間複雜度（space complexity）：O(1)


## 補充

二級修剪法的部分：

```C++ 
if (nums[k] + nums[i] > target && nums[k] + nums[i] >= 0) {
    break;
}
```

可以最佳化為：

```C++ 
if (nums[k] + nums[i] > target && nums[i] >= 0) {
    break;
}
```

因為只要 `nums[k] + nums[i] > target`，那麼 `nums[i]` 後面的數都是正數的話，就一定不符合條件了。

不過這種修剪法其實有點小繞，大家能夠理解文章給的完整程式碼的修剪法就夠了。

```C
    int a = *(int *)arg1;
    int b = *(int *)arg2;

int** fourSum(int* nums, int numsSize, int target, int* returnSize, int** returnColumnSizes) {

    /* 對 nums 陣列進行排序 */
    qsort(nums, numsSize, sizeof(int), cmp);

    int **res = (int **)malloc(sizeof(int *) * 40000);
    int index = 0;

    /* k */
    for (int k = 0; k < numsSize - 3; k++) { /* 第一級 */

        /* k 修剪 */
        if ((nums[k] > target) && (nums[k] >= 0)) {
            break;
        }
        /* k 去重複 */
        if ((k > 0) && (nums[k] == nums[k - 1])) {
            continue;
        }

        /* i */
        for (int i = k + 1; i < numsSize - 2; i++) { /* 第二級 */

            /* i 修剪 */
            if ((nums[k] + nums[i] > target) && (nums[i] >= 0)) {
                break;
            }
            /* i 去重複 */
            if ((i > (k + 1)) && (nums[i] == nums[i - 1])) {
                continue;
            }

            /* left and right */
            int left = i + 1;
            int right = numsSize - 1;

            while (left < right) {

                /* 防止大數溢位 */
                long long val = (long long)nums[k] + nums[i] + nums[left] + nums[right];
                if (val > target) {
                    right--;
                } else if (val < target) {
                    left++;
                } else {
                    int *res_tmp = (int *)malloc(sizeof(int) * 4);
                    res_tmp[0] = nums[k];
                    res_tmp[1] = nums[i];
                    res_tmp[2] = nums[left];
                    res_tmp[3] = nums[right];
                    res[index++] = res_tmp;
                    
                    /* right 去重複 */
                    while ((right > left) && (nums[right] == nums[right - 1])) {
                        right--;
                    }
                    /* left 去重複 */
                    while ((left < right) && (nums[left] == nums[left + 1])) {
                        left++;
                    }

                    /* 更新 right 與 left */
                    left++, right--;
                }
            }
        }
    }

    /* 回傳值處理 */
    *returnSize = index;

    int *column = (int *)malloc(sizeof(int) * index);
    for (int i = 0; i < index; i++) {
        column[i] = 4;
    }
    *returnColumnSizes = column;
    return res;
}
```

```python
class Solution(object):
    def fourSum(self, nums, target):
        """
        :type nums: List[int]
        :type target: int
        :rtype: List[List[int]]
        """
        # 建立一個字典來儲存輸入列表中每個數字的頻率
        freq = {}
        for num in nums:
            freq[num] = freq.get(num, 0) + 1
        
        # 建立一個集合來儲存最終答案，並遍歷 4 個數字的所有唯一組合
        ans = set()
        for i in range(len(nums)):
            for j in range(i + 1, len(nums)):
                for k in range(j + 1, len(nums)):
                    val = target - (nums[i] + nums[j] + nums[k])
                    if val in freq:
                        # 確保沒有重複
                        count = (nums[i] == val) + (nums[j] == val) + (nums[k] == val)
                        if freq[val] > count:
                            ans.add(tuple(sorted([nums[i], nums[j], nums[k], val])))
        
        return [list(x) for x in ans]
```

```typescript
function fourSum(nums: number[], target: number): number[][] {
    nums.sort((a, b) => a - b);
    let first: number = 0,
        second: number,
        third: number,
        fourth: number;
    let length: number = nums.length;
    let resArr: number[][] = [];
    for (; first < length; first++) {
        if (first > 0 && nums[first] === nums[first - 1]) {
            continue;
        }
        for (second = first + 1; second < length; second++) {

                } else if (total < target) {
                    third++;
                } else {
                    fourth--;
                }
            }
        }
    }
```

```csharp
                            left++;
                        }

                        while (left < right && nums[right] == n4)
                        {
                            right--;
                        }
                    }
                }
            }
        }

        return result;
    }
```

```Rust
use std::cmp::Ordering;
impl Solution {
    pub fn four_sum(nums: Vec<i32>, target: i32) -> Vec<Vec<i32>> {
        let mut result: Vec<Vec<i32>> = Vec::new();
        let mut nums = nums;
        nums.sort();
        let len = nums.len();
        for k in 0..len {
            // 修剪
            if nums[k] > target && (nums[k] > 0 || target > 0) { break; }
            // 去重複
            if k > 0 && nums[k] == nums[k - 1] { continue; }
            for i in (k + 1)..len {
                // 修剪
                if nums[k] + nums[i] > target && (nums[k] + nums[i] >= 0 || target >= 0) { break; }
                // 去重複
                if i > k + 1 && nums[i] == nums[i - 1] { continue; }
                let (mut left, mut right) = (i + 1, len - 1);
                while left < right {
                    match (nums[k] + nums[i] + nums[left] + nums[right]).cmp(&target){
		        Ordering::Equal => {
			    result.push(vec![nums[k], nums[i], nums[left], nums[right]]);
			    left += 1;
			    right -= 1;
			    while left < right && nums[left] == nums[left - 1]{
			        left += 1;
			    }
			    while left < right && nums[right] == nums[right + 1]{
			        right -= 1;
			    }
			}
			Ordering::Less => {
			    left +=1;
			},
			Ordering::Greater => {
			    right -= 1;
			}
		    }
                }
            }
        }
        result
    }
}
```

```scala
object Solution {
  // 匯入套件
  import scala.collection.mutable.ListBuffer
  import scala.util.control.Breaks.{break, breakable}
  def fourSum(nums: Array[Int], target: Int): List[List[Int]] = {
    val res = ListBuffer[List[Int]]()
    val nums_tmp = nums.sorted // 先排序
    for (i <- nums_tmp.indices) {
      breakable {
        if (i > 0 && nums_tmp(i) == nums_tmp(i - 1)) {
          break // 如果該值和上次的值相同，跳過本次迴圈，相當於 continue
        } else {
          for (j <- i + 1 until nums_tmp.length) {
            breakable {
              if (j > i + 1 && nums_tmp(j) == nums_tmp(j - 1)) {
                break // 同上
              } else {
                // two pointers
                var (left, right) = (j + 1, nums_tmp.length - 1)
                while (left < right) {
                  var sum = nums_tmp(i) + nums_tmp(j) + nums_tmp(left) + nums_tmp(right)
                  if (sum == target) {
                    // 滿足要求，直接加入到集合裡面去
                    res += List(nums_tmp(i), nums_tmp(j), nums_tmp(left), nums_tmp(right))
                    while (left < right && nums_tmp(left) == nums_tmp(left + 1)) left += 1
                    while (left < right && nums_tmp(right) == nums_tmp(right - 1)) right -= 1
                    left += 1
                    right -= 1
                  } else if (sum < target) left += 1
                  else right -= 1
                }
              }
            }
          }
        }
      }
    }
    // 最後回傳的 res 要轉換為 List，return 關鍵字可以省略
    res.toList
  }
}
```

```ruby
def four_sum(nums, target)
  # 結果集
  result = []
  nums = nums.sort!

  for i in 0..nums.size - 1
    return result if i > 0 && nums[i] > target && nums[i] >= 0
    # 對 a 進行去重複
    next if i > 0 && nums[i] == nums[i - 1]

    for j in i + 1..nums.size - 1
      break if nums[i] + nums[j] > target && nums[i] + nums[j] >= 0
      # 對 b 進行去重複
      next if j > i + 1 && nums[j] == nums[j - 1]
      left = j + 1
      right = nums.size - 1
      while left < right
        sum = nums[i] + nums[j] + nums[left] + nums[right]
        if sum > target
          right -= 1
        elsif sum < target
          left += 1
        else
          result << [nums[i], nums[j], nums[left], nums[right]]

          # 對 c 進行去重複
          while left < right && nums[left] == nums[left + 1]
            left += 1
          end

          # 對 d 進行去重複
          while left < right && nums[right] == nums[right - 1]
            right -= 1
          end

          right -= 1
          left += 1
        end
      end
    end
  end

  return result
end
```
