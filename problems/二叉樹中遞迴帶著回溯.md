# 二元樹：以為使用了遞迴，其實還隱藏著回溯

> 補充一波

昨天的總結篇中[還在玩耍的你，該總結啦！（本週小結之二元樹）](https://programmercarl.com/周总结/20201003二叉树周末总结.html)，有兩處問題需要說明一下。

## 求相同的樹

[還在玩耍的你，該總結啦！（本週小結之二元樹）](https://programmercarl.com/周总结/20201003二叉树周末总结.html)中求 100.相同的樹的程式碼中，我筆誤貼出了 求對稱樹的程式碼了，細心的同學應該都發現了。

那麼如下我再給出求 100. 相同的樹 的程式碼，如下：

```CPP
class Solution {
public:
    bool compare(TreeNode* tree1, TreeNode* tree2) {
        if (tree1 == NULL && tree2 != NULL) return false;
        else if (tree1 != NULL && tree2 == NULL) return false;
        else if (tree1 == NULL && tree2 == NULL) return true;
        else if (tree1->val != tree2->val) return false; // 注意這裡我沒有使用 else

        // 此時就是：左右節點都不為空，且數值相同的情況
        // 此時才做遞迴，做下一層的判斷
        bool compareLeft = compare(tree1->left, tree2->left);       // 左子樹：左、 右子樹：左
        bool compareRight = compare(tree1->right, tree2->right);    // 左子樹：右、 右子樹：右
        bool isSame = compareLeft && compareRight;                  // 左子樹：中、 右子樹：中（邏輯處理）
        return isSame;

    }
    bool isSameTree(TreeNode* p, TreeNode* q) {
        return compare(p, q);
    }
};
```

以上的程式碼相對於：[二元樹：我對稱嗎？](https://programmercarl.com/0101.对称二叉树.html) 僅僅修改了變數（variable）的名字（為了符合判斷相同樹的語境）和 遍歷（traversal）的順序。

大家應該會體會到：**認清[判斷對稱樹](https://programmercarl.com/0101.对称二叉树.html)本質之後， 對稱樹的程式碼 稍作修改 就可以直接用來 AC 100.相同的樹。**

## 遞迴中隱藏著回溯

在[二元樹：找我的所有路徑？](https://programmercarl.com/0257.二叉树的所有路径.html)中我強調了本題其實是用到了回溯（backtracking）的，並且給出了第一個版本的程式碼，把回溯的過程充分地體現了出來。

如下的程式碼充分地體現出回溯：(257. 二元樹（binary tree）的所有路徑（path）)

```CPP
class Solution {
private:

    void traversal(TreeNode* cur, vector<int>& path, vector<string>& result) {
        path.push_back(cur->val);
        // 這才到了葉節點
        if (cur->left == NULL && cur->right == NULL) {
            string sPath;
            for (int i = 0; i < path.size() - 1; i++) {
                sPath += to_string(path[i]);
                sPath += "->";
            }
            sPath += to_string(path[path.size() - 1]);
            result.push_back(sPath);
            return;
        }
        if (cur->left) {
            traversal(cur->left, path, result);
            path.pop_back(); // 回溯
        }
        if (cur->right) {
            traversal(cur->right, path, result);
            path.pop_back(); // 回溯
        }
    }

public:
    vector<string> binaryTreePaths(TreeNode* root) {
        vector<string> result;
        vector<int> path;
        if (root == NULL) return result;
        traversal(root, path, result);
        return result;
    }
};
```


如下為精簡之後的遞迴（recursion）程式碼：(257. 二元樹的所有路徑)
```CPP
class Solution {
private:
    void traversal(TreeNode* cur, string path, vector<string>& result) {
        path += to_string(cur->val); // 中
        if (cur->left == NULL && cur->right == NULL) {
            result.push_back(path);
            return;
        }
        if (cur->left) traversal(cur->left, path + "->", result); // 左  回溯就隱藏在這裡
        if (cur->right) traversal(cur->right, path + "->", result); // 右 回溯就隱藏在這裡
    }

public:
    vector<string> binaryTreePaths(TreeNode* root) {
        vector<string> result;
        string path;
        if (root == NULL) return result;
        traversal(root, path, result);
        return result;
    }
};
```

上面的程式碼，大家貌似感受不到回溯了，其實**回溯就隱藏在 traversal(cur->left, path + "->", result); 中的 path + "->"。 每次函數（function）呼叫完，path 依然是沒有加上 "->" 的，這就是回溯了。**

為了把這份精簡程式碼的回溯過程展現出來，大家可以試一試把：

```CPP
if (cur->left) traversal(cur->left, path + "->", result); // 左  回溯就隱藏在這裡
```

改成如下程式碼：

```CPP
path += "->";
traversal(cur->left, path, result); // 左
```

即：

``` CPP
if (cur->left) {
    path += "->";
    traversal(cur->left, path, result); // 左
}
if (cur->right) {
    path += "->";
    traversal(cur->right, path, result); // 右
}
```

因為在遞迴右子樹（right subtree）之前需要還原 path，所以在左子樹（left subtree）遞迴後必須為了右子樹而進行回溯操作。而只右子樹自己不新增回溯也可以成功 AC。

因此，在上面程式碼的基礎上，再加上左右子樹的回溯程式碼，就可以 AC 了。

```CPP
if (cur->left) {
    path += "->";
    traversal(cur->left, path, result); // 左
    path.pop_back(); // 回溯，拋掉 val
    path.pop_back(); // 回溯，拋掉 ->
}
if (cur->right) {
    path += "->";
    traversal(cur->right, path, result); // 右
    path.pop_back(); // 回溯（非必要）
    path.pop_back(); 
}
```

**大家應該可以感受出來，如果把 `path + "->"` 作為函數參數（parameter）就是可以的，因為並沒有改變 path 的數值，執行完遞迴函數之後，path 依然是之前的數值（相當於回溯了）**

如果有點遺忘了，建議把這篇[二元樹：找我的所有路徑？](https://programmercarl.com/0257.二叉树的所有路径.html)再仔細看一下，然後再看這裡的總結，相信會豁然開朗。

    pub fn is_same_tree(
        p: Option<Rc<RefCell<TreeNode>>>,
        q: Option<Rc<RefCell<TreeNode>>>,
    ) -> bool {
        match (p, q) {
            (None, None) => true,
            (None, Some(_)) => false,
            (Some(_), None) => false,
            (Some(n1), Some(n2)) => {
                if n1.borrow().val == n2.borrow().val {

                    let left =
                        Self::is_same_tree(n1.borrow().right.clone(), n2.borrow().right.clone());
                    right && left
                } else {
                    false
                }
            }
        }
    }
}

// 遞迴
use std::cell::RefCell;
use std::rc::Rc;
impl Solution {
    pub fn binary_tree_paths(root: Option<Rc<RefCell<TreeNode>>>) -> Vec<String> {
        let mut res = vec![];
        let mut path = vec![];
        Self::recur(&root, &mut path, &mut res);
        res
    }

    pub fn recur(
        root: &Option<Rc<RefCell<TreeNode>>>,
        path: &mut Vec<String>,
        res: &mut Vec<String>,
    ) {
        let node = root.as_ref().unwrap().borrow();
        path.push(node.val.to_string());
        if node.left.is_none() && node.right.is_none() {
            res.push(path.join("->"));
            return;
        }
        if node.left.is_some() {
            Self::recur(&node.left, path, res);
            path.pop(); //回溯
        }
        if node.right.is_some() {
            Self::recur(&node.right, path, res);
            path.pop(); //回溯
        }
    }
}
