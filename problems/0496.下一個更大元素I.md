# 496. 下一個更大元素 I

[LeetCode 題目連結](https://leetcode.cn/problems/next-greater-element-i/)

給你兩個沒有重複（duplicate）元素（element）的陣列（array） nums1 和 nums2，其中 nums1 是 nums2 的子集（subset）。

請你找出 nums1 中每個元素在 nums2 中的下一個比其大的值。

nums1 中數字 x 的下一個更大元素是指 x 在 nums2 中對應位置的右邊的第一個比 x 大的元素。如果不存在，對應位置輸出 -1。

範例 1:

輸入: nums1 = [4,1,2], nums2 = [1,3,4,2].    
輸出: [-1,3,-1]      
解釋:       
對於 num1 中的數字 4，你無法在第二個陣列中找到下一個更大的數字，因此輸出 -1。    
對於 num1 中的數字 1，第二個陣列中數字 1 右邊的下一個較大數字是 3。       
對於 num1 中的數字 2，第二個陣列中沒有下一個更大的數字，因此輸出 -1。       

範例 2:   
輸入: nums1 = [2,4], nums2 = [1,2,3,4].     
輸出: [3,-1]     
解釋:        
對於 num1 中的數字 2，第二個陣列中的下一個較大數字是 3。       
對於 num1 中的數字 4，第二個陣列中沒有下一個更大的數字，因此輸出 -1。     

提示：

* 1 <= nums1.length <= nums2.length <= 1000
* 0 <= nums1[i], nums2[i] <= 10^4
* nums1 和 nums2 中所有整數（integer）互不相同
* nums1 中的所有整數同樣出現在 nums2 中

## 解題思路

做本題之前，建議先做一下[739. 每日溫度](https://programmercarl.com/0739.每日温度.html)

在[739. 每日溫度](https://programmercarl.com/0739.每日温度.html)中是求每個元素下一個比當前元素大的元素的位置。

本題則是說 nums1 是 nums2 的子集，找 nums1 中的元素在 nums2 中下一個比當前元素大的元素。

看上去和[739. 每日溫度](https://programmercarl.com/0739.每日温度.html)就如出一轍了。

幾乎是一樣的，但是這麼繞了一下，其實還上升了一點難度。

需要對 monotonic stack 使用得更熟練一些，才能順利地把本題寫出來。

從題目範例中我們可以看出最後是要求 nums1 的每個元素在 nums2 中下一個比當前元素大的元素，那麼就要定義一個和 nums1 一樣大小的陣列 result 來存放結果。

一些同學可能看到兩個陣列都已經懵了，不知道要定義一個多大的 result 陣列來存放結果了。

**這麼定義這個 result 陣列初始化（initialization）應該為多少呢？**

題目說如果不存在對應位置就輸出 -1，所以 result 陣列如果某位置沒有被賦值，那麼就應該是 -1，所以就初始化為 -1。

在遍歷（traversal） nums2 的過程中，我們要判斷 nums2[i] 是否在 nums1 中出現過，因為最後是要根據 nums1 元素的下標（subscript）來更新 result 陣列。

**注意題目中說是兩個沒有重複元素的陣列 nums1 和 nums2**。

沒有重複元素，我們就可以用 map 來做映射（map / mapping）了。根據數值快速找到下標，還可以判斷 nums2[i] 是否在 nums1 中出現過。

C++ 中，當我們要使用集合（set）來解決雜湊（hash）問題的時候，優先使用 unordered_set，因為它的查詢和增刪效率是最佳的。我在[關於雜湊表（hash table），你該了解這些！](https://programmercarl.com/哈希表理论基础.html)中也做了詳細的解釋。

那麼預處理（preprocessing）程式碼如下:

```CPP
unordered_map<int, int> umap; // key: 下標元素，value：下標
for (int i = 0; i < nums1.size(); i++) {
    umap[nums1[i]] = i;
}
```

使用 monotonic stack，首先要想 monotonic stack 是從大到小還是從小到大。

本題和 739. 每日溫度是一樣的。

堆疊頂（top of stack）到堆疊底端（stack bottom）的順序，要從小到大，也就是保持堆疊（stack）裡的元素為遞增順序。只要保持遞增，才能找到右邊第一個比自己大的元素。

可能這裡有一些同學不理解，那麼可以自己嘗試一下用遞減堆疊，能不能求出來。**其實遞減堆疊就是求右邊第一個比自己小的元素了**。


接下來就要分析如下三種情況，一定要分析清楚。

1. 情況一：當前遍歷的元素 T[i] 小於堆疊頂元素 T[st.top()] 的情況

此時滿足遞增堆疊（堆疊頂到堆疊底端的順序），所以直接放入堆疊。

2. 情況二：當前遍歷的元素 T[i] 等於堆疊頂元素 T[st.top()] 的情況

如果相等的話，依然直接放入堆疊，因為我們要求的是右邊第一個比自己大的元素，而不是大於等於！

3. 情況三：當前遍歷的元素 T[i] 大於堆疊頂元素 T[st.top()] 的情況

此時如果放入堆疊就不滿足遞增堆疊了，這也是找到右邊第一個比自己大的元素的時候。

判斷堆疊頂元素是否在 nums1 裡出現過，（注意堆疊裡的元素是 nums2 的元素），如果出現過，開始記錄結果。

記錄結果這塊邏輯有一點小繞，要清楚，此時堆疊頂元素在 nums2 陣列中右面第一個大的元素是 nums2[i]（即當前遍歷元素）。

程式碼如下：

```CPP
while (!st.empty() && nums2[i] > nums2[st.top()]) {
    if (umap.count(nums2[st.top()]) > 0) { // 看 map 裡是否存在這個元素
        int index = umap[nums2[st.top()]]; // 根據 map 找到 nums2[st.top()] 在 nums1 中的下標
        result[index] = nums2[i];
    }
    st.pop();
}
st.push(i);
```

以上分析完畢，C++ 程式碼如下：（其實本題程式碼和 [739. 每日溫度](https://programmercarl.com/0739.每日温度.html) 是基本差不多的）


```CPP
// 版本一
class Solution {
public:
    vector<int> nextGreaterElement(vector<int>& nums1, vector<int>& nums2) {
        stack<int> st;
        vector<int> result(nums1.size(), -1);
        if (nums1.size() == 0) return result;

        unordered_map<int, int> umap; // key: 下標元素，value：下標
        for (int i = 0; i < nums1.size(); i++) {
            umap[nums1[i]] = i;
        }
        st.push(0);
        for (int i = 1; i < nums2.size(); i++) {
            if (nums2[i] < nums2[st.top()]) {           // 情況一
                st.push(i);
            } else if (nums2[i] == nums2[st.top()]) {   // 情況二
                st.push(i);
            } else {                                    // 情況三
                while (!st.empty() && nums2[i] > nums2[st.top()]) {
                    if (umap.count(nums2[st.top()]) > 0) { // 看 map 裡是否存在這個元素
                        int index = umap[nums2[st.top()]]; // 根據 map 找到 nums2[st.top()] 在 nums1 中的下標
                        result[index] = nums2[i];
                    }
                    st.pop();
                }
                st.push(i);
            }
        }
        return result;
    }
};
```

/* 先用 monotonic stack 的方法計算出結果，再根據 nums1 中的元素去查找對應的結果 */
/**
 * Note: The returned array must be malloced, assume caller calls free().
 */
int* nextGreaterElement(int* nums1, int nums1Size, int* nums2, int nums2Size, int* returnSize) {

    /* stcak */
    int top = -1;
    int stack_len = nums2Size;
    int stack[stack_len];
    //memset(stack, 0x00, sizeof(stack));

    /* nums2 result */
    int* result_nums2 = (int *)malloc(sizeof(int) * nums2Size);
    //memset(result_nums2, 0x00, sizeof(int) * nums2Size);

    /* result */
    int* result = (int *)malloc(sizeof(int) * nums1Size);
    //memset(result, 0x00, sizeof(int) * nums1Size);
    *returnSize = nums1Size;

    /* init */
    stack[++top] = 0; /* stack loaded with array subscripts */

    for (int i = 0; i < nums2Size; i++) {
        result_nums2[i] = -1;
    }

    /* get the result_nums2 */
    for (int i = 1; i < nums2Size; i++) {
        if (nums2[i] <= nums2[stack[top]]) {
            stack[++top] = i; /* push */
        } else {
            while ((top >= 0) && (nums2[i] > nums2[stack[top]])) {
                result_nums2[stack[top]] = nums2[i];
                top--; /* pop */
            }
            stack[++top] = i;
        }
    }

    /* get the result */
    for (int i = 0; i < nums1Size; i++) {
        for (int j = 0; j < nums2Size; j++) {
            if (nums1[i] == nums2[j]) {
                result[i] = result_nums2[j];
            }
        }
    }
    return result;
}

class Solution {
    public int[] nextGreaterElement(int[] nums1, int[] nums2) {
        Stack<Integer> temp = new Stack<>();
        int[] res = new int[nums1.length];
        Arrays.fill(res,-1);
        HashMap<Integer, Integer> hashMap = new HashMap<>();
        for (int i = 0 ; i< nums1.length ; i++){
            hashMap.put(nums1[i],i);
        }
        temp.add(0);
        for (int i = 1; i < nums2.length; i++) {
            if (nums2[i] <= nums2[temp.peek()]) {
                temp.add(i);
            } else {
                while (!temp.isEmpty() && nums2[temp.peek()] < nums2[i]) {
                    if (hashMap.containsKey(nums2[temp.peek()])){
                        Integer index = hashMap.get(nums2[temp.peek()]);
                        res[index] = nums2[i];
                    }
                    temp.pop();
                }
                temp.add(i);
            }
        }

        return res;
    }

class Solution:
    def nextGreaterElement(self, nums1: List[int], nums2: List[int]) -> List[int]:
        stack = []
        # 建立答案陣列
        ans = [-1] * len(nums1)
        for i in range(len(nums2)):
            while len(stack) > 0 and nums2[i] > nums2[stack[-1]]:
                # 判斷 num1 是否有 nums2[stack[-1]]。如果沒有這個判斷會出現指標例外

func nextGreaterElement(nums1 []int, nums2 []int) []int {

    for i:= range res {
        res[i] = -1
    }
    mp := map[int]int{}

        mp[v] = i

    stack := []int{}

function nextGreaterElement(nums1: number[], nums2: number[]): number[] {
    const resArr: number[] = new Array(nums1.length).fill(-1);
    const stack: number[] = [];
    const helperMap: Map<number, number> = new Map();
    nums1.forEach((num, index) => {
        helperMap.set(num, index);
    })
    stack.push(0);
    for (let i = 1, length = nums2.length; i < length; i++) {
        let top = stack[stack.length - 1];
        while (stack.length > 0 && nums2[top] < nums2[i]) {
            let index = helperMap.get(nums2[top]);
            if (index !== undefined) {
                resArr[index] = nums2[i];
            }
            stack.pop();
            top = stack[stack.length - 1];
        }
        if (helperMap.get(nums2[i]) !== undefined) {
            stack.push(i);
        }
    }
    return resArr;
};

use std::collections::HashMap;
impl Solution {
    pub fn next_greater_element(nums1: Vec<i32>, nums2: Vec<i32>) -> Vec<i32> {
        let (mut res, mut map) = (vec![-1; nums1.len()], HashMap::new());
        if nums1.is_empty() {
            return res;
        }

        nums1.into_iter().enumerate().for_each(|(v, k)| {
            map.insert(k, v);
        });

        let mut stack = vec![];
        for (i, &value) in nums2.iter().enumerate() {
            while let Some(&top) = stack.last() {
                if value <= nums2[top] {
                    break;
                }
                let stacked_index = stack.pop().unwrap();
                if let Some(&mapped_index) = map.get(&nums2[stacked_index]) {
                    res[mapped_index] = value;
                }
            }
            stack.push(i);
        }

        res
    }
}
