之前可能有些讀者／錄友已經可以熟練寫出背包了，但只要把這篇文章仔細看完，相信你會有意外收穫！

### 0/1 背包

有 n 件物品和一個最多能背重量為 w 的背包。第 i 件物品的重量是 weight[i]，得到的價值是 value[i]。**每件物品只能用一次**，求解將哪些物品裝入背包裡物品價值總和最大。

這是標準的背包問題，以至於很多同學看了這個自然就會想到背包，甚至都不知道蠻力法（brute force）應該怎麼解了。

這樣其實是沒有由下而上（bottom-up）去思考，而是習慣性想到了背包，那麼蠻力法應該是怎麼樣的呢？

每一件物品其實只有兩個狀態（state），取或者不取，所以可以使用回溯演算法（backtracking algorithm）搜尋出所有的情況，那麼時間複雜性（time complexity）就是 O(2^n)，這裡的 n 表示物品數量。

**所以蠻力法是指數（exponential）等級的時間複雜性。進而才需要動態規劃的解法（solution）來進行最佳化！**

在下面的講解中，我舉一個例子：

背包最大重量為 4。

物品為：

|       | 重量 | 價值 |
| ----- | ---- | ---- |
| 物品0 | 1    | 15   |
| 物品1 | 3    | 20   |
| 物品2 | 4    | 30   |

問背包能背的物品最大價值是多少？

以下講解和圖示中出現的數字都是以這個例子為例。

（為了方便表述，下面描述統一用容量為 XX 的背包，放下容量（重量）為 XX 的物品，物品的價值是 XX）

### 二維（two-dimensional）dp 陣列（array） 0/1 背包

依然動規五部曲分析一波。

#### 1. 確定 dp 陣列以及下標（subscript）的含義

我們需要使用二維陣列，為什麼呢？

因為有兩個維度需要分別表示：物品和背包容量

如圖，二維陣列為 dp[i][j]。

![動態規劃-背包問題1](https://file1.kamacoder.com/i/algo/20210110103003361.png)

那麼這裡 i、j、dp[i][j] 分別表示什麼呢？

i 來表示物品、j 表示背包容量。

（如果想用 j 表示物品，i 表示背包容量行不行？都可以的，個人習慣而已）

我們來嘗試把上面的二維表格填寫一下。

動態規劃的思路是根據子問題的求解推導出整體的最佳解。

我們先看把物品 0 放入背包的情況：

![](https://file1.kamacoder.com/i/algo/20240730113455.png)

背包容量為 0，放不下物品 0，此時背包裡的價值為 0。

背包容量為 1，可以放下物品 0，此時背包裡的價值為 15。

背包容量為 2，依然可以放下物品 0（注意 0/1 背包裡物品只有一個），此時背包裡的價值為 15。

以此類推。

再看把物品 1 放入背包：

![](https://file1.kamacoder.com/i/algo/20240730114228.png)

背包容量為 0，放不下物品 0 或者物品 1，此時背包裡的價值為 0。

背包容量為 1，只能放下物品 0，背包裡的價值為 15。

背包容量為 2，只能放下物品 0，背包裡的價值為 15。

背包容量為 3，上一列（row）同一狀態，背包只能放物品 0，這次也可以選擇物品 1 了，背包可以放物品 1 或者物品 0，物品 1 價值更大，背包裡的價值為 20。

背包容量為 4，上一列同一狀態，背包只能放物品 0，這次也可以選擇物品 1 了，背包可以放下物品 0 和物品 1，背包價值為 35。

以上舉例比較容易看懂，我主要是透過這個例子，來幫助大家明確 dp 陣列的含義。

上圖中，我們看 dp[1][4] 表示什麼意思呢。

任取物品 0、物品 1 放進容量為 4 的背包裡，最大價值是 dp[1][4]。

透過這個舉例，我們來進一步明確 dp 陣列的含義。

即 **dp[i][j] 表示從下標為 [0-i] 的物品裡任意取，放進容量為 j 的背包，價值總和最大是多少**。

**要時刻記著這個 dp 陣列的含義，下面的一些步驟都圍繞這個 dp 陣列的含義進行的**，如果哪裡看懵了，就來回顧一下 i 代表什麼，j 又代表什麼。

#### 2. 確定遞迴公式（recurrence formula）

這裡再把基本資訊給出來：

|       | 重量 | 價值 |
| ----- | ---- | ---- |
| 物品0 | 1    | 15   |
| 物品1 | 3    | 20   |
| 物品2 | 4    | 30   |

對於遞迴公式，首先我們要明確有哪些方向可以推導出 dp[i][j]。

這裡我們拿 dp[1][4] 的狀態來舉例：

求取 dp[1][4] 有兩種情況：

1. 放物品 1
2. 還是不放物品 1

如果不放物品 1，那麼背包的價值應該是 dp[0][4]，即容量為 4 的背包，只放物品 0 的情況。

推導方向如圖：

![](https://file1.kamacoder.com/i/algo/20240730174246.png)

如果放物品 1，**那麼背包要先留出物品 1 的容量**，目前容量是 4，物品 1 的容量（就是物品 1 的重量）為 3，此時背包剩下容量為 1。

容量為 1，只考慮放物品 0 的最大價值是 dp[0][1]，這個值我們之前就計算過。

所以放物品 1 的情況 = dp[0][1] + 物品 1 的價值，推導方向如圖：

![](https://file1.kamacoder.com/i/algo/20240730174436.png)

兩種情況，分別是放物品 1 和不放物品 1，我們要取最大值（畢竟求的是最大價值）

`dp[1][4] = max(dp[0][4], dp[0][1] + 物品1 的價值) `

以上過程，抽象化如下：

* **不放物品 i**：背包容量為 j，裡面不放物品 i 的最大價值是 dp[i - 1][j]。

* **放物品 i**：背包空出物品 i 的容量後，背包容量為 j - weight[i]，dp[i - 1][j - weight[i]] 為背包容量為 j - weight[i] 且不放物品 i 的最大價值，那麼 dp[i - 1][j - weight[i]] + value[i]（物品 i 的價值），就是背包放物品 i 得到的最大價值

遞迴公式：`dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - weight[i]] + value[i]);`

#### 3. dp 陣列如何初始化（initialization）

**關於初始化，一定要和 dp 陣列的定義吻合，否則到遞迴公式的時候就會越來越亂**。

首先從 dp[i][j] 的定義出發，如果背包容量 j 為 0 的話，即 dp[i][0]，無論是選取哪些物品，背包價值總和一定為 0。如圖：

![動態規劃-背包問題2](https://file1.kamacoder.com/i/algo/2021011010304192.png)

再看其他情況。

狀態變遷方程式（state transition equation）`dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - weight[i]] + value[i]);` 可以看出 i 是由 i-1 推導出來，那麼 i 為 0 的時候就一定要初始化。

dp[0][j]，即：i 為 0，存放編號 0 的物品的時候，各個容量的背包所能存放的最大價值。

那麼很明顯當 `j < weight[0]` 的時候，dp[0][j] 應該是 0，因為背包容量比編號 0 的物品重量還小。

當 `j >= weight[0]` 時，dp[0][j] 應該是 value[0]，因為背包容量足夠放編號 0 物品。

程式碼初始化如下：

```CPP
for (int i = 1; i < weight.size(); i++) {  // 當然這一步，如果把 dp 陣列預先初始化為 0 了，這一步就可以省略，但很多同學應該沒有想清楚這一點。
    dp[i][0] = 0;
}
// 正序遍歷
for (int j = weight[0]; j <= bagweight; j++) {
    dp[0][j] = value[0];
}
```


此時 dp 陣列初始化情況如圖所示：

![動態規劃-背包問題7](https://file1.kamacoder.com/i/algo/20210110103109140.png)

dp[0][j] 和 dp[i][0] 都已經初始化了，那麼其他下標應該初始化多少呢？

其實從遞迴公式：dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - weight[i]] + value[i]); 可以看出 dp[i][j] 是由左上方數值推導出來的，那麼其他下標初始為什麼數值都可以，因為都會被覆蓋。

**初始 -1，初始 -2，初始 100，都可以！**

但只不過一開始就統一把 dp 陣列初始為 0，更方便一些。

如圖：

![動態規劃-背包問題10](https://file1.kamacoder.com/i/algo/%E5%8A%A8%E6%80%81%E8%A7%84%E5%88%92-%E8%83%8C%E5%8C%85%E9%97%AE%E9%A2%9810.jpg)

最後初始化程式碼如下：

```CPP
// 初始化 dp
vector<vector<int>> dp(weight.size(), vector<int>(bagweight + 1, 0));
for (int j = weight[0]; j <= bagweight; j++) {
    dp[0][j] = value[0];
}

```

**費了這麼大的功夫，才把如何初始化講清楚，相信不少同學平時初始化 dp 陣列是憑感覺來的，但有時候感覺是不靠譜的**。

#### 4. 確定遍歷（traversal）順序

在如下圖中，可以看出，有兩個遍歷的維度：物品與背包重量

![動態規劃-背包問題3](https://file1.kamacoder.com/i/algo/2021011010314055.png)

那麼問題來了，**先遍歷物品還是先遍歷背包重量呢？**

**其實都可以！！但是先遍歷物品更好理解**。

那麼我先給出先遍歷物品，然後遍歷背包重量的程式碼。

```CPP
// weight 陣列的大小就是物品個數
for(int i = 1; i < weight.size(); i++) { // 遍歷物品
    for(int j = 0; j <= bagweight; j++) { // 遍歷背包容量
        if (j < weight[i]) dp[i][j] = dp[i - 1][j];
        else dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - weight[i]] + value[i]);

    }
}
```

**先遍歷背包，再遍歷物品，也是可以的！（注意我這裡使用的二維 dp 陣列）**

例如這樣：

```CPP
// weight 陣列的大小就是物品個數
for(int j = 0; j <= bagweight; j++) { // 遍歷背包容量
    for(int i = 1; i < weight.size(); i++) { // 遍歷物品
        if (j < weight[i]) dp[i][j] = dp[i - 1][j];
        else dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - weight[i]] + value[i]);
    }
}
```

為什麼也是可以的呢？

**要理解遞迴（recursion）的本質和遞推的方向**。

`dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - weight[i]] + value[i]);` 遞迴公式中可以看出 dp[i][j] 是靠 dp[i-1][j] 和 dp[i - 1][j - weight[i]] 推導出來的。

dp[i-1][j] 和 dp[i - 1][j - weight[i]] 都在 dp[i][j] 的左上角方向（包括正上方向），那麼先遍歷物品，再遍歷背包的過程如圖所示：

![動態規劃-背包問題5](https://file1.kamacoder.com/i/algo/202101101032124.png)

再來看看先遍歷背包，再遍歷物品呢，如圖：

![動態規劃-背包問題6](https://file1.kamacoder.com/i/algo/20210110103244701.png)

**大家可以看出，雖然兩個 for 迴圈（for-loop）遍歷的次序不同，但是 dp[i][j] 所需要的資料就是左上角，根本不影響 dp[i][j] 公式的推導！**

但先遍歷物品再遍歷背包這個順序更好理解。

**其實背包問題裡，兩個 for 迴圈的先後順序是非常有講究的，理解遍歷順序其實比理解推導公式難多了**。

來看一下對應的 dp 陣列的數值，如圖：

**做動態規劃的題目，最好的過程就是自己在紙上舉一個例子把對應的 dp 陣列的數值推導一下，然後再動手寫程式碼！**

很多同學做 dp 題目，遇到各種問題，然後憑感覺東改改西改改，怎麼改都不對，或者稀里糊塗就改過了。

主要就是自己沒有動手推導一下 dp 陣列的演變過程，如果推導明白了，程式碼寫出來就算有問題，只要把 dp 陣列印出來，對比一下和自己推導的有什麼差異，很快就可以發現問題了。

本題 LeetCode 上沒有原題，大家可以去[KamaCoder 第 46 題](https://kamacoder.com/problempage.php?pid=1046)練習，題意是一樣的，程式碼如下：

```CPP 
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, bagweight;// bagweight 代表行李箱空間

    cin >> n >> bagweight;

    vector<int> weight(n, 0); // 儲存每件物品所佔空間
    vector<int> value(n, 0);  // 儲存每件物品價值

    for(int i = 0; i < n; ++i) {
        cin >> weight[i];
    }
    for(int j = 0; j < n; ++j) {
        cin >> value[j];
    }
    // dp 陣列, dp[i][j] 代表行李箱空間為 j 的情況下,從下標為 [0, i] 的物品裡面任意取,能達到的最大價值
    vector<vector<int>> dp(weight.size(), vector<int>(bagweight + 1, 0));

    // 初始化, 因為需要用到 dp[i - 1] 的值
    // j < weight[0] 已在上方被初始化為 0
    // j >= weight[0] 的值就初始化為 value[0]
    for (int j = weight[0]; j <= bagweight; j++) {
        dp[0][j] = value[0];
    }

    for(int i = 1; i < weight.size(); i++) { // 遍歷科研物品
        for(int j = 0; j <= bagweight; j++) { // 遍歷行李箱容量
            if (j < weight[i]) dp[i][j] = dp[i - 1][j]; // 如果裝不下這個物品,那麼就繼承 dp[i - 1][j] 的值
            else {
                dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - weight[i]] + value[i]);
            }
        }
    }
    cout << dp[n - 1][bagweight] << endl;

    return 0;
}


```

## 其他語言版本

### Java

```Java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int bagweight = scanner.nextInt();

        int[] weight = new int[n];
        int[] value = new int[n];

        for (int i = 0; i < n; ++i) {
            weight[i] = scanner.nextInt();
        }
        for (int j = 0; j < n; ++j) {
            value[j] = scanner.nextInt();
        }

        int[][] dp = new int[n][bagweight + 1];

        for (int j = weight[0]; j <= bagweight; j++) {
            dp[0][j] = value[0];
        }

        for (int i = 1; i < n; i++) {
            for (int j = 0; j <= bagweight; j++) {
                if (j < weight[i]) {
                    dp[i][j] = dp[i - 1][j];
                } else {
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i - 1][j - weight[i]] + value[i]);
                }
            }
        }

        System.out.println(dp[n - 1][bagweight]);
    }
}

```

### Go

```go
package main

import (
    "fmt"
)

func main() {
    var n, bagweight int // bagweight 代表行李箱空間
    fmt.Scan(&n, &bagweight)

    weight := make([]int, n) // 儲存每件物品所佔空間
    value := make([]int, n)  // 儲存每件物品價值

    for i := 0; i < n; i++ {
        fmt.Scan(&weight[i])
    }
    for j := 0; j < n; j++ {
        fmt.Scan(&value[j])
    }
    // dp 陣列, dp[i][j] 代表行李箱空間為 j 的情況下,從下標為 [0, i] 的物品裡面任意取,能達到的最大價值
    dp := make([][]int, n)
    for i := range dp {
        dp[i] = make([]int, bagweight + 1)
    }

    // 初始化, 因為需要用到 dp[i - 1] 的值
    // j < weight[0] 已在上方被初始化為 0
    // j >= weight[0] 的值就初始化為 value[0]
    for j := weight[0]; j <= bagweight; j++ {
        dp[0][j] = value[0]
    }

    for i := 1; i < n; i++ { // 遍歷科研物品
        for j := 0; j <= bagweight; j++ { // 遍歷行李箱容量
            if j < weight[i] {
                dp[i][j] = dp[i-1][j] // 如果裝不下這個物品,那麼就繼承 dp[i - 1][j] 的值
            } else {
                dp[i][j] = max(dp[i-1][j], dp[i-1][j-weight[i]]+value[i])
            }
        }
    }

    fmt.Println(dp[n-1][bagweight])
}

func max(x, y int) int {
    if x > y {
        return x
    }
    return y
}
```
