# 1221. 分割平衡字串（string）

[LeetCode 題目連結](https://leetcode.cn/problems/split-a-string-in-balanced-strings/)

在一個 平衡字串 中，'L' 和 'R' 字元（character）的數量是相同的。

給你一個平衡字串 s，請你將它分割成盡可能多的平衡字串。

注意：分割得到的每個字串都必須是平衡字串。

回傳可以透過分割得到的平衡字串的 最大數量。


範例 1：

* 輸入：s = "RLRRLLRLRL"
* 輸出：4
* 解釋：s 可以分割為 "RL"、"RRLL"、"RL"、"RL"，每個子字串（substring）中都包含相同數量的 'L' 和 'R'。

範例 2：
* 輸入：s = "RLLLLRRRLR"
* 輸出：3
* 解釋：s 可以分割為 "RL"、"LLLRRR"、"LR"，每個子字串中都包含相同數量的 'L' 和 'R'。

範例 3：
* 輸入：s = "LLLLRRRR"
* 輸出：1
* 解釋：s 只能保持原樣 "LLLLRRRR".

範例 4：
* 輸入：s = "RLRRRLLRLL"
* 輸出：2
* 解釋：s 可以分割為 "RL"、"RRRLLRLL"，每個子字串中都包含相同數量的 'L' 和 'R'。

## 解題思路

這道題目看起來好像很複雜，其實是非常簡單的貪心法（greedy），關於貪心法，我在這裡[關於貪心演算法（greedy algorithm），你該了解這些！](https://programmercarl.com/贪心算法理论基础.html)有詳細的講解。

從前向後遍歷（traversal），只要遇到平衡子字串，計數就 +1，遍歷一遍即可。

區域最佳（local optimum）：從前向後遍歷，只要遇到平衡子字串就統計

總體最佳（global optimum）：統計了最多的平衡子字串。

區域最佳可以推出總體最佳，舉不出反例，那麼就試試貪心法。


例如，LRLR 這本身就是平衡子字串，但要遇到 LR 就可以分割。

C++ 程式碼如下：

```CPP
class Solution {
public:
    int balancedStringSplit(string s) {
        int result = 0;
        int count = 0;
        for (int i = 0; i < s.size(); i++) {
            if (s[i] == 'R') count++;
            else count--;
            if (count == 0) result++;
        }
        return result;
    }
};
```

## 拓展

一些同學可能想，你這個推理不靠譜，都沒有數學證明。怎麼就能說是合理的呢，怎麼就能說明區域最佳可以推出總體最佳呢？

一般數學證明有如下兩種方法：

* 數學歸納法
* 反證法

如果真的去嚴格數學證明其實不是在我們刷題或者面試的考察範圍內了。

所以貪心法題目的思考過程是：如果發現區域最佳好像可以推出總體最佳，那麼就嘗試一下舉反例，如果舉不出反例，那麼就試試貪心法。

### Python

```python
class Solution:
    def balancedStringSplit(self, s: str) -> int:
        diff = 0 # 右左差值
        ans = 0
        for c in s:
            if c == "L":
                diff -= 1
            else:
                diff += 1
            if diff == 0:
                ans += 1
        return ans
```

### Go

```go
func balancedStringSplit(s string) int {
    diff := 0 // 右左差值
    ans := 0
    for _, c := range s {
        if c == 'L' {
            diff--
        }else {
            diff++
        }
        if diff == 0 {
            ans++
        }
    }
    return ans
}
```

### JavaScript

```js
var balancedStringSplit = function(s) {
    let res = 0, total = 0;// res 為平衡字串數量 total 為當前 "R" 字元和 "L" 字元的數量差
    for(let c of s){// 遍歷字串每個字元
        // 因為開始字元數量差就是 0，遍歷的時候要先改變數量差，否則會影響結果數量
        total += c === 'R' ? 1:-1;// 遇到 "R", total++; 遇到 "L", total--
        if(total === 0) res++;// 只要 "R""L" 數量一樣就可以算是一個平衡字串
    }
    return res;
};
```
