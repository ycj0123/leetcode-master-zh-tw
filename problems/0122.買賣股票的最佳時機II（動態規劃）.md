# 122.買賣股票的最佳時機II 

[LeetCode 題目連結](https://leetcode.com/problems/best-time-to-buy-and-sell-stock-ii/)

給定一個陣列（array），它的第 i 個元素（element）是一支給定股票第 i 天的價格。

設計一個演算法來計算你所能獲取的最大利潤。你可以盡可能地完成更多的交易（多次買賣一支股票）。

注意：你不能同時參與多筆交易（你必須在再次購買前出售掉之前的股票）。


* 範例 1:         
* 輸入: [7,1,5,3,6,4]    
* 輸出: 7                   
解釋: 在第 2 天（股票價格 = 1）的時候買入，在第 3 天（股票價格 = 5）的時候賣出, 這筆交易所能獲得利潤 = 5-1 = 4。隨後，在第 4 天（股票價格 = 3）的時候買入，在第 5 天（股票價格 = 6）的時候賣出, 這筆交易所能獲得利潤 = 6-3 = 3 。         

* 範例 2:           
* 輸入: [1,2,3,4,5]        
* 輸出: 4                         
解釋: 在第 1 天（股票價格 = 1）的時候買入，在第 5 天 （股票價格 = 5）的時候賣出, 這筆交易所能獲得利潤 = 5-1 = 4 。注意你不能在第 1 天和第 2 天接連購買股票，之後再將它們賣出。因為這樣屬於同時參與了多筆交易，你必須在再次購買前出售掉之前的股票。

* 範例 3:           
* 輸入: [7,6,4,3,1]        
* 輸出: 0         
解釋: 在這種情況下, 沒有交易完成, 所以最大利潤為 0。       

提示：    
* 1 <= prices.length <= 3 * 10 ^ 4
* 0 <= prices[i] <= 10 ^ 4

## 解題思路 

本題我們在講解貪心法（greedy）專題的時候就已經講解過了[貪心演算法（greedy algorithm）：買賣股票的最佳時機II](./0122.買賣股票的最佳時機II.md)，只不過沒有深入講解動態規劃（dynamic programming, DP）的解法，那麼這次我們再好好分析一下動規的解法。


本題和[121. 買賣股票的最佳時機](./0121.買賣股票的最佳時機.md)的唯一區別是本題股票可以買賣多次了（注意只有一支股票，所以再次購買前要出售掉之前的股票）

**在動規五部曲中，這個區別主要是體現在遞迴公式（recurrence formula）上，其他都和[121. 買賣股票的最佳時機](./0121.買賣股票的最佳時機.md)一模一樣**。

所以我們重點講一講遞迴公式。

這裡重申一下dp陣列的含義：

* dp[i][0] 表示第i天持有股票所得現金。
* dp[i][1] 表示第i天不持有股票所得最多現金


如果第i天持有股票即dp[i][0]， 那麼可以由兩個狀態推出來 
* 第i-1天就持有股票，那麼就保持現狀，所得現金就是昨天持有股票的所得現金 即：dp[i - 1][0]
* 第i天買入股票，所得現金就是昨天不持有股票的所得現金減去 今天的股票價格 即：dp[i - 1][1] - prices[i] 

**注意這裡和[121. 買賣股票的最佳時機](./0121.買賣股票的最佳時機.md)唯一不同的地方，就是推導dp[i][0]的時候，第i天買入股票的情況**。

在[121. 買賣股票的最佳時機](./0121.買賣股票的最佳時機.md)中，因為股票全程只能買賣一次，所以如果買入股票，那麼第i天持有股票即dp[i][0]一定就是 -prices[i]。

而本題，因為一支股票可以買賣多次，所以當第i天買入股票的時候，所持有的現金可能有之前買賣過的利潤。

那麼第i天持有股票即dp[i][0]，如果是第i天買入股票，所得現金就是昨天不持有股票的所得現金 減去 今天的股票價格 即：dp[i - 1][1] - prices[i]。

再來看看如果第i天不持有股票即dp[i][1]的情況， 依然可以由兩個狀態推出來
* 第i-1天就不持有股票，那麼就保持現狀，所得現金就是昨天不持有股票的所得現金 即：dp[i - 1][1]
* 第i天賣出股票，所得現金就是按照今天股票價格賣出後所得現金即：prices[i] + dp[i - 1][0] 

**注意這裡和[121. 買賣股票的最佳時機](./0121.買賣股票的最佳時機.md)就是一樣的邏輯，賣出股票收穫利潤（可能是負值）天經地義！** 

程式碼如下：（注意程式碼中的註解，標記了和121.買賣股票的最佳時機唯一不同的地方）

```CPP
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int len = prices.size();
        vector<vector<int>> dp(len, vector<int>(2, 0));
        dp[0][0] -= prices[0];
        dp[0][1] = 0;
        for (int i = 1; i < len; i++) {
            dp[i][0] = max(dp[i - 1][0], dp[i - 1][1] - prices[i]); // 注意這裡是和121. 買賣股票的最佳時機唯一不同的地方。
            dp[i][1] = max(dp[i - 1][1], dp[i - 1][0] + prices[i]);
        }
        return dp[len - 1][1];
    }
};
```

* 時間複雜度（time complexity）：O(n)
* 空間複雜度（space complexity）：O(n)

大家可以看到本題和[121. 買賣股票的最佳時機](./0121.買賣股票的最佳時機.md)的程式碼幾乎一樣，唯一的區別在：

```
dp[i][0] = max(dp[i - 1][0], dp[i - 1][1] - prices[i]);
```

**這正是因為本題的股票可以買賣多次！** 所以買入股票的時候，可能會有之前買賣的利潤即：dp[i - 1][1]，所以dp[i - 1][1] - prices[i]。

想到這一點，對這兩道題的理解就比較深刻了。

這裡我依然給出滾動陣列（rolling array）的版本，C++程式碼如下：

```CPP
// 版本二
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int len = prices.size();
        vector<vector<int>> dp(2, vector<int>(2)); // 注意這裡只開闢了一個2 * 2大小的二維陣列
        dp[0][0] -= prices[0];
        dp[0][1] = 0;
        for (int i = 1; i < len; i++) {
            dp[i % 2][0] = max(dp[(i - 1) % 2][0], dp[(i - 1) % 2][1] - prices[i]);
            dp[i % 2][1] = max(dp[(i - 1) % 2][1], prices[i] + dp[(i - 1) % 2][0]);
        }
        return dp[(len - 1) % 2][1];
    }
};
```

* 時間複雜度：O(n)
* 空間複雜度：O(1)

class Solution {
    public int maxProfit(int[] prices) {
        int[] dp = new int[2];
        // 0表示持有，1表示賣出
        dp[0] = -prices[0];
        dp[1] = 0;
        for(int i = 1; i <= prices.length; i++){
            // 前一天持有; 既然不限制交易次數，那麼再次買股票時，要加上之前的收益
            dp[0] = Math.max(dp[0], dp[1] - prices[i-1]);
            // 前一天賣出; 或當天賣出，當天賣出，得先持有
            dp[1] = Math.max(dp[1], dp[0] + prices[i-1]);
        }
        return dp[1];
    }

const maxProfit = (prices) => {
    // 滾動陣列
    // have: 第i天持有股票最大收益; notHave: 第i天不持有股票最大收益
    let n = prices.length,
        have = -prices[0],
        notHave = 0;
    for (let i = 1; i < n; i++) {
        have = Math.max(have, notHave - prices[i]);
        notHave = Math.max(notHave, have + prices[i]);
    }
    // 最終手裡不持有股票才能保證收益最大化
    return notHave;

    /**
        dp[i][0]: 第i天持有股票
        dp[i][1]: 第i天不持有股票

    const length: number = prices.length;

    return dp[length - 1][1];
