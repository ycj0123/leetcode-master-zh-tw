# 151. 翻轉字串（string）裡的單字

[LeetCode 題目連結](https://leetcode.cn/problems/reverse-words-in-a-string/)

給定一個字串，逐個翻轉字串中的每個單字。

範例 1：  
輸入: "the sky is blue"   
輸出: "blue is sky the"    

範例 2：   
輸入: "  hello world!  "   
輸出: "world! hello"      
解釋: 輸入字串可以在前面或者後面包含多餘的空格，但是反轉（reverse）後的字元（character）不能包括。 

範例 3：   
輸入: "a good   example"  
輸出: "example good a"     
解釋: 如果兩個單字間有多餘的空格，將反轉後單字間的空格減少到只含一個。

## 解題思路

**這道題目可以說是綜合考察了字串的多種操作。**

一些同學會使用 split 程式館函數（library function），分隔單字，然後定義一個新的 string 字串，最後再把單字倒序相加，那麼這道題目就是一道水題了，失去了它的意義。

所以這裡我還是提高一下本題的難度：**不要使用 auxiliary space，空間複雜度（space complexity）要求為 O(1)。**

不能使用 auxiliary space 之後，那麼只能在原字串上下功夫了。

想一下，將整個字串都反轉過來，那麼單字的順序必定是倒序了，只不過單字本身也倒序了，那麼再把單字反轉一下，單字不就正過來了。

所以解題思路如下：

* 移除多餘空格
* 將整個字串反轉
* 將每個單字反轉

舉個例子，來源字串為："the sky is    blue   "

* 移除多餘空格 : "the sky is blue"
* 字串反轉："eulb si yks eht"
* 單字反轉："blue is sky the"

這樣我們就完成了翻轉字串裡的單字。


解題思路很明確了，我們說一說程式碼的實作細節，就拿移除多餘空格來說，一些同學會上來寫如下程式碼：

```CPP
void removeExtraSpaces(string& s) {
    for (int i = s.size() - 1; i > 0; i--) {
        if (s[i] == s[i - 1] && s[i] == ' ') {
            s.erase(s.begin() + i);
        }
    }
    // 刪除字串最後面的空格
    if (s.size() > 0 && s[s.size() - 1] == ' ') {
        s.erase(s.begin() + s.size() - 1);
    }
    // 刪除字串最前面的空格
    if (s.size() > 0 && s[0] == ' ') {
        s.erase(s.begin());
    }
}
```

邏輯很簡單，從前向後遍歷（traversal），遇到空格了就 erase。

如果不仔細琢磨一下 erase 的時間複雜性（time complexity），還以為以上的程式碼是 O(n) 的時間複雜性呢。

想一下真正的時間複雜性是多少，一個 erase 本來就是 O(n) 的操作。

erase 操作上面還套了一個 for 迴圈（for-loop），那麼以上程式碼移除冗餘（redundant）空格的程式碼時間複雜性為 O(n^2)。

那麼使用 two pointers 法來去移除空格，最後 resize（重新設定）一下字串的大小，就可以做到 O(n) 的時間複雜性。

```CPP
// 版本一 
void removeExtraSpaces(string& s) {
    int slowIndex = 0, fastIndex = 0; // 定義快指標，慢指標
    // 去掉字串前面的空格
    while (s.size() > 0 && fastIndex < s.size() && s[fastIndex] == ' ') {
        fastIndex++;
    }
    for (; fastIndex < s.size(); fastIndex++) {
        // 去掉字串中間部分的冗餘空格
        if (fastIndex - 1 > 0
                && s[fastIndex - 1] == s[fastIndex]
                && s[fastIndex] == ' ') {
            continue;
        } else {
            s[slowIndex++] = s[fastIndex];
        }
    }
    if (slowIndex - 1 > 0 && s[slowIndex - 1] == ' ') { // 去掉字串末尾的空格
        s.resize(slowIndex - 1);
    } else {
        s.resize(slowIndex); // 重新設定字串大小
    }
}
```


有的同學可能發現用 erase 來移除空格，在 leetcode 上效能也還行。主要是以下幾點：

1. leetcode 上的測試集裡，字串的長度不夠長，如果足夠長，效能差距會非常明顯。
2. leetcode 的測程式耗時不是很準確的。

版本一的程式碼是一般的思考過程，就是先移除字串前的空格，再移除中間的，再移除後面部分。 

不過其實還可以最佳化，這部分和 [27.移除元素](https://programmercarl.com/0027.移除元素.html) 的邏輯是一模一樣的，本題是移除空格，而 27.移除元素（element） 就是移除元素。 

所以程式碼可以寫得很精簡，大家可以看如下程式碼 removeExtraSpaces 函式（function）的實作：

```CPP
// 版本二 
void removeExtraSpaces(string& s) {// 去除所有空格並在相鄰單字之間添加空格, fast and slow pointers。
    int slow = 0;   // 整體思路參考 https://programmercarl.com/0027.移除元素.html
    for (int i = 0; i < s.size(); ++i) { //
        if (s[i] != ' ') { // 遇到非空格就處理，即刪除所有空格。
            if (slow != 0) s[slow++] = ' '; // 手動控制空格，給單字之間添加空格。slow != 0 說明不是第一個單字，需要在單字前添加空格。
            while (i < s.size() && s[i] != ' ') { // 補上該單字，遇到空格說明單字結束。
                s[slow++] = s[i++];
            }
        }
    }
    s.resize(slow); // slow 的大小即為去除多餘空格後的大小。
}
```

還要實作反轉字串的功能，支援反轉字串子區間（interval），這個實作我們分別在 [344.反轉字串](https://programmercarl.com/0344.反转字符串.html) 和 [541.反轉字串 II](https://programmercarl.com/0541.反转字符串II.html) 裡已經講過了。

程式碼如下：

```CPP
// 反轉字串 s 中左閉右閉的區間 [start, end]
void reverse(string& s, int start, int end) {
    for (int i = start, j = end; i < j; i++, j--) {
        swap(s[i], s[j]);
    }
}
```

整體程式碼如下：

```CPP
class Solution {
public:
    void reverse(string& s, int start, int end){ // 翻轉，區間寫法：左閉右閉 []
        for (int i = start, j = end; i < j; i++, j--) {
            swap(s[i], s[j]);
        }
    }

    void removeExtraSpaces(string& s) {// 去除所有空格並在相鄰單字之間添加空格, fast and slow pointers。
        int slow = 0;   // 整體思路參考 https://programmercarl.com/0027.移除元素.html
        for (int i = 0; i < s.size(); ++i) { //
            if (s[i] != ' ') { // 遇到非空格就處理，即刪除所有空格。
                if (slow != 0) s[slow++] = ' '; // 手動控制空格，給單字之間添加空格。slow != 0 說明不是第一個單字，需要在單字前添加空格。
                while (i < s.size() && s[i] != ' ') { // 補上該單字，遇到空格說明單字結束。
                    s[slow++] = s[i++];
                }
            }
        }
        s.resize(slow); // slow 的大小即為去除多餘空格後的大小。
    }

    string reverseWords(string s) {
        removeExtraSpaces(s); // 去除多餘空格，保證單字之間只有一個空格，且字串首尾沒空格。
        reverse(s, 0, s.size() - 1);
        int start = 0; // removeExtraSpaces 後保證第一個單字的開始索引一定是 0。
        for (int i = 0; i <= s.size(); ++i) {
            if (i == s.size() || s[i] == ' ') { // 到達空格或者串尾，說明一個單字結束。進行翻轉。
                reverse(s, start, i - 1); // 翻轉，注意是左閉右閉 [] 的翻轉。
                start = i + 1; // 更新下一個單字的開始索引 start
            }
        }
        return s;
    }
};
```

* 時間複雜性: O(n)
* 空間複雜度: O(1) 或 O(n)，取決於語言中字串是否可變

class Solution {
   /**
     * 不使用 Java 內建方法實作
     * <p>
     * 1. 去除首尾以及中間多餘空格
     * 2. 反轉整個字串
     * 3. 反轉各個單字
     */
    public String reverseWords(String s) {
        // System.out.println("ReverseWords.reverseWords2() called with: s = [" + s + "]");
        // 1. 去除首尾以及中間多餘空格
        StringBuilder sb = removeSpace(s);
        // 2. 反轉整個字串
        reverseString(sb, 0, sb.length() - 1);
        // 3. 反轉各個單字
        reverseEachWord(sb);
        return sb.toString();
    }

    private StringBuilder removeSpace(String s) {
        // System.out.println("ReverseWords.removeSpace() called with: s = [" + s + "]");
        int start = 0;
        int end = s.length() - 1;
        while (s.charAt(start) == ' ') start++;
        while (s.charAt(end) == ' ') end--;
        StringBuilder sb = new StringBuilder();
        while (start <= end) {
            char c = s.charAt(start);
            if (c != ' ' || sb.charAt(sb.length() - 1) != ' ') {
                sb.append(c);
            }
            start++;
        }
        // System.out.println("ReverseWords.removeSpace returned: sb = [" + sb + "]");
        return sb;
    }

    /**
     * 反轉字串指定區間 [start, end] 的字元
     */
    public void reverseString(StringBuilder sb, int start, int end) {
        // System.out.println("ReverseWords.reverseString() called with: sb = [" + sb + "], start = [" + start + "], end = [" + end + "]");
        while (start < end) {
            char temp = sb.charAt(start);
            sb.setCharAt(start, sb.charAt(end));
            sb.setCharAt(end, temp);
            start++;
            end--;
        }
        // System.out.println("ReverseWords.reverseString returned: sb = [" + sb + "]");
    }

    private void reverseEachWord(StringBuilder sb) {
        int start = 0;
        int end = 1;
        int n = sb.length();
        while (start < n) {
            while (end < n && sb.charAt(end) != ' ') {
                end++;
            }
            reverseString(sb, start, end - 1);
            start = end + 1;
            end = start + 1;
        }
    }
}

// 解法二：建立新字元陣列填充。時間複雜性 O(n)
class Solution {
    public String reverseWords(String s) {
        // 來源字元陣列
        char[] initialArr = s.toCharArray();
        // 新字元陣列
        char[] newArr = new char[initialArr.length+1];// 下面迴圈添加"單字 "，最終末尾的空格不會回傳
        int newArrPos = 0;
        // i 來進行整體對來源字元陣列從後往前遍歷
        int i = initialArr.length-1;
        while(i>=0){
            while(i>=0 && initialArr[i] == ' '){i--;}  // 跳過空格
            // 此時 i 位置是邊界或 != 空格，先記錄目前索引，之後的 while 用來確定單字的首字母的位置
            int right = i;
            while(i>=0 && initialArr[i] != ' '){i--;} 
            // 指定區間單字取出(由於 i 為首字母的前一位，所以這裡 +1)，取出的每組末尾都帶有一個空格
            for (int j = i+1; j <= right; j++) {
                newArr[newArrPos++] = initialArr[j];
                if(j == right){
                    newArr[newArrPos++] = ' ';// 空格
                }
            }
        }
        // 若是原始字串沒有單字，直接回傳空字串；若是有單字，回傳 0-末尾空格索引前範圍的字元陣列(轉成 String 回傳)
        if(newArrPos == 0){
            return "";
        }else{
            return new String(newArr,0,newArrPos-1);
        }
    }
}

```java
// 解法三：雙反轉 + 移位，String 的 toCharArray() 方法底層會 new 一個和原字串相同大小的 char 陣列，空間複雜度：O(n)
class Solution {
    /**
     * 思路：
     *	① 反轉字串  "the sky is blue " => " eulb si yks eht"
     *	② 遍歷 " eulb si yks eht"，每次先對某個單字進行反轉再移位
     *	   這裡以第一個單字為例示範：" eulb si yks eht" ==反轉=> " blue si yks eht" ==移位=> "blue si yks eht"
     */
    public String reverseWords(String s) {
        // 步驟 1：字串整體反轉（此時其中的單字也都反轉了）
        char[] initialArr = s.toCharArray();
        reverse(initialArr, 0, s.length() - 1);
        int k = 0;
        for (int i = 0; i < initialArr.length; i++) {
            if (initialArr[i] == ' ') {
                continue;
            }
            int tempCur = i;
            while (i < initialArr.length && initialArr[i] != ' ') {
                i++;
            }
            for (int j = tempCur; j < i; j++) {
                if (j == tempCur) { // 步驟二：二次反轉
                    reverse(initialArr, tempCur, i - 1);// 對指定範圍字串進行反轉，不反轉從後往前遍歷一個個填充有問題
                }
                // 步驟三：移動操作
                initialArr[k++] = initialArr[j];
                if (j == i - 1) { // 遍歷結束
                    // 避免越界情況，例如 => "asdasd df f"，不加判斷最後就會陣列越界
                    if (k < initialArr.length) {
                        initialArr[k++] = ' ';
                    }
                }
            }
        }
        if (k == 0) {
            return "";
        } else {
            // 參數三：以防出現如 "asdasd df f" => "f df asdasd" 正好湊滿不需要省略空格情況
            return new String(initialArr, 0, (k == initialArr.length) && (initialArr[k - 1] != ' ') ? k : k - 1);
        }
    }

    public void reverse(char[] chars, int begin, int end) {
        for (int i = begin, j = end; i < j; i++, j--) {
            chars[i] ^= chars[j];
            chars[j] ^= chars[i];
            chars[i] ^= chars[j];
        }
    }
}
```

```java
/*
 * 解法四：時間複雜性 O(n)
 * 參考卡哥 c++ 程式碼的三步驟：先移除多餘空格，再將整個字串反轉，最後把單字逐個反轉
 * 有別於解法一：沒有用 StringBuilder 實作，而是對 String 的 char[] 陣列操作來實作以上三個步驟
 */
class Solution {
    // 用 char[] 來實作 String 的 removeExtraSpaces，reverse 操作
    public String reverseWords(String s) {
        char[] chars = s.toCharArray();
        // 1. 去除首尾以及中間多餘空格
        chars = removeExtraSpaces(chars);
        // 2. 整個字串反轉
        reverse(chars, 0, chars.length - 1);
        // 3. 單字反轉
        reverseEachWord(chars);
        return new String(chars);
    }

    // 1. 用 fast and slow pointers 去除首尾以及中間多餘空格，可參考陣列元素移除的題解
    public char[] removeExtraSpaces(char[] chars) {
        int slow = 0;
        for (int fast = 0; fast < chars.length; fast++) {
            // 先用 fast 移除所有空格
            if (chars[fast] != ' ') {
                // 再用 slow 加空格。除第一個單字外，單字末尾要加空格
                if (slow != 0)
                    chars[slow++] = ' ';
                // fast 遇到空格或遍歷到字串末尾，就證明遍歷完一個單字了
                while (fast < chars.length && chars[fast] != ' ')
                    chars[slow++] = chars[fast++];
            }
        }
        // 相當於 c++ 裡的 resize()
        char[] newChars = new char[slow];
        System.arraycopy(chars, 0, newChars, 0, slow); 
        return newChars;
    }

    // two pointers 實作指定範圍內字串反轉，可參考字串反轉題解
    public void reverse(char[] chars, int left, int right) {
        if (right >= chars.length) {
            System.out.println("set a wrong right");
            return;
        }
        while (left < right) {
            chars[left] ^= chars[right];
            chars[right] ^= chars[left];
            chars[left] ^= chars[right];
            left++;
            right--;
        }
    }

    // 3. 單字反轉
    public void reverseEachWord(char[] chars) {
        int start = 0;
        // end <= s.length() 這裡的 =，是為了讓 end 永遠指向單字末尾後一個位置，這樣 reverse 的引數更好設定
        for (int end = 0; end <= chars.length; end++) {
            // end 每次到單字末尾後的空格或串尾, 開始反轉單字
            if (end == chars.length || chars[end] == ' ') {
                reverse(chars, start, end - 1);
                start = end + 1;
            }
        }
    }
}
```

        words = s.split()

            left += 1
            right -= 1

class Solution:
    def single_reverse(self, s, start: int, end: int):
        while start < end:
            s[start], s[end] = s[end], s[start]
            start += 1
            end -= 1

    def reverseWords(self, s: str) -> str:
        result = ""
        fast = 0
        # 1. 首先將原字串反轉並且除掉空格, 並且加入到新的字串當中
        # 由於 Python 字串的不可變性，因此只能轉換為串列進行處理
        s = list(s)
        s.reverse()
        while fast < len(s):
            if s[fast] != " ":
                if len(result) != 0:
                    result += " "
                while s[fast] != " " and fast < len(s):
                    result += s[fast]
                    fast += 1
            else:
                fast += 1
        # 2. 其次將每個單字進行翻轉操作
        slow = 0
        fast = 0
        result = list(result)
        while fast <= len(result):
            if fast == len(result) or result[fast] == " ":
                self.single_reverse(result, slow, fast - 1)
                slow = fast + 1
                fast += 1
            else:
                fast += 1

        return "".join(result)

class Solution:
    def reverseWords(self, s: str) -> str:
        words = []
        word = ''

// two pointers 解法。指標逆序遍歷，將遍歷後得到的單字（間隔為空格，用以區分）順序放置在額外空間
// 時間複雜性 O(n)，空間複雜度 O(n)
func reverseWords(s string) string {
    strBytes := []byte(s)
    n := len(strBytes)
    // 記錄有效字元範圍的起始和結束位置
    start, end := 0, n-1
    // 去除開頭空格
    for start < n && strBytes[start] == 32 {
        start++
    }
    // 處理全是空格或空字串情況
    if start == n {
        return ""
    }
    // 去除結尾空格
    for end >= 0 && strBytes[end] == 32 {
        end--
    }
    // 結果切片，預先分配容量
    res := make([]byte, 0, end-start+1)// 這裡挺重要的，本人之前沒有預先分配容量，每次迴圈都添加單字，導致記憶體超限（也可能就是我之前的思路有問題）
    // 從後往前遍歷有效字元範圍
    for i := end; i >= start; {
        // 找單字起始位置，直接透過迴圈條件判斷定位
        for ; i >= start && strBytes[i] == 32; i-- {
        }
        j := i
        for ; j >= start && strBytes[j]!= 32; j-- {
        }
        res = append(res, strBytes[j+1:i+1]...)
        // 只在不是最後一個單字時添加空格
        if j > start {
            res = append(res, 32)
        }
        i = j
    }
    return string(res)
}

function removeExtraSpaces(strArr) {

  let fastIndex = 0;

    // 移除開始位置和重複的空格
    if (strArr[fastIndex] === ' ' && (fastIndex === 0 || strArr[fastIndex - 1] === ' ')) {
      fastIndex++;
    } else {
      strArr[slowIndex++] = strArr[fastIndex++];

  strArr.length = strArr[slowIndex - 1] === ' ' ? slowIndex - 1 : slowIndex;

  let left = start;
  let right = end;

  while(left < right) {
    // 交換
    [strArr[left], strArr[right]] = [strArr[right], strArr[left]];
    left++;
    right--;
  }

    function delExtraSpace(arr: string[]): void {

            right: number = 0,

        while (right < length && arr[right] === ' ') {
            right++;
        }
        while (right < length) {
            if (arr[right] === ' ' && arr[right - 1] === ' ') {
                right++;
                continue;
            }
            arr[left++] = arr[right++];
        }

        } else {
            arr.length = left;

            end--;

/// 1、移除多餘的空格（前後所有的空格，中間只留一個空格）
func removeSpace(_ s: String) -> [Character] {
    let ch = Array(s)
    var left = 0
    var right = ch.count - 1
    // 忽略字串前面的所有空格
    while ch[left] == " " {
        left += 1
    }
    // 忽略字串後面的所有空格
    while ch[right] == " " {
        right -= 1
    }

    // 接下來就是要處理中間的多餘空格
    var lastArr = Array<Character>()
    while left <= right {
        // 準備加到新字串當中的字元
        let char = ch[left]
        // 新的字串的最後一個字元；或者原字串中，準備加到新字串的那個字元；這兩個字元當中，只要有一個不是空格，就可以加到新的字串當中
        if char != " " || lastArr[lastArr.count - 1] != " "  {
            lastArr.append(char)
        }
      
        left += 1
    }
    return lastArr
}

/// 2、反轉整個字串
func reverseString(_ s: inout [Character], startIndex: Int, endIndex: Int)  {
    var start = startIndex
    var end = endIndex
    while start < end {
        (s[start], s[end]) = (s[end], s[start])
        start += 1
        end -= 1
    }
}

/// 3、再次將字串裡面的單字反轉
func reverseWord(_ s: inout [Character]) {
    var start = 0
    var end = 0
    var entry = false

    for i in 0..<s.count {
        if !entry {
            start = i
            entry = true
        }
      
        if entry && s[i] == " " && s[i - 1] != " " {
            end = i - 1
            entry = false
            reverseString(&s, startIndex: start, endIndex: end)
        }

        if entry && (i == s.count - 1) && s[i] != " " {
            end = i
            entry = false
            reverseString(&s, startIndex: start, endIndex: end)
        }
    }

object Solution {
  def reverseWords(s: String): String = {
    var sb = removeSpace(s) // 移除多餘的空格
    reverseString(sb, 0, sb.length - 1) // 翻轉字串
    reverseEachWord(sb)
    sb.mkString
  }

  // 移除多餘的空格
  def removeSpace(s: String): Array[Char] = {
    var start = 0
    var end = s.length - 1
    // 移除字串前面的空格
    while (start < s.length && s(start) == ' ') start += 1
    // 移除字串後面的空格
    while (end >= 0 && s(end) == ' ') end -= 1
    var sb = "" // String
    // 當 start 小於等於 end 的時候，執行添加操作
    while (start <= end) {
      var c = s(start)
      // 目前字元不等於空，sb 的最後一個字元不等於空的時候添加到 sb
      if (c != ' ' || sb(sb.length - 1) != ' ') {
        sb ++= c.toString
      }
      start += 1 // 指標向右移動
    }
    sb.toArray
  }

  // 翻轉字串
  def reverseString(s: Array[Char], start: Int, end: Int): Unit = {
    var (left, right) = (start, end)
    while (left < right) {
      var tmp = s(left)
      s(left) = s(right)
      s(right) = tmp
      left += 1
      right -= 1
    }
  }

  // 翻轉每個單字
  def reverseEachWord(s: Array[Char]): Unit = {
    var i = 0
    while (i < s.length) {
      var j = i + 1
      // 向後疊代尋找每個單字的坐標
      while (j < s.length && s(j) != ' ') j += 1
      reverseString(s, i, j - 1)  // 翻轉每個單字
      i = j + 1   // i 往後更新
    }
  }
}

void removeExtraSpace(char* s) {
    int start = 0; // 指向字串開頭的指標
    int end = strlen(s) - 1; // 指向字串結尾的指標
    while (s[start] == ' ') start++; // 移動指標 start，直到找到第一個非空格字元
    while (s[end] == ' ') end--; // 移動指標 end，直到找到第一個非空格字元
    int slow = 0; // 指向新字串的下一個寫入位置的指標
    for (int i = start; i <= end; i++) { // 遍歷整個字串
