## 解題思路

我們之前介紹的都是各種方式遍歷（traversal）二元樹，這次要反轉了，感覺還是有點傻眼。

這得怎麼反轉呢？

如果要從整個樹（tree）來看，反轉還真的挺複雜，整個樹以中間分割線進行反轉，如圖：


![226.反轉二元樹1](https://file1.kamacoder.com/i/algo/20210203192724351.png)

可以發現想要反轉它，其實就把每一個節點（node）的左右孩子交換（swap）一下就可以了。

關鍵在於遍歷順序，前中後序應該選哪一種遍歷順序？（一些同學這道題都過了，但是不知道自己用的是什麼順序）

遍歷的過程中去反轉每一個節點的左右孩子就可以達到整體反轉的效果。

**注意只要把每一個節點的左右孩子反轉一下，就可以達到整體反轉的效果**

**這道題目使用前序遍歷（preorder traversal）和後序遍歷（post-order traversal）都可以，唯獨中序橫過（inorder traversal）不方便，因為中序橫過會把某些節點的左右孩子反轉了兩次！建議拿紙畫一畫，就理解了**

那麼層次序走訪（level order traversal）可以不可以呢？**依然可以的！只要把每一個節點的左右孩子反轉一下的遍歷方式都是可以的！**

### 遞迴（recursion）法

對於二元樹的遞迴法的前中後序遍歷，已經在[二元樹：前中後序遞迴遍歷](https://programmercarl.com/二叉树的递归遍历.html)詳細講解了。

我們下文以前序遍歷為例，透過動畫來看一下反轉的過程:

![反轉二元樹](https://file1.kamacoder.com/i/algo/%E7%BF%BB%E8%BD%AC%E4%BA%8C%E5%8F%89%E6%A0%91.gif)

我們來看一下遞迴三部曲：

1. 確定遞迴函式（recursive function）的參數（parameter）和轉回值（return value）

參數就是要傳入節點的指標（pointer），不需要其他參數了，通常此時定下來主要參數，如果在寫遞迴的邏輯（logic）中發現還需要其他參數的時候，隨時補充。

轉回值的話其實也不需要，但是題目中給出的要回傳 root 節點的指標，可以直接使用題目定義好的函式（function），所以就函式的傳回類型（return type）為 `TreeNode*`。

```cpp
TreeNode* invertTree(TreeNode* root)
```

2. 確定終止條件（termination condition）

目前節點為空的時候，就回傳

```cpp
if (root == NULL) return root;
```

3. 確定單層遞迴的邏輯

因為是前序遍歷，所以先進行交換左右孩子節點，然後反轉左子樹（left subtree），反轉右子樹（right subtree）。

```cpp
swap(root->left, root->right);
invertTree(root->left);
invertTree(root->right);
```

基於這遞迴三步法，程式碼基本寫完，C++ 程式碼如下：

```CPP
class Solution {
public:
    TreeNode* invertTree(TreeNode* root) {
        if (root == NULL) return root;
        swap(root->left, root->right);  // 中
        invertTree(root->left);         // 左
        invertTree(root->right);        // 右
        return root;
    }
};
```

### 疊代（iteration）法

#### 深度優先搜尋（depth-first search, DFS）遍歷

[二元樹：聽說遞迴能做的，堆疊也能做！](https://programmercarl.com/二叉树的迭代遍历.html)中給出了前中後序疊代方式的寫法，所以本題可以很輕鬆的寫出如下疊代法的程式碼：

C++ 程式碼疊代法（前序遍歷）

```CPP
class Solution {
public:
    TreeNode* invertTree(TreeNode* root) {
        if (root == NULL) return root;
        stack<TreeNode*> st;
        st.push(root);
        while(!st.empty()) {
            TreeNode* node = st.top();              // 中
            st.pop();
            swap(node->left, node->right);
            if(node->right) st.push(node->right);   // 右
            if(node->left) st.push(node->left);     // 左
        }
        return root;
    }
};
```
如果這個程式碼看不懂的話可以再回顧一下[二元樹：聽說遞迴能做的，堆疊也能做！](https://programmercarl.com/二叉树的迭代遍历.html)。


我們在[二元樹：前中後序疊代方式的統一寫法](https://programmercarl.com/二叉树的统一迭代法.html)中介紹了統一的寫法，所以，本題也只需將文中的程式碼稍作修改便可。

C++ 程式碼如下疊代法（前序遍歷）

```CPP
class Solution {
public:
    TreeNode* invertTree(TreeNode* root) {
        stack<TreeNode*> st;
        if (root != NULL) st.push(root);
        while (!st.empty()) {
            TreeNode* node = st.top();
            if (node != NULL) {
                st.pop();
                if (node->right) st.push(node->right);  // 右
                if (node->left) st.push(node->left);    // 左
                st.push(node);                          // 中
                st.push(NULL);
            } else {
                st.pop();
                node = st.top();
                st.pop();
                swap(node->left, node->right);          // 節點處理邏輯
            }
        }
        return root;
    }
};
```

如果上面這個程式碼看不懂，回顧一下文章[二元樹：前中後序疊代方式的統一寫法](https://programmercarl.com/二叉树的统一迭代法.html)。

#### 廣度優先搜尋（breadth-first search, BFS）遍歷

也就是層次序走訪，層次序走訪也是可以反轉這棵樹的，因為層次序走訪也可以把每個節點的左右孩子都反轉一遍，程式碼如下：

```CPP
class Solution {
public:
    TreeNode* invertTree(TreeNode* root) {
        queue<TreeNode*> que;
        if (root != NULL) que.push(root);
        while (!que.empty()) {
            int size = que.size();
            for (int i = 0; i < size; i++) {
                TreeNode* node = que.front();
                que.pop();
                swap(node->left, node->right); // 節點處理
                if (node->left) que.push(node->left);
                if (node->right) que.push(node->right);
            }
        }
        return root;
    }
};
```
如果對以上程式碼不理解，或者不清楚二元樹的層次序走訪，可以看這篇[二元樹：層次序走訪登場！](https://programmercarl.com/0102.二叉树的层序遍历.html)

## 拓展 

**文中我指的是遞迴的中序橫過是不行的，因為使用遞迴的中序橫過，某些節點的左右孩子會反轉兩次。**

如果非要使用遞迴中序的方式寫，也可以，如下程式碼就可以避免節點左右孩子反轉兩次的情況：

```CPP
class Solution {
public:
    TreeNode* invertTree(TreeNode* root) {
        if (root == NULL) return root;
        invertTree(root->left);         // 左
        swap(root->left, root->right);  // 中
        invertTree(root->left);         // 注意 這裡依然要遍歷左孩子，因為中間節點已經反轉了
        return root;
    }
};
```

程式碼雖然可以，但這畢竟不是真正的遞迴中序橫過了。

但使用疊代方式統一寫法的中序是可以的。

程式碼如下：

```CPP
class Solution {
public:
    TreeNode* invertTree(TreeNode* root) {
        stack<TreeNode*> st;
        if (root != NULL) st.push(root);
        while (!st.empty()) {
            TreeNode* node = st.top();
            if (node != NULL) {
                st.pop();
                if (node->right) st.push(node->right);  // 右
                st.push(node);                          // 中
                st.push(NULL);
                if (node->left) st.push(node->left);    // 左

            } else {
                st.pop();
                node = st.top();
                st.pop();
                swap(node->left, node->right);          // 節點處理邏輯
            }
        }
        return root;
    }
};

```

為什麼這個中序就是可以的呢，因為這是用堆疊（stack）來遍歷，而不是靠指標來遍歷，避免了遞迴法中反轉了兩次的情況，大家可以畫圖理解一下，這裡有點意思的。

## 總結

針對二元樹的問題，解題之前一定要想清楚究竟是前中後序遍歷，還是層次序走訪。

**二元樹解題的大忌就是自己稀里糊塗的過了（因為這道題相對簡單），但是也不知道自己是怎麼遍歷的。**

這也是造成了二元樹的題目「一看就會，一寫就廢」的原因。

**針對反轉二元樹，我給出了一種遞迴，三種疊代（兩種模擬（simulation）深度優先搜尋遍歷，一種層次序走訪）的寫法，都是之前我們講過的寫法，融會貫通一下而已。**

大家一定也有自己的解法，但一定要成方法論，這樣才能通用，才能舉一反三！

```Java
//DFS遞迴
class Solution {
   /**
     * 前後序遍歷都可以
     * 中序不行，因為先左孩子交換孩子，再根交換孩子（做完後，右孩子已經變成了原來的左孩子），再右孩子交換孩子（此時其實是對原來的左孩子做交換）
     */
    public TreeNode invertTree(TreeNode root) {
        if (root == null) {
            return null;
        }
        invertTree(root.left);
        invertTree(root.right);
        swapChildren(root);
        return root;
    }

    private void swapChildren(TreeNode root) {
        TreeNode tmp = root.left;
        root.left = root.right;
        root.right = tmp;
    }
}

//BFS
class Solution {
    public TreeNode invertTree(TreeNode root) {
        if (root == null) {return null;}
        ArrayDeque<TreeNode> deque = new ArrayDeque<>();
        deque.offer(root);
        while (!deque.isEmpty()) {
            int size = deque.size();
            while (size-- > 0) {
                TreeNode node = deque.poll();
                swap(node);
                if (node.left != null) deque.offer(node.left);
                if (node.right != null) deque.offer(node.right);
            }
        }
        return root;
    }

    public void swap(TreeNode root) {
        TreeNode temp = root.left;
        root.left = root.right;
        root.right = temp;
    }
}
```

```go
    node := root
    var prev *TreeNode
```

```javascript
var invertTree = function(root) {
    //我們先定義節點交換函式
    const invertNode = function(root, left, right) {
        let temp = left;
        left = right;
        right = temp;
        root.left = left;
        root.right = right;
    }
    //使用疊代方法的前序遍歷 
    let stack = [];
    if(root === null) {
        return root;
    }
    stack.push(root);
    while(stack.length) {
        let node = stack.pop();
        if(node !== null) {
            //前序遍歷順序中左右  入堆疊順序是前序遍歷的倒序右左中
            node.right && stack.push(node.right);
            node.left && stack.push(node.left);
            stack.push(node);
            stack.push(null);
        } else {
            node = stack.pop();
            //節點處理邏輯
            invertNode(node, node.left, node.right);
        }
    }
    return root;
};
```

```javascript
var invertTree = function(root) {
    //我們先定義節點交換函式
    const invertNode = function(root, left, right) {
        let temp = left;
        left = right;
        right = temp;
        root.left = left;
        root.right = right;
    }
    //使用層次序走訪
    let queue = [];
    if(root === null) {
        return root;
    } 
    queue.push(root);
    while(queue.length) {
        let length = queue.length;
        while(length--) {
            let node = queue.shift();
            //節點處理邏輯
            invertNode(node, node.left, node.right);
            node.left && queue.push(node.left);
            node.right && queue.push(node.right);
        }
    }
    return root;
};
```

```scala
object Solution {
  import scala.collection.mutable
  def invertTree(root: TreeNode): TreeNode = {
    if (root == null) return root
    val queue = mutable.Queue[TreeNode]()
    queue.enqueue(root)
    while (!queue.isEmpty) {
      val len = queue.size
      for (i <- 0 until len) {
        var curNode = queue.dequeue()
        if (curNode.left != null) queue.enqueue(curNode.left)
        if (curNode.right != null) queue.enqueue(curNode.right)
        // 反轉
```
