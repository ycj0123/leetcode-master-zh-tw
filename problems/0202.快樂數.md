# 第 202 題. 快樂數

[LeetCode 題目連結](https://leetcode.cn/problems/happy-number/)

編寫一個演算法來判斷一個數 n 是不是快樂數。

「快樂數」定義為：對於一個正整數（positive integer），每一次將該數替換為它每個位置上的數字的平方和，然後重複（duplicate）這個過程直到這個數變為 1，也可能是 無限迴路（infinite loop） 但始終變不到 1。如果 可以變為 1，那麼這個數就是快樂數。

如果 n 是快樂數就回傳 True ；不是，則回傳 False 。

**範例：**

輸入：19     
輸出：true    
解釋：           
1^2 + 9^2 = 82        
8^2 + 2^2 = 68     
6^2 + 8^2 = 100   
1^2 + 0^2 + 0^2 = 1    

## 解題思路

這道題目看上去貌似一道數學問題，其實並不是！

題目中說了會 **無限迴路**，那麼也就是說**求和的過程中，sum 會重複出現，這對解題很重要！**

正如：[關於雜湊表（hash table），你該了解這些！](https://programmercarl.com/哈希表理论基础.html)中所說，**當我們遇到了要快速判斷一個元素（element）是否出現在集合（set）裡的時候，就要考慮雜湊法（hashing）了。**

所以這道題目使用雜湊法，來判斷這個 sum 是否重複出現，如果重複了就是 return false， 否則一直找到 sum 為 1 為止。

判斷 sum 是否重複出現就可以使用 unordered_set。

**還有一個難點就是求和的過程，如果對取數值各個位上的單數操作不熟悉的話，做這道題也會比較艱難。**

C++ 程式碼如下：

```CPP
class Solution {
public:
    // 取數值各個位上的單數之和
    int getSum(int n) {
        int sum = 0;
        while (n) {
            sum += (n % 10) * (n % 10);
            n /= 10;
        }
        return sum;
    }
    bool isHappy(int n) {
        unordered_set<int> set;
        while(1) {
            int sum = getSum(n);
            if (sum == 1) {
                return true;
            }
            // 如果這個 sum 曾經出現過，說明已經陷入了無限迴路了，立刻 return false
            if (set.find(sum) != set.end()) {
                return false;
            } else {
                set.insert(sum);
            }
            n = sum;
        }
    }
};
```

* 時間複雜度（time complexity）: O(logn)
* 空間複雜度（space complexity）: O(logn)

  import scala.collection.mutable
  def isHappy(n: Int): Boolean = {
    // 存放每次計算後的結果
    val set: mutable.HashSet[Int] = new mutable.HashSet[Int]()
    var tmp = n // 因為形式參數是不可變數，所以需要找到一個臨時變數
