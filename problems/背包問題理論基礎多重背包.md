## 多重背包

對於多重背包，我在 LeetCode 上還沒發現對應的題目，所以這裡就做一下簡單介紹，大家大概了解一下。

有 N 種物品和一個容量為 V 的背包。第 i 種物品最多有 Mi 件可用，每件耗費的空間是 Ci，價值是 Wi。求解將哪些物品裝入背包可使這些物品的耗費空間總和不超過背包容量，且價值總和最大。

多重背包和 0/1 背包是非常像的，為什麼和 0/1 背包像呢？

每件物品最多有 Mi 件可用，把 Mi 件攤開，其實就是一個 0/1 背包問題了。

例如：

背包最大重量為 10。

物品為：

|       | 重量 | 價值 | 數量 |
| ---   | ---  | ---  | ---  |
| 物品0 | 1    | 15   | 2    |
| 物品1 | 3    | 20   | 3    |
| 物品2 | 4    | 30   | 2    |

問背包能背的物品最大價值是多少？

和如下情況有區別嗎？

|       | 重量 | 價值 | 數量 |
| ---   | ---  | ---  | ---  |
| 物品0 | 1    | 15   | 1    |
| 物品0 | 1    | 15   | 1    |
| 物品1 | 3    | 20   | 1    |
| 物品1 | 3    | 20   | 1    |
| 物品1 | 3    | 20   | 1    |
| 物品2 | 4    | 30   | 1    |
| 物品2 | 4    | 30   | 1    |

毫無區別，這就轉成了一個 0/1 背包問題了，且每個物品只用一次。


練習題目：[KamaCoder 第 56 題，bounded knapsack](https://kamacoder.com/problempage.php?pid=1066)

程式碼如下：


```CPP
// 超時了
#include<iostream>
#include<vector>
using namespace std;
int main() {
    int bagWeight,n;
    cin >> bagWeight >> n;
    vector<int> weight(n, 0); 
    vector<int> value(n, 0);
    vector<int> nums(n, 0);
    for (int i = 0; i < n; i++) cin >> weight[i];
    for (int i = 0; i < n; i++) cin >> value[i];
    for (int i = 0; i < n; i++) cin >> nums[i];    
    
    for (int i = 0; i < n; i++) {
        while (nums[i] > 1) { // 物品數量不是一的，都展開
            weight.push_back(weight[i]);
            value.push_back(value[i]);
            nums[i]--;
        }
    }
 
    vector<int> dp(bagWeight + 1, 0);
    for(int i = 0; i < weight.size(); i++) { // 遍歷物品，注意此時的物品數量不是 n
        for(int j = bagWeight; j >= weight[i]; j--) { // 遍歷背包容量
            dp[j] = max(dp[j], dp[j - weight[i]] + value[i]);
        }
    }
    cout << dp[bagWeight] << endl;
}
```

大家去提交之後，發現這個解法超時了，為什麼呢，哪裡耗時呢？

耗時就在這段程式碼：

```CPP 
for (int i = 0; i < n; i++) {
    while (nums[i] > 1) { // 物品數量不是一的，都展開
        weight.push_back(weight[i]);
        value.push_back(value[i]);
        nums[i]--;
    }
}
```

如果物品數量很多的話，C++ 中，這種操作十分費時，主要消耗在 vector 的動態底層擴容上。（其實這裡也可以最佳化，先把所有物品數量都計算好，一起申請 vector 的空間。）


這裡也有另一種實作方式，就是把每種商品遍歷（traversal）的個數放在 0/1 背包裡面再遍歷一遍。

程式碼如下：（詳看註解）

```CPP 
#include<iostream>
#include<vector>
using namespace std;
int main() {
    int bagWeight,n;
    cin >> bagWeight >> n;
    vector<int> weight(n, 0);
    vector<int> value(n, 0);
    vector<int> nums(n, 0);
    for (int i = 0; i < n; i++) cin >> weight[i];
    for (int i = 0; i < n; i++) cin >> value[i];
    for (int i = 0; i < n; i++) cin >> nums[i];

    vector<int> dp(bagWeight + 1, 0);

    for(int i = 0; i < n; i++) { // 遍歷物品
        for(int j = bagWeight; j >= weight[i]; j--) { // 遍歷背包容量
            // 以上為 0/1 背包，然後加一個遍歷個數
            for (int k = 1; k <= nums[i] && (j - k * weight[i]) >= 0; k++) { // 遍歷個數
                dp[j] = max(dp[j], dp[j - k * weight[i]] + k * value[i]);
            }
        }
    }

    cout << dp[bagWeight] << endl;
}
```

時間複雜度（time complexity）：O(m × n × k)，m：物品種類個數，n：背包容量，k：單類物品數量

從程式碼裡可以看出是 0/1 背包裡面再加一個 for 迴圈（for-loop）遍歷每種商品的數量。和 0/1 背包還是如出一轍的。

當然還有那種二進制（binary）最佳化的方法，其實就是把每種物品的數量，打包成一個個獨立的包。

和以上在迴圈（loop）遍歷上有所不同，因為是分拆為各個包最後可以組成一個完整背包，具體原理我就不做過多解釋了，大家了解一下就行，面試的話基本不會考到這個深度了，感興趣可以自己深入研究一下。

### Java：

```Java
import java.util.Scanner;
class multi_pack{
    public static void main(String [] args) {
        Scanner sc = new Scanner(System.in);

        /**
         * bagWeight:背包容量
         * n:物品種類
         */
        int bagWeight, n;
        
        //取得使用者輸入資料，中間用空格隔開，Enter 鍵換行
        bagWeight = sc.nextInt();
        n = sc.nextInt();
        int[] weight = new int[n];
        int[] value = new int[n];
        int[] nums = new int[n];
        for (int i = 0; i < n; i++) weight[i] = sc.nextInt();
        for (int i = 0; i < n; i++) value[i] = sc.nextInt();
        for (int i = 0; i < n; i++) nums[i] = sc.nextInt();

        int[] dp = new int[bagWeight + 1];

        //先遍歷物品再遍歷背包，作為 0/1 背包處理
        for (int i = 0; i < n; i++) {
            for (int j = bagWeight; j >= weight[i]; j--) {
                //遍歷每種物品的個數
                for (int k = 1; k <= nums[i] && (j - k * weight[i]) >= 0; k++) {
                    dp[j] = Math.max(dp[j], dp[j - k * weight[i]] + k * value[i]);
                }
            }
        }
        System.out.println(dp[bagWeight]);
    }
}
```

C, N = input().split(" ")
C, N = int(C), int(N)

# value 陣列需要判斷一下非空不然過不了
weights = [int(x) for x in input().split(" ")]
values = [int(x) for x in input().split(" ") if x]
nums = [int(x) for x in input().split(" ")]

dp = [0] * (C + 1)
# 遍歷背包容量
for i in range(N):
    for j in range(C, weights[i] - 1, -1):
        for k in range(1, nums[i] + 1):
            # 遍歷 k，如果已經大於背包容量直接跳出迴圈
            if k * weights[i] > j:
                break
            dp[j] = max(dp[j], dp[j - weights[i] * k] + values[i] * k) 
print(dp[-1])
