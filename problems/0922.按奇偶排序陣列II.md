# 922. 按奇偶排序（sorting）陣列（array） II

[LeetCode 題目連結](https://leetcode.cn/problems/sort-array-by-parity-ii/)

給定一個非負整數（nonnegative integer）陣列 nums，nums 中一半整數（integer）是奇數，一半整數是偶數。

對陣列進行排序，以便當 nums[i] 為奇數時，i 也是奇數；當 nums[i] 為偶數時，i 也是偶數。

你可以回傳任何滿足上述條件（condition）的陣列作為答案。

範例：

* 輸入：[4,2,5,7]
* 輸出：[4,5,2,7]
* 解釋：[4,7,2,5]，[2,5,4,7]，[2,7,4,5] 也會被接受。


## 解題思路

這道題目直接的想法可能是兩層 for 迴圈（for-loop）再加上 used 陣列表示使用過的元素（element）。這樣的時間複雜度（time complexity）是 O(n^2)。

### 方法一

其實這道題可以用很樸實的方法（method），時間複雜度就是 O(n) 了，C++ 程式碼如下：

```CPP
class Solution {
public:
    vector<int> sortArrayByParityII(vector<int>& nums) {
        vector<int> even(nums.size() / 2); // 初始化就確定陣列大小，節省開銷
        vector<int> odd(nums.size() / 2);
        vector<int> result(nums.size());
        int evenIndex = 0;
        int oddIndex = 0;
        int resultIndex = 0;
        // 把 nums 陣列放進偶數陣列和奇數陣列
        for (int i = 0; i < nums.size(); i++) {
            if (nums[i] % 2 == 0) even[evenIndex++] = nums[i];
            else odd[oddIndex++] = nums[i];
        }
        // 把偶數陣列、奇數陣列分別放進 result 陣列中
        for (int i = 0; i < evenIndex; i++) {
            result[resultIndex++] = even[i];
            result[resultIndex++] = odd[i];
        }
        return result;
    }
};
```

* 時間複雜度：O(n)
* 空間複雜度（space complexity）：O(n)

### 方法二

以上程式碼我是建了兩個輔助陣列（auxiliary array），而且 nums 陣列還相當於遍歷（traversal）了兩次，用輔助陣列的好處就是思路清晰，最佳化一下就是不用這兩個輔助陣列，程式碼如下：

```CPP
class Solution {
public:
    vector<int> sortArrayByParityII(vector<int>& nums) {
        vector<int> result(nums.size());
        int evenIndex = 0;  // 偶數下標
        int oddIndex = 1;   // 奇數下標
        for (int i = 0; i < nums.size(); i++) {
            if (nums[i] % 2 == 0) {
                result[evenIndex] = nums[i];
                evenIndex += 2;
            }
            else {
                result[oddIndex] = nums[i];
                oddIndex += 2;
            }
        }
        return result;
    }
};
```

* 時間複雜度：O(n)
* 空間複雜度：O(n)

### 方法三

當然還可以在原陣列上修改，連 result 陣列都不用了。

```CPP
class Solution {
public:
    vector<int> sortArrayByParityII(vector<int>& nums) {
        int oddIndex = 1;
        for (int i = 0; i < nums.size(); i += 2) {
            if (nums[i] % 2 == 1) { // 在偶數位遇到了奇數
                while(nums[oddIndex] % 2 != 0) oddIndex += 2; // 在奇數位找一個偶數
                swap(nums[i], nums[oddIndex]); // 調換
            }
        }
        return nums;
    }
};
```

* 時間複雜度：O(n)
* 空間複雜度：O(1)

這裡時間複雜度並不是 O(n^2)，因為偶數位和奇數位都只操作一次，不是 n/2 * n/2 的關係，而是 n/2 + n/2 的關係！

class Solution922 {
    public int[] sortArrayByParityII(int[] nums) {
        // 定義 two pointers
        int oddPoint = 1, evenPoint = 0;
        // 開始移動並交換，最後一層必然為相互交換後再移動，或者相同直接移動
        while(oddPoint < nums.length && evenPoint < nums.length){
            // 進行判斷
            if(nums[oddPoint] % 2 == 0 && nums[evenPoint] % 2 == 1){    // 如果均不滿足
                int temp = 0;
                temp = nums[oddPoint];
                nums[oddPoint] = nums[evenPoint];
                nums[evenPoint] = temp;
                oddPoint += 2;
                evenPoint += 2;
            }else if(nums[oddPoint] % 2 == 0 && nums[evenPoint] % 2 == 0){  // 偶數滿足
                evenPoint += 2;
            }else if(nums[oddPoint] % 2 == 1 && nums[evenPoint] % 2 == 1){  // 奇數滿足
                oddPoint += 2;
            }else{
                oddPoint += 2;
                evenPoint += 2;
            }
        }
        return nums;
    }

function sortArrayByParityII(nums: number[]): number[] {
    const length: number = nums.length;
    let oddIndex: number = 1;
    for (let evenIndex = 0; evenIndex < length; evenIndex += 2) {
        if (nums[evenIndex] % 2 === 1) {
            // 在偶數位遇到了奇數
            while (oddIndex < length && nums[oddIndex] % 2 === 1) {
                oddIndex += 2;
            }
            // 在奇數位遇到了偶數，交換
            let temp = nums[evenIndex];
            nums[evenIndex] = nums[oddIndex];
            nums[oddIndex] = temp;
        }

};
