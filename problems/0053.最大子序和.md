# 53. 最大子序和

[LeetCode 題目連結](https://leetcode.cn/problems/maximum-subarray/)

給定一個整數（integer）陣列（array） nums ，找到一個具有最大和的連續子陣列（subarray）（子陣列最少包含一個元素（element）），回傳其最大和。

範例:

- 輸入: [-2,1,-3,4,-1,2,1,-5,4]
- 輸出: 6
- 解釋:  連續子陣列 [4,-1,2,1] 的和最大，為 6。

## 解題思路

### 蠻力（brute force）解法

蠻力解法的想法，第一層 for 就是設定起始位置，第二層 for 迴圈（for-loop）遍歷（traversal）陣列尋找最大值


```CPP
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int result = INT32_MIN;
        int count = 0;
        for (int i = 0; i < nums.size(); i++) { // 設定起始位置
            count = 0;
            for (int j = i; j < nums.size(); j++) { // 每次從起始位置 i 開始遍歷尋找最大值
                count += nums[j];
                result = count > result ? count : result;
            }
        }
        return result;
    }
};
```
* 時間複雜性（time complexity）：O(n^2)
* 空間複雜度（space complexity）：O(1)


以上蠻力的解法 C++ 勉強可以過，其他語言就不確定了。

### 貪心解法

**貪心貪的是哪裡呢？**

如果 -2 1 在一起，計算起點的時候，一定是從 1 開始計算，因為負數只會拉低總和，這就是貪心貪的地方！

區域最佳（local optimum）：目前「連續和」為負數的時候立刻放棄，從下一個元素重新計算「連續和」，因為負數加上下一個元素「連續和」只會越來越小。

總體最佳（global optimum）：選取最大「連續和」

**區域最佳的情況下，並記錄最大的「連續和」，可以推出總體最佳**。

從程式碼角度上來講：遍歷 nums，從頭開始用 count 累積，如果 count 一旦加上 nums[i] 變為負數，那麼就應該從 nums[i+1] 開始從 0 累積 count 了，因為已經變為負數的 count，只會拖累總和。

**這相當於蠻力解法中的不斷調整最大子序和區間（interval）的起始位置**。

**那有同學問了，區間終止位置不用調整嗎？ 如何才能得到最大「連續和」呢？**

區間的終止位置，其實就是如果 count 取到最大值了，及時記錄下來了。例如如下程式碼：

```
if (count > result) result = count;
```

**這樣相當於是用 result 記錄最大子序和區間和（變相地算是調整了終止位置）**。

如動畫所示：

![53.最大子序和](https://file1.kamacoder.com/i/algo/53.%E6%9C%80%E5%A4%A7%E5%AD%90%E5%BA%8F%E5%92%8C.gif)

紅色的起始位置就是貪心每次取 count 為正數的時候，開始一個區間的統計。

那麼不難寫出如下 C++ 程式碼（關鍵地方已經註解）

```CPP
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int result = INT32_MIN;
        int count = 0;
        for (int i = 0; i < nums.size(); i++) {
            count += nums[i];
            if (count > result) { // 取區間累計的最大值（相當於不斷確定最大子序終止位置）
                result = count;
            }
            if (count <= 0) count = 0; // 相當於重置最大子序起始位置，因為遇到負數一定是拉低總和
        }
        return result;
    }
};
```
- 時間複雜性：O(n)
- 空間複雜度：O(1)

當然題目沒有說如果陣列為空，應該回傳什麼，所以陣列為空的話回傳啥都可以了。

### 常見誤區

誤區一：

不少同學認為 如果輸入案例都是 -1，或者都是負數，這個貪心演算法跑出來的結果是 0，這是**又一次證明腦補模擬（simulation）不靠譜的經典案例**，建議大家把程式碼執行一下試一試，就知道了，也會理解為什麼 result 要初始化（initialization）為最小負數了。

誤區二：

大家在使用貪心演算法求解本題，經常陷入的誤區，就是分不清，是遇到負數就選擇起始位置，還是連續和為負選擇起始位置。

在動畫演示中，大家可以發現，4，遇到 -1 的時候，我們依然累加了，為什麼呢？

因為和為 3，只要連續和還是正數就會對後面的元素起到增大總和的作用。所以只要連續和為正數我們就保留。

這裡也會有錄友疑惑，那 4 + -1 之後不就變小了嗎？ 會不會錯過 4 成為最大連續和的可能性？

其實並不會，因為還有一個變數（variable） result 一直在更新最大的連續和，只要有更大的連續和出現，result 就更新了，那麼 result 已經把 4 更新了，後面連續和變成 3，也不會對最後結果有影響。

### 動態規劃（dynamic programming, DP）

當然本題還可以用動態規劃來做，在代碼隨想錄動態規劃章節我會詳細介紹，如果大家現在想看，可以直接跳轉：[動態規劃版本詳解](https://programmercarl.com/0053.%E6%9C%80%E5%A4%A7%E5%AD%90%E5%BA%8F%E5%92%8C%EF%BC%88%E5%8A%A8%E6%80%81%E8%A7%84%E5%88%92%EF%BC%89.html#%E6%80%9D%E8%B7%AF)

那麼先給出我的 dp 程式碼如下，有時間的錄友可以提前做一做：

```CPP
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        if (nums.size() == 0) return 0;
        vector<int> dp(nums.size(), 0); // dp[i] 表示包括 i 之前的最大連續次序列和
        dp[0] = nums[0];
        int result = dp[0];
        for (int i = 1; i < nums.size(); i++) {
            dp[i] = max(dp[i - 1] + nums[i], nums[i]); // 狀態變遷方程式
            if (dp[i] > result) result = dp[i]; // result 保存 dp[i] 的最大值
        }
        return result;
    }
};
```

- 時間複雜性：O(n)
- 空間複雜度：O(n)

```python
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        max_sum = float("-inf") # 初始化結果為負無窮大，方便比較取最大值
        current_sum = 0         # 初始化目前連續和

        for num in nums:

            # 更新目前連續和
            # 如果原本的連續和加上目前數字之後沒有目前數字大，說明原本的連續和是負數，那麼就直接從目前數字開始重新計算連續和
            current_sum = max(current_sum+num, num) 
            max_sum = max(max_sum, current_sum) # 更新結果

        return max_sum
```

### C:

貪心：

```c
int maxSubArray(int* nums, int numsSize){
    int maxVal = INT_MIN;
    int subArrSum = 0;

    int i;
    for(i = 0; i < numsSize; ++i) {
        subArrSum += nums[i];
        // 若目前局部和大於之前的最大結果，對結果進行更新
        maxVal = subArrSum > maxVal ? subArrSum : maxVal;
        // 若目前局部和為負，對結果無益。則從 nums[i+1] 開始應重新計算。
        subArrSum = subArrSum < 0 ? 0 : subArrSum;
    }

    return maxVal;
}
```

動態規劃：

```c
/**
 * 解題思路：動態規劃：
 * 1. dp 陣列：dp[i] 表示從 0 到 i 的次序列中最大序列和的值
 * 2. 遞迴公式：dp[i] = max(dp[i-1] + nums[i], nums[i])
        若 dp[i-1]<0，對最後結果無益。dp[i] 則為 nums[i]。
 * 3. dp 陣列初始化：dp[0] 的最大子陣列和為 nums[0]
 * 4. 推導順序：從前往後遍歷
 */

#define max(a, b) (((a) > (b)) ? (a) : (b))

int maxSubArray(int* nums, int numsSize){
    int dp[numsSize];
    // dp[0] 最大子陣列和為 nums[0]
    dp[0] = nums[0];
    // 若 numsSize 為 1，應直接回傳 nums[0]
    int subArrSum = nums[0];

    int i;
    for(i = 1; i < numsSize; ++i) {
        dp[i] = max(dp[i - 1] + nums[i], nums[i]);

        // 若 dp[i] 大於之前記錄的最大值，進行更新
        if(dp[i] > subArrSum)
            subArrSum = dp[i];
    }

    return subArrSum;
}
```
