# 189. 旋轉陣列（array）

[LeetCode 題目連結](https://leetcode.cn/problems/rotate-array/)

給定一個陣列，將陣列中的元素（element）向右移動 k 個位置，其中 k 是非負數。

進階：

盡可能想出更多的解決方案，至少有三種不同的方法可以解決這個問題。
你可以使用空間複雜度（space complexity）為 O(1) 的 in-place 演算法解決這個問題嗎？

範例 1:

* 輸入: nums = [1,2,3,4,5,6,7], k = 3
* 輸出: [5,6,7,1,2,3,4]
* 解釋:
向右旋轉 1 步: [7,1,2,3,4,5,6]。
向右旋轉 2 步: [6,7,1,2,3,4,5]。
向右旋轉 3 步: [5,6,7,1,2,3,4]。

範例 2:
* 輸入：nums = [-1,-100,3,99], k = 2
* 輸出：[3,99,-1,-100]
* 解釋:
向右旋轉 1 步: [99,-1,-100,3]。
向右旋轉 2 步: [3,99,-1,-100]。


## 解題思路

這道題目在字串（string）裡其實很常見，我把字串反轉（reverse）相關的題目列一下：

* [字串：LeetCode 541.反轉字串 II](https://programmercarl.com/0541.反转字符串II.html)
* [字串：LeetCode 151.翻轉字串裡的單詞](https://programmercarl.com/0151.翻转字符串里的单词.html)
* [字串：劍指 Offer 58-II.左旋轉字串](https://programmercarl.com/剑指Offer58-II.左旋转字符串.html)

本題其實和[字串：劍指 Offer 58-II.左旋轉字串](https://programmercarl.com/剑指Offer58-II.左旋转字符串.html)就非常像了，劍指 offer 上左旋轉，本題是右旋轉。

注意題目要求是**要求使用空間複雜度為 O(1) 的 in-place 演算法**

那麼我來提供一種旋轉的方式哈。

在[字串：劍指 Offer 58-II.左旋轉字串](https://programmercarl.com/剑指Offer58-II.左旋转字符串.html)中，我們提到，如下步驟就可以左旋轉字串：

1. 反轉區間（interval）為前 n 的子字串（substring）
2. 反轉區間為 n 到末尾的子字串
3. 反轉整個字串

本題是右旋轉，其實就是反轉的順序改動一下，優先反轉整個字串，步驟如下：

1. 反轉整個字串
2. 反轉區間為前 k 的子字串
3. 反轉區間為 k 到末尾的子字串

**需要注意的是，本題還有一個小陷阱，題目輸入中，如果 k 大於 nums.size 了應該怎麼辦？**

舉個例子，比較容易想，

例如，1,2,3,4,5,6,7  如果右移動 15 次的話，是 7 1 2 3 4 5 6  。

所以其實就是右移 k % nums.size() 次，即：15 % 7 = 1

C++ 程式碼如下：

```CPP
class Solution {
public:
    void rotate(vector<int>& nums, int k) {
        k = k % nums.size();
        reverse(nums.begin(), nums.end());
        reverse(nums.begin(), nums.begin() + k);
        reverse(nums.begin() + k, nums.end());

    }
};
```


## 其他語言版本

### Java

```java
class Solution {
    private void reverse(int[] nums, int start, int end) {
        for (int i = start, j = end; i < j; i++, j--) {
            int temp = nums[j];
            nums[j] = nums[i];
            nums[i] = temp;
        }
    }
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        k %= n;
        reverse(nums, 0, n - 1);
        reverse(nums, 0, k - 1);
        reverse(nums, k, n - 1);
    }
}
```

### Python

方法一：局部翻轉 + 整體翻轉
```python
class Solution:
    def rotate(self, A: List[int], k: int) -> None:
        def reverse(i, j):
            while i < j:
                A[i], A[j] = A[j], A[i]
                i += 1
                j -= 1
        n = len(A)
        k %= n
        reverse(0, n - 1)
        reverse(0, k - 1)
        reverse(k, n - 1)
```

方法二：利用餘數

```python 
class Solution:
    def rotate(self, nums: List[int], k: int) -> None:
        copy = nums[:]

        for i in range(len(nums)):
            nums[(i + k) % len(nums)] = copy[i]
        
        return nums

        # 備註：這個方法會導致空間複雜度變成 O(n) 因為我們要建立一個 copy 陣列。但是不失為一種思路。
```

### TypeScript

```typescript
function rotate(nums: number[], k: number): void {
    const length: number = nums.length;
    k %= length;
    reverseByRange(nums, 0, length - 1);
    reverseByRange(nums, 0, k - 1);
    reverseByRange(nums, k, length - 1);
};
function reverseByRange(nums: number[], left: number, right: number): void {
    while (left < right) {
        const temp = nums[left];
        nums[left] = nums[right];
        nums[right] = temp;
        left++;
        right--;
    }
}
```

impl Solution {
    pub fn rotate(nums: &mut Vec<i32>, k: i32) {
        let k = k as usize % nums.len();
        nums.reverse();
        nums[..k].reverse();
        nums[k..].reverse();
    }
}
