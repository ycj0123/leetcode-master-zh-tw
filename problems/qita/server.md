## 架設 Git 私有伺服器

大家平時工作的時候一定有一個自己的工作資料夾，學生的話就是自己的課程講義、考試、準備面試的資料等等。

已經工作的錄友，會有一個資料夾放著自己重要的文件、Markdown、圖片、履歷等等。

這麼重要的資料夾，而且我們每天都要更新，也擔心哪天電腦丟了，或者壞了，突然這些都不見了。

所以我們想備份嘛。

還有就是我們經常個人電腦和工作電腦要同步一些私人資料，而不是用微信傳來傳去。

這些都是 Git 私有伺服器的使用情境，而且很好用。

大家也知道 GitHub、Gitee 也可以搞私人儲存庫（repository）用來備份、同步檔案，但自己的文件可能放著很多重要的資訊，包括自己的各種密碼、金鑰之類的，放到上面未必安全。你就不怕哪些重大錯誤（bug）把你的資訊都洩漏了嗎[機智]

更關鍵的是，GitHub 和 Gitee 都限速的。畢竟人家的功能定位並不是雲端硬碟。

專案裡有大檔案（幾百 MB 以上），例如 PDF、PPT 等等，其上傳和下載速度會讓你窒息。

## 搞一個檔案儲存

這個可以用來產生檔案的下載連結，也可以把本機檔案傳到伺服器上。

相當於自己做一個物件（object）儲存，其實雲端服務商也有物件儲存的產品。

不過我們自己也可以做一個，不過很多同學應該都不知道物件儲存怎麼用吧，其實我們用伺服器可以自己做一個類似的功能。

我現在就用自己用 Go 寫的一個工具，部署在伺服器上。用來和伺服器傳檔案，或者產生一些檔案的臨時下載連結。

這些都是直接命令列操作的，

操作方式這樣，我把命令包裝成一個 shell 命令，想傳哪個檔案，直接 uploadtomyserver，然後就回傳可以下載的連結，這個檔案也同時傳到了我的伺服器上。

## 網站

做網站，例如大家知道用 HTML 寫幾行程式碼，就可以產生一個網頁，但怎麼給別人展示呢？

大家如果用自己的電腦做伺服器，只能同一個路由器下的裝置可以存取你的網站，可能這個裝置出了這個屋子都存取不了你的網站了。

因為你的 IP 不是公網 IP。

如果有一台雲端伺服器，都會配置公網 IP，你的網站就可以讓任何人存取了。

或者說你提供的一個服務就可以讓任何人使用。

例如第二個例子中，我們可以自己開發一個檔案儲存，這個服務我只把命令列工具給其他人，其他人都可以使用我的服務來產生連結，當然他們的檔案也都傳到了我的伺服器上。

再說一個使用情境。

我之前在舉辦免費領伺服器的活動的時候，阿里雲給我一個 Excel，裡面就是從我這裡買伺服器的錄友名單，我直接把這個名單丟到群裡，讓大家自己檢查，出現在名單裡就可以找我領現金回饋，這樣做是不是也可以？

這麼做有幾個很大的問題：
* 大家都要去下載 Excel，做對比，會有人改 Excel 的內容然後就說是從你這裡買的，我不可能逐一去比較 Excel 有沒有改動
* Excel 有其他人的個人資訊，這是不能暴露的。
* 如果每個人自己用 Excel 查詢，私訊我領現金回饋，將近兩千人找我領現金回饋，我微信根本處理不過來，這就變成體力活了。

那應該怎麼做呢？

我就簡單寫一個查詢的頁面，後端邏輯就是讀取一個 Excel 表格，大家在查詢頁面輸入自己的阿里雲 ID，如果在 Excel 裡，頁面就會回傳回饋群組的 QR Code，大家就可以自主掃碼加群組了。

這樣，我最後就直接在回饋群組裡發等額紅包就好了，是不是極大降低人力成本了

當然我是把 17 個回饋群組的 QR Code 都產生好了，按照一定的規則，展現給查詢通過的錄友。

就是這樣一個非常普通的查詢頁面。

![](https://file1.kamacoder.com/i/algo/20211126160200.png)

查詢通過之後，就會展現回饋群組 QR Code。

![](https://file1.kamacoder.com/i/algo/20211127160558.png)

## 學習 Linux

學習 Linux 其實在自己的電腦上搞一台虛擬機器（virtual machine），或者安裝雙系統也可以學習，不過這很考驗你的電腦效能如何了。

如果你有一個伺服器，那就是獨立的一台電腦，你想怎麼折騰就怎麼折騰，而且一年都不用關機，可以一直跑你的任務，和你本機電腦也完全隔離。

更方便的是，你目前系統假如是 CentOS，想做一個實驗需要在 Ubuntu 上，如果是雲端伺服器，更換系統就是在後台點一下，一鍵重灌，雲端服務商基本都是支援所有系統一鍵安裝的。

我們平時自己玩 Linux 經常是設定各種環境，然後這個 Linux 就被自己玩壞了（一般都是毫無節制使用 root 權限導致的），總之就是環境設定不起來了，基本就要重灌了。

那雲端伺服器重灌系統可太方便了。

還有就是假如你好不容易設定好的環境，如果以後把這個環境玩壞了，你想回退到之前設定好的環境而不是重灌系統再重新設定一遍吧。

那麼可以用雲端伺服器的映像檔保存功能，就是你設定好環境的那一刻就可以打包一個映像檔，以後如果環境壞了，直接回退到上次映像檔的狀態，這是不是就很香了。
