


# 圖論（graph theory）為什麼統一使用 ACM 模式

代碼隨想錄圖論章節給大家統一換成 ACM 輸入輸出模式。

圖論是在筆試還有面試中，通常都是以 ACM 模式來考察大家，而大家習慣在 LeetCode 練習題目（核心程式碼模式），核心程式碼模式對圖（graph）的儲存和輸出都隱藏了。

而圖論題目的輸入輸出相對其他類型題目來說是最難處理的。

ACM 模式是最考察候選人對程式碼細節把控程度的，圖的構成、圖的輸出，這些只有 ACM 輸入輸出模式才能體現出來。 

### 輸入的細節

圖論的輸入難在圖的儲存結構，**如果沒有練習過相鄰串列（adjacency list）和相鄰矩陣（adjacency matrix），很多錄友是寫不出來的**。

而 LeetCode 上是直接給好現成的資料結構（data structure），可以直接用，所以練習不到圖的輸入，也練習不到相鄰串列和相鄰矩陣。

**如果連相鄰串列和相鄰矩陣都不知道或者寫不出來的話，可以說圖論沒有入門**。 

舉個例子，對於 LeetCode [797.所有可能的路徑](https://leetcode.cn/problems/all-paths-from-source-to-target/description/)，錄友了解深度優先搜尋（depth-first search, DFS）之後，這道題目就是模板（template）題，是送分題。 

如果面試的時候出一道原題（筆試都是 ACM 模式，部分面試也是 ACM 模式），不少熟練刷 LeetCode 的錄友都難住了，**因為不知道圖應該怎麼存，也不知道自己存的圖如何去遍歷（traversal）**。

即使面試的時候，有的面試官讓你用核心程式碼模式做題，當你寫出程式碼後，**面試官補充一句：這個圖你是怎麼存的**？ 

難道和面試官說：我只知道圖的演算法（algorithm），但我不知道圖怎麼存。

後面大家在刷代碼隨想錄圖論第一題 [98. 所有可達路徑](./0098.所有可達路徑.md) 的時候，就可以感受到圖儲存的難點所在。

所以這也是為什麼我要讓大家練習 ACM 模式，也是我為什麼在代碼隨想錄圖論講解中，不惜自己親自出題，讓大家統一練習 ACM 模式。

### 輸出的細節

同樣，圖論的輸出也有細節，例如求節點（node）1 到節點 5 的所有路徑（path），輸出可能是：

```
1 2 4 5
1 3 5
```

表示有兩條路可以到節點 5，那儲存這個結果需要二維（2D）陣列（array），最後再一起輸出，LeetCode 是直接 return 陣列就好了，但 ACM 模式要求我們自己輸出，這裡就有細節了。

就拿只輸出一行資料，輸出 `1 2 4 5` 來說，

很多錄友程式碼可能直接就這麼寫了：

```CPP
for (int i = 0 ; i < result.size(); i++) {
    cout << result[i] << " ";
}
```

這麼寫輸出的結果是 `1 2 4 5 `，發現結果是對的，一提交，發現 OJ 回傳格式錯誤或者結果錯誤。

如果沒練習過這種輸出方式的錄友，就開始懷疑了，這結果一樣一樣的，怎麼就不對，我在 LeetCode 上提交都是對的！

**大家要注意，5 後面要不要有空白**！

上面這段程式碼輸出，5 後面是加上了空白了，如果評測機判斷結果的長度，標準答案 `1 2 4 5` 長度是 7，而上面程式碼輸出的長度是 8，很明顯就是不對的。

所以正確的寫法應該是：

```CPP
for (int i = 0 ; i < result.size() - 1; i++) {
    cout << result[i] << " ";
}
cout << result[result.size() - 1];
```

這麼寫，最後一個元素（element）後面就沒有空白了。

這是很多錄友經常疏忽的，也是大家刷習慣了 LeetCode（核心程式碼模式）根本不會注意到的細節。

**同樣在工程開發中，這些細節都是影響系統穩定執行的因素之一**。

**ACM 模式除了考驗演算法思路，也考驗大家對程式碼的把控力度**，而核心程式碼模式只注重演算法的解題思路，所以輸入輸出這些就省略掉了。


### 其他 

**大家如果熟練 ACM 模式，那麼核心程式碼模式沒問題，但反過來就不一定了**。

而且我在講解圖論的時候，最頭疼的就是找題，在 LeetCode 上找題總是找不到符合思路且來完整表達演算法精髓的題目。

特別是最短路徑（shortest path）演算法相關的題目，例如 Bellman_ford 系列、Floyd、A* 等等總是找不到符合思路的題目。

索性統一我自己來出題，這其中也是巨大的工作量。為了給大家帶來極致的學習體驗，我在很多細節上都下了功夫。

等大家將圖論刷完，就會感受到我的良苦用心。加油
