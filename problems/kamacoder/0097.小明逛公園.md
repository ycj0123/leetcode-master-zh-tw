# Floyd 演算法精講

[KamaCoder：97. 小明逛公園](https://kamacoder.com/problempage.php?pid=1155)

【題目描述】

小明喜歡去公園散步，公園內佈置了許多的景點，相互之間透過小路連接，小明希望在觀看景點的同時，能夠節省體力，走最短的路徑（path）。


給定一個公園景點圖（graph），圖中有 N 個景點（編號為 1 到 N），以及 M 條雙向道路連接著這些景點。每條道路上行走的距離都是已知的。


小明有 Q 個觀景計畫，每個計畫都有一個起點 start 和一個終點 end，表示他想從景點 start 前往景點 end。由於小明希望節省體力，他想知道每個觀景計畫中從起點到終點的最短路徑長度。請你幫助小明計算出每個觀景計畫的最短路徑長度。

【輸入描述】

第一行包含兩個整數（integer）N, M，分別表示景點的數量和道路的數量。

接下來的 M 行，每行包含三個整數 u, v, w，表示景點 u 和景點 v 之間有一條長度為 w 的雙向道路。

接下來的一行包含一個整數 Q，表示觀景計畫的數量。

接下來的 Q 行，每行包含兩個整數 start, end，表示一個觀景計畫的起點和終點。

【輸出描述】

對於每個觀景計畫，輸出一行表示從起點到終點的最短路徑長度。如果兩個景點之間不存在路徑，則輸出 -1。

【輸入範例】

```
7 3
1 2 4
2 5 6
3 6 8
2
1 2
2 3
```

【輸出範例】

```
4
-1
```

【提示資訊】

從 1 到 2 的路徑長度為 4，2 到 3 之間並沒有道路。

1 <= N, M, Q <= 1000.

## 解題思路 

本題是經典的多源最短路徑（shortest path）問題。 

在這之前我們講解過，dijkstra 樸素版、dijkstra 堆積（heap）最佳化、Bellman 演算法、Bellman 佇列（queue）最佳化（SPFA）都是單源最短路徑，即只能有一個起點。 

而本題是多源最短路徑，即求多個起點到多個終點的多條最短路徑。 

透過本題，我們來系統講解一個新的最短路徑演算法——福洛伊德－瓦沙耳最短路徑演算法（Floyd-Warshall algorithm）。  

**Floyd 演算法對邊（edge）的權值（weight）正負沒有要求，都可以處理**。 

Floyd 演算法核心思想是動態規劃（dynamic programming, DP）。 

例如我們在求節點（node）1 到節點 9 的最短距離，用二維（2D）陣列（array）來表示即：grid[1][9]，如果最短距離是 10，那就是 grid[1][9] = 10。 

那節點 1 到節點 9 的最短距離是不是可以由節點 1 到節點 5 的最短距離 + 節點 5 到節點 9 的最短距離組成呢？ 

即 grid[1][9] = grid[1][5] + grid[5][9] 

節點 1 到節點 5 的最短距離是不是可以由節點 1 到節點 3 的最短距離 + 節點 3 到節點 5 的最短距離組成呢？ 

即 grid[1][5] = grid[1][3] + grid[3][5]

以此類推，節點 1 到節點 3 的最短距離可以由更小的區間（interval）組成。 

那麼這樣我們是不是就找到了子問題推導求出整體最佳方案的遞迴關係（recurrence relation）呢。 

節點 1 到節點 9 的最短距離可以由節點 1 到節點 5 的最短距離 + 節點 5 到節點 9 的最短距離組成，也可以由節點 1 到節點 7 的最短距離 + 節點 7 到節點 9 的最短距離組成。 

那麼選哪個呢？ 

是不是要選一個最小的，畢竟是求最短路徑。

此時我們已經接近明確遞迴公式（recurrence formula）了。 

之前在講解動態規劃的時候，給出過動態規劃五部曲： 

* 確定 dp 陣列（dp table）以及下標（subscript）的含義
* 確定遞迴公式
* dp 陣列如何初始化（initialization）
* 確定遍歷（traversal）順序
* 舉例推導 dp 陣列

那麼接下來我們還是用這五步來給大家講解 Floyd。 

1、確定 dp 陣列（dp table）以及下標的含義 

這裡我們用 grid 陣列來存圖，那就把 dp 陣列命名為 grid。 

grid[i][j][k] = m，表示 **節點 i 到節點 j 以 [1...k] 集合（set）中的一個節點為中間節點的最短距離為 m**。


可能有讀者會想，憑什麼就這麼定義呢？ 

節點 i 到節點 j 的最短距離為 m，這句話可以理解，但以 [1...k] 集合為中間節點就理解不了了。 

節點 i 到節點 j 的最短路徑中一定是經過很多節點，那麼這個集合用 [1...k] 來表示。  

你可以反過來想，節點 i 到節點 j 中間一定經過很多節點，那麼你能用什麼方式來表述中間這麼多節點呢？ 

所以這裡的 k 不能單獨指某個節點，k 一定要表示一個集合，即 [1...k]，表示節點 1 到節點 k 一共 k 個節點的集合。


2、確定遞迴公式 

在上面的分析中我們已經初步感受到了遞迴（recursion）的關係。 

我們分兩種情況： 

1. 節點 i 到節點 j 的最短路徑經過節點 k
2. 節點 i 到節點 j 的最短路徑不經過節點 k 

對於第一種情況，`grid[i][j][k] = grid[i][k][k - 1] + grid[k][j][k - 1]`  

節點 i 到節點 k 的最短距離是不經過節點 k，中間節點集合為 [1...k-1]，所以表示為 `grid[i][k][k - 1]` 

節點 k 到節點 j 的最短距離也是不經過節點 k，中間節點集合為 [1...k-1]，所以表示為 `grid[k][j][k - 1]` 

第二種情況，`grid[i][j][k] = grid[i][j][k - 1]` 

如果節點 i 到節點 j 的最短距離不經過節點 k，那麼中間節點集合 [1...k-1]，表示為 `grid[i][j][k - 1]`

因為我們是求最短路徑，對於這兩種情況自然是取最小值。 

即：`grid[i][j][k] = min(grid[i][k][k - 1] + grid[k][j][k - 1]， grid[i][j][k - 1])`


3、dp 陣列如何初始化 

grid[i][j][k] = m，表示節點 i 到節點 j 以 [1...k] 集合為中間節點的最短距離為 m。   

剛開始初始化 k 是不確定的。

例如題目中只是輸入邊（節點 2 -> 節點 6，權值為 3），那麼 grid[2][6][k] = 3，k 需要填什麼呢？ 

把 k 填成 1，那如何一上來就知道節點 2 經過節點 1 到達節點 6 的最短距離是多少呢。 

所以只能把 k 賦值（assignment）為 0，本題節點 0 是無意義的，節點是從 1 到 n。  

這樣我們在下一輪計算的時候，就可以根據 grid[i][j][0] 來計算 grid[i][j][1]，此時的 grid[i][j][1] 就是節點 i 經過節點 1 到達節點 j 的最小距離了。 


grid 陣列是一個三維（three-dimensional）陣列，那麼我們初始化的資料在 i 與 j 構成的平層，如圖： 

![](https://file1.kamacoder.com/i/algo/20240425104247.png)

紅色的底部一層是我們初始化好的資料，注意：從三維角度去看初始化的資料很重要，下面我們在聊遍歷順序的時候還會再講。

所以初始化程式碼：

```CPP
vector<vector<vector<int>>> grid(n + 1, vector<vector<int>>(n + 1, vector<int>(n + 1, 10005)));  // C++ 定義了一個三維陣列，10005 是因為邊的最大距離是 10^4

for(int i = 0; i < m; i++){
    cin >> p1 >> p2 >> val;
    grid[p1][p2][0] = val;
    grid[p2][p1][0] = val; // 注意這裡是雙向圖
} 

```

grid 陣列中其他元素（element）數值應該初始化多少呢？ 

本題求的是最小值，所以輸入資料沒有涉及到的節點的情況都應該初始為一個最大數。 

這樣才不會影響每次計算取最小值的時候初始值對計算結果的影響。

所以 grid 陣列的定義可以是：  

```CPP
// C++ 寫法，定義了一個三維陣列，10005 是因為邊的最大距離是 10^4
vector<vector<vector<int>>> grid(n + 1, vector<vector<int>>(n + 1, vector<int>(n + 1, 10005)));  

```

4、確定遍歷順序  

從遞迴公式：`grid[i][j][k] = min(grid[i][k][k - 1] + grid[k][j][k - 1]， grid[i][j][k - 1])` 可以看出，我們需要三個 for 迴圈（for-loop），分別遍歷 i、j 和 k 

而 k 依賴於 k - 1，i 和 j 並不依賴於 i - 1 或者 j - 1 等等。

那麼這三個 for 的巢狀順序應該是什麼樣的呢？ 

我們來看初始化，我們是把 k = 0 的 i 和 j 對應的數值都初始化了，這樣才能去計算 k = 1 的時候 i 和 j 對應的數值。 

這就好比是一個三維坐標（coordinate），i 和 j 是平層，而 k 是垂直向上的。 

遍歷的順序是從底向上一層一層去遍歷。 

所以遍歷 k 的 for 迴圈一定是在最外面，這樣才能一層一層去遍歷。如圖： 

![](https://file1.kamacoder.com/i/algo/20240424120109.png)

至於遍歷 i 和 j 的話，for 迴圈的先後順序無所謂。

程式碼如下：

```CPP
for (int k = 1; k <= n; k++) {
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            grid[i][j][k] = min(grid[i][j][k-1], grid[i][k][k-1] + grid[k][j][k-1]);
        }
    }
}
```

有讀者可能想，難道遍歷 k 放在最裡層就不行嗎？ 

k 放在最裡層，程式碼是這樣： 

```CPP
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= n; j++) {
        for (int k = 1; k <= n; k++) {
            grid[i][j][k] = min(grid[i][j][k-1], grid[i][k][k-1] + grid[k][j][k-1]);
        }
    }
}
```

此時就遍歷了 j 與 k 形成一個平面，i 則是縱面，那遍歷就是這樣的： 

![](https://file1.kamacoder.com/i/algo/20240424115827.png)


而我們初始化的資料是 k 為 0、i 和 j 形成的平面做初始化，如果以 k 和 j 形成的平面去一層一層遍歷，就造成了遞迴公式用不上上一輪計算的結果，從而導致結果不對（初始化的部分是 i 與 j 形成的平面，在初始化部分有講過）。 

我再給大家舉一個測試案例（test case）

```
5 4
1 2 10
1 3 1
3 4 1
4 2 1
1
1 2
```

就是圖： 

![](https://file1.kamacoder.com/i/algo/20240424120942.png) 

求節點 1 到節點 2 的最短距離，運行結果是 10，但正確的結果很明顯是 3。 

為什麼呢？ 

因為 k 放在最裡面，先就把節點 1 和節點 2 的最短距離確定了，後面再也不會計算節點 1 和節點 2 的距離，同時也不會基於初始化或者之前計算過的結果來計算，即：不會考慮節點 1 到節點 3、節點 3 到節點 4、節點 4 到節點 2 的距離。  


造成這一原因，是在三維立體坐標中，我們初始化的是 i 和 j 在 k 為 0 所構成的平面，但遍歷的時候是以 j 和 k 構成的平面以 i 為垂直方向去層次走訪（level order traversal）。 


而遍歷 k 的 for 迴圈如果放在中間呢，同樣是 j 與 k 形成一個平面，i 是縱面，遍歷的也是這樣： 

![](https://file1.kamacoder.com/i/algo/20240424115827.png)

同樣不能完全用上初始化和上一層計算的結果。 

根據這個情況再舉一個例子： 

```
5 2
1 2 1
2 3 10
1
1 3
```

圖： 

![](https://file1.kamacoder.com/i/algo/20240425112636.png)

求節點 1 到節點 3 的最短距離，如果 k 迴圈放中間，程式的運行結果是 -1，也就是不能到達節點 3。

在計算 grid[i][j][k] 的時候，需要基於 grid[i][k][k-1] 和 grid[k][j][k-1] 的數值。 

也就是計算 grid[1][3][2]（表示節點 1 到節點 3，經過節點 2）的時候，需要基於 grid[1][2][1] 和 grid[2][3][1] 的數值，而我們初始化，只初始化了 k 為 0 的那一層。 

造成這一原因依然是在三維立體坐標中，我們初始化的是 i 和 j 在 k 為 0 所構成的平面，但遍歷的時候是以 j 和 k 構成的平面以 i 為垂直方向去層次走訪。 


很多讀者對於 floyd 演算法的遍歷順序搞不懂，**其實是沒有從三維的角度去思考**，同時我把三維立體圖給大家畫出來，遍歷順序標出來，大家就很容易想明白，為什麼 k 放在最外層才能用上初始化和上一輪計算的結果了。

5、舉例推導 dp 陣列

這裡涉及到三維矩陣（matrix），可以一層一層印出來去分析，例如 k=0 的這一層，k=1 的這一層，但一起把三維帶資料的圖畫出來其實不太好畫。  

## 程式碼如下 

以上分析完畢，最後程式碼如下：


```CPP 
#include <iostream>
#include <vector>
#include <list>
using namespace std;

int main() {
    int n, m, p1, p2, val;
    cin >> n >> m;

    vector<vector<vector<int>>> grid(n + 1, vector<vector<int>>(n + 1, vector<int>(n + 1, 10005)));  // 因為邊的最大距離是 10^4
    for(int i = 0; i < m; i++){
        cin >> p1 >> p2 >> val;
        grid[p1][p2][0] = val;
        grid[p2][p1][0] = val; // 注意這裡是雙向圖

    }
    // 開始 floyd
    for (int k = 1; k <= n; k++) {
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= n; j++) {
                grid[i][j][k] = min(grid[i][j][k-1], grid[i][k][k-1] + grid[k][j][k-1]);
            }
        }
    }
    // 輸出結果
    int z, start, end;
    cin >> z;
    while (z--) {
        cin >> start >> end;
        if (grid[start][end][n] == 10005) cout << -1 << endl;
        else cout << grid[start][end][n] << endl;
    }
}

```

## 空間最佳化

這裡我們可以做一下空間上的最佳化，從 rolling array 的角度來看，我們定義一個 grid[n + 1][n + 1][2] 這麼大的陣列就可以，因為 k 只是依賴於 k-1 的狀態（state），並不需要記錄 k-2、k-3、k-4 等等這些狀態。 

那麼我們只需要記錄 grid[i][j][1] 和 grid[i][j][0] 就好，之後就是 grid[i][j][1] 和 grid[i][j][0] 交替滾動。

再進一步想，如果本層計算（本層計算即 k 相同，從三維角度來講）grid[i][j] 用到了本層中剛計算好的 grid[i][k] 會有什麼問題嗎？ 

如果本層剛計算好的 grid[i][k] 比上一層（即 k-1 層）計算的 grid[i][k] 小，說明確實有 i 到 k 的更短路徑，那麼基於更小的 grid[i][k] 去計算 grid[i][j] 沒有問題。 

如果本層剛計算好的 grid[i][k] 比上一層（即 k-1 層）計算的 grid[i][k] 大，這不可能，因為這樣也不會做更新 grid[i][k] 的操作。 

所以本層計算中，使用了本層計算過的 grid[i][k] 和 grid[k][j] 是沒問題的。

那麼就沒必要區分 grid[i][k] 和 grid[k][j] 是屬於 k - 1 層的呢，還是 k 層的。 

所以遞迴公式可以為： 

```CPP
grid[i][j] = min(grid[i][j], grid[i][k] + grid[k][j]);
```

基於二維陣列的本題程式碼為： 


```CPP
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, m, p1, p2, val;
    cin >> n >> m;

    vector<vector<int>> grid(n + 1, vector<int>(n + 1, 10005));  // 因為邊的最大距離是 10^4

    for(int i = 0; i < m; i++){
        cin >> p1 >> p2 >> val;
        grid[p1][p2] = val;
        grid[p2][p1] = val; // 注意這裡是雙向圖

    }
    // 開始 floyd
    for (int k = 1; k <= n; k++) {
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= n; j++) {
                grid[i][j] = min(grid[i][j], grid[i][k] + grid[k][j]);
            }
        }
    }
    // 輸出結果
    int z, start, end;
    cin >> z;
    while (z--) {
        cin >> start >> end;
        if (grid[start][end] == 10005) cout << -1 << endl;
        else cout << grid[start][end] << endl;
    }
}

```

* 時間複雜性（time complexity）：O(n^3)
* 空間複雜度（space complexity）：O(n^2)

## 總結

本期如果一上來只用二維陣列來講的話，其實更容易，但遍歷順序那裡用二維陣列其實是講不清楚的，所以我直接用三維陣列來講，目的是將遍歷順序這裡講清楚。 

理解了遍歷順序才是 floyd 演算法最精髓的地方。 


floyd 演算法的時間複雜性相對較高，適合密集圖（dense graph）且源點較多的情況。

如果是稀疏圖形（sparse graph），floyd 是從節點的角度去計算的，例如圖中節點數量是 1000，就一條邊，那 floyd 的時間複雜性依然是 O(n^3)。

如果源點少，其實可以多次 dijkstra 求源點到終點。

### Java 

- 基於三維陣列的 Floyd 演算法

```java
public class FloydBase {

    // public static int MAX_VAL = Integer.MAX_VALUE;
    public static int MAX_VAL = 10005; // 邊的最大距離是 10^4（不選用 Integer.MAX_VALUE 是為了避免相加導致數值溢位）

    public static void main(String[] args) {
        // 輸入控制
        Scanner sc = new Scanner(System.in);
        System.out.println("1.輸入N M");
        int n = sc.nextInt();
        int m = sc.nextInt();

        System.out.println("2.輸入M條邊");

        // ① dp 定義（grid[i][j][k] 節點 i 到節點 j 可能經過節點 K（k∈[1,n]））的最短路徑
        int[][][] grid = new int[n + 1][n + 1][n + 1];
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= n; j++) {
                for (int k = 0; k <= n; k++) {
                    grid[i][j][k] = grid[j][i][k] = MAX_VAL; // 其餘設定為最大值
                }
            }
        }

        // ② dp 推導：grid[i][j][k] = min{grid[i][k][k-1] + grid[k][j][k-1], grid[i][j][k-1]}
        while (m-- > 0) {
            int u = sc.nextInt();
            int v = sc.nextInt();
            int weight = sc.nextInt();
            grid[u][v][0] = grid[v][u][0] = weight; // 初始化（處理 k=0 的情況） ③ dp 初始化
        }

        // ④ dp 推導：floyd 推導
        for (int k = 1; k <= n; k++) {
            for (int i = 1; i <= n; i++) {
                for (int j = 1; j <= n; j++) {
                    grid[i][j][k] = Math.min(grid[i][k][k - 1] + grid[k][j][k - 1], grid[i][j][k - 1]);
                }
            }
        }

        System.out.println("3.輸入[起點-終點]計畫個數");
        int x = sc.nextInt();

        System.out.println("4.輸入每個起點src 終點dst");

        while (x-- > 0) {
            int src = sc.nextInt();
            int dst = sc.nextInt();
            // 根據 floyd 推導結果輸出計畫路徑的最小距離
            if (grid[src][dst][n] == MAX_VAL) {
                System.out.println("-1");
            } else {
                System.out.println(grid[src][dst][n]);
            }
        }
    }
}
```

```python
if __name__ == '__main__':

    for _ in range(m):
        p1, p2, w = map(int, input().split())

    # 開始 floyd
    for k in range(1, n+1):

                grid[i][j][k] = min(grid[i][j][k-1], grid[i][k][k-1] + grid[k][j][k-1])
```
