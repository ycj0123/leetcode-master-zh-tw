# 105.有向圖的完全連通

[KamaCoder 題目連結（ACM模式）](https://kamacoder.com/problempage.php?pid=1177)

【題目描述】

給定一個有向圖（directed graph），包含 N 個節點（node），節點編號分別為 1，2，...，N。現從 1 號節點開始，如果可以從 1 號節點的邊（edge）可以到達任何節點，則輸出 1，否則輸出 -1。

【輸入描述】

第一行包含兩個正整數（positive integer），表示節點數量 N 和邊的數量 K。後續 K 行，每行兩個正整數 s 和 t，表示從 s 節點有一條邊單向連接到 t 節點。

【輸出描述】

如果可以從 1 號節點的邊可以到達任何節點，則輸出 1，否則輸出 -1。

【輸入範例】

```
4 4
1 2
2 1
1 3
2 4
```

【輸出範例】

1

【提示資訊】

![](https://file1.kamacoder.com/i/algo/20240522174707.png)

從 1 號節點可以到達任意節點，輸出 1。

資料範圍：

* 1 <= N <= 100；
* 1 <= K <= 2000。

## 思路

**[《程式碼隨想錄》演算法影片公開課](https://programmercarl.com/other/gongkaike.html)：[圖論（graph theory）：這次我們能到達有向圖的所有節點嗎？| 深度優先搜尋（depth-first search, DFS） | KamaCoder：105. 有向圖的完全連通](https://www.bilibili.com/video/BV1QRJ6ziEvJ),相信結合影片再看本篇題解，更有助於大家對本題的理解**。

本題給我們的是一個有向圖，意識到這是有向圖很重要！ 

接下來我們再畫一個圖，從圖裡可以直觀看出來，節點 6 是不能到達節點 1 的

![](https://file1.kamacoder.com/i/algo/20240522175451.png)

這就很容易讓我們想起島嶼問題，只要發現獨立的島，就是不可到達的。 

**但本題是有向圖**，在有向圖中，即使所有節點都是連結的，但依然不可能從 0 出發遍歷（traversal）所有邊。 

例如上圖中，節點 1 可以到達節點 2，但節點 2 是不能到達節點 1 的。

所以本題是一個**有向圖搜尋全路徑（path）的問題**。只能用深搜（DFS）或者廣搜（BFS）來搜。 

**以下 dfs 分析大家一定要仔細看，本題有兩種 dfs 的解法，很多題解沒有講清楚**。看完之後相信你對 dfs 會有更深的理解。 

深搜三部曲： 

1. 確認遞迴函數（recursive function）、參數（parameter） 

需要傳入地圖，需要知道當前我們拿到的 key，以便去下一個節點。 

同時還需要一個陣列（array），用來記錄我們都走過了哪些節點，這樣好知道最後有沒有把所有節點都遍歷到，可以定義一個一維陣列（one dimensional array）。

所以遞迴函數參數如下： 

```C++ 
// key 當前得到的 key 
// visited 記錄訪問過的節點
void dfs(const vector<list<int>>& graph, int key, vector<bool>& visited) {
```

2. 確認終止條件（termination condition） 

遍歷的時候，什麼時候終止呢？  

這裡有一個很重要的邏輯，就是在遞迴（recursion）中，**我們是處理當前訪問的節點，還是處理下一個要訪問的節點**。 

這決定終止條件怎麼寫。  

首先明確，本題中什麼叫做處理，就是 visited 陣列來記錄訪問過的節點，該節點預設（default）陣列裡元素（element）都是 false，把元素標記為 true 就是處理本節點了。 

如果我們是處理當前訪問的節點，當前訪問的節點如果是 true，說明是訪問過的節點，那就終止本層遞迴，如果不是 true，我們就把它賦值（assignment）為 true，因為這是我們處理本層遞迴的節點。 

程式碼就是這樣： 

```C++
// 寫法一：處理當前訪問的節點
void dfs(const vector<list<int>>& graph, int key, vector<bool>& visited) {
    if (visited[key]) {
        return;
    }
    visited[key] = true;
    list<int> keys = graph[key];
    for (int key : keys) {
        // 深度優先搜尋遍歷
        dfs(graph, key, visited);
    }
}
```

如果我們是處理下一層訪問的節點，而不是當前層。那麼就要在深搜三部曲中第三步：處理目前搜尋節點出發的路徑的時候對節點進行處理。 

這樣的話，就不需要終止條件，而是在搜尋下一個節點的時候，直接判斷下一個節點是否是我們要搜的節點。 

程式碼就是這樣的：

```C++
// 寫法二：處理下一個要訪問的節點
void dfs(const vector<list<int>>& graph, int key, vector<bool>& visited) {
    list<int> keys = graph[key];
    for (int key : keys) {
        if (visited[key] == false) { // 確認下一個是沒訪問過的節點
            visited[key] = true;
            dfs(graph, key, visited);
        }
    }
}
```

可以看出，**如何看待我們要訪問的節點，直接決定了兩種不一樣的寫法**，很多錄友對這一塊很模糊，可能做過這道題，但沒有思考到這個維度上。


3. 處理目前搜尋節點出發的路徑 

其實在上面，深搜三部曲第二步就已經講了，因為終止條件的兩種寫法，直接決定了兩種不一樣的遞迴寫法。 

這裡還有細節：

看上面兩個版本的寫法中，好像沒有發現回溯（backtracking）的邏輯。

我們都知道，有遞迴就有回溯，回溯就在遞迴函數的下面，那麼之前我們做的 dfs 題目，都需要回溯操作，例如：[0098.所有可達路徑](./0098.所有可达路径)，**為什麼本題就沒有回溯呢？** 

程式碼中可以看到 dfs 函數下面並沒有回溯的操作。 

此時就要再思考本題的要求了，本題是需要判斷 1 節點是否能到所有節點，那麼我們就沒有必要回溯去撤銷操作了，只要遍歷過的節點一律都標記上。

**那什麼時候需要回溯操作呢？** 

當我們需要搜尋一條可行路徑的時候，就需要回溯操作了，因為沒有回溯，就沒法「調頭」，如果不理解的話，去看我寫的 [0098.所有可達路徑](./0098.所有可達路徑.md) 的題解。 


以上分析完畢，DFS 整體實作 C++ 程式碼如下： 

```CPP
// 寫法一：dfs 處理當前訪問的節點
#include <iostream>
#include <vector>
#include <list>
using namespace std;

void dfs(const vector<list<int>>& graph, int key, vector<bool>& visited) {
    if (visited[key]) {
        return;
    }
    visited[key] = true;
    list<int> keys = graph[key];
    for (int key : keys) {
        // 深度優先搜尋遍歷
        dfs(graph, key, visited);
    }
}

int main() {
    int n, m, s, t;
    cin >> n >> m;

    // 節點編號從 1 到 n，所以申請 n+1 這麼大的陣列
    vector<list<int>> graph(n + 1); // 相鄰串列
    while (m--) {
        cin >> s >> t;
        // 使用相鄰串列，表示 s -> t 是相連的
        graph[s].push_back(t);
    }
    vector<bool> visited(n + 1, false);
    dfs(graph, 1, visited);
    //檢查是否都訪問到了
    for (int i = 1; i <= n; i++) {
        if (visited[i] == false) {
            cout << -1 << endl;
            return 0;
        }
    }
    cout << 1 << endl;
}

```

本題我也給出 BFS C++ 程式碼，[廣度優先搜尋（breadth-first search, BFS）理論基礎](https://programmercarl.com/kamacoder/%E5%9B%BE%E8%AE%BA%E6%B7%B1%E6%90%9C%E7%90%86%E8%AE%BA%E5%9F%BA%E7%A1%80.html)，程式碼如下：

```CPP
#include <iostream>
#include <vector>
#include <list>
#include <queue>
using namespace std;

int main() {
    int n, m, s, t;
    cin >> n >> m;

    vector<list<int>> graph(n + 1);
    while (m--) {
        cin >> s >> t;
        graph[s].push_back(t);

    }
    vector<bool> visited(n + 1, false);
    visited[1] = true; //  節點 1 開始
    queue<int> que;
    que.push(1); //  節點 1 開始

    // 廣度優先搜尋的過程
    while (!que.empty()) {
        int key = que.front(); que.pop();
         list<int> keys = graph[key];
         for (int key : keys) {
             if (!visited[key]) {
                 que.push(key);
                 visited[key] = true;
             }
         }
    }

    for (int i = 1; i <= n; i++) {
        if (visited[i] == false) {
            cout << -1 << endl;
            return 0;
        }
    }
    cout << 1 << endl;
}
```

```java
import java.util.*;

public class Main {
    public static List<List<Integer>> adjList = new ArrayList<>();

    public static void dfs(boolean[] visited, int key) {
        if (visited[key]) {
            return;
        }
        visited[key] = true;
        List<Integer> nextKeys = adjList.get(key);
        for (int nextKey : nextKeys) {
            dfs(visited, nextKey);
        }
    }

    public static void bfs(boolean[] visited, int key) {
        Queue<Integer> queue = new LinkedList<Integer>();
        queue.add(key);
        visited[key] = true;
        while (!queue.isEmpty()) {
            int curKey = queue.poll();
            List<Integer> list = adjList.get(curKey);
            for (int nextKey : list) {
                if (!visited[nextKey]) {
                    queue.add(nextKey);
                    visited[nextKey] = true;
                }
            }
        }
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int vertices_num = sc.nextInt();
        int line_num = sc.nextInt();
        for (int i = 0; i < vertices_num; i++) {
            adjList.add(new LinkedList<>());
        }//Initialization
        for (int i = 0; i < line_num; i++) {
            int s = sc.nextInt();
            int t = sc.nextInt();
            adjList.get(s - 1).add(t - 1);
        }//建構相鄰串列
        boolean[] visited = new boolean[vertices_num];
        dfs(visited, 0);
//        bfs(visited, 0);

        for (int i = 0; i < vertices_num; i++) {
            if (!visited[i]) {
                System.out.println(-1);
                return;
            }
        }
        System.out.println(1);
    }
}
```

```Python
import collections

path = set()  # 記錄 BFS 所經過之節點

def bfs(root, graph):
    global path
    
    que = collections.deque([root])
    while que:
        cur = que.popleft()
        path.add(cur)
        
        for nei in graph[cur]:
            que.append(nei)
        graph[cur] = []
    return

def main():
    N, K = map(int, input().strip().split())
    graph = collections.defaultdict(list)
    for _ in range(K):
        src, dest = map(int, input().strip().split())
        graph[src].append(dest)
    
    bfs(1, graph)
    if path == {i for i in range(1, N + 1)}:
        return 1
    return -1
        

if __name__ == "__main__":
    print(main())
```

```go
package main

import (
    "bufio"

func dfs(graph [][]int, key int, visited []bool) {
    visited[key] = true
    for _, neighbor := range graph[key] {
        if !visited[neighbor] {
            dfs(graph, neighbor, visited)
        }
    }
}

func main() {

    scanner.Scan()

            fmt.Println(-1)
```
