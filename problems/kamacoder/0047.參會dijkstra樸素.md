## 解題思路

本題就是求最短路徑（shortest path），最短路徑是圖論（graph theory）中的經典問題，即：給出一個有向圖（directed graph），一個起點，一個終點，問起點到終點的最短路徑。 

接下來，我們來詳細講解最短路徑演算法中的 Dijkstra 演算法（Dijkstra algorithm）。

dijkstra 演算法：在加權圖形（weighted graph）（權重（weight）非負數）中求從起點到其他節點（node）的最短路徑演算法。

需要注意兩點： 

* dijkstra 演算法可以同時求起點到所有節點的最短路徑
* 權重不能為負數 

（這兩點後面我們會講到）

如本題範例中的圖：

![](https://file1.kamacoder.com/i/algo/20240125162647.png)

起點（節點 1）到終點（節點 7）的最短路徑是圖中標記綠線的部分。

最短路徑的權重為 12。 

其實 dijkstra 演算法和我們之前講解的 Prim 的最小生成樹演算法（Prim's algorithm）思路非常接近，如果大家認真學過 [Prim 的最小生成樹演算法](./0053.尋寶-prim.md)，那麼理解 Dijkstra 演算法會相對容易很多。（這也是我要先講 prim 再講 dijkstra 的原因）

dijkstra 演算法同樣是貪心法（greedy）的思路，不斷尋找距離源點最近的沒有訪問過的節點。 

這裡我也給出 **dijkstra 三部曲**：

1. 第一步，選源點到哪個節點近且該節點未被訪問過
2. 第二步，該最近節點被標記訪問過
3. 第三步，更新非訪問節點到源點的距離（即更新 minDist 陣列（array））

大家此時已經會發現，這和 prim 演算法怎麼這麼像呢。 

我在 [prim 演算法](./0053.尋寶-prim.md)講解中也給出了三部曲。prim 和 dijkstra 確實很像，思路也是類似的，這一點我在後面還會詳細來講。

在 dijkstra 演算法中，同樣有一個陣列很重要，取名為：minDist。 

**minDist 陣列用來記錄每一個節點距離源點的最小距離**。 

理解這一點很重要，也是理解 dijkstra 演算法的核心所在。

沒關係，先讓大家有一個印象，對理解後面講解有幫助。

### 程式碼實作

本題程式碼如下，裡面的三部曲我都做了註解，大家按照我上面的講解來看如下程式碼：

```CPP 
#include <iostream>
#include <vector>
#include <climits>
using namespace std;
int main() {
    int n, m, p1, p2, val;
    cin >> n >> m;

    vector<vector<int>> grid(n + 1, vector<int>(n + 1, INT_MAX));
    for(int i = 0; i < m; i++){
        cin >> p1 >> p2 >> val;
        grid[p1][p2] = val;
    }

    int start = 1;
    int end = n;

    // 儲存從源點到每個節點的最短距離
    std::vector<int> minDist(n + 1, INT_MAX);

    // 記錄頂點是否被訪問過
    std::vector<bool> visited(n + 1, false);

    minDist[start] = 0;  // 起始點到自身的距離為 0

    for (int i = 1; i <= n; i++) { // 遍歷所有節點

        int minVal = INT_MAX;
        int cur = 1;

        // 1、選距離源點最近且未訪問過的節點
        for (int v = 1; v <= n; ++v) {
            if (!visited[v] && minDist[v] < minVal) {
                minVal = minDist[v];
                cur = v;
            }
        }

        visited[cur] = true;  // 2、標記該節點已被訪問

        // 3、第三步，更新非訪問節點到源點的距離（即更新 minDist 陣列）
        for (int v = 1; v <= n; v++) {
            if (!visited[v] && grid[cur][v] != INT_MAX && minDist[cur] + grid[cur][v] < minDist[v]) {
                minDist[v] = minDist[cur] + grid[cur][v];
            }
        }

    }

    if (minDist[end] == INT_MAX) cout << -1 << endl; // 不能到達終點
    else cout << minDist[end] << endl; // 到達終點最短路徑

}
```

* 時間複雜性（time complexity）：O(n^2) 
* 空間複雜度（space complexity）：O(n^2)

```CPP 
#include <iostream>
#include <vector>
#include <climits>
using namespace std;
int main() {
    int n, m, p1, p2, val;
    cin >> n >> m;

    vector<vector<int>> grid(n + 1, vector<int>(n + 1, INT_MAX));
    for(int i = 0; i < m; i++){
        cin >> p1 >> p2 >> val;
        grid[p1][p2] = val;
    }

    int start = 1;
    int end = n;

    std::vector<int> minDist(n + 1, INT_MAX);

    std::vector<bool> visited(n + 1, false);

    minDist[start] = 0; 

    // 加上初始化
    vector<int> parent(n + 1, -1);

    for (int i = 1; i <= n; i++) {

        int minVal = INT_MAX;
        int cur = 1;

        for (int v = 1; v <= n; ++v) {
            if (!visited[v] && minDist[v] < minVal) {
                minVal = minDist[v];
                cur = v;
            }
        }

        visited[cur] = true;

        for (int v = 1; v <= n; v++) {
            if (!visited[v] && grid[cur][v] != INT_MAX && minDist[cur] + grid[cur][v] < minDist[v]) {
                minDist[v] = minDist[cur] + grid[cur][v];
                parent[v] = cur; // 記錄邊
            }
        }

    }

    // 輸出最短情況
    for (int i = 1; i <= n; i++) {
        cout << parent[i] << "->" << i << endl;
    }
}
```

### 出現負數

## dijkstra 與 prim 演算法的區別 

> 這裡再次提示，需要先看我的 [prim 演算法精講](./0053.尋寶-prim.md) ，否則可能不知道我下面講的是什麼。

大家可以發現 dijkstra 的程式碼看上去怎麼和 prim 演算法這麼像呢。 

其實程式碼大體不差，唯一區別在三部曲中的第三步：更新 minDist 陣列 

因為 **prim 是求非訪問節點到最小生成樹（minimum spanning tree, MST）的最小距離，而 dijkstra 是求非訪問節點到源點的最小距離**。

prim 更新 minDist 陣列的寫法：  


```CPP 
for (int j = 1; j <= v; j++) {
    if (!isInTree[j] && grid[cur][j] < minDist[j]) {
        minDist[j] = grid[cur][j];
    }
}
```

因為 minDist 表示節點到最小生成樹的最小距離，所以新節點 cur 的加入，只需要使用 grid[cur][j]，grid[cur][j] 就表示 cur 加入生成樹後，生成樹到節點 j 的距離。 

dijkstra 更新 minDist 陣列的寫法：

```CPP 
for (int v = 1; v <= n; v++) {
    if (!visited[v] && grid[cur][v] != INT_MAX && minDist[cur] + grid[cur][v] < minDist[v]) {
        minDist[v] = minDist[cur] + grid[cur][v];
    }
}
```

因為 minDist 表示節點到源點的最小距離，所以新節點 cur 的加入，需要使用源點到 cur 的距離（minDist[cur]）+ cur 到節點 v 的距離（grid[cur][v]），才是源點到節點 v 的距離。 

此時大家可能不禁要想，prim 演算法可以有負權重嗎？ 

當然可以！ 

讀者們可以自己思考一下，這是為什麼？

這裡我提示一下：prim 演算法只需要將節點以最小權重和連結在一起，不涉及到單一路徑。

```Python
import sys

def dijkstra(n, m, edges, start, end):
    # 初始化相鄰矩陣
    grid = [[float('inf')] * (n + 1) for _ in range(n + 1)]
    for p1, p2, val in edges:
        grid[p1][p2] = val

    # 初始化距離陣列和訪問陣列
    minDist = [float('inf')] * (n + 1)
    visited = [False] * (n + 1)

    minDist[start] = 0  # 起始點到自身的距離為 0

    for _ in range(1, n + 1):  # 遍歷所有節點
        minVal = float('inf')
        cur = -1

        # 選擇距離源點最近且未訪問過的節點
        for v in range(1, n + 1):
            if not visited[v] and minDist[v] < minVal:
                minVal = minDist[v]
                cur = v

        if cur == -1:  # 如果找不到未訪問過的節點，提前結束
            break

        visited[cur] = True  # 標記該節點已被訪問

        # 更新未訪問節點到源點的距離
        for v in range(1, n + 1):
            if not visited[v] and grid[cur][v] != float('inf') and minDist[cur] + grid[cur][v] < minDist[v]:
                minDist[v] = minDist[cur] + grid[cur][v]

    return -1 if minDist[end] == float('inf') else minDist[end]
```

```js
function dijkstra(grid, start, end) {
    const visited = Array.from({length: end + 1}, () => false)
    const minDist = Array.from({length: end + 1}, () => Number.MAX_VALUE)
    minDist[start] = 0
    
    for (let i = 1 ; i < end + 1 ; i++) {
        let cur = -1
        let tempMinDist = Number.MAX_VALUE
        // 1. 找尋與起始點距離最近且未被訪問的節點
        for (let j = 1 ; j < end + 1 ; j++) {
            if (!visited[j] && minDist[j] < tempMinDist) {
                cur = j
                tempMinDist = minDist[j]
            }
        }
        if (cur === -1) break;
        
        // 2. 更新節點狀態為已拜訪
        visited[cur] = true
        
        // 3. 更新未拜訪節點與起始點的最短距離
        for (let j = 1 ; j < end + 1 ; j++) {
            if(!visited[j] && grid[cur][j] != Number.MAX_VALUE 
                && grid[cur][j] + minDist[cur] < minDist[j]
            ) {
                minDist[j] = grid[cur][j] + minDist[cur]
            }
        }
    }
    
    return minDist[end] === Number.MAX_VALUE ? -1 : minDist[end]
}
```
