## 解題思路

這道題目和 [198. 打家劫舍](https://programmercarl.com/0198.打家劫舍.html)、[213. 打家劫舍 II](https://programmercarl.com/0213.打家劫舍II.html)也是如出一轍，只不過這個換成了樹（tree）。

如果對樹的遍歷（traversal）不夠熟悉的話，那本題就有難度了。

對於樹的話，首先就要想到遍歷方式，前中後序（深度優先搜尋（depth-first search, DFS））還是層次序走訪（level order traversal）（廣度優先搜尋（breadth-first search, BFS））。

**本題一定要使用後序遍歷（post-order traversal），因為需要透過遞迴函數（recursive function）的轉回值（return value）來做下一步計算**。

與 198. 打家劫舍、213. 打家劫舍 II 一樣，關鍵是要討論當前節點（node）搶還是不搶。

如果搶了當前節點，兩個孩子就不能動，如果沒搶當前節點，就可以考慮搶左右孩子（**注意這裡說的是「考慮」**）

### 蠻力（brute force）遞迴（recursion）

程式碼如下：

```CPP
class Solution {
public:
    int rob(TreeNode* root) {
        if (root == NULL) return 0;
        if (root->left == NULL && root->right == NULL) return root->val;
        // 偷父節點
        int val1 = root->val;
        if (root->left) val1 += rob(root->left->left) + rob(root->left->right); // 跳過 root->left，相當於不考慮左孩子了
        if (root->right) val1 += rob(root->right->left) + rob(root->right->right); // 跳過 root->right，相當於不考慮右孩子了
        // 不偷父節點
        int val2 = rob(root->left) + rob(root->right); // 考慮 root 的左右孩子
        return max(val1, val2);
    }
};
```

* 時間複雜性（time complexity）：O(n^2)，這個時間複雜性不太標準，也不容易準確化，例如越往下的節點重複計算次數就越多
* 空間複雜度（space complexity）：O(log n)，算上遞迴系統堆疊（stack）的空間

當然以上程式碼逾時了，這個遞迴的過程中其實是有重複計算了。

我們計算了 root 的四個孫子（左右孩子的孩子）為頭節點（head node）的子樹（subtree）的情況，又計算了 root 的左右孩子為頭節點的子樹的情況，計算左右孩子的時候其實又把孫子計算了一遍。

### 備忘（memoization）遞推

所以可以使用一個 map 把計算過的結果保存一下，這樣如果計算過孫子了，那麼計算孩子的時候可以複用孫子節點的結果。

程式碼如下：

```CPP
class Solution {
public:
    unordered_map<TreeNode* , int> umap; // 記錄計算過的結果
    int rob(TreeNode* root) {
        if (root == NULL) return 0;
        if (root->left == NULL && root->right == NULL) return root->val;
        if (umap[root]) return umap[root]; // 如果 umap 裡已經有記錄則直接回傳
        // 偷父節點
        int val1 = root->val;
        if (root->left) val1 += rob(root->left->left) + rob(root->left->right); // 跳過 root->left
        if (root->right) val1 += rob(root->right->left) + rob(root->right->right); // 跳過 root->right
        // 不偷父節點
        int val2 = rob(root->left) + rob(root->right); // 考慮 root 的左右孩子
        umap[root] = max(val1, val2); // umap 記錄一下結果
        return max(val1, val2);
    }
};

```

* 時間複雜性：O(n)
* 空間複雜度：O(log n)，算上遞迴系統堆疊的空間


### 動態規劃

在上面兩種方法，其實對一個節點偷與不偷得到的最大金錢都沒有做記錄，而是需要即時計算。

而動態規劃其實就是使用狀態（state）轉移容器（container）來記錄狀態的變化，這裡可以使用一個長度為 2 的陣列（array），記錄當前節點偷與不偷所得到的最大金錢。

**這道題目算是樹狀 DP 的入門題目，因為是在樹上進行狀態轉移，我們在講解二元樹的時候說過遞迴三部曲，那麼下面我以遞迴三部曲為框架（framework），其中融合動態規劃五部曲的內容來進行講解**。

1. 確定遞迴函數的參數（parameter）和轉回值

這裡我們要求一個節點偷與不偷的兩個狀態所得到的金錢，那麼轉回值就是一個長度為 2 的陣列。

參數為當前節點，程式碼如下：

```CPP
vector<int> robTree(TreeNode* cur) {
```

其實這裡的回傳陣列就是 dp 陣列。

所以 dp 陣列（dp table）以及下標（subscript）的含義：下標為 0 記錄不偷該節點所得到的最大金錢，下標為 1 記錄偷該節點所得到的最大金錢。

**所以本題 dp 陣列就是一個長度為 2 的陣列！**

那麼有同學可能疑惑，長度為 2 的陣列怎麼標記樹中每個節點的狀態呢？

**別忘了在遞迴的過程中，系統堆疊會保存每一層遞迴的參數**。

如果還不理解的話，就接著往下看，看到程式碼就理解了。

2. 確定終止條件（termination condition）

在遍歷的過程中，如果遇到 null node 的話，很明顯，無論偷還是不偷都是 0，所以就回傳
```
if (cur == NULL) return vector<int>{0, 0};
```
這也相當於 dp 陣列的初始化（initialization）


3. 確定遍歷順序

首先明確的是使用後序遍歷。因為要透過遞迴函數的轉回值來做下一步計算。

透過遞迴左節點，得到左節點偷與不偷的金錢。

透過遞迴右節點，得到右節點偷與不偷的金錢。

程式碼如下：

```CPP
// 下標 0：不偷，下標 1：偷
vector<int> left = robTree(cur->left); // 左
vector<int> right = robTree(cur->right); // 右
// 中

```

4. 確定單層遞迴的邏輯

如果是偷當前節點，那麼左右孩子就不能偷，val1 = cur->val + left[0] + right[0];（**如果對下標含義不理解就再回顧一下 dp 陣列的含義**）

如果不偷當前節點，那麼左右孩子就可以偷，至於到底偷不偷一定是選一個最大的，所以：val2 = max(left[0], left[1]) + max(right[0], right[1]);

最後當前節點的狀態就是 {val2, val1}; 即：{不偷當前節點得到的最大金錢，偷當前節點得到的最大金錢}

程式碼如下：

```CPP
vector<int> left = robTree(cur->left); // 左
vector<int> right = robTree(cur->right); // 右

// 偷 cur
int val1 = cur->val + left[0] + right[0];
// 不偷 cur
int val2 = max(left[0], left[1]) + max(right[0], right[1]);
return {val2, val1};
```



5. 舉例推導 dp 陣列

以範例 1 為例，dp 陣列狀態如下：（**注意用後序遍歷的方式推導**）


![](https://file1.kamacoder.com/i/algo/20230203110031.png)

**最後頭節點就是取下標 0 和下標 1 的最大值就是偷得的最大金錢**。

遞迴三部曲與動態規劃五部曲分析完畢，C++ 程式碼如下：

```CPP
class Solution {
public:
    int rob(TreeNode* root) {
        vector<int> result = robTree(root);
        return max(result[0], result[1]);
    }
    // 長度為 2 的陣列，0：不偷，1：偷
    vector<int> robTree(TreeNode* cur) {
        if (cur == NULL) return vector<int>{0, 0};
        vector<int> left = robTree(cur->left);
        vector<int> right = robTree(cur->right);
        // 偷 cur，那麼就不能偷左右節點。
        int val1 = cur->val + left[0] + right[0];
        // 不偷 cur，那麼可以偷也可以不偷左右節點，則取較大的情況
        int val2 = max(left[0], left[1]) + max(right[0], right[1]);
        return {val2, val1};
    }
};
```
* 時間複雜性：O(n)，每個節點只遍歷了一次
* 空間複雜度：O(log n)，算上遞迴系統堆疊的空間

```Java
    public int rob(TreeNode root) {
        if (root == null)
            return 0;
        int money = root.val;
        if (root.left != null) {
            money += rob(root.left.left) + rob(root.left.right);
        }
        if (root.right != null) {
            money += rob(root.right.left) + rob(root.right.right);
        }
        return Math.max(money, rob(root.left) + rob(root.right));
```

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def rob(self, root: Optional[TreeNode]) -> int:
        # dp 陣列（dp table）以及下標的含義：
        # 1. 下標為 0 記錄 **不偷該節點** 所得到的最大金錢
        # 2. 下標為 1 記錄 **偷該節點** 所得到的最大金錢
        dp = self.traversal(root)
        return max(dp)

    # 要用後序遍歷, 因為要透過遞迴函式的轉回值來做下一步計算
    def traversal(self, node):
        
        # 遞迴終止條件，就是遇到了空節點，那肯定是不偷的
        if not node:
            return (0, 0)

        left = self.traversal(node.left)
        right = self.traversal(node.right)

        # 不偷當前節點, 偷子節點
        val_0 = max(left[0], left[1]) + max(right[0], right[1])

        # 偷當前節點, 不偷子節點
        val_1 = node.val + left[0] + right[0]

        return (val_0, val_1)
```

```go
func robTree(cur *TreeNode) []int {
	if cur == nil {
		return []int{0, 0}
	}

	left := robTree(cur.Left)
	right := robTree(cur.Right)
```

### JavaScript 

> 動態規劃

```javascript
const rob = root => {
    // 後序遍歷函式
    const postOrder = node => {
        // 遞迴出口
        if (!node) return [0, 0];
        // 遍歷左子樹
        const left = postOrder(node.left);
        // 遍歷右子樹
        const right = postOrder(node.right);
        // 不偷當前節點，左右子節點都可以偷或不偷，取最大值
        const DoNot = Math.max(left[0], left[1]) + Math.max(right[0], right[1]);
        // 偷當前節點，左右子節點只能不偷
        const Do = node.val + left[0] + right[0];
        // [不偷，偷]
        return [DoNot, Do];
    };
    const res = postOrder(root);
    // 回傳最大值
    return Math.max(...res);
};
```

```typescript
const memory: Map<TreeNode, number> = new Map();
function rob(root: TreeNode | null): number {
    if (root === null) return 0;
    if (memory.has(root)) return memory.get(root);
    // 不取當前節點
    const res1: number = rob(root.left) + rob(root.right);
    // 取當前節點
    let res2: number = root.val;
    if (root.left !== null) res2 += rob(root.left.left) + rob(root.left.right);
    if (root.right !== null) res2 += rob(root.right.left) + rob(root.right.right);
    const res: number = Math.max(res1, res2);
    memory.set(root, res);
    return res;
};
```

```typescript
    return Math.max(...robNode(root));

// [0]-不偷當前節點能獲得的最大金額; [1]-偷~~
type MaxValueArr = [number, number];
function robNode(node: TreeNode | null): MaxValueArr {
    if (node === null) return [0, 0];
    const leftArr: MaxValueArr = robNode(node.left);
    const rightArr: MaxValueArr = robNode(node.right);
    // 不偷
    const val1: number = Math.max(leftArr[0], leftArr[1]) +
        Math.max(rightArr[0], rightArr[1]);
    // 偷
    const val2: number = leftArr[0] + rightArr[0] + node.val;
    return [val1, val2];
}
```

```c
int *robTree(struct TreeNode *node) {
    int* amounts = (int*) malloc(sizeof(int) * 2);
    memset(amounts, 0, sizeof(int) * 2);
    if(node == NULL){
        return amounts;
    }
    int * left = robTree(node->left);
    int * right = robTree(node->right);
    // 偷當前節點
    amounts[1] = node->val + left[0] + right[0];
    // 不偷當前節點
    amounts[0] = max(left[0], left[1]) + max(right[0], right[1]);
    return amounts;
}

int rob(struct TreeNode* root) {
    int * dp = robTree(root);
    // 0 代表不偷當前節點可以獲得的最大值，1 表示偷當前節點可以獲取的最大值
    return max(dp[0], dp[1]);
}
```

```rust
use std::cell::RefCell;
use std::rc::Rc;
impl Solution {
    pub fn rob(root: Option<Rc<RefCell<TreeNode>>>) -> i32 {
        let (v1, v2) = Self::rob_tree(&root);
        v1.max(v2)
    }
    pub fn rob_tree(cur: &Option<Rc<RefCell<TreeNode>>>) -> (i32, i32) {
        match cur {
            None => (0, 0),
            Some(node) => {
                let left = Self::rob_tree(&node.borrow_mut().left);
                let right = Self::rob_tree(&node.borrow_mut().right);
                (
                    left.0.max(left.1) + right.0.max(right.1), // 偷左右節點
                    node.borrow().val + left.0 + right.0,      // 偷父節點
                )
            }
        }
    }
}
```
