## 解題思路

這道題目描述很簡短，但估計大部分同學看完都是霧煞煞的狀態，這該怎麼統計呢？

關於什麼是二元搜尋樹，我們之前在講解二元樹（binary tree）專題的時候已經詳細講解過了，也可以看看這篇[二元樹：二元搜尋樹登場！](https://programmercarl.com/0700.二叉搜索树中的搜索.html)再回顧一波。

了解了二元搜尋樹之後，我們應該先舉幾個例子，畫畫圖，看看有沒有什麼規律，如圖：

![96. 不同的二元搜尋樹](https://file1.kamacoder.com/i/algo/20210107093106367.png)

n 為 1 的時候有一棵樹，n 為 2 有兩棵樹，這是很直觀的。

![96. 不同的二元搜尋樹1](https://file1.kamacoder.com/i/algo/20210107093129889.png)

來看看 n 為 3 的時候，有哪幾種情況。

當 1 為頭節點（head node）的時候，其右子樹（right subtree）有兩個節點，看這兩個節點的佈局，是不是和 n 為 2 的時候兩棵樹的佈局是一樣的啊！

（可能有同學問了，這佈局不一樣啊，節點數值都不一樣。別忘了我們就是求不同樹的數量，並不用把搜尋樹都列出來，所以不用關心其具體數值的差異）

當 3 為頭節點的時候，其左子樹（left subtree）有兩個節點，看這兩個節點的佈局，是不是和 n 為 2 的時候兩棵樹的佈局也是一樣的啊！

當 2 為頭節點的時候，其左右子樹都只有一個節點，佈局是不是和 n 為 1 的時候只有一棵樹的佈局也是一樣的啊！

發現到這裡，其實我們就找到了 重疊次問題（overlapping subproblems） 了，其實也就是發現可以透過 dp[1] 和 dp[2] 來推導出來 dp[3] 的某種方式。

思考到這裡，這道題目就有眉目了。

dp[3]，就是 元素（element）1 為頭節點搜尋樹的數量 + 元素 2 為頭節點搜尋樹的數量 + 元素 3 為頭節點搜尋樹的數量

元素 1 為頭節點搜尋樹的數量 = 右子樹有 2 個元素的搜尋樹數量 * 左子樹有 0 個元素的搜尋樹數量

元素 2 為頭節點搜尋樹的數量 = 右子樹有 1 個元素的搜尋樹數量 * 左子樹有 1 個元素的搜尋樹數量

元素 3 為頭節點搜尋樹的數量 = 右子樹有 0 個元素的搜尋樹數量 * 左子樹有 2 個元素的搜尋樹數量

有 2 個元素的搜尋樹數量就是 dp[2]。

有 1 個元素的搜尋樹數量就是 dp[1]。

有 0 個元素的搜尋樹數量就是 dp[0]。

所以 dp[3] = dp[2] * dp[0] + dp[1] * dp[1] + dp[0] * dp[2]

如圖所示：

![96. 不同的二元搜尋樹2](https://file1.kamacoder.com/i/algo/20210107093226241.png)


此時我們已經找到遞迴關係（recurrence relation）了，那麼可以用動態規劃五部曲再系統分析一遍。

1. 確定 dp 陣列（array）（dp table）以及下標（subscript）的含義

**dp[i]：1 到 i 為節點組成的二元搜尋樹的個數為 dp[i]**。

也可以理解是 i 個不同元素節點組成的二元搜尋樹的個數為 dp[i]，都是一樣的。

以下分析如果想不清楚，就來回想一下 dp[i] 的定義

2. 確定遞迴公式（recurrence formula）

在上面的分析中，其實已經看出其遞迴關係，dp[i] += dp[以 j 為頭節點左子樹節點數量] * dp[以 j 為頭節點右子樹節點數量]

j 相當於是頭節點的元素，從 1 遍歷（traversal）到 i 為止。

所以遞迴公式：dp[i] += dp[j - 1] * dp[i - j];，j - 1 為 j 為頭節點左子樹節點數量，i - j 為以 j 為頭節點右子樹節點數量

3. dp 陣列如何初始化（initialization）

初始化，只需要初始化 dp[0] 就可以了，推導的基礎，都是 dp[0]。

那麼 dp[0] 應該是多少呢？

從定義上來講，null node 也是一棵二元樹，也是一棵二元搜尋樹，這是可以說得通的。

從遞迴公式上來講，dp[以 j 為頭節點左子樹節點數量] * dp[以 j 為頭節點右子樹節點數量] 中以 j 為頭節點左子樹節點數量為 0，也需要 dp[以 j 為頭節點左子樹節點數量] = 1，否則乘法的結果就都變成 0 了。

所以初始化 dp[0] = 1

4. 確定遍歷順序

首先一定是遍歷節點數，從遞迴公式：dp[i] += dp[j - 1] * dp[i - j] 可以看出，節點數為 i 的狀態（state）是依靠 i 之前節點數的狀態。

那麼遍歷 i 裡面每一個數作為頭節點的狀態，用 j 來遍歷。

程式碼如下：

```CPP
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= i; j++) {
        dp[i] += dp[j - 1] * dp[i - j];
    }
}
```

5. 舉例推導 dp 陣列

n 為 5 時候的 dp 陣列狀態如圖：

![96. 不同的二元搜尋樹3](https://file1.kamacoder.com/i/algo/20210107093253987.png)

當然如果自己畫圖舉例的話，基本舉例到 n 為 3 就可以了，n 為 4 的時候，畫圖已經比較麻煩了。

**我這裡列到了 n 為 5 的情況，是為了方便大家 debug 程式碼的時候，把 dp 陣列印出來，看看哪裡有問題**。

綜上分析完畢，C++ 程式碼如下：

```CPP
class Solution {
public:
    int numTrees(int n) {
        vector<int> dp(n + 1);
        dp[0] = 1;
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= i; j++) {
                dp[i] += dp[j - 1] * dp[i - j];
            }
        }
        return dp[n];
    }
};
```

* 時間複雜性（time complexity）：$O(n^2)$
* 空間複雜度（space complexity）：$O(n)$

大家應該發現了，我們分析了這麼多，最後程式碼卻如此簡單！

```Java
class Solution {
    public int numTrees(int n) {
        //初始化 dp 陣列
        int[] dp = new int[n + 1];
        //初始化 0 個節點和 1 個節點的情況
        dp[0] = 1;
        dp[1] = 1;
        for (int i = 2; i <= n; i++) {
            for (int j = 1; j <= i; j++) {
                //對於第 i 個節點，需要考慮 1 作為根節點直到 i 作為根節點的情況，所以需要累加
                //一共 i 個節點，對於根節點 j 時，左子樹的節點個數為 j-1，右子樹的節點個數為 i-j
                dp[i] += dp[j - 1] * dp[i - j];
            }
        }
        return dp[n];
    }
}
```

```python
class Solution:
    def numTrees(self, n: int) -> int:
        dp = [0] * (n + 1)  # 建立一個長度為 n+1 的陣列，初始化為 0
        dp[0] = 1  # 當 n 為 0 時，只有一種情況，即空樹，所以 dp[0] = 1
        for i in range(1, n + 1):  # 遍歷從 1 到 n 的每個數字

        return dp[n]  # 回傳以 1 到 n 為節點的二元搜尋樹的總數量
```

### TypeScript

```typescript
function numTrees(n: number): number {
    /**
        dp[i]: i 個節點對應的種數
        dp[0]: -1; 無意義；
        dp[1]: 1;
        ...
        dp[i]: 2 * dp[i - 1] +
            (dp[1] * dp[i - 2] + dp[2] * dp[i - 3] + ... + dp[i - 2] * dp[1]); 從 1 加到 i-2
     */
    const dp: number[] = [];
    dp[0] = -1; // 表示無意義
    dp[1] = 1;
    for (let i = 2; i <= n; i++) {
        dp[i] = 2 * dp[i - 1];
        for (let j = 1, end = i - 1; j < end; j++) {
            dp[i] += dp[j] * dp[end - j];
        }
    }
    return dp[n];
};
```
