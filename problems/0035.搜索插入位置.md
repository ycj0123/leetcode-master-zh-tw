# 35.搜尋插入位置

[LeetCode 題目連結](https://leetcode.cn/problems/search-insert-position/)

給定一個已排序陣列（sorted array）和一個目標值，在陣列（array）中找到目標值，並回傳其索引（index）。如果目標值不存在於陣列中，回傳它將會被按順序插入的位置。

你可以假設陣列中無重複元素（element）。

範例 1:

* 輸入: [1,3,5,6], 5
* 輸出: 2

範例 2:

* 輸入: [1,3,5,6], 2
* 輸出: 1

範例 3:

* 輸入: [1,3,5,6], 7
* 輸出: 4

範例 4:

* 輸入: [1,3,5,6], 0
* 輸出: 0

## 解題思路

這道題目不難，但是為什麼通過率相對來說並不高呢，我理解是大家對邊界（boundary）處理的判斷有所失誤導致的。

這道題目，要在陣列中插入目標值，無非是這四種情況。

![35_搜尋插入位置3](https://file1.kamacoder.com/i/algo/20201216232148471.png)

* 目標值在陣列所有元素之前
* 目標值等於陣列中某一個元素
* 目標值插入陣列中的位置
* 目標值在陣列所有元素之後

這四種情況確認清楚了，就可以嘗試解題了。

接下來我將從蠻力法（brute force）和二元搜尋（binary search）來講解此題，也藉此好好講一講二元搜尋法。

### 蠻力解法

蠻力解題不一定時間消耗就非常高，關鍵看實作的方式，就像是二元搜尋時間消耗不一定就很低，是一樣的。

C++ 程式碼

```CPP
class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        for (int i = 0; i < nums.size(); i++) {
        // 分別處理如下三種情況
        // 目標值在陣列所有元素之前
        // 目標值等於陣列中某一個元素
        // 目標值插入陣列中的位置
            if (nums[i] >= target) { // 一旦發現大於或者等於 target 的 nums[i]，那麼 i 就是我們要的結果
                return i;
            }
        }
        // 目標值在陣列所有元素之後的情況
        return nums.size(); // 如果 target 是最大的，或者 nums 為空，則回傳 nums 的長度
    }
};
```

* 時間複雜性（time complexity）：O(n)
* 空間複雜度（space complexity）：O(1)

### 二元搜尋

既然蠻力解法的時間複雜性是 O(n)，就要嘗試一下使用二元搜尋法。


![35_搜尋插入位置4](https://file1.kamacoder.com/i/algo/202012162326354.png)

大家注意這道題目的前提是陣列是有序陣列（ordered array），這也是使用二元搜尋的基礎條件（condition）。

以後大家**只要看到面試題裡給出的陣列是有序陣列，都可以想一想是否可以使用二元搜尋。**

同時題目還強調陣列中無重複元素，因為一旦有重複元素，使用二元搜尋法回傳的元素下標（subscript）可能不是唯一的。

大體講解一下二元搜尋的解題思路，這裡來舉一個例子，例如在這個陣列中，使用二元搜尋尋找元素為 5 的位置，並回傳其下標。

![35_搜尋插入位置5](https://file1.kamacoder.com/i/algo/20201216232659199.png)

二元搜尋涉及很多的邊界條件，邏輯比較簡單，就是寫不好。

相信很多同學對二元搜尋法中邊界條件處理不好。

例如到底是 `while(left < right)` 還是 `while(left <= right)`，到底是 `right = middle` 呢，還是要 `right = middle - 1` 呢？

這裡弄不清楚主要是因為**對區間（interval）的定義沒有想清楚，這就是不變（invariant）**。

要在二元搜尋的過程中，保持不變，這也就是 **loop invariant**（感興趣的同學可以查一查）。

### 二元搜尋第一種寫法

以這道題目來舉例，以下的程式碼中定義 target 是在一個左閉右閉的區間裡，**也就是 [left, right] （這個很重要）**。

這就決定了這個二元搜尋的程式碼如何去寫，大家看如下程式碼：

**大家要仔細看註解，思考為什麼要寫 while(left <= right)，為什麼要寫 right = middle - 1**。

```CPP
class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        int n = nums.size();
        int left = 0;
        int right = n - 1; // 定義 target 在左閉右閉的區間裡，[left, right]
        while (left <= right) { // 當 left==right，區間 [left, right] 依然有效
            int middle = left + ((right - left) / 2);// 防止溢位，等同於 (left + right)/2
            if (nums[middle] > target) {
                right = middle - 1; // target 在左區間，所以 [left, middle - 1]
            } else if (nums[middle] < target) {
                left = middle + 1; // target 在右區間，所以 [middle + 1, right]
            } else { // nums[middle] == target
                return middle;
            }
        }
        // 分別處理如下四種情況
        // 目標值在陣列所有元素之前  [0, -1]
        // 目標值等於陣列中某一個元素  return middle;
        // 目標值插入陣列中的位置 [left, right]，return  right + 1
        // 目標值在陣列所有元素之後的情況 [left, right]， 因為是右閉區間，所以 return right + 1
        return right + 1;
    }
};
```

* 時間複雜性：O(log n)
* 空間複雜度：O(1)

### 二元搜尋第二種寫法

如果說定義 target 是在一個左閉右開的區間裡，也就是 [left, right) 。

那麼二元搜尋的邊界處理方式則截然不同。

維持不變的是 [left, right) 的區間，如下程式碼可以看出是如何在迴圈（loop）中堅持這個不變的。

**大家要仔細看註解，思考為什麼要寫 while (left < right)，為什麼要寫 right = middle**。

```CPP
class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        int n = nums.size();
        int left = 0;
        int right = n; // 定義 target 在左閉右開的區間裡，[left, right)  target
        while (left < right) { // 因為 left == right 的時候，在 [left, right) 是無效的空間
            int middle = left + ((right - left) >> 1);
            if (nums[middle] > target) {
                right = middle; // target 在左區間，在 [left, middle) 中
            } else if (nums[middle] < target) {
                left = middle + 1; // target 在右區間，在 [middle+1, right) 中
            } else { // nums[middle] == target
                return middle; // 陣列中找到目標值的情況，直接回傳下標
            }
        }
        // 分別處理如下四種情況
        // 目標值在陣列所有元素之前 [0,0)
        // 目標值等於陣列中某一個元素 return middle
        // 目標值插入陣列中的位置 [left, right) ，return right 即可
        // 目標值在陣列所有元素之後的情況 [left, right)，因為是右開區間，所以 return right
        return right;
    }
};
```

* 時間複雜性：O(log n)
* 空間複雜度：O(1)

## 總結

希望透過這道題目，大家會發現平時寫二元搜尋，為什麼總寫不好，就是因為對區間定義不清楚。

確定要尋找的區間到底是左閉右開 [left, right)，還是左閉右閉 [left, right]，這就是不變。

然後在**二元搜尋的迴圈中，堅持 loop invariant 的原則**，很多細節問題，自然會知道如何處理了。

//版本一 [left, right] 左閉右閉區間
int searchInsert(int* nums, int numsSize, int target){
    //左閉右開區間 [0 , numsSize-1]
        int left =0;
        int mid =0;
        int right = numsSize - 1;
        while(left <= right){//左閉右閉區間 所以可以 left == right
            mid = left + (right - left) / 2;

        //target 在左區間 [left, mid - 1] 中，原區間包含 mid，右區間邊界可以向左內縮
                right = mid -1;

        //target 在右區間 [mid + 1, right] 中，原區間包含 mid，左區間邊界可以向右內縮
