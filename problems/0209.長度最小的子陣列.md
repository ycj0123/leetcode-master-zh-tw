# 209.長度最小的子陣列

[LeetCode 題目連結](https://leetcode.cn/problems/minimum-size-subarray-sum/)

給定一個含有 n 個正整數（positive integer）的陣列（array）和一個正整數 s，找出該陣列中滿足其和 ≥ s 的長度最小的連續子陣列（subarray），並回傳其長度。如果不存在符合條件（condition）的子陣列，回傳 0。

範例：

* 輸入：s = 7, nums = [2,3,1,2,4,3]
* 輸出：2
* 解釋：子陣列 [4,3] 是該條件下的長度最小的子陣列。

提示：

* 1 <= target <= 10^9
* 1 <= nums.length <= 10^5
* 1 <= nums[i] <= 10^5

## 解題思路 

### 蠻力法（brute force method）

這道題目蠻力法當然是兩個 for 迴圈（for-loop），然後不斷地尋找符合條件的次序列（subsequence），時間複雜性（time complexity）很明顯是 O(n^2)。

程式碼如下：

```CPP
class Solution {
public:
    int minSubArrayLen(int s, vector<int>& nums) {
        int result = INT32_MAX; // 最終的結果
        int sum = 0; // 次序列的數值之和
        int subLength = 0; // 次序列的長度
        for (int i = 0; i < nums.size(); i++) { // 設定次序列起點為 i
            sum = 0;
            for (int j = i; j < nums.size(); j++) { // 設定次序列終止位置為 j
                sum += nums[j];
                if (sum >= s) { // 一旦發現次序列和超過了 s，更新 result
                    subLength = j - i + 1; // 取次序列的長度
                    result = result < subLength ? result : subLength;
                    break; // 因為我們是找符合條件最短的次序列，所以一旦符合條件就 break
                }
            }
        }
        // 如果 result 沒有被賦值的話，就回傳 0，說明沒有符合條件的次序列
        return result == INT32_MAX ? 0 : result;
    }
};
```
* 時間複雜性：O(n^2)
* 空間複雜度（space complexity）：O(1)

### 滑動視窗（sliding windows）

接下來就開始介紹陣列操作中另一個重要的方法：**滑動視窗**。

所謂滑動視窗，**就是不斷地調節次序列的起始位置和終止位置，從而得出我們想要的結果**。

在蠻力法中，是一個 for 迴圈滑動視窗的起始位置，一個 for 迴圈為滑動視窗的終止位置，用兩個 for 迴圈完成了一個不斷搜尋區間（interval）的過程。

那麼滑動視窗如何用一個 for 迴圈來完成這個操作呢。

首先要思考如果用一個 for 迴圈，那麼應該表示滑動視窗的起始位置，還是終止位置。

如果只用一個 for 迴圈來表示滑動視窗的起始位置，那麼如何遍歷（traversal）剩下的終止位置？

此時難免再次陷入蠻力法的怪圈。

所以只用一個 for 迴圈，那麼這個迴圈的索引（index），一定是表示滑動視窗的終止位置。

那麼問題來了，滑動視窗的起始位置如何移動呢？

這裡還是以題目中的範例來舉例，s=7，陣列是 2，3，1，2，4，3，來看一下尋找的過程：

![209.長度最小的子陣列](https://file1.kamacoder.com/i/algo/209.%E9%95%BF%E5%BA%A6%E6%9C%80%E5%B0%8F%E7%9A%84%E5%AD%90%E6%95%B0%E7%BB%84.gif)

最後找到 4，3 是最短距離。

其實從動畫中可以發現滑動視窗也可以理解為 two pointers 法的一種！只不過這種解法更像是一個視窗的移動，所以叫做滑動視窗更適合一些。

在本題中實作滑動視窗，主要確定如下三點：

* 視窗內是什麼？
* 如何移動視窗的起始位置？
* 如何移動視窗的結束位置？

視窗就是滿足其和 ≥ s 的長度最小的連續子陣列。

視窗的起始位置如何移動：如果當前視窗的值（value）大於等於 s 了，視窗就要向前移動了（也就是該縮小了）。

視窗的結束位置如何移動：視窗的結束位置就是遍歷陣列的指標（pointer），也就是 for 迴圈裡的索引。

解題的關鍵在於視窗的起始位置如何移動，如圖所示：

![leetcode_209](https://file1.kamacoder.com/i/algo/20210312160441942.png)

可以發現**滑動視窗的精妙之處在於根據當前次序列和大小的情況，不斷調節次序列的起始位置。從而將 O(n^2) 蠻力法降為 O(n)。**

C++ 程式碼如下：

```CPP
class Solution {
public:
    int minSubArrayLen(int s, vector<int>& nums) {
        int result = INT32_MAX;
        int sum = 0; // 滑動視窗數值之和
        int i = 0; // 滑動視窗起始位置
        int subLength = 0; // 滑動視窗的長度
        for (int j = 0; j < nums.size(); j++) {
            sum += nums[j];
            // 注意這裡使用 while，每次更新 i（起始位置），並不斷比較次序列是否符合條件
            while (sum >= s) {
                subLength = (j - i + 1); // 取次序列的長度
                result = result < subLength ? result : subLength;
                sum -= nums[i++]; // 這裡體現出滑動視窗的精髓之處，不斷變更 i（次序列的起始位置）
            }
        }
        // 如果 result 沒有被賦值的話，就回傳 0，說明沒有符合條件的次序列
        return result == INT32_MAX ? 0 : result;
    }
};
```

* 時間複雜性：O(n)
* 空間複雜度：O(1)

**一些讀者會疑惑為什麼時間複雜性是 O(n)**。

不要以為 for 裡放一個 while 迴圈（while loop）就以為是 O(n^2) 啊，主要是看每一個元素（element）被操作的次數，每個元素在滑動視窗進來操作一次，出去操作一次，每個元素都是被操作兩次，所以時間複雜性是 2 × n 也就是 O(n)。

class Solution {
   fun minSubArrayLen(target: Int, nums: IntArray): Int {
    // 左邊界 和 右邊界
    var left: Int = 0
    var right: Int = 0
    // sum 用來記錄和
    var sum: Int = 0
    // result 記錄一個固定值，便於判斷是否存在這樣的陣列
    var result: Int = Int.MAX_VALUE
    // subLength 記錄長度
    var subLength = Int.MAX_VALUE
   

    while (right < nums.size) {
        // 從陣列首元素開始逐次求和
        sum += nums[right++]
        // 判斷
        while (sum >= target) {
            var temp = right - left 
            // 每次和上一次比較求出最小陣列長度
            subLength = if (subLength > temp) temp else subLength
            // sum 減少，左邊界右移
            sum -= nums[left++]
        }
    }
    // 如果 subLength 為初始值，則說明長度為 0，否則回傳 subLength
    return if(subLength == result) 0 else subLength
    }
}
