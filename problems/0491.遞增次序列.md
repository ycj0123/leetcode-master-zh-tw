# 491.遞增次序列

[LeetCode 題目連結](https://leetcode.cn/problems/non-decreasing-subsequences/)

給定一個整數（integer）陣列（array），你的任務是找到所有該陣列的遞增次序列（subsequence），遞增次序列的長度至少是 2。

範例:

* 輸入: [4, 6, 7, 7]
* 輸出: [[4, 6], [4, 7], [4, 6, 7], [4, 6, 7, 7], [6, 7], [6, 7, 7], [7,7], [4,7,7]]

說明:
* 給定陣列的長度不會超過 15。
* 陣列中的整數範圍是 [-100,100]。
* 給定陣列中可能包含重複數字，相等的數字應該被視為遞增的一種情況。

## 解題思路

這個遞增次序列比較像是取有序（ordered）的子集（subset）。而且本題也要求不能有相同的遞增次序列。

這又是子集，又是去重，是不是不由自主地想起了剛剛講過的[90.子集 II](https://programmercarl.com/0090.子集II.html)。

就是因為太像了，更要注意差別所在，要不然就掉進陷阱裡了！

在[90.子集 II](https://programmercarl.com/0090.子集II.html)中我們是透過排序（sorting），再加一個標記陣列來達到去重的目的。

而本題求自增次序列，是不能對原陣列進行排序的，排完序的陣列都是自增次序列了。

**所以不能使用之前的去重邏輯！**

本題給出的範例，還是一個有序陣列 [4, 6, 7, 7]，這更容易誤導大家按照排序的思路去做了。

為了有鮮明的對比，我用 [4, 7, 6, 7] 這個陣列來舉例，抽象為樹狀結構（tree structure）如圖：

### 回溯三部曲

* 遞迴函數（recursive function）參數（parameter）

本題求次序列，很明顯一個元素（element）不能重複使用，所以需要 startIndex，調整下一層遞迴（recursion）的起始位置。

程式碼如下：

```cpp
vector<vector<int>> result;
vector<int> path;
void backtracking(vector<int>& nums, int startIndex)
```

* 終止條件（termination condition）

本題其實類似求子集問題，也是要遍歷（traversal）樹狀結構找每一個節點（node），所以和[回溯演算法：求子集問題！](https://programmercarl.com/0078.子集.html)一樣，可以不加終止條件，startIndex 每次都會加 1，並不會無限遞迴（infinite recursion）。

但本題收集結果有所不同，題目要求遞增次序列大小至少為 2，所以程式碼如下：

```cpp
if (path.size() > 1) {
    result.push_back(path);
    // 注意這裡不要加return，因為要取樹上的所有節點
}
```

* 單層搜尋邏輯

![491. 遞增次序列1](https://file1.kamacoder.com/i/algo/20201124200229824-20230310131640070.png)
在圖中可以看出，**同一父節點（father node）下的同層上使用過的元素就不能再使用了**

那麼單層搜尋程式碼如下：

```cpp
unordered_set<int> uset; // 使用set來對本層元素進行去重
for (int i = startIndex; i < nums.size(); i++) {
    if ((!path.empty() && nums[i] < path.back())
            || uset.find(nums[i]) != uset.end()) {
            continue;
    }
    uset.insert(nums[i]); // 記錄這個元素在本層用過了，本層後面不能再用了
    path.push_back(nums[i]);
    backtracking(nums, i + 1);
    path.pop_back();
}
```

**對於已經習慣寫回溯（backtracking）的同學，看到遞迴函數上面的 `uset.insert(nums[i]);`，下面卻沒有對應的 pop 之類的操作，應該很不習慣吧**

**這也是需要注意的點，`unordered_set<int> uset;` 是記錄本層元素是否重複使用，新的一層 uset 都會重新定義（清空），所以要知道 uset 只負責本層！**


最後整體 C++ 程式碼如下：

```CPP
// 版本一
class Solution {
private:
    vector<vector<int>> result;
    vector<int> path;
    void backtracking(vector<int>& nums, int startIndex) {
        if (path.size() > 1) {
            result.push_back(path);
            // 注意這裡不要加return，要取樹上的節點
        }
        unordered_set<int> uset; // 使用set對本層元素進行去重
        for (int i = startIndex; i < nums.size(); i++) {
            if ((!path.empty() && nums[i] < path.back())
                    || uset.find(nums[i]) != uset.end()) {
                    continue;
            }
            uset.insert(nums[i]); // 記錄這個元素在本層用過了，本層後面不能再用了
            path.push_back(nums[i]);
            backtracking(nums, i + 1);
            path.pop_back();
        }
    }
public:
    vector<vector<int>> findSubsequences(vector<int>& nums) {
        result.clear();
        path.clear();
        backtracking(nums, 0);
        return result;
    }
};
```
* 時間複雜性（time complexity）: O(n * 2^n)
* 空間複雜度（space complexity）: O(n)

## 最佳化

以上程式碼我用了 `unordered_set<int>` 來記錄本層元素是否重複使用。

**其實用陣列來做雜湊（hash），效率就高了很多**。

注意題目中說了，數值範圍 [-100,100]，所以完全可以用陣列來做雜湊。

程式執行的時候對 unordered_set 頻繁地 insert，unordered_set 需要做 hash map（也就是把鍵（key）透過雜湊函數（hash function）映射（mapping）為唯一的雜湊值）相對費時間，而且每次重新定義 set，insert 的時候其底層的符號表（symbol table）也要做相應的擴充，也是費事的。

那麼最佳化後的程式碼如下：

```CPP
// 版本二
class Solution {
private:
    vector<vector<int>> result;
    vector<int> path;
    void backtracking(vector<int>& nums, int startIndex) {
        if (path.size() > 1) {
            result.push_back(path);
        }
        int used[201] = {0}; // 這裡使用陣列來進行去重操作，題目說數值範圍[-100, 100]
        for (int i = startIndex; i < nums.size(); i++) {
            if ((!path.empty() && nums[i] < path.back())
                    || used[nums[i] + 100] == 1) {
                    continue;
            }
            used[nums[i] + 100] = 1; // 記錄這個元素在本層用過了，本層後面不能再用了
            path.push_back(nums[i]);
            backtracking(nums, i + 1);
            path.pop_back();
        }
    }
public:
    vector<vector<int>> findSubsequences(vector<int>& nums) {
        result.clear();
        path.clear();
        backtracking(nums, 0);
        return result;
    }
};
```

這份程式碼在 LeetCode 上提交，要比版本一耗時好得多。

**所以正如在[雜湊表（hash table）：總結篇！（每逢總結必經典）](https://programmercarl.com/哈希表总结.html)中說的那樣，陣列，set，map 都可以做雜湊表，而且陣列幹的活，map 和 set 都能幹，但如果數值範圍小的話能用陣列盡量用陣列**。


## 總結

本題題解清一色都說是深度優先搜尋（depth-first search, DFS），但我更傾向於說它用回溯法，而且本題我也是完全使用回溯法的邏輯來分析的。

相信大家在本題中處處都能看到是[回溯演算法：求子集問題（二）](https://programmercarl.com/0090.子集II.html)的身影，但處處又都是陷阱。

```go
func findSubsequences(nums []int) [][]int {
    res, path = make([][]int, 0), make([]int, 0, len(nums))
    dfs(nums, 0)

func dfs(nums []int, start int) {
    if len(path) >= 2 {
        tmp := make([]int, len(path))
        copy(tmp, path)
        res = append(res, tmp)
    }
    used := make(map[int]bool, len(nums))   // 初始化used字典，用以對同層元素去重

            continue
        }
        if len(path) == 0 || nums[i] >= path[len(path)-1] {
            path = append(path, nums[i])
            used[nums[i]] = true
            dfs(nums, i+1)
            path = path[:len(path)-1]
        }
    }
}
```

```c
int** ans;
int ansTop;

//將當前path中的內容複製到ans中
void copy() {
    int* tempPath = (int*)malloc(sizeof(int) * pathTop);
    memcpy(tempPath, path, pathTop * sizeof(int));
    length[ansTop] = pathTop;
    ans[ansTop++] = tempPath;
}

//查找uset中是否存在值為key的元素
int find(int* uset, int usetSize, int key) {
    int i;
    for(i = 0; i < usetSize; i++) {
        if(uset[i] == key)
            return 1;
    }
    return 0;
}

void backTracking(int* nums, int numsSize, int startIndex) {
    //當path中元素大於1個時，將path複製到ans中
    if(pathTop > 1) {
        copy();
    }
    int* uset = (int*)malloc(sizeof(int) * numsSize);
    int usetTop = 0;
    int i;
    for(i = startIndex; i < numsSize; i++) {
        //若當前元素小於path中最後一位元素 || 在樹的同一層找到了相同的元素，則continue
        if((pathTop > 0 && nums[i] < path[pathTop - 1]) || find(uset, usetTop, nums[i]))
            continue;
        //將當前元素放入uset
        uset[usetTop++] = nums[i];
        //將當前元素放入path
        path[pathTop++] = nums[i];
        backTracking(nums, numsSize, i + 1);
        //回溯
        pathTop--;
    }
}

int** findSubsequences(int* nums, int numsSize, int* returnSize, int** returnColumnSizes){
    //輔助陣列初始化
    path = (int*)malloc(sizeof(int) * numsSize);
    ans = (int**)malloc(sizeof(int*) * 33000);
    length = (int*)malloc(sizeof(int*) * 33000);

    *returnSize = ansTop;
    *returnColumnSizes = (int*)malloc(sizeof(int) * ansTop);
    int i;
```

```swift
func findSubsequences(_ nums: [Int]) -> [[Int]] {
    var result = [[Int]]()
    var path = [Int]()
    func backtracking(startIndex: Int) {
        // 收集結果，但不回傳，因為後續還要以此基礎拼接
        if path.count > 1 {
            result.append(path)
        }

        var uset = Set<Int>()
        let end = nums.count
        guard startIndex < end else { return } // 終止條件
        for i in startIndex ..< end {
            let num = nums[i]
            if uset.contains(num) { continue } // 跳過重複元素
            if !path.isEmpty, num < path.last! { continue } // 確保遞增
            uset.insert(num) // 透過set記錄
            path.append(num) // 處理：收集元素
            backtracking(startIndex: i + 1) // 元素不重複存取
            path.removeLast() // 回溯
        }
    }
    backtracking(startIndex: 0)
    return result
}
```

```csharp
public class Solution {
    public IList<IList<int>> res = new List<IList<int>>();
    public IList<int> path = new List<int>();
    public IList<IList<int>> FindSubsequences(int[] nums) {
        BackTracking(nums, 0);
        return res;
    }
    public void BackTracking(int[] nums, int start){
        if(path.Count >= 2){
            res.Add(new List<int>(path));
        }
        HashSet<int> hs = new HashSet<int>();
        for(int i = start; i < nums.Length; i++){
            if(path.Count > 0 && path[path.Count - 1] > nums[i] || hs.Contains(nums[i])){
                continue;
            }
            hs.Add(nums[i]);
            path.Add(nums[i]);
            BackTracking(nums, i + 1);
            path.RemoveAt(path.Count - 1);
        }
    }
}
```
