# 第 454 題.四數相加 II

[LeetCode 題目連結](https://leetcode.com/problems/4sum-ii/)

給定四個包含整數（integer）的陣列（array）串列（list） A , B , C , D ,計算有多少個元組 (i, j, k, l) ，使得 A[i] + B[j] + C[k] + D[l] = 0。

為了使問題簡單化，所有的 A, B, C, D 具有相同的長度 N，且 0 ≤ N ≤ 500 。所有整數的範圍在 -2^28 到 2^28 - 1 之間，最終結果不會超過 2^31 - 1 。

**例如:**

輸入:
* A = [ 1, 2]
* B = [-2,-1]
* C = [-1, 2]
* D = [ 0, 2]

輸出:

2

**解釋:**

兩個元組如下:

1. (0, 0, 0, 1) -> A[0] + B[0] + C[0] + D[1] = 1 + (-2) + (-1) + 2 = 0
2. (1, 1, 0, 0) -> A[1] + B[1] + C[0] + D[0] = 2 + (-1) + (-1) + 0 = 0

## 解題思路

本題乍眼一看好像和[0015.三數之和](./0015.三數之和.md)，[0018.四數之和](./0018.四數之和.md)差不多，其實差很多。

**本題是使用雜湊法的經典題目，而[0015.三數之和](./0015.三數之和.md)，[0018.四數之和](./0018.四數之和.md)並不適合使用雜湊法**，因為三數之和和四數之和這兩道題目使用雜湊法在不逾時的情況下做到對結果去重是很困難的，有很多細節需要處理。

**而這道題目是四個獨立的陣列，只要找到 A[i] + B[j] + C[k] + D[l] = 0 就可以，不用考慮有重複的四個元素（element）相加等於 0 的情況，所以相對於題目 18. 四數之和，題目 15.三數之和，還是簡單了不少！**

如果本題想難度升級：就是給出一個陣列（而不是四個陣列），在這裡找出四個元素相加等於 0，答案中不可以包含重複的四元組（quadruple），大家可以思考一下，後續的文章我也會講到的。

本題解題步驟：

1. 首先定義 一個 unordered_map，key 放 a 和 b 兩數之和，value 放 a 和 b 兩數之和出現的次數。
2. 遍歷（traversal）大 A 和大 B 陣列，統計兩個陣列元素之和，和出現的次數，放到 map 中。
3. 定義 int 變數（variable） count，用來統計 a+b+c+d = 0 出現的次數。
4. 再遍歷大 C 和大 D 陣列，找到如果 0-(c+d) 在 map 中出現過的話，就用 count 把 map 中 key 對應的 value 也就是出現次數統計出來。
5. 最後回傳統計值 count 就可以了

C++ 程式碼:

```CPP
class Solution {
public:
    int fourSumCount(vector<int>& nums1, vector<int>& nums2, vector<int>& nums3, vector<int>& nums4) {
        unordered_map<int, int> umap; // key: a+b 的數值，value: a+b 數值出現的次數
        // 遍歷大 A 和大 B 陣列，統計兩個陣列元素之和，和出現的次數，放到 map 中
        for (int a : nums1) {
            for (int b : nums2) {
                umap[a + b]++;
            }
        }
        int count = 0; // 統計 a+b+c+d = 0 出現的次數
        // 再遍歷大 C 和大 D 陣列，找到如果 0-(c+d) 在 map 中出現過的話，就把 map 中 key 對應的 value 也就是出現次數統計出來。
        for (int c : nums3) {
            for (int d : nums4) {
                if (umap.find(0 - (c + d)) != umap.end()) {
                    count += umap[0 - (c + d)];
                }
            }
        }
        return count;
    }
};

```

* 時間複雜度（time complexity）: O(n^2)
* 空間複雜度（space complexity）: O(n^2)，最壞情況下 A 和 B 的值各不相同，相加產生的數字個數為 n^2

```Java
        Map<Integer, Integer> map = new HashMap<Integer, Integer>();
        // 統計兩個陣列中的元素之和，同時統計出現的次數，放入 map
```

```scala
object Solution {
  // 匯入套件
  import scala.collection.mutable
  def fourSumCount(nums1: Array[Int], nums2: Array[Int], nums3: Array[Int], nums4: Array[Int]): Int = {
    // 定義一個 HashMap，key 儲存值，value 儲存該值出現的次數
    val map = new mutable.HashMap[Int, Int]()
    // 遍歷前兩個陣列，把他們所有可能的情況都記錄到 map
    for (i <- nums1.indices) {
      for (j <- nums2.indices) {
        val tmp = nums1(i) + nums2(j)
        // 如果包含該值，則對他的 key 加 1，不包含則新增進去
        if (map.contains(tmp)) {
          map.put(tmp, map.get(tmp).get + 1)
        } else {
          map.put(tmp, 1)
        }
      }
    }
    var res = 0 // 結果變數
    // 遍歷後兩個陣列
    for (i <- nums3.indices) {
      for (j <- nums4.indices) {
        val tmp = -(nums3(i) + nums4(j))
        // 如果 map 中存在該值，結果就 += value
        if (map.contains(tmp)) {
          res += map.get(tmp).get
        }
      }
    }
    // 回傳最終結果，可以省略關鍵字 return
    res
  }
}
```

### C：

```c
// 雜湊表大小
const int HASH_SIZE = 101;

typedef struct node {
    int val;
    int count;
    struct node *next;
} node, *HashMap;

// 雜湊表插入
void hash_insert(HashMap hashmap[], int val) {
    int idx = val < 0 ? (-val) % HASH_SIZE : val % HASH_SIZE, count = 0;
    node *p = hashmap[idx];
    while (p->next != NULL) {
        p = p->next;
        if (p->val == val) {
            (p->count)++;
            return;
        }
    }
    node *new = malloc(sizeof(node));
    new->val = val;
    new->count = 1;
    new->next = NULL;
    p->next = new;
    return;
}

// 雜湊表查找
int hash_search(HashMap hashmap[], int val) {
    int idx = val < 0 ? (-val) % HASH_SIZE : val % HASH_SIZE;
    node *p = hashmap[idx];
    while (p->next != NULL) {
        p = p->next;
        if (p->val == val) return p->count;
    }
    return 0;
}

int fourSumCount(int* nums1, int nums1Size, int* nums2, int nums2Size, int* nums3, int nums3Size, int* nums4, int nums4Size){
    // 初始化雜湊表
    HashMap hashmap[HASH_SIZE];
    for (int i = 0; i < HASH_SIZE; i++) {
        hashmap[i] = malloc(sizeof(node));
        hashmap[i]->next = NULL;
    }
    
    // 統計兩個陣列元素之和的負值和出現的次數，放到雜湊表中
    int count = 0, num;
    for (int i = 0; i < nums1Size; i++) {
        for(int j = 0; j < nums2Size; j++) {
            num = - nums1[i] - nums2[j];
            hash_insert(hashmap, num);
        }
    }
    
    // 統計另外兩個陣列元素之和，查找雜湊表中對應元素的出現次數，加入總次數
    for (int i = 0; i < nums3Size; i++) {
        for(int j = 0; j < nums4Size; j++) {
            num = nums3[i] + nums4[j];
            count += hash_search(hashmap, num);
        }
    }
    return count;
}
```

```ruby
# @param {Integer[]} nums1

# @param {Integer[]} nums3

# 新想法：和版主的想法基本相同，只是對後面兩個陣列的雙重迴圈，用一個方法呼叫外加單層迴圈替代，簡化了一點。
#       簡單地說，就是把四數和變成了兩個兩數和的統計（結果放到兩個 hash 中），然後再來一次兩數和為 0。
#       把四個數分成兩組兩個數，然後分別計算每組可能的和情況，分別存入 hash 中，key 是 和，value 是 數量；
#       最後，得到的兩個 hash 只需要遍歷一次，符合和為零的 value 相乘並加總。
def four_sum_count(nums1, nums2, nums3, nums4)
    num_to_count_1 = two_sum_mapping(nums1, nums2)
    num_to_count_2 = two_sum_mapping(nums3, nums4)

    count_sum = 0

    num_to_count_1.each do |num, count|
        count_sum += num_to_count_2[-num] * count # 反查另一個 hash，看有沒有匹配的，沒有的話，hash 預設值為 0，不影響加總；有匹配的，乘積就是可能的情況
    end

    count_sum
end

def two_sum_mapping(nums1, nums2)
    num_to_count = Hash.new(0)

    nums1.each do |num1|
        nums2.each do |nums2|
            num_to_count[num1 + nums2] += 1 # 統計和為 num1 + nums2 的有幾個
        end
    end

    num_to_count
end
```
