# 1005. K 次取反後最大化的陣列（array）和

[LeetCode 題目連結](https://leetcode.com/problems/maximize-sum-of-array-after-k-negations/)

給定一個整數（integer）陣列 A，我們只能用以下方法（method）修改該陣列：我們選擇某個索引（index） i 並將 A[i] 替換為 -A[i]，然後總共重複（duplicate）這個過程 K 次。（我們可以多次選擇同一個索引 i。）

以這種方式修改陣列後，回傳陣列可能的最大和。

範例 1：
* 輸入：A = [4,2,3], K = 1
* 輸出：5
* 解釋：選擇索引 (1) ，然後 A 變為 [4,-2,3]。

範例 2：
* 輸入：A = [3,-1,0,2], K = 3
* 輸出：6
* 解釋：選擇索引 (1, 2, 2) ，然後 A 變為 [3,1,0,2]。

範例 3：
* 輸入：A = [2,-3,-1,5,-4], K = 2
* 輸出：13
* 解釋：選擇索引 (1, 4) ，然後 A 變為 [2,3,-1,5,4]。

提示：

* 1 <= A.length <= 10000
* 1 <= K <= 10000
* -100 <= A[i] <= 100

## 解題思路

本題思路其實比較好想了，如何可以讓陣列和最大呢？

貪心的思路，區域最佳（local optimum）：讓絕對值（absolute value）大的負數（negative number）變為正數，當前數值達到最大，總體最佳（global optimum）：整個陣列和達到最大。

區域最佳可以推出總體最佳。

那麼如果將負數都轉變為正數了，K 依然大於 0，此時的問題是一個有序（ordered）正整數（positive integer）序列（sequence），如何轉變 K 次正負，讓陣列和達到最大。

那麼又是一個貪心：區域最佳：只找數值最小的正整數進行反轉（reverse），當前數值和可以達到最大（例如正整數陣列 {5, 3, 1}，反轉 1 得到 -1 比反轉 5 得到的 -5 大多了），總體最佳：整個陣列和達到最大。

雖然這道題目大家做的時候，可能都不會去想什麼貪心演算法，一鼓作氣，就 AC 了。

**我這裡其實是為了給大家展現出來經常被大家忽略的貪心思路，這麼一道簡單題，就用了兩次貪心！**

那麼本題的解題步驟為：

* 第一步：將陣列按照絕對值大小從大到小排序（sorting），**注意要按照絕對值的大小**
* 第二步：從前向後遍歷（traversal），遇到負數將其變為正數，同時 K--
* 第三步：如果 K 還大於 0，那麼反覆轉變數值最小的元素（element），將 K 用完
* 第四步：求和

對應 C++ 程式碼如下：

```CPP
class Solution {
static bool cmp(int a, int b) {
    return abs(a) > abs(b);
}
public:
    int largestSumAfterKNegations(vector<int>& A, int K) {
        sort(A.begin(), A.end(), cmp);       // 第一步
        for (int i = 0; i < A.size(); i++) { // 第二步
            if (A[i] < 0 && K > 0) {
                A[i] *= -1;
                K--;
            }
        }
        if (K % 2 == 1) A[A.size() - 1] *= -1; // 第三步
        int result = 0;
        for (int a : A) result += a;        // 第四步
        return result;
    }
};
```

* 時間複雜度（time complexity）：O(nlogn)
* 空間複雜度（space complexity）：O(1)

```java
class Solution {
    public int largestSumAfterKNegations(int[] nums, int K) {
    	// 將陣列按照絕對值大小從大到小排序，注意要按照絕對值的大小
	nums = IntStream.of(nums)
		     .boxed()
		     .sorted((o1, o2) -> Math.abs(o2) - Math.abs(o1))
		     .mapToInt(Integer::intValue).toArray();
	int len = nums.length;	    
	for (int i = 0; i < len; i++) {
	    // 從前向後遍歷，遇到負數將其變為正數，同時 K--
	    if (nums[i] < 0 && K > 0) {
	    	nums[i] = -nums[i];
	    	K--;
	    }
	}
	// 如果 K 還大於 0，那麼反覆轉變數值最小的元素，將 K 用完

	if (K % 2 == 1) nums[len - 1] = -nums[len - 1];
	return Arrays.stream(nums).sum();

    }
}

// 版本二：排序陣列並貪心地盡可能將負數翻轉為正數，再根據剩餘的 k 值調整最小元素的符號，從而最大化陣列的總和。
class Solution {
    public int largestSumAfterKNegations(int[] nums, int k) {
        if (nums.length == 1) return nums[0];

        // 排序：先把負數處理了
        Arrays.sort(nums); 

        for (int i = 0; i < nums.length && k > 0; i++) { // 貪心點，透過負轉正，消耗盡可能多的 k
            if (nums[i] < 0) {
                nums[i] = -nums[i];
                k--;
            }
        }

        // 退出迴圈，k > 0 || k < 0 (k 消耗完了不用討論)
        if (k % 2 == 1) { // k > 0 && k is odd：對於負數：負-正-負-正
            Arrays.sort(nums); // 再次排序得到剩餘的負數，或者最小的正數
            nums[0] = -nums[0];
        }
        // k > 0 && k is even，flip 數字不會產生影響：對於負數：負-正-負；對於正數：正-負-正

        int sum = 0;
        for (int num : nums) { // 計算最大和
            sum += num;
        }
        return sum;
    }
}
```

```Javascript
var largestSumAfterKNegations = function(nums, k) {
    nums.sort((a, b) => Math.abs(b) - Math.abs(a)); // 排序
    let sum = 0;
    for(let i = 0; i < nums.length; i++) {
        if(nums[i] < 0 && k-- > 0) { // 負數取反（k 數量足夠時）
            nums[i] = -nums[i];
        }
        sum += nums[i]; // 求和
```

```c
int largestSumAfterKNegations(int* nums, int numsSize, int k){
    qsort(nums, numsSize, sizeof(int), cmp);

    int i;
    for(i = 0; i < numsSize; ++i) {
        // 遍歷陣列，若當前元素 < 0 則將當前元素轉變，k--
        if(nums[i] < 0 && k > 0) {
            nums[i] *= -1;
            --k;
        }
```

```typescript
function largestSumAfterKNegations(nums: number[], k: number): number {
    nums.sort((a, b) => Math.abs(b) - Math.abs(a));
    let curIndex: number = 0;
    const length = nums.length;
    while (curIndex < length && k > 0) {
        if (nums[curIndex] < 0) {
            nums[curIndex] *= -1;
            k--;
        }
        curIndex++;
    }
    while (k > 0) {
        nums[length - 1] *= -1;
        k--;
    }
    return nums.reduce((pre, cur) => pre + cur, 0);
};
```
