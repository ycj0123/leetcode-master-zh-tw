# 1207.獨一無二的出現次數

[LeetCode 題目連結](https://leetcode.cn/problems/unique-number-of-occurrences/)

給你一個整數（integer）陣列（array） arr，請你幫忙統計陣列中每個數的出現次數。

如果每個數的出現次數都是獨一無二的，就回傳 true；否則回傳 false。

範例 1：
* 輸入：arr = [1,2,2,1,1,3]
* 輸出：true
* 解釋：在該陣列中，1 出現了 3 次，2 出現了 2 次，3 只出現了 1 次。沒有兩個數的出現次數相同。

範例 2：
* 輸入：arr = [1,2]
* 輸出：false

範例 3：
* 輸入：arr = [-3,0,1,-3,1,1,1,-3,10,0]
* 輸出：true

提示：

* 1 <= arr.length <= 1000
* -1000 <= arr[i] <= 1000


## 解題思路

這道題目是陣列在雜湊（hash）法中的經典應用，如果對陣列在雜湊法中的使用還不熟悉的同學可以看這兩篇：[陣列在雜湊法中的應用](https://programmercarl.com/0242.有效的字母异位词.html)和[雜湊法：383. 贖金信](https://programmercarl.com/0383.赎金信.html)

進而可以學習一下[set 在雜湊法中的應用](https://programmercarl.com/0349.两个数组的交集.html)，以及[map 在雜湊法中的應用](https://programmercarl.com/0001.两数之和.html)

回歸本題，**本題強調了 -1000 <= arr[i] <= 1000**，那麼就可以用陣列來做雜湊，arr[i] 作為雜湊表（hash table）（陣列）的下標（subscript），那麼 arr[i] 可以是負數（negative number），怎麼辦？負數不能做陣列下標。


**此時可以定義一個 2001 大小的陣列，例如 int count[2001];**，統計的時候，將 arr[i] 統一加 1000，這樣就可以統計 arr[i] 的出現頻率了。

題目中要求的是是否有相同的頻率出現，那麼需要再定義一個雜湊表（陣列）用來記錄頻率是否重複（duplicate）出現過，bool fre[1001]; 定義布林（Boolean）類型的就可以了，**因為題目中強調 1 <= arr.length <= 1000，所以雜湊表大小為 1000 就可以了**。

C++ 程式碼如下：

```CPP
class Solution {
public:
    bool uniqueOccurrences(vector<int>& arr) {
        int count[2001] = {0}; // 統計數字出現的頻率
        for (int i = 0; i < arr.size(); i++) {
            count[arr[i] + 1000]++;
        }
        bool fre[1001] = {false}; // 看相同頻率是否重複出現
        for (int i = 0; i <= 2000; i++) {
            if (count[i]) {
                if (fre[count[i]] == false) fre[count[i]] = true;
                else return false;
            }
        }
        return true;
    }
};
```

``` javascript
// 方法一：使用陣列記錄元素出現次數
var uniqueOccurrences = function(arr) {
    const count = new Array(2001).fill(0);// -1000 <= arr[i] <= 1000
    for(let i = 0; i < arr.length; i++){
        count[arr[i] + 1000]++;// 防止負數作為下標
    }
    // 標記相同頻率是否重複出現
    const fre = new Array(1001).fill(false);// 1 <= arr.length <= 1000
    for(let i = 0; i <= 2000; i++){
        if(count[i] > 0){// 有 i 出現過
            if(fre[count[i]] === false) fre[count[i]] = true;// 之前未出現過，標記為出現
            else return false;// 之前就出現了，重複出現
        }
    }
    return true;
};

// 方法二：使用 Map 和 Set
/**
 * @param {number[]} arr
 * @return {boolean}
 */
var uniqueOccurrences = function(arr) {
    // 記錄每個元素出現次數
    let map = new Map();
    arr.forEach( x => {
        map.set(x, (map.get(x) || 0) + 1); 
    })
    // Set() 裡的元素是不重複的。如果有元素出現次數相同，則最後的 set 的長度不等於 map 的長度
    return map.size === new Set(map.values()).size
};
```

```typescript
function uniqueOccurrences(arr: number[]): boolean {
    const countArr: number[] = new Array(2001).fill(0);
    for (let i = 0, length = arr.length; i < length; i++) {
        countArr[arr[i] + 1000]++;
```

```typescript
function uniqueOccurrences(arr: number[]): boolean {
``` 

### Rust

```rust
use std::collections::{HashMap, HashSet};
impl Solution {
    pub fn unique_occurrences(arr: Vec<i32>) -> bool {
        let mut hash = HashMap::<i32, i32>::new();
        for x in arr {
            *hash.entry(x).or_insert(0) += 1;
        }
        let mut set = HashSet::<i32>::new();
        for (_k, v) in hash {
            if set.contains(&v) {
                return false
            } else {
                set.insert(v);
            }
        }
        true
    }
}
```
