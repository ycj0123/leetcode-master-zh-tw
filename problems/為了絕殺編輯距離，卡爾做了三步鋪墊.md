# 動態規劃之編輯距離（edit distance）總結篇

本週我們講了動態規劃（dynamic programming, DP）之終極絕殺：編輯距離，為什麼叫做終極絕殺呢？

細心的讀者應該知道，我們在前三篇DP的文章就一直為編輯距離這道題目做鋪墊。

## 判斷次序列

[動態規劃：392.判斷子序列](./0392.判斷次序列.md) 給定字串（string） s 和 t ，判斷 s 是否為 t 的次序列（subsequence）。


這道題目 其實是可以用雙指標（two pointers）或者貪心法（greedy）的，但是我在開篇的時候就說了這是編輯距離的入門題目，因為從題意中我們也可以發現，只需要計算刪除的情況，不用考慮增加和替換的情況。

* if (s[i - 1] == t[j - 1])
    * t 中找到了一個字元（character）在 s 中也出現了
* if (s[i - 1] != t[j - 1])
    * 相當於 t 要刪除元素（element），繼續匹配

狀態變遷方程式（state transition equation）：

```
if (s[i - 1] == t[j - 1]) dp[i][j] = dp[i - 1][j - 1] + 1;
else dp[i][j] = dp[i][j - 1];
```

## 不同的次序列

[動態規劃：115.不同的子序列](./0115.不同的次序列.md) 給定一個字串 s 和一個字串 t ，計算在 s 的次序列中 t 出現的個數。

本題雖然也只有刪除操作，不用考慮替換增加之類的，但相對於[動態規劃：392.判斷子序列](./0392.判斷次序列.md)就有難度了，這道題目雙指標法可就做不了。


當 s[i - 1] 與 t[j - 1] 相等時，dp[i][j] 可以有兩部分組成。

一部分是用 s[i - 1] 來匹配，那麼個數為 dp[i - 1][j - 1]。

一部分是不用 s[i - 1] 來匹配，個數為 dp[i - 1][j]。

這裡可能有同學不明白了，為什麼還要考慮 不用 s[i - 1] 來匹配，都相同了肯定要匹配啊。

例如： s：bagg 和 t：bag ，s[3] 和 t[2] 是相同的，但是字串 s 也可以不用 s[3] 來匹配，即用 s[0]s[1]s[2] 組成的 bag。

當然也可以用 s[3] 來匹配，即：s[0]s[1]s[3] 組成的 bag。

所以當 s[i - 1] 與 t[j - 1] 相等時，dp[i][j] = dp[i - 1][j - 1] + dp[i - 1][j];

當 s[i - 1] 與 t[j - 1] 不相等時，dp[i][j] 只有一部分組成，不用 s[i - 1] 來匹配，即：dp[i - 1][j]

所以遞迴公式（recurrence formula）為：dp[i][j] = dp[i - 1][j];


狀態變遷方程式：
```CPP
if (s[i - 1] == t[j - 1]) {
    dp[i][j] = dp[i - 1][j - 1] + dp[i - 1][j];
} else {
    dp[i][j] = dp[i - 1][j];
}
```

## 兩個字串的刪除操作

[動態規劃：583.兩個字符串的刪除操作](./0583.兩個字串的刪除操作.md)給定兩個單詞 word1 和 word2，找到使得 word1 和 word2 相同所需的最少步數，每步可以刪除任意一個字串中的一個字元。

本題和[動態規劃：115.不同的子序列](./0115.不同的次序列.md)相比，其實就是兩個字串都可以刪除了，情況雖說複雜一些，但整體解題思路是不變的。


* 當 word1[i - 1] 與 word2[j - 1] 相同的時候
* 當 word1[i - 1] 與 word2[j - 1] 不相同的時候

當 word1[i - 1] 與 word2[j - 1] 相同的時候，dp[i][j] = dp[i - 1][j - 1];

當 word1[i - 1] 與 word2[j - 1] 不相同的時候，有三種情況：

情況一：刪 word1[i - 1]，最少操作次數為 dp[i - 1][j] + 1

情況二：刪 word2[j - 1]，最少操作次數為 dp[i][j - 1] + 1

情況三：同時刪 word1[i - 1] 和 word2[j - 1]，操作的最少次數為 dp[i - 1][j - 1] + 2

那最後當然是取最小值，所以當 word1[i - 1] 與 word2[j - 1] 不相同的時候，遞迴公式：dp[i][j] = min({dp[i - 1][j - 1] + 2, dp[i - 1][j] + 1, dp[i][j - 1] + 1});

狀態變遷方程式：
```CPP
if (word1[i - 1] == word2[j - 1]) {
    dp[i][j] = dp[i - 1][j - 1];
} else {
    dp[i][j] = min({dp[i - 1][j - 1] + 2, dp[i - 1][j] + 1, dp[i][j - 1] + 1});
}
```


## 編輯距離

[動態規劃：72.編輯距離](./0072.編輯距離.md) 給你兩個單詞 word1 和 word2，請你計算出將 word1 轉換成 word2 所使用的最少操作數 。


編輯距離終於來了，**有了前面三道題目的鋪墊，應該有想法了**，本題是兩個字串可以增刪改，比 [動態規劃：判斷子序列](./0392.判斷次序列.md)，[動態規劃：不同的子序列](./0115.不同的次序列.md)，[動態規劃：兩個字符串的刪除操作](./0583.兩個字串的刪除操作.md)都要複雜得多。


在確定遞迴公式的時候，首先要考慮清楚編輯的幾種操作，整理如下：

* if (word1[i - 1] == word2[j - 1])
    * 不操作
* if (word1[i - 1] != word2[j - 1])
    * 增
    * 刪
    * 換

也就是如上四種情況。

if (word1[i - 1] == word2[j - 1]) 那麼說明不用任何編輯，dp[i][j] 就應該是 dp[i - 1][j - 1]，即 dp[i][j] = dp[i - 1][j - 1];

此時可能有同學有點不明白，為什麼要 dp[i][j] = dp[i - 1][j - 1] 呢？

那麼就再回顧上面講過的 dp[i][j] 的定義，word1[i - 1] 與 word2[j - 1] 相等了，那麼就不用編輯了，以下標（subscript） i-2 為結尾的字串 word1 和以下標 j-2 為結尾的字串 word2 的最近編輯距離 dp[i - 1][j - 1] 就是 dp[i][j] 了。

在下面的講解中，如果哪裡看不懂，就回想一下 dp[i][j] 的定義，就明白了。

**在整個DP的過程中，最為關鍵就是正確理解 dp[i][j] 的定義！**

if (word1[i - 1] != word2[j - 1])，此時就需要編輯了，如何編輯呢？

操作一：word1 增加一個元素，使其 word1[i - 1] 與 word2[j - 1] 相同，那麼就是以下標 i-2 為結尾的 word1 與 i-1 為結尾的 word2 的最近編輯距離加上一個增加元素的操作。

即 dp[i][j] = dp[i - 1][j] + 1;


操作二：word2 添加一個元素，使其 word1[i - 1] 與 word2[j - 1] 相同，那麼就是以下標 i-1 為結尾的 word1 與 j-2 為結尾的 word2 的最近編輯距離加上一個增加元素的操作。

即 dp[i][j] = dp[i][j - 1] + 1;

這裡有同學發現了，怎麼都是添加元素，刪除元素去哪了。

**word2 添加一個元素，相當於 word1 刪除一個元素**，例如 word1 = "ad" ，word2 = "a"，word2 添加一個元素 d，也就是相當於 word1 刪除一個元素 d，操作數是一樣！

操作三：替換元素，word1 替換 word1[i - 1]，使其與 word2[j - 1] 相同，此時不用增加元素，那麼以下標 i-2 為結尾的 word1 與 j-2 為結尾的 word2 的最近編輯距離加上一個替換元素的操作。

即 dp[i][j] = dp[i - 1][j - 1] + 1;

綜上，當 if (word1[i - 1] != word2[j - 1]) 時取最小的，即：dp[i][j] = min({dp[i - 1][j - 1], dp[i - 1][j], dp[i][j - 1]}) + 1;

遞迴公式程式碼如下：

```CPP
if (word1[i - 1] == word2[j - 1]) {
    dp[i][j] = dp[i - 1][j - 1];
}
else {
    dp[i][j] = min({dp[i - 1][j - 1], dp[i - 1][j], dp[i][j - 1]}) + 1;
}
```

## 其他語言版本

### Java：

```java
class Solution {
    public int minDistance(String word1, String word2) {
        int m = word1.length();
        int n = word2.length();
        int[][] dp = new int[m+1][n+1];
        for(int i = 1; i <= m; i++){
            dp[i][0] = i;
        }
        for(int i = 1; i <= n; i++){
            dp[0][i] = i;
        }
        for(int i = 1; i <= m; i++){
            for(int j = 1; j <= n; j++){
                int left = dp[i][j-1]+1;
                int mid = dp[i-1][j-1];
                int right = dp[i-1][j]+1;
                if(word1.charAt(i-1) != word2.charAt(j-1)){
                    mid ++;
                }
                dp[i][j] = Math.min(left,Math.min(mid,right));
            }
        }
        return dp[m][n];
    }
}
```
