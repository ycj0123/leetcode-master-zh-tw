# 383. 贖金信

[LeetCode 題目連結](https://leetcode.cn/problems/ransom-note/)

給定一個贖金信 (ransom) 字串（string）和一個雜誌 (magazine) 字串，判斷第一個字串 ransom 能不能由第二個字串 magazines 裡面的字元（character）構成。如果可以構成，回傳 true ；否則回傳 false。

(題目說明：為了不暴露贖金信字跡，要從雜誌上搜尋各個需要的字母，組成單字來表達意思。雜誌字串中的每個字元只能在贖金信字串中使用一次。)

**注意：**

你可以假設兩個字串均只含有小寫字母。

canConstruct("a", "b") -> false     
canConstruct("aa", "ab") -> false      
canConstruct("aa", "aab") -> true      

## 解題思路

這道題目和 [242.有效的迴文（anagram）](https://programmercarl.com/0242.有效的字母异位词.html) 很像，[242.有效的迴文](https://programmercarl.com/0242.有效的字母异位词.html) 相當於求 字串 a 和 字串 b 是否可以相互組成，而這道題目是求 字串 a 能否組成字串 b，而不用管字串 b 能不能組成字串 a。

本題判斷第一個字串 ransom 能不能由第二個字串 magazines 裡面的字元構成，但是這裡需要注意兩點。

*  第一點「為了不暴露贖金信字跡，要從雜誌上搜尋各個需要的字母，組成單字來表達意思」 這裡*說明雜誌裡面的字母不可重複使用。*

*  第二點 「你可以假設兩個字串均只含有小寫字母。」 *說明只有小寫字母*，這一點很重要

### 蠻力法（brute force）

那麼第一個思路其實就是蠻力列舉（enumeration）了，兩層 for 迴圈（for-loop），不斷去尋找，程式碼如下：

```CPP
class Solution {
public:
    bool canConstruct(string ransomNote, string magazine) {
        for (int i = 0; i < magazine.length(); i++) {
            for (int j = 0; j < ransomNote.length(); j++) {
                // 在ransomNote中找到和magazine相同的字元
                if (magazine[i] == ransomNote[j]) {
                    ransomNote.erase(ransomNote.begin() + j); // ransomNote刪除這個字元
                    break;
                }
            }
        }
        // 如果ransomNote為空，則說明magazine的字元可以組成ransomNote
        if (ransomNote.length() == 0) {
            return true;
        }
        return false;
    }
};
```

* 時間複雜性（time complexity）: O(n^2)
* 空間複雜度（space complexity）: O(1)

這裡時間複雜性是比較高的，而且裡面還有一個字串刪除（delete）也就是 erase 的操作，也是費時的，當然這段程式碼也可以通過這道題。


### 雜湊解法

因為題目說只有小寫字母，那可以採用空間換取時間的雜湊策略，用一個長度為 26 的陣列來記錄 magazine 裡字母出現的次數。

然後再用 ransomNote 去驗證這個陣列是否包含了 ransomNote 所需要的所有字母。

依然是陣列在雜湊法中的應用。

一些同學可能想，用陣列幹嘛，都用 map 就好了，**其實在本題的情況下，使用 map 的空間消耗要比陣列大一些的，因為 map 要維護紅-黑樹（red-black tree）或者雜湊表（hash table），而且還要做雜湊函數（hash function），是費時的！資料量大的話就能體現出來差別了。所以陣列更加簡單直接有效！**

程式碼如下：

```CPP
class Solution {
public:
    bool canConstruct(string ransomNote, string magazine) {
        int record[26] = {0};
        //add
        if (ransomNote.size() > magazine.size()) {
            return false;
        }
        for (int i = 0; i < magazine.length(); i++) {
            // 透過record資料記錄 magazine裡各個字元出現次數
            record[magazine[i]-'a'] ++;
        }
        for (int j = 0; j < ransomNote.length(); j++) {
            // 遍歷ransomNote，在record裡對應的字元個數做--操作
            record[ransomNote[j]-'a']--;
            // 如果小於零說明ransomNote裡出現的字元，magazine沒有
            if(record[ransomNote[j]-'a'] < 0) {
                return false;
            }
        }
        return true;
    }
};
```

* 時間複雜性: O(m+n)，其中 m 表示 ransomNote 的長度，n 表示 magazine 的長度
* 空間複雜度: O(1)

```scala
object Solution {
  def canConstruct(ransomNote: String, magazine: String): Boolean = {
    // 如果magazine的長度小於ransomNote的長度，必然是false
    if (magazine.length < ransomNote.length) {
      return false
    }
    // 定義一個陣列，儲存magazine字元出現的次數
    val map: Array[Int] = new Array[Int](26)

      else return false
    }
    // 如果上面沒有回傳false，直接回傳true，關鍵字return可以省略
    true
  }
}
```

```scala
object Solution {
  import scala.collection.mutable
  def canConstruct(ransomNote: String, magazine: String): Boolean = {
    // 如果magazine的長度小於ransomNote的長度，必然是false
    if (magazine.length < ransomNote.length) {
      return false
    }
    // 定義map，key是字元，value是字元出現的次數
    val map = new mutable.HashMap[Char, Int]()
    // 遍歷magazine，把所有的字元都記錄到map裡面
    for (i <- magazine.indices) {
      val tmpChar = magazine(i)
      // 如果map包含該字元，那麼對應的value++，否則添加該字元
      if (map.contains(tmpChar)) {
        map.put(tmpChar, map.get(tmpChar).get + 1)
      } else {
        map.put(tmpChar, 1)
      }
    }
    // 遍歷ransomNote
    for (i <- ransomNote.indices) {
      val tmpChar = ransomNote(i)
      // 如果map包含並且該字元的value大於0，則匹配成功，map對應的--，否則直接回傳false
      if (map.contains(tmpChar) && map.get(tmpChar).get > 0) {
        map.put(tmpChar, map.get(tmpChar).get - 1)
      } else {
        return false
      }
    }
    // 如果上面沒有回傳false，直接回傳true，關鍵字return可以省略
    true
  }
}
```

```c
bool canConstruct(char* ransomNote, char* magazine) {
    // 定義hash map陣列
    int hashmap[26] = {0};
    // 對magazine中字元計數
    while (*magazine != '\0') hashmap[*magazine++ % 26]++;
    // 遍歷ransomNote，對應的字元自減，小於0說明該字元magazine沒有或不足夠表示
    while (*ransomNote != '\0') hashmap[*ransomNote++ % 26]--;
    // 如果陣列中存在負數，說明ransomNote不能由magazine裡面的字元構成
    for (int i = 0; i < 26; i++) {
        if (hashmap[i] < 0) return false;
    }
    return true;
}
```
