# 738.單調增加（monotonically increasing）的數字
[LeetCode 題目連結](https://leetcode.cn/problems/monotone-increasing-digits/)

給定一個非負整數（nonnegative integer） `N`，找出小於或等於 `N` 的最大的整數（integer），同時這個整數需要滿足其各個位數上的數字是單調增加的。

（當且僅當每個相鄰位數上的數字 `x` 和 `y` 滿足 `x <= y` 時，我們稱這個整數是單調增加的。）

範例 1:
* 輸入: N = 10
* 輸出: 9

範例 2:
* 輸入: N = 1234
* 輸出: 1234

範例 3:
* 輸入: N = 332
* 輸出: 299

說明: `N` 是在 `[0, 10^9]` 範圍內的一個整數。

## 解題思路


### 蠻力法（brute force）

題意很簡單，那麼首先想的就是蠻力法了，來我替大家暴力一波，結果自然是逾時！

程式碼如下：
```CPP
class Solution {
private:
    // 判斷一個數字的各位上是否是遞增
    bool checkNum(int num) {
        int max = 10;
        while (num) {
            int t = num % 10;
            if (max >= t) max = t;
            else return false;
            num = num / 10;
        }
        return true;
    }
public:
    int monotoneIncreasingDigits(int N) {
        for (int i = N; i > 0; i--) { // 從大到小遍歷
            if (checkNum(i)) return i;
        }
        return 0;
    }
};
```
* 時間複雜性（time complexity）：O(n × m)，m 為 n 的數字長度
* 空間複雜度（space complexity）：O(1)

### 貪心演算法

題目要求小於等於 `N` 的最大單調增加的整數，那麼拿一個兩位的數字來舉例。

例如：98，一旦出現 `strNum[i - 1] > strNum[i]` 的情況（非單調增加），首先想讓 `strNum[i - 1]--`，然後 `strNum[i]` 設為 9，這樣這個整數就是 89，即小於 98 的最大的單調增加整數。

這一點如果想清楚了，這道題就好辦了。

此時是從前向後遍歷（traversal）還是從後向前遍歷呢？

從前向後遍歷的話，遇到 `strNum[i - 1] > strNum[i]` 的情況，讓 `strNum[i - 1]` 減一，但此時如果 `strNum[i - 1]` 減一了，可能又小於 `strNum[i - 2]`。

這麼說有點抽象，舉個例子，數字：332，從前向後遍歷的話，那麼就變成了 329，此時 2 又小於了第一位的 3 了，真正的結果應該是 299。

那麼從後向前遍歷，就可以重複利用上次比較得出的結果了，從後向前遍歷 332 的數值變化為：332 -> 329 -> 299

確定了遍歷順序之後，那麼此時區域最佳（local optimum）就可以推出總體最佳（global optimum），找不出反例，試試貪心法（greedy）。

C++ 程式碼如下：

```CPP
class Solution {
public:
    int monotoneIncreasingDigits(int N) {
        string strNum = to_string(N);
        // flag 用來標記賦值 9 從哪裡開始
        // 設定為這個預設值，為了防止第二個 for 迴圈在 flag 沒有被賦值的情況下執行
        int flag = strNum.size();
        for (int i = strNum.size() - 1; i > 0; i--) {
            if (strNum[i - 1] > strNum[i] ) {
                flag = i;
                strNum[i - 1]--;
            }
        }
        for (int i = flag; i < strNum.size(); i++) {
            strNum[i] = '9';
        }
        return stoi(strNum);
    }
};

```

* 時間複雜性：O(n)，n 為數字長度
* 空間複雜度：O(n)，需要一個字串（string），轉化為字串操作更方便

## 總結

本題只要想清楚個例，例如 98，一旦出現 `strNum[i - 1] > strNum[i]` 的情況（非單調增加），首先想讓 `strNum[i - 1]` 減一，`strNum[i]` 賦值 9，這樣這個整數就是 89。就可以很自然想到對應的貪心解法了。

想到了貪心，還要考慮遍歷順序，只有從後向前遍歷才能重複利用上次比較的結果。

最後程式碼實作的時候，也需要一些技巧，例如用一個旗標（flag）來標記從哪裡開始賦值 9。

```go
func monotoneIncreasingDigits(n int) int {
	s := strconv.Itoa(n)
	// 從左到右遍歷字串，找到第一個不滿足單調增加的位置
	for i := len(s) - 2; i >= 0; i-- {
		if s[i] > s[i+1] {
			// 將該位置的數字減 1
			s = s[:i] + string(s[i]-1) + s[i+1:]
			// 將該位置之後的所有數字設為 9
			for j := i + 1; j < len(s); j++ {
				s = s[:j] + "9" + s[j+1:]
			}
		}
	}
	result, _ := strconv.Atoi(s)
	return result
}
```

### Scala

直接轉換為了整數陣列: 
```scala
object Solution {
  import scala.collection.mutable
  def monotoneIncreasingDigits(n: Int): Int = {
    var digits = mutable.ArrayBuffer[Int]()
    // 提取每位數字
    var temp = n // 因為參數 n 為 immutable 所以需要賦值給一個可變變數
    while (temp != 0) {
      digits.append(temp % 10)
      temp = temp / 10
    }
    // 貪心
    var flag = -1 
    for (i <- 0 until (digits.length - 1) if digits(i) < digits(i + 1)) {
      flag = i
      digits(i + 1) -= 1
    }
    for (i <- 0 to flag) digits(i) = 9

    // 拼接
    var res = 0
    for (i <- 0 until digits.length) {
      res += digits(i) * math.pow(10, i).toInt
    }
    res
  }
}
```

```Rust
    pub fn monotone_increasing_digits(n: i32) -> i32 {
        let mut n_bytes = n.to_string().into_bytes();
        let mut flag = n_bytes.len();
        for i in (1..n_bytes.len()).rev() {
            if n_bytes[i - 1] > n_bytes[i] {
                flag = i;
                n_bytes[i - 1] -= 1;
            }
        }
```
